版本日志 ​

V1.6.0（开发版本） ​

  • KiCadTools：概念验证模块，可读取 KiCad 6 的 .kicad_sch 原理图文件并生成网表。此模块可对 KiCad 原理图进行任意处理。目前位于源码中，但可能成为独立项目。 对 PySpice 而言，它提供了一种灵活的方式——在 KiCad 中绘制电路，在不使用 KiCad 网表导出功能的情况下即可生成网表。

V1.5.0（正式版）2021-05-15 ​

  • 支持 Ngspice 最高至 34 版
  • 将自定义双下划线属性 __dunder__ 重命名为 CONSTANT 或 _private 类属性
  • 修复文档中的拼写错误（感谢 endolith 和 brollb）
  • 添加 DC 温度扫描支持 #272（感谢 Fatsie）
  • PWL 支持改进 #271（感谢 Fatsie）
  • 创建温度扫描向量时分配单位 #263（感谢 ARF1）
  • 通过释放 ngspice 命令日志防止内存泄漏 #260（感谢 ARF1）
  • 性能优化：批量发送多个 alter 命令 #259（感谢 ARF1）
  • 添加 spice 库支持 #258（感谢 Fatsie）
  • 允许为 PWL 指定 DC 值 #257（感谢 Fatsie）
  • 支持 .nodeset 类型初始条件 #256（感谢 Fatsie）
  • 修复精度问题 #254（感谢 sotw1957）
  • 改进在大量 SPICE 模型中使用的体验 #249（感谢 xesscorp）
  • 修复网表解析时的参数合并错误 #245（感谢 cyber-g）
  • Unit：添加 Pickle 支持
  • 引入 #136 的解析器代码（感谢 jmgc，尚未合并）
  • Unit：添加 np.mean

V1.4.3 2020-07-04 ​

感谢 @stuarteberg Stuart Berg 的大量工作，Ngspice 和 PySpice 现已可通过 Anaconda（conda-forge）在 Windows、OSX 和 Linux 平台上使用。借助 conda-forge 持续集成平台，我们可以在这些平台上自动运行单元测试和示例。

  • PySpice 现在以 conda-forge 包和 PyPI wheel 的形式发布
  • 添加安装后工具，用于在 Windows 上下载 Ngspice DLL 并检查安装
  • 该工具还可下载示例和 Ngspice PDF 手册
  • Linux 和 OSX 上，Ngspice 包现可从 Anaconda（conda-forge）获取
  • 更新了 Linux 安装文档，主流发行版现已提供 ngspice 共享包
  • 添加前端网站，使旧版本文档可在线访问
  • 修复并重新构建所有示例
  • 示例现以 Python 文件和 Jupyter notebook 两种形式提供
  • 支持 NgSpice 32 API（无变化）
  • 修复若干问题：NonLinearVoltageSource、Unicode 问题（°C）、ffi_string_utf8、OSX 日志格式化等
  • 将 cir2py 转为入口点以支持所有平台
  • 更新示例中 Matplotlib 子图
  • 添加单位示例、NMOS 示例 #221

V1.4.0 2020-05-05 ​

此版本因 Windows 支持存在问题被撤回。

  • 修复 NgSpice 共享的 setlocale(LC_NUMERIC, "C"); 问题 #172

  • 修复多种设备和 API 问题
  • 支持 NgSpice 31 API
  • 添加多项分析与参数支持（pole-zero、noise、distorsion、transfer-function、.measure）
  • 添加 Xyce Mosfet nfin #177
