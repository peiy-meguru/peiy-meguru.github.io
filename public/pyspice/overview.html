概览 ​

什么是 PySpice？ ​

PySpice 是一个开源 Python 模块，为 Ngspice 和 Xyce 电路模拟器提供 Python 接口。

Ngspice 源自著名的 SPICE 电路模拟器，Xyce 则是由 Sandia 国家实验室 开发的 SPICE 兼容模拟器。

PySpice 允许你：

  • 通过网表定义电路
  • 使用 Ngspice 和 Xyce 进行仿真
  • 使用 NumPy 和 Matplotlib 分析仿真结果

许可协议 ​

PySpice 基于 GPLv3 许可协议发布。

演讲与论文 ​

你可以观看在 PyParis 2017 会议上发表的演讲 Circuit Simulation using Python（PDF 文件）。

深入学习 PySpice ​

了解 PySpice 功能的最佳方式是查看示例：

  • 示例
  • API 参考
  • 参考文献

PySpice 如何用于学习？ ​

PySpice 提供了大量涵盖多个主题的示例。

支持的平台 ​

PySpice 可在 Linux、64 位 Windows 和 macOS 上运行。

如何安装？ ​

安装步骤见安装指南。

PySpice 与 LTspice 等模拟器的区别？ ​

  • PySpice、Ngspice 和 Xyce 都是自由软件，开源
  • PySpice 没有原理图编辑器或 GUI，但
  • 它拥有 Python 强大的数据分析能力
  • 提供现代数据分析工具
  • 开放的架构使功能不受限制

（不过你可以从 KiCad 导出网表到 PySpice。）

无 GUI 模拟器的优势？ ​

编写网表并非总是轻松，原理图编辑器有助于电路的可视化。Circuit_macros 和 Tikz 等工具确实需要学习，但学习曲线不会比学乐器更陡。

每个工具都有各自的优缺点，往往互为补充。

主要优势：

  • 用代码完整描述仿真项目，无需鼠标操作 GUI
  • 可用 Git 轻松进行版本管理
  • 在编辑器和终端间快速修改并重新运行仿真，比如注释掉一个二极管看效果。而用 GUI 则需要多次操作
  • 借助 Pyterate 工具，可以用文本、公式和图表丰富仿真内容

能否同时使用两种方式？技术上的答案是肯定的。例如 Modelica 语言使用注释概念来描述原理图。KiCad 等原理图编辑器也可以升级后与 PySpice 紧密集成。

PySpice 相比 Ngspice/Xyce 的优势？ ​

  • 你可以用 Python 控制网表和仿真

    这超越了 SPICE 的参数和表达式，使蒙特卡洛仿真等变得更容易

  • 你可以用 Python 科学计算包分析输出

    这超越了 TclSpice 等工具

PySpice 如何与 Ngspice 交互？ ​

  • PySpice 可以解析 SPICE 网表并生成等效 Python 代码，或直接实例化

  • PySpice 可以生成 SPICE 网表

  • PySpice 可以将仿真发送到 Ngspice，并通过服务器或共享模式读取输出

    默认使用服务器模式。共享模式仅用于需要高级功能的场景

使用共享模式时：

  • PySpice 允许在 Python（甚至 C 语言）中定义外部电压和电流源
  • PySpice 允许在仿真过程中向模拟器发送和接收数据
  • 使用 CFFI 实现 C 到 Python 的接口

PySpice 如何与 Xyce 交互？ ​

目前，PySpice 将 Xyce 作为子进程运行并读取原始输出。

如何定义网表？ ​

  • 使用面向对象 API 定义网表
  • PySpice 也可以处理 SPICE 网表，并从 KiCad 等原理图编辑器导入网表

能否使用解释器命令运行 Ngspice？ ​

通过 Ngspice 共享库绑定，你不必局限于 PySpice 的面向对象 API。你可以像以前一样运行 Ngspice，只需将仿真输出转换为 NumPy 数组。示例请参考 Ngspice 共享模式示例。

如何处理 SPICE 库？ ​

  • PySpice 提供一个库管理器，可扫描路径中的库文件
  • 可以使用 include 指令原样包含库
  • 子电路可以定义为 Python 类

如何处理单位？ ​

  • PySpice 提供一个支持国际单位制的单位模块
  • 可以使用函数快捷方式或特殊语法定义带单位的值，例如 kilo(1.2)、1.2@u_kV、1.2@u_mΩ

要求 Python 版本？ ​

PySpice 需要 Python 3，推荐 3.5 以上版本以使用新的 @ 语法处理单位。

要求 Ngspice 版本？ ​

应使用最新版 Ngspice，并确保按照 Ngspice 手册编译 -- 检查是否有人启用了可能破坏 PySpice 的实验性功能。

注意：Ngspice 不随 PySpice 分发！

要求 Xyce 版本？ ​

应使用 Sandia 提供的最新版本。

支持哪些 SPICE 变体？ ​

目前 PySpice 仅支持 Ngspice 和 Xyce。

但 PySpice 可以轻松支持任何提供类似 Ngspice API 的仿真器。

还需要注意什么？ ​

用户应注意以下免责声明：

  • Ngspice 和 PySpice 不提供任何担保。在实际设计中务必谨慎使用
  • 最好使用工业级仿真器交叉验证仿真结果
  • Ngspice 不符合工业质量保证流程
  • 仿真是设计工具，不是现实世界的完美描述
