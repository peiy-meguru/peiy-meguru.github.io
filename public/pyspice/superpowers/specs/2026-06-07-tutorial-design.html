初升大教程 设计方案 ​

概述 ​

在 PySpice 中文文档站点中新增"初升大教程"模块，面向初中→高中→高校学生，以人教版物理/电子学教材知识点为序，从零开始教学电路仿真。教程降低 Python 门槛，每章先设计理解电路，再用 Python 实现仿真验证，保证所有示例真实可运行。

1. 入口与导航 ​

1.1 首页 Hero 区域 ​

在 docs/index.md 的 hero.actions 中新增第三个按钮：

yaml
actions:
  - theme: brand
    text: 快速开始
    link: /overview
  - theme: brand
    text: 初升大教程
    link: /tutorial/
  - theme: alt
    text: 查看示例
    link: /example-introduction

三个按钮颜色统一为品牌蓝（#3451b2）。窄屏时自动换行。

1.2 顶部导航栏 ​

在 docs/.vitepress/config.js 的 nav 数组最前面插入：

js
{ text: '教程', link: '/tutorial/' },

1.3 侧边栏 ​

侧边栏最前面新增"初升大教程"分组，默认收起（collapsed: true）。展开后显示三级结构：两个前置章 + 三个可折叠的子级分组（初中篇/高中篇/高校篇），每级包含若干章。

初升大教程（收起）
├── 环境配置安装
├── Python 速成入门
├── ▶ 初中篇 (6 章)
├── ▶ 高中篇 (11 章)
└── ▶ 高校篇 (17 章)

5. Python 示例验证规范 ​

5.1 核心原则 ​

所有 Python 代码示例和运行结果必须真实运行，不得手写或猜测。

5.2 验证流程 ​

每章开发遵循以下循环：

1. 编写 .py 仿真脚本
2. 在虚拟环境中运行：python script.py
3. 确认代码无报错，输出正确
4. 将终端输出原封不动保存
5. 编写 .py 电路图绘制脚本（如需要）
6. 运行生成 SVG，保存到 docs/public/tutorial/
7. 编写 .md 章节内容（嵌入代码块、输出、图表引用）
8. npm run docs:dev 本地预览
9. 检查格式、链接、图表渲染

5.3 运行环境要求 ​

.venv 虚拟环境中必须安装：

  • Python ≥ 3.8
  • PySpice ≥ 1.5
  • Ngspice（系统级安装，libngspice.so）

6. Podman 容器方案 ​

6.1 目标 ​

为读者提供零配置的一键运行环境，避免因操作系统差异导致的安装问题。

6.2 交付方式 ​

  • Containerfile 存入 repo：docs/tutorial/Containerfile，git 可版本管理
  • CI 自动构建推送：GitHub Actions 构建镜像并推送到 ghcr.io
  • 教程中提供两种路径：
    • 路径 A（推荐）： podman pull ghcr.io/... && podman run -it ...
    • 路径 B： podman build -f Containerfile && podman run -it ...

6.3 容器内容 ​

  • 基础镜像：python:3.11-slim（或类似轻量镜像）
  • 安装：ngspice、libngspice-dev、pyspice、numpy、matplotlib、schemdraw
  • 工作目录挂载方式：--volume "$PWD":/workspace

10. 约束与注意事项 ​

  1. 教学优先： Python 是学习电路的工具，不作为独立教学目标。Python 新概念随文讲解。
  2. 准确性第一： 所有仿真结果对照手工计算验证。不可靠的内容不写入。
  3. 循序渐进： 每章只引入少量新概念，不给读者造成认知负担。
  4. 可读性： 使用通俗中文、短段落、代码逐行注释。避免术语堆砌。
  5. 不重复造轮： 高校篇后期（二极管/BJT/MOSFET/运放）可适度引用原有示例文档链接作为"进阶阅读"。
  6. 磁场章节特殊处理： 高中第5章"磁场与电磁力"不可直接电路仿真，以定性讲解配合类比说明。
