安装 ​

要使用 PySpice，你需要在计算机上安装 Python 环境以及 Ngspice/Xyce 模拟器。这里仅详细介绍最简单的方法。

Python 的标准做法是使用虚拟环境和 pip 工具，参见此指南。

如果你主要从事数据科学，最简单的方案可能是安装专为此设计的 Anaconda。你也可以选择其轻量级替代品 Miniconda。

Anaconda 的优势在于为用户提供一体化的环境，例如安装 PySpice 时会自动安装 Ngspice。但正因此，尤其是 Linux 上，Anaconda 会比虚拟环境占用更多磁盘空间。

TIP

我们建议按此顺序阅读文档：先 Windows（了解入门流程），再 Linux（了解 Unix 系统流程），最后 macOS（如有需要）。

PySpice 包 ​

PySpice 提供 Anaconda 和 PyPI 包。Anaconda 有两个频道，官方频道是 conda-forge，fabricesalvaire 频道仅用于测试。

conda-forge 上的 Ngspice ​

INFO

如果使用 conda-forge 包，无需手动安装 Ngspice——它已作为依赖包 ngspice-lib 提供。

如果还需要 Ngspice 可执行文件，运行：

sh
conda install -c conda-forge ngspice-exe  # 安装 ngspice 可执行文件
conda install -c conda-forge ngspice      # 安装主包
conda install -c conda-forge ngspice-lib  # 安装 ngspice 库

PySpice 持续集成 ​

PySpice 在以下平台进行测试：

  • Travis CI：
    • Bionic Ubuntu Linux（手动编译 Ngspice）
    • macOS 10.14.4 Mojave（使用 Brew）
    • Windows 10.0.17134（使用 Chocolatey）
  • Azure CI
  • Fedora

Windows 安装 ​

推荐在 Windows 上安装 Anaconda 或 Miniconda 作为 Python 环境。

安装后打开 Anaconda Navigator，启动根环境的终端。

只需一条命令即可在 Anaconda 上安装 PySpice：

sh
conda install -c conda-forge pyspice

如使用 conda-forge 包，则无需以下步骤。

pip 替代方案：pip install PySpice

在 Windows 上安装 Ngspice 的最简单方式是使用 PySpice 工具自动下载和安装 Windows 64 位 DLL 库：

sh
pyspice-post-installation --install-ngspice-dll

然后检查安装：

sh
pyspice-post-installation --check-install

Linux 安装 ​

可以自由使用 Linux 发行版提供的包。

安装 Ngspice ​

如果不使用 Anaconda，Ngspice 及其共享库在许多发行版中可用：

  • Fedora: libngspice
  • Ubuntu: libngspice0
  • Debian: libngspice0

WARNING

建议检查 Ngspice 的编译方式，特别是维护者是否启用了实验性功能！

RPM 发行版（Fedora、RHEL、CentOS）可使用此 Copr 仓库：

sh
dnf copr enable fabricesalvaire/ngspice
dnf install libngspice

如果无法轻松安装 Ngspice 共享库但能安装 Ngspice 程序，可以使用"子进程"模式代替"共享"模式。此时需全局设置默认模拟器：

python
PySpice.Spice.Simulation.CircuitSimulator.DEFAULT_SIMULATOR = 'ngspice-subprocess'

安装 Python 环境 ​

Linux 上有几种安装 Python 环境的方式：

  1. 新手方案：安装 Anaconda 或 Miniconda
  2. 使用发行版的 Python 包
  3. 熟练用户：自行管理虚拟环境

然后使用 conda 或 pip 安装 PySpice：

sh
conda install -c conda-forge pyspice

# 或

pip install PySpice

# 然后检查

pyspice-post-installation --check-install

macOS 安装 ​

macOS 上获取 Python 有多种途径：

  • 使用内置 Python（注意版本）
  • 安装 Miniconda
  • 安装完整 Anaconda
  • 通过 Brew 安装：brew install python3

安装 PySpice 请参考 Linux 说明。

Ngspice 共享库也可通过 Brew 获取：

sh
brew install libngspice

获取示例 ​

简答：

sh
pyspice-post-installation --download-example

详细说明：示例不会通过 pip 或 setup.py 安装。安装过程只在 Python 环境中安装 PySpice 模块。你需要下载 PySpice 压缩包或克隆 Git 仓库才能获取示例。见"从源码安装"。

通过 pip 从 GitHub 安装最新版本 ​

如需安装尚未在 PyPI 发布的版本：

sh
pip install git+https://github.com/FabriceSalvaire/PySpice

pip install git+https://github.com/FabriceSalvaire/PySpice@devel

从源码安装 ​

PySpice 源码托管在 GitHub。

有两种方式获取源码：克隆仓库；或从 GitHub 页面下载压缩包。

克隆 Git 仓库：

sh
git clone https://github.com/FabriceSalvaire/PySpice.git

构建和安装：

sh
python setup.py build
python setup.py install

开发环境设置 ​

Windows 上设置 PYTHONPATH：

  • PowerShell: $env:PYTHONPATH='list;of;paths'
  • 命令提示符: set PYTHONPATH=list;of;paths

修复 Windows CP1252/Unicode 错误：

sh
$env:PYTHONIOENCODING="utf_8"

Windows 上设置 PySpice 日志级别：

sh
$env:PySpiceLogLevel="debug"

依赖 ​

PySpice 依赖列表见：

  • requirements.txt
  • requirements-dev.txt（仅开发）

如何生成文档 ​

生成文档需要以下 Python 模块（见 requirements-dev.txt）：

  • invoke
  • Sphinx
  • Pyterate

以及以下依赖（安装较困难）用于生成图形：

  • ImageMagick（转换 SVG 为 PNG）
  • circuit_macros 和 LaTeX 环境
  • mutool（转换 circuit_macros PDF 为 PNG）

基本流程：

sh
inv doc.make-examples
inv doc.make-api

编译 Ngspice ​

通常 Ngspice 在主流 Linux 发行版中均以包形式提供。但建议在用于正式项目前检查编译选项。

WARNING

编译选项 --enable-ndev 已知会破坏服务器模式。

推荐 Linux 编译方式：

sh
mkdir ngspice-32-build
pushd ngspice-32-build

/.../ngspice-32/configure \
  --prefix=/usr/local \
  --enable-xspice \
  --disable-debug \
  --enable-cider \
  --with-readline=yes \
  --enable-openmp \
  --with-ngshared

 make
 make install

如何获取 Xyce？ ​

虽然 Xyce 基于 GPLv3 许可协议发布，但 Sandia 要求你在注册页面创建账户后才能下载源码或可执行文件（需要提供邮箱）。

构建过程见构建指南。
