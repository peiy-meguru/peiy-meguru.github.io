如何引用 PySpice？ ​

截至目前，PySpice 官方网址为 https://pyspice.fabrice-salvaire.fr

如果将来域名变更，将设置永久重定向。

在 GitHub 上，可使用 pyspice 主题标签标记与 PySpice 相关的仓库。

典型 BibTeX 引用格式：

bibtex
@software{PySpice,
  author = {Fabrice Salvaire},
  title = {PySpice},
  url = {https://pyspice.fabrice-salvaire.fr},
  version = {x.y},
  date = {yyyy-mm-dd},
}

@Misc{PySpice,
  author = {Fabrice Salvaire},
  title = {PySpice},
  howpublished = {\url{https://pyspice.fabrice-salvaire.fr}},
  year = {yyyy}
}
