第3章 戴维南与诺顿定理 ​

1. 本节你将学到 ​

  • 掌握戴维南定理：任何线性有源二端网络，对外部负载而言，可等效为一个理想电压源 VthV_{th}Vth​ 串联一个等效电阻 RthR_{th}Rth​
  • 掌握诺顿定理：任何线性有源二端网络，对外部负载而言，可等效为一个理想电流源 InI_nIn​ 并联一个等效电阻 RthR_{th}Rth​
  • 理解 VthV_{th}Vth​、InI_nIn​、RthR_{th}Rth​ 三者关系：In=Vth/RthI_n = V_{th} / R_{th}In​=Vth​/Rth​，Rth=Voc/IscR_{th} = V_{oc} / I_{sc}Rth​=Voc​/Isc​
  • 学会用 PySpice 构建原电路和等效电路，通过负载扫描验证两者的对外特性完全一致

2. 知识回顾/情景引入 ​

前两章我们学习了基尔霍夫定律和叠加定理——前者给出了分析任意电路的普适方程，后者提供了将复杂电路"分解"为简单部分的思路。但到目前为止，我们每次分析一个电路，都需要考虑其内部所有元件。

试想这样一个场景：你的手机充电器是一个复杂的电路——里面可能有变压器、整流桥、滤波电容、稳压芯片……但你并不需要知道充电器内部到底怎么工作。对你来说，充电器就是一个黑盒子，它有两个输出端子，你只需要知道"插上手机后，它输出 5V 电压，最大能提供 2A 电流"。

这个黑盒子的对外特性——无论内部多么复杂，从外部看，它等效于一个电压源加一个内阻——这就是戴维南定理告诉我们的核心事实。

2.1 为什么需要等效电路 ​

在实际工程中，等效电路思维无处不在：

  • 电源建模：任何实际电源（电池、直流稳压源、信号发生器）都可以等效为戴维南形式（理想电压源 + 内阻）或诺顿形式（理想电流源 + 内阻）
  • 负载匹配：给定一个有内阻的信号源，接多大的负载电阻才能获得最大功率？答案是 RL=RthR_L = R_{th}RL​=Rth​——这需要知道源的戴维南等效电阻
  • 多级放大器级联：第一级的输出可以等效为一个戴维南源，驱动第二级的输入——这样每一级都可以独立分析

2.2 戴维南定理的直观理解 ​

考虑一个由 12 V 电池、4 kΩ 串联电阻（R1）和 6 kΩ 对地电阻（R2）组成的分压网络。从 R2 两端（中间节点和地之间）看进去：

  • 开路电压 VocV_{oc}Voc​：去掉负载后，中间节点的电压是多少？由于 R1 和 R2 组成分压器，Voc=12×6/(4+6)=7.2 VV_{oc} = 12 \times 6/(4+6) = 7.2\text{ V}Voc​=12×6/(4+6)=7.2 V。这就是戴维南电压 VthV_{th}Vth​。

  • 等效电阻 RthR_{th}Rth​：将 12 V 电池短路（变成导线），从输出端看进去的电阻是多少？R1 和 R2 并联——Rth=4∥6=2.4 kΩR_{th} = 4 \parallel 6 = 2.4\text{ kΩ}Rth​=4∥6=2.4 kΩ。

因此，这个简单的分压网络，对任何外接负载而言，其行为与一个 7.2 V 的理想电压源串联一个 2.4 kΩ 的电阻完全相同。

2.3 诺顿定理：戴维南的"镜像" ​

诺顿定理是戴维南定理的电流源版本。任何线性有源二端网络等效为一个理想电流源 InI_nIn​ 并联一个等效电阻 RthR_{th}Rth​。其中：

In=VthRth=IscI_n = \frac{V_{th}}{R_{th}} = I_{sc} In​=Rth​Vth​​=Isc​

IscI_{sc}Isc​ 是输出端短接时的短路电流。戴维南和诺顿等效电路可以互相转换。

4. 用 Python 实现电路仿真 ​

4.1 原电路、戴维南等效、诺顿等效对比 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import numpy as np

print("Thevenin/Norton Theorem Verification")
print()

R1, R2, RL = 4, 6, 3
Vthevenin = 12 * R2 / (R1 + R2)
Rthevenin = R1 * R2 / (R1 + R2)
I_norton = Vthevenin / Rthevenin

print(f"Theoretical calculation:")
print(f"  R1 = {R1} kΩ, R2 = {R2} kΩ (parallel), RL = {RL} kΩ")
print(f"  Vth (open circuit voltage) = 12 * R2/(R1+R2) = 12*{R2}/{R1+R2} = {Vthevenin:.2f} V")
print(f"  Rth (equivalent resistance) = R1||R2 = {R1}*{R2}/{R1+R2} = {Rthevenin:.2f} kΩ")
print(f"  In (Norton current) = Vth/Rth = {Vthevenin:.2f}/{Rthevenin:.2f} = {I_norton:.2f} mA")
print()

print("Original circuit simulation (RL at middle node 2):")
circuit = Circuit('Thevenin Original')
circuit.V('v1', 1, circuit.gnd, 12@u_V)
circuit.R('R1', 1, 2, R1@u_kΩ)
circuit.R('R2', 2, circuit.gnd, R2@u_kΩ)
circuit.R('load', 2, circuit.gnd, RL@u_kΩ)
sim = circuit.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
analysis = sim.operating_point()
v_load = float(np.array(analysis['2']).flat[0])
i_load = v_load / RL * 1000
print(f"  Load voltage V_L = {v_load:.3f} V")
print(f"  Load current I_L = {i_load:.3f} mA")
v_load_theory = Vthevenin * RL / (Rthevenin + RL)
print(f"  Thevenin calculation: V_L = Vth*RL/(Rth+RL) = {Vthevenin}*{RL}/({Rthevenin}+{RL}) = {v_load_theory:.3f} V")
print()

print("Thevenin equivalent circuit verification:")
circuit_thev = Circuit('Thevenin Equivalent')
circuit_thev.V('vth', 1, circuit_thev.gnd, Vthevenin@u_V)
circuit_thev.R('rth', 1, 2, Rthevenin@u_kΩ)
circuit_thev.R('load', 2, circuit_thev.gnd, RL@u_kΩ)
sim_thev = circuit_thev.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_thev = sim_thev.operating_point()
v_load_thev = float(np.array(an_thev['2']).flat[0])
print(f"  Thevenin equivalent load voltage = {v_load_thev:.3f} V")
print(f"  Original circuit load voltage = {v_load:.3f} V")
print(f"  Match: {'PASS' if abs(v_load - v_load_thev) < 1e-6 else 'FAIL'}")

print()
print("Norton equivalent circuit verification:")
circuit_nort = Circuit('Norton Equivalent')
circuit_nort.I('in', 1, circuit_nort.gnd, I_norton@u_mA)
circuit_nort.R('rth', 1, circuit_nort.gnd, Rthevenin@u_kΩ)
circuit_nort.R('load', 1, circuit_nort.gnd, RL@u_kΩ)
sim_nort = circuit_nort.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_nort = sim_nort.operating_point()
v_load_nort = float(np.array(an_nort['1']).flat[0])
print(f"  Norton equivalent load voltage = {(-v_load_nort):.3f} V")
print(f"  Match: {'PASS' if abs(abs(v_load) - abs(v_load_nort)) < 1e-6 else 'CHECK'}")

print()
print("Load sweep — verify Thevenin for various RL values:")
print(f"  {'RL (kΩ)':>10} {'V_load (V)':>12} {'V_th_eq (V)':>13} {'Match':>8}")
print("-" * 46)
for rl_val in [1, 2, 3, 5, 10, 20]:
    c = Circuit('RL sweep')
    c.V('v1', 1, c.gnd, 12@u_V)
    c.R('R1', 1, 2, R1@u_kΩ)
    c.R('R2', 2, c.gnd, R2@u_kΩ)
    c.R('load', 2, c.gnd, rl_val@u_kΩ)
    s = c.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
    a = s.operating_point()
    vl = float(np.array(a['2']).flat[0])
    vl_th = Vthevenin * rl_val / (Rthevenin + rl_val)
    match = "PASS" if abs(vl - vl_th) < 1e-6 else "FAIL"
    print(f"  {rl_val:>10} {vl:>12.3f} {vl_th:>13.3f} {match:>8}")

5. 深入理解 ​

5.1 最大功率传输定理 ​

戴维南定理引出了一个重要的工程结论：最大功率传输定理。

给定一个戴维南等效电路（VthV_{th}Vth​，RthR_{th}Rth​），接上负载 RLR_LRL​，负载获得的功率为：

PL=(VthRth+RL)2⋅RLP_L = \left(\frac{V_{th}}{R_{th} + R_L}\right)^2 \cdot R_L PL​=(Rth​+RL​Vth​​)2⋅RL​

对 RLR_LRL​ 求导并令导数为零，可得当 RL=RthR_L = R_{th}RL​=Rth​ 时，负载获得最大功率：

PL,max=Vth24RthP_{L,max} = \frac{V_{th}^2}{4R_{th}} PL,max​=4Rth​Vth2​​

此时效率为 50%（一半功率消耗在内阻上，一半传输到负载）。这就是为什么音频功放的输出阻抗要匹配喇叭阻抗（通常都设计为 4Ω 或 8Ω）——不是为了最高效率，而是为了最大功率传输。

5.2 求等效电阻的三种方法 ​

  1. 直接法（独立源置零法）：将所有独立电压源短路、电流源开路，从端口看进去计算等效电阻。适用于纯电阻网络。

  2. 开路-短路法：先测开路电压 VocV_{oc}Voc​，再测短路电流 IscI_{sc}Isc​，Rth=Voc/IscR_{th} = V_{oc} / I_{sc}Rth​=Voc​/Isc​。适用于含受控源或无法直接求电阻的网络。

  3. 外加激励法：在端口加一个测试电压源 VtestV_{test}Vtest​（或电流源 ItestI_{test}Itest​），计算端口电流（或电压），Rth=Vtest/ItestR_{th} = V_{test} / I_{test}Rth​=Vtest​/Itest​。此方法最通用，SPICE 内部也是通过这种方式（.TF 分析）计算等效输出电阻。

5.3 戴维南定理的局限性 ​

  • 仅适用于线性电路：包含二极管、晶体管等非线性元件的电路不能用戴维南等效来精确替代（但在工作点附近的小信号等效中是可行的）
  • 仅对外部等效：戴维南/诺顿等效电路只能替代对外部负载的表现，不能替代内部的功耗、发热等细节。例如原电路 R1 和 R2 消耗的功率在等效电路中是通过一个 Rth 消耗的——但原电路可能有两个电阻分别发热，而等效电路只有一个。

5.4 与 PySpice 的 .TF 分析 ​

Ngspice 提供了 .TF (Transfer Function) 分析，可以直接计算电路的戴维南等效参数。例如：

python
analysis = simulator.transfer_function(output_node='2', input_source='v1')
# 返回：输出电压/输入电压 和 输出阻抗

这是一个方便的内置功能。不过本章我们使用".op + 手算"的方法来演示，目的是加深对原理的理解。

6. 本章小结 ​

  • 戴维南定理：任何线性有源二端网络 = VthV_{th}Vth​ 串联 RthR_{th}Rth​
  • 诺顿定理：任何线性有源二端网络 = InI_nIn​ 并联 RthR_{th}Rth​，In=Vth/RthI_n = V_{th} / R_{th}In​=Vth​/Rth​
  • Vth 求法：开路电压（去掉负载，测量端口电压）
  • Rth 求法：独立源置零后从端口看入的等效电阻；或 Voc/IscV_{oc} / I_{sc}Voc​/Isc​
  • 等效验证：对原电路和等效电路做负载扫描，所有负载值下输出电压必须一致
  • PySpice 中通过 operating_point() 的分析结果构建等效电路并通过循环验证

"任何线性电路，对外都可以等效为一个电压源加一个电阻"——这是电路理论中最优美、最实用的结论之一。从移动电源建模到射频天线匹配，从音频功放到传感器接口，戴维南思想无处不在。

7. 练习 ​

  1. 开路-短路法实践：在仿真中构建一个含三个电阻和一个电压源的电路。先去掉所有负载测出 VocV_{oc}Voc​，再将输出短路（接一个 0 V 的电压源）测出 IscI_{sc}Isc​。验证 Rth=Voc/IscR_{th} = V_{oc} / I_{sc}Rth​=Voc​/Isc​。

  2. 含受控源的戴维南等效：设计一个含 VCVS（电压控制电压源）的简单电路。用开路-短路法求其戴维南等效电路。外部激励法在其中起什么作用？

  3. 最大功率验证：对本章电路做负载电阻扫描（从 0.1 kΩ 到 100 kΩ），绘制 PLP_LPL​ vs RLR_LRL​ 曲线，找到最大功率点，验证 RL,opt=RthR_{L,opt} = R_{th}RL,opt​=Rth​。

  4. 诺顿到戴维南的变换：将诺顿等效电路中的 In=5 mAI_n = 5\text{ mA}In​=5 mA 和 Rth=2 kΩR_{th} = 2\text{ kΩ}Rth​=2 kΩ 变换为戴维南等效。用仿真验证两者对 1 kΩ 负载的输出电压和电流完全一致。
