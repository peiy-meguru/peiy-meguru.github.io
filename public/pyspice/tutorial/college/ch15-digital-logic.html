第15章 数字逻辑基础 ​

1. 本节你将学到 ​

  • 理解数字信号与模拟信号的区别：离散电平（高/低） vs 连续变化
  • 掌握基本逻辑门的真值表：NOT、AND、OR、NAND、NOR、XOR
  • 理解逻辑电平标准：VOHV_{OH}VOH​、VOLV_{OL}VOL​、VIHV_{IH}VIH​、VILV_{IL}VIL​ 及噪声容限
  • 认识电压传输特性（VTC）：从输入电压到输出电压的映射曲线
  • 了解通用门的概念：仅用 NAND（或 NOR）可构成任何逻辑函数
  • 学会用 PySpice 的 B 元件（行为源）实现逻辑门仿真

2. 知识回顾/情景引入 ​

前 14 章我们一直处理模拟电路——电压和电流可以在一定范围内连续取值，一个正弦波有无穷多个电压值。然而，现代计算和通信的核心是数字电路——信号被限制在两个离散电平（逻辑 0 和逻辑 1）。

为什么数字电路统治了现代电子技术？一个关键原因是噪声容限。

假设你有一段 5 V 的模拟信号，在传输过程中被 0.5 V 的噪声污染。在接收端，你无法区分原本是 4.5 V 还是 5.0 V——信息已经丢失。但如果这是数字信号，5 V 代表逻辑 1，0 V 代表逻辑 0，接收端只需判断电压是否超过 2.5 V——0.5 V 的噪声不足以翻转逻辑状态。

这就是数字电路的革命性优势：用电压范围换取逻辑确定性。只要噪声幅度不超过预定的界限，信息就完美无损。

在晶体管层面，数字逻辑由 CMOS 反相器实现——一个 PMOS 和一个 NMOS 互补工作，实现了接近零静态功耗的理想开关特性。但在设计初期，我们可以用行为模型（Behavioral Source）来描述逻辑门的功能，而不必深入晶体管的物理细节。

2.1 基本逻辑门 ​

NAND 和 NOR 是通用门——任何布尔函数都可以仅用 NAND 门（或仅用 NOR 门）实现。例如：

  • NOT 用 NAND：Y=A‾=A⋅A‾Y = \overline{A} = \overline{A \cdot A}Y=A=A⋅A
  • AND 用 NAND：Y=A⋅B=A⋅B‾‾Y = A \cdot B = \overline{\overline{A \cdot B}}Y=A⋅B=A⋅B
  • OR 用 NAND：Y=A+B=A‾⋅B‾‾Y = A + B = \overline{\overline{A} \cdot \overline{B}}Y=A+B=A⋅B

这个性质使得数字 IC 可以只生产一种基本门单元，极大简化了制造工艺。

2.3 电压传输特性（VTC） ​

VTC 曲线刻画了一个逻辑门的输入电压与输出电压之间的关系。对于理想反相器（NOT 门），VTC 在切换阈值处垂直翻转：输入 < VMV_MVM​ 时输出为高，输入 > VMV_MVM​ 时输出为低。VMV_MVM​ 称为开关阈值——通常位于 VDD/2V_{DD}/2VDD​/2。

实际 CMOS 反相器的 VTC 是连续过渡而非理想阶跃，过渡区的斜率决定了增益——增益越高，过渡越陡峭，"数字性"越强。

4. 用 Python 实现电路仿真 ​

4.1 NOT 门与 VTC ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

print("=== Chapter 15: Digital Logic Circuits ===")
print()

# Part 1: NOT Gate using Behavioral Source
circuit_not = Circuit('NOT Gate')
circuit_not.V('v1', 'n1', circuit_not.gnd, 5@u_V)
circuit_not.R('r1', 'n1', circuit_not.gnd, 1@u_kΩ)
circuit_not.B('b_not', 'out', circuit_not.gnd, v='V(n1) < 2.5 ? 5.0 : 0.0')

sim_not = circuit_not.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_not = sim_not.dc(Vv1=slice(0, 5, 0.1))

vin_not = np.array(an_not['n1'])
vout_not = np.array(an_not['out'])

print("NOT Gate Truth Table:")
print("  In   |  Out (ideal) | Out (simulated)")
print("  -----+--------------+----------------")
for v_test in [0.0, 5.0]:
    idx = np.argmin(np.abs(vin_not - v_test))
    vout = float(vout_not[idx])
    logic_out = 1 if vout > 2.5 else 0
    print(f"  {int(v_test)}V   |    {int(not bool(v_test))}V         | {vout:.2f}V (logic {logic_out})")

代码解释：

  • B('b_not', 'out', gnd, v='V(n1) < 2.5 ? 5.0 : 0.0')：行为源 B1，实现 NOT 逻辑。当节点 n1 的电压低于 2.5 V 时，输出 5.0 V；否则输出 0.0 V。语法为 C 风格的三元运算符 condition ? true_val : false_val。
  • .dc(Vv1=slice(0, 5, 0.1))：对电压源 V1 进行直流扫描，从 0 V 到 5 V，步长 0.1 V。这用于绘制 VTC。
  • 逻辑电平阈值为 2.5 V（VDD/2V_{DD}/2VDD​/2）——这是 CMOS 反相器的典型切换阈值。

4.2 AND、OR、NAND 真值表验证 ​

python
print("--- AND Gate ---")
print("AND Gate Truth Table:")
for va_val in [0, 5]:
    for vb_val in [0, 5]:
        c_and = Circuit('AND_' + str(va_val) + '_' + str(vb_val))
        c_and.V('v_a', 'a', c_and.gnd, va_val@u_V)
        c_and.V('v_b', 'b', c_and.gnd, vb_val@u_V)
        c_and.B('b_and', 'out_and', c_and.gnd,
                v='V(a) > 2.5 && V(b) > 2.5 ? 5.0 : 0.0')
        s_and = c_and.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
        an_and = s_and.operating_point()
        vout_and = float(np.array(an_and['out_and']).item())
        expected = 5.0 if va_val > 2.5 and vb_val > 2.5 else 0.0
        logic = 1 if vout_and > 2.5 else 0
        print(f"  {va_val}V  {vb_val}V |     {expected:.0f}V          | {vout_and:.2f}V (logic {logic})")

AND、OR、NAND 以类似方式仿真，区别仅在于 B 元件的条件表达式。OR 使用 ||（逻辑或），NAND 使用 &&（逻辑与）并将结果取反。

5. 深入理解 ​

5.1 B 元件 vs 晶体管级仿真 ​

本节的 B 元件（行为源）以功能性方式描述逻辑门——它直接表达输入输出之间的布尔关系，而不关心底层的物理实现。这在系统级验证中非常高效。

实际的 CMOS 逻辑门由互补 MOS 管对构成。以反相器为例：

  • PMOS 管在上（连接 VDDV_{DD}VDD​ 到输出），NMOS 管在下（连接输出到 GND）
  • 输入为低电平 → PMOS 导通，NMOS 截止 → 输出被拉高到 VDDV_{DD}VDD​
  • 输入为高电平 → PMOS 截止，NMOS 导通 → 输出被拉低到 GND
  • 两种情况下，都只有一个管子导通——零静态功耗！

如果在 PySpice 中要仿真晶体管级逻辑门，需要使用第 12 章的 MOSFET 模型。

5.2 噪声容限的量化 ​

VTC 曲线上，VOHV_{OH}VOH​、VOLV_{OL}VOL​、VIHV_{IH}VIH​、VILV_{IL}VIL​ 由斜率为 -1（单位增益点）的两个位置定义：

  • VILV_{IL}VIL​：VTC 上斜率 = -1 的低电平侧输入电压
  • VIHV_{IH}VIH​：VTC 上斜率 = -1 的高电平侧输入电压

噪声容限 NML=VIL−VOLNM_L = V_{IL} - V_{OL}NML​=VIL​−VOL​，NMH=VOH−VIHNM_H = V_{OH} - V_{IH}NMH​=VOH​−VIH​。

对于理想行为模型（阈值切换），VTC 在 2.5 V 处是无限陡峭的阶跃——VIL=VIH=2.5V_{IL} = V_{IH} = 2.5VIL​=VIH​=2.5 V，噪声容限为 2.52.52.5 V（VDD/2V_{DD}/2VDD​/2）。这是在 BSIM 级别的晶体管模型中无法达到的理想极限。

5.3 组合逻辑与时序逻辑 ​

本章的逻辑门属于组合逻辑——输出仅取决于当前输入，没有"记忆"。加入时钟和存储元件（锁存器、触发器）后，实现时序逻辑——输出依赖输入的历史（状态）。

在 SPICE 中，时序逻辑通常由晶体管级的传输门和反馈网络实现，或者用更高级的硬件描述语言（Verilog/VHDL）描述。PySpice 的 B 源虽然可以表达简单状态，但复杂的时序行为更适合在逻辑仿真器（如 Verilator）中处理。

5.4 布尔代数基础 ​

逻辑门是布尔代数的物理实现。布尔代数有三大基本定律：

  • 交换律：A+B=B+AA + B = B + AA+B=B+A，A⋅B=B⋅AA \cdot B = B \cdot AA⋅B=B⋅A
  • 结合律：A+(B+C)=(A+B)+CA + (B + C) = (A + B) + CA+(B+C)=(A+B)+C，A⋅(B⋅C)=(A⋅B)⋅CA \cdot (B \cdot C) = (A \cdot B) \cdot CA⋅(B⋅C)=(A⋅B)⋅C
  • 德·摩根定律：A⋅B‾=A‾+B‾\overline{A \cdot B} = \overline{A} + \overline{B}A⋅B=A+B，A+B‾=A‾⋅B‾\overline{A + B} = \overline{A} \cdot \overline{B}A+B​=A⋅B

德·摩根定律特别重要——它允许我们将 AND 门转换为 NOR 门（或 OR 门转换为 NAND 门），这是数字电路优化的核心工具。

6. 本章小结 ​

  • 基本逻辑门：NOT、AND、OR、NAND、NOR、XOR ——前两者分别对应取反、逻辑乘、逻辑加
  • NAND 和 NOR 是通用门——仅用 NAND 即可构建任何布尔函数（包括 AND、OR、NOT）
  • 逻辑电平：VOHV_{OH}VOH​（输出高最小）、VOLV_{OL}VOL​（输出低最大）、VIHV_{IH}VIH​（输入高最小）、VILV_{IL}VIL​（输入低最大）
  • 噪声容限 NM=min⁡(VOH−VIH,VIL−VOL)\text{NM} = \min(V_{OH} - V_{IH}, V_{IL} - V_{OL})NM=min(VOH​−VIH​,VIL​−VOL​) 决定了数字电路的抗干扰能力
  • VTC（电压传输特性）决定逻辑门的阈值和斜率——越陡峭越好
  • PySpice 的 B 源（v='V(a) > 2.5 && V(b) > 2.5 ? 5.0 : 0.0'）可用于行为级逻辑仿真
  • 数字电路的核心优势：用电压范围换取信息确定性，只要噪声在容限内，逻辑状态可靠不变

7. 练习 ​

  1. 通用门实现：仅使用 B 源构建的 NAND 门，组合实现 XOR 门。画出电路拓扑，列出真值表，用 PySpice 仿真验证。提示：A⊕B=A‾⋅B+A⋅B‾A \oplus B = \overline{A}\cdot B + A \cdot \overline{B}A⊕B=A⋅B+A⋅B。

  2. 三输入多数表决器：设计一个三输入逻辑电路，当三个输入中至少有两个为 1 时输出 1。写出布尔表达式，用 B 源仿真验证全部 23=82^3 = 823=8 种输入组合。

  3. 噪声容限测试：在 NOT 门的输入端叠加不同幅值的正弦噪声（Vin=2.5 V+Vnoise⋅sin⁡(2π⋅1000t)V_{in} = 2.5 \text{ V} + V_{noise} \cdot \sin(2\pi \cdot 1000t)Vin​=2.5 V+Vnoise​⋅sin(2π⋅1000t)），找出导致输出翻转的临界噪声幅值。这与噪声容限定义的关系如何？

  4. 逻辑电平转换：设计一个电路，将 3.3 V CMOS 逻辑电平（VOH≈3.3V_{OH} \approx 3.3VOH​≈3.3 V，VOL≈0V_{OL} \approx 0VOL​≈0 V）转换为 5 V TTL 逻辑电平。用 B 源的行为条件表达式实现。
