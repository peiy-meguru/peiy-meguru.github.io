第13章 运算放大器 (Op-Amp) ​

1. 本节你将学到 ​

  • 理解理想运放的两条"黄金法则"：虚短（V+≈V−V_+ \approx V_-V+​≈V−​）和虚断（I+=I−=0I_+ = I_- = 0I+​=I−​=0）
  • 掌握三种基本运放电路：反相放大器、同相放大器、电压跟随器
  • 理解闭环增益由反馈电阻比决定：Av=−R2/R1A_v = -R_2/R_1Av​=−R2​/R1​（反相）或 Av=1+R2/R1A_v = 1 + R_2/R_1Av​=1+R2​/R1​（同相）
  • 认识差分放大器：放大两个输入信号的差值，抑制共模信号（CMRR）
  • 学会用 PySpice 的 VCVS（电压控制电压源）建立理想运放模型

2. 知识回顾/情景引入 ​

前两章我们学习了单个晶体管（BJT 和 MOSFET）的放大电路——需要精心设计偏置网络，工作点对温度敏感，增益有限且不稳定。

但在实际电路设计中，工程师几乎从不使用"裸"单管放大器。取而代之的是运算放大器（Operational Amplifier, Op-Amp）——一种包含数十个晶体管的高增益差分放大器，封装成一个通用 IC（如经典的 LM741、TL081）。

运放的出现将模拟电路设计从"晶体管级"抽象到了"系统级"。设计者只需选择几个电阻，就能获得精确、稳定、可预测的增益——而不必关心内部的偏置、温度漂移或非线性的细节。

2.1 理想运放模型 ​

理想运放有五个基本属性：

属性理想值实际值（如 TL081）
开环增益 AolA_{ol}Aol​∞\infty∞10510^5105（100 dB）
输入阻抗 RinR_{in}Rin​∞\infty∞1012 Ω10^{12}\,\Omega1012Ω
输出阻抗 RoutR_{out}Rout​000∼75 Ω\sim 75\,\Omega∼75Ω
带宽∞\infty∞几 MHz（GBW）
共模抑制比 CMRR∞\infty∞80∼12080\sim12080∼120 dB

有了"无穷大开环增益 + 负反馈"，运放的反相输入端会精确跟踪同相输入端的电压——虚短（virtual short）机制。

2.2 负反馈的神奇 ​

考虑一个反相放大器：输入信号 VinV_{in}Vin​ 经 R1R_1R1​ 到反相输入端（-），输出经 R2R_2R2​ 反馈到反相输入端。同相输入端（+）接地。

若 Vin>0V_{in} > 0Vin​>0，反相输入端电压暂时升高 → 运放的高开环增益使输出剧烈下降（负电压）→ R2R_2R2​ 将负电压反馈回反相输入端，将其拉回接近 0 V。最终达到平衡：V−≈V+=0V_- \approx V_+ = 0V−​≈V+​=0（虚地）。

此时通过 R1R_1R1​ 的电流 I=Vin/R1I = V_{in}/R_1I=Vin​/R1​，该电流全部流过 R2R_2R2​（因为理想运放不吸收输入电流），所以 Vout=−I×R2=−Vin×(R2/R1)V_{out} = -I \times R_2 = -V_{in} \times (R_2/R_1)Vout​=−I×R2​=−Vin​×(R2​/R1​)。

增益完全由电阻比决定——运放的内部参数（Aol,Rin,RoutA_{ol}, R_{in}, R_{out}Aol​,Rin​,Rout​）只影响精度，不影响增益的主值。

3. 动手设计电路 ​

3.1 本节电路 ​

四种经典运放电路：

  • 反相放大器：R1=1R_1=1R1​=1 kΩ, R2=10R_2=10R2​=10 kΩ，Av=−10A_v = -10Av​=−10
  • 同相放大器：R1=1R_1=1R1​=1 kΩ, R2=9R_2=9R2​=9 kΩ，Av=1+9/1=10A_v = 1 + 9/1 = 10Av​=1+9/1=10
  • 电压跟随器：输出直连反相输入端，Av=1A_v = 1Av​=1
  • 差分放大器：R1=R3=1R_1=R_3=1R1​=R3​=1 kΩ, R2=R4=10R_2=R_4=10R2​=R4​=10 kΩ，差模增益 Adm=−10A_{dm} = -10Adm​=−10，共模增益 Acm≈0A_{cm} \approx 0Acm​≈0

运放使用 VCVS（Voltage-Controlled Voltage Source）建模：开环增益 Aol=105A_{ol}=10^5Aol​=105。

Vout=R2R1(V2−V1)=10(V2−V1)V_{out} = \frac{R_2}{R_1}(V_2 - V_1) = 10(V_2 - V_1) Vout​=R1​R2​​(V2​−V1​)=10(V2​−V1​)

5. 深入理解 ​

5.1 虚短与虚地的区别 ​

  • 虚短（virtual short）：V+≈V−V_+ \approx V_-V+​≈V−​——因为 AolA_{ol}Aol​ 极大，只要有微小的差分电压（如 0.1 mV），输出就会摆动到电源轨，直到反馈将差分电压消除。V+≈V−V_+ \approx V_-V+​≈V−​ 的精度取决于 AolA_{ol}Aol​：V+−V−=Vout/AolV_+ - V_- = V_{out}/A_{ol}V+​−V−​=Vout​/Aol​。

  • 虚地（virtual ground）：反相放大器的一个特殊情况——当 V+V_+V+​ 接地时，V−≈0V_- \approx 0V−​≈0 V（虚地）。但注意："虚地"不是真正的接地——不能直接连到地，因为正是 V−V_-V−​ 处的反馈节点提供了信号的电流路径。

5.2 用 VCVS 建立运放模型 ​

在 PySpice 中，VCVS('name', out+, out-, in+, in-, voltage_gain=A) 创建一个理想电压控制电压源：

python
circuit.VCVS('oa1',  # 元件名
    'out', circuit.gnd,  # 输出正、负端
    circuit.gnd, 'sum',  # 输入正、负端
    voltage_gain=1e5)    # 增益

输入端正-负端之间的电压乘以增益，出现在输出端正-负端之间。注意 VCVS 的输入阻抗无穷大、输出阻抗为零——这是理想运放的核心特性。

更复杂的运放模型可以加入输入阻抗（在输入端并联电阻）、输出阻抗（在输出端串联电阻）、带宽限制（在 VCVS 后面加 RC 滤波），这就是下一章要讨论的频率补偿。

5.3 差分放大器的共模抑制 ​

差分放大器能放大差模信号（V1−V2V_1 - V_2V1​−V2​）同时抑制共模信号（(V1+V2)/2(V_1 + V_2)/2(V1​+V2​)/2）。这个能力用共模抑制比（CMRR）衡量：

CMRR=20log⁡10(AdmAcm) (dB)CMRR = 20\log_{10}\left(\frac{A_{dm}}{A_{cm}}\right) \text{ (dB)} CMRR=20log10​(Acm​Adm​​) (dB)

在电阻完全匹配（R1=R3R_1=R_3R1​=R3​, R2=R4R_2=R_4R2​=R4​）的理想情况下，Acm=0A_{cm}=0Acm​=0，CMRR 无穷大。但实际电阻容差为 1% 时，CMRR 降至约 46 dB——仍相当不错。差分放大器是 ECG（心电图）仪器、电流检测等应用的输入端标准电路。

6. 本章小结 ​

  • 理想运放的黄金法则：V+≈V−V_+ \approx V_-V+​≈V−​（虚短）和 I+=I−=0I_+ = I_- = 0I+​=I−​=0（虚断）
  • 反相放大器：Av=−R2/R1A_v = -R_2/R_1Av​=−R2​/R1​，相位反转 180°；同相放大器：Av=1+R2/R1A_v = 1 + R_2/R_1Av​=1+R2​/R1​，相位 0°
  • 电压跟随器：Av=1A_v = 1Av​=1，提供阻抗隔离——高输入阻抗（到传感器），低输出阻抗（到负载）
  • 差分放大器放大差模、抑制共模——CMRR 取决于电阻匹配精度
  • PySpice 的 VCVS 元件提供了理想运放的简单建模，适合大部分"系统级"分析

运放是第 14 章反馈与稳定性分析的载体——负反馈使运放实用化，但也在高频下引入了稳定性问题。

7. 练习 ​

  1. 增益精确度：用 Aol=103A_{ol}=10^3Aol​=103（而非 10510^5105）重复反相放大器仿真。记录增益偏差——验证公式 Av,cl=Av,ideal/(1+1/(βAol))A_{v,cl} = A_{v,ideal} / (1 + 1/(\beta A_{ol}))Av,cl​=Av,ideal​/(1+1/(βAol​))，其中 β=R1/(R1+R2)\beta = R_1/(R_1+R_2)β=R1​/(R1​+R2​)。

  2. 跟随器负载效应：在跟随器输出端接 10 Ω 负载（替代原来的 1 kΩ），如果运放有输出阻抗 Rout=75 ΩR_{out}=75\,\OmegaRout​=75Ω，输出电压下降了多少？用仿真验证你的计算。

  3. 差分 CMRR 测量：将两个输入信号设为同相（V1=V2=1V_1=V_2=1V1​=V2​=1 V），测量输出电压。然后改变 R4R_4R4​ 为 9.9 kΩ（模拟 1% 失配），再次测量。计算 CMRR 的变化。

  4. 仪表放大器：将三个运放组合成仪表放大器（两个跟随器 + 差分放大器），分析其输入阻抗和共模抑制比为何远优于简单差分放大器。用 PySpice 验证你的分析。
