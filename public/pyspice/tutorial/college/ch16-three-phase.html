第16章 三相电路 ​

1. 本节你将学到 ​

  • 理解三相交流电的产生原理：三个绕组在空间上相差 120∘120^\circ120∘，产生相位差 120∘120^\circ120∘ 的正弦电压
  • 掌握星形（Y）接法和三角形（Δ）接法中相电压与线电压、相电流与线电流的关系
  • 掌握三相功率公式：Ptotal=3⋅Vline⋅Iline⋅cos⁡φP_{total} = \sqrt{3} \cdot V_{line} \cdot I_{line} \cdot \cos\varphiPtotal​=3​⋅Vline​⋅Iline​⋅cosφ（平衡负载）
  • 理解平衡负载与不平衡负载的区别及其对中线电流的影响
  • 学会用 PySpice 的 SinusoidalVoltageSource(delay=...) 构建三相电源并进行瞬态分析
  • 分析 Y-Δ 变换对电压、电流和功率的影响

2. 知识回顾/情景引入 ​

第 6 章和第 7 章我们学习了单相交流电路——一个正弦电压源驱动负载。在家用环境中，墙壁插座提供的就是单相 220 V/50 Hz 交流电。但你是否想过：发电厂是怎么把电送到你家的？

答案是三相输电。发电机内部有三组线圈，空间互差 120∘120^\circ120∘，转动的磁极在三组线圈中感应出相位各差 120∘120^\circ120∘ 的三组正弦电压。这三组电压通过三根输电线（加上可选的中线）传输到用户端。

三相系统有几大核心优势：

  1. 瞬时功率恒定：三相对称负载的瞬时功率之和为常数，不像单相那样以两倍频率脉动——这意味着发电机和电动机的转矩更平稳
  2. 输电效率高：三相只需三根导线，单相传输相同功率需要六根导线（三组独立单相回路）
  3. 旋转磁场：三相对称绕组通入三相电流，自动产生旋转磁场，驱动异步电动机
  4. 灵活性：可根据需要选择 Y 或 Δ 接法，改变电压和电流等级

全球电力系统的发电、输电、配电几乎全部采用三相制。了解三相电路，是跨入电力工程的第一步。

2.1 三相电压的数学表达 ​

以 A 相为参考（0∘0^\circ0∘），三相相电压为：

va(t)=2Vphcos⁡(ωt)v_a(t) = \sqrt{2} V_{ph} \cos(\omega t) va​(t)=2​Vph​cos(ωt)

vb(t)=2Vphcos⁡(ωt−120∘)v_b(t) = \sqrt{2} V_{ph} \cos(\omega t - 120^\circ) vb​(t)=2​Vph​cos(ωt−120∘)

vc(t)=2Vphcos⁡(ωt−240∘)v_c(t) = \sqrt{2} V_{ph} \cos(\omega t - 240^\circ) vc​(t)=2​Vph​cos(ωt−240∘)

对应的相量表示：

Va=Vph∠0∘,Vb=Vph∠−120∘,Vc=Vph∠−240∘\mathbf{V}_a = V_{ph} \angle 0^\circ, \quad \mathbf{V}_b = V_{ph} \angle -120^\circ, \quad \mathbf{V}_c = V_{ph} \angle -240^\circ Va​=Vph​∠0∘,Vb​=Vph​∠−120∘,Vc​=Vph​∠−240∘

在平衡系统中，Va+Vb+Vc=0\mathbf{V}_a + \mathbf{V}_b + \mathbf{V}_c = 0Va​+Vb​+Vc​=0。

2.2 Y 接法（星形） ​

在 Y 接法中，三个负载（或电源绕组）的一端连接到一个公共点——中性点（Neutral），另一端分别接三条线。

关系公式说明
线电压 vs 相电压Vline=3⋅VphaseV_{line} = \sqrt{3} \cdot V_{phase}Vline​=3​⋅Vphase​线电压比相电压超前 30∘30^\circ30∘
线电流 vs 相电流Iline=IphaseI_{line} = I_{phase}Iline​=Iphase​线电流等于相电流
每相功率Pphase=Vphase⋅Iphase⋅cos⁡φP_{phase} = V_{phase} \cdot I_{phase} \cdot \cos\varphiPphase​=Vphase​⋅Iphase​⋅cosφ
总功率Ptotal=3Pphase=3VlineIlinecos⁡φP_{total} = 3 P_{phase} = \sqrt{3} V_{line} I_{line} \cos\varphiPtotal​=3Pphase​=3​Vline​Iline​cosφ

中国低压配电采用 Y 接法：相电压 220 V（单相家用），线电压 380 V（三相动力）。这正是 3×220≈380\sqrt{3} \times 220 \approx 3803​×220≈380 的体现。

2.3 Δ 接法（三角形） ​

在 Δ 接法中，三个负载首尾相连，形成闭合三角形回路，三条电源线连接三个顶点。

关系公式说明
线电压 vs 相电压Vline=VphaseV_{line} = V_{phase}Vline​=Vphase​线电压等于相电压
线电流 vs 相电流Iline=3⋅IphaseI_{line} = \sqrt{3} \cdot I_{phase}Iline​=3​⋅Iphase​线电流比相电流滞后 30∘30^\circ30∘
总功率Ptotal=3VlineIlinecos⁡φP_{total} = \sqrt{3} V_{line} I_{line} \cos\varphiPtotal​=3​Vline​Iline​cosφ（同 Y）

Δ 接法的总功率公式与 Y 接法完全相同（对于相同的线电压和线电流），但相电流和相电压的分配不同。关键在于：**Y 和 Δ 之间的等效变换（Y-Δ 变换）**可以将任意负载在两种拓扑之间转换。

4. 用 Python 实现电路仿真 ​

4.1 构建三相 Y 源与平衡负载 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

V_phase = 220
f = 50
T = 1 / f
omega = 2 * np.pi * f

print(f"Three-Phase Source: V_phase = {V_phase} V RMS, f = {f} Hz")
print(f"Phase angles: 0°, -120°, -240°")
print()

delay_120 = T * 120 / 360
delay_240 = T * 240 / 360

circuit_y = Circuit('Three-Phase Y-Source')
circuit_y.SinusoidalVoltageSource('va', 'a', 'n', amplitude=V_phase*np.sqrt(2)@u_V, frequency=f@u_Hz)
circuit_y.SinusoidalVoltageSource('vb', 'b', 'n', amplitude=V_phase*np.sqrt(2)@u_V, frequency=f@u_Hz, delay=delay_120@u_s)
circuit_y.SinusoidalVoltageSource('vc', 'c', 'n', amplitude=V_phase*np.sqrt(2)@u_V, frequency=f@u_Hz, delay=delay_240@u_s)
circuit_y.R('ra', 'a', circuit_y.gnd, 100@u_Ω)
circuit_y.R('rb', 'b', circuit_y.gnd, 100@u_Ω)
circuit_y.R('rc', 'c', circuit_y.gnd, 100@u_Ω)
circuit_y.R('rn', 'n', circuit_y.gnd, 1e-3@u_Ω)

sim_y = circuit_y.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_y = sim_y.transient(step_time=10@u_us, end_time=40@u_ms)

time = np.array(an_y.time) * 1000
va = np.array(an_y['a'])
vb = np.array(an_y['b'])
vc = np.array(an_y['c'])

V_ab = va - vb
V_bc = vb - vc
V_ca = vc - va

代码解释：

  • SinusoidalVoltageSource('va', 'a', 'n', amplitude=..., frequency=...)：创建正弦电压源，正极连接节点 'a'，负极连接中性点 'n'。幅值为 2202220\sqrt{2}2202​ V（RMS 的峰值），频率 50 Hz。
  • delay=delay_120@u_s：B 相延迟 (20 ms)×120/360=6.667 ms(20 \text{ ms}) \times 120/360 = 6.667 \text{ ms}(20 ms)×120/360=6.667 ms，对应 −120∘-120^\circ−120∘ 相位。C 相延迟 13.33313.33313.333 ms（−240∘-240^\circ−240∘）。
  • 中性点通过 10−310^{-3}10−3 Ω 的极小电阻接地——目的是在 SPICE 中为中性点提供一个直流通路（避免浮空节点），同时对计算结果几乎无影响。
  • V_ab = va - vb：线电压定义为两相之间的电压差。在 Y 接法中，线电压 = 相电压之差（相量），其幅值为相电压的 3\sqrt{3}3​ 倍。

5. 深入理解 ​

5.1 瞬时功率的恒定性 ​

三相系统区别于单相的最大特点——瞬时功率恒定。单相负载的瞬时功率以 2ω2\omega2ω 的频率在零和峰值之间脉动：

p1ϕ(t)=VmImcos⁡2(ωt)=VmIm2[1+cos⁡(2ωt)]p_{1\phi}(t) = V_{m} I_{m} \cos^2(\omega t) = \frac{V_m I_m}{2}[1 + \cos(2\omega t)] p1ϕ​(t)=Vm​Im​cos2(ωt)=2Vm​Im​​[1+cos(2ωt)]

三相平衡负载的瞬时功率之和：

p3ϕ(t)=vaia+vbib+vcicp_{3\phi}(t) = v_a i_a + v_b i_b + v_c i_c p3ϕ​(t)=va​ia​+vb​ib​+vc​ic​

代入三角函数并化简，交叉项全部抵消，得到：

p3ϕ(t)=32VmImcos⁡φ=常数p_{3\phi}(t) = \frac{3}{2} V_m I_m \cos\varphi = \text{常数} p3ϕ​(t)=23​Vm​Im​cosφ=常数

这对电动机和发电机至关重要——恒定功率意味恒定转矩，没有振动和噪音。这也是为什么大功率电机一定是三相的。

5.2 Y-Δ 变换（星-三角变换） ​

对于一个三端电阻网络，Y 和 Δ 之间的等效变换为：

Δ → Y：

Ra=RabRcaRab+Rbc+Rca,Rb=RabRbcRab+Rbc+Rca,Rc=RbcRcaRab+Rbc+RcaR_a = \frac{R_{ab} R_{ca}}{R_{ab} + R_{bc} + R_{ca}}, \quad R_b = \frac{R_{ab} R_{bc}}{R_{ab} + R_{bc} + R_{ca}}, \quad R_c = \frac{R_{bc} R_{ca}}{R_{ab} + R_{bc} + R_{ca}} Ra​=Rab​+Rbc​+Rca​Rab​Rca​​,Rb​=Rab​+Rbc​+Rca​Rab​Rbc​​,Rc​=Rab​+Rbc​+Rca​Rbc​Rca​​

Y → Δ：

Rab=RaRb+RbRc+RcRaRc,Rbc=RaRb+RbRc+RcRaRa,Rca=RaRb+RbRc+RcRaRbR_{ab} = \frac{R_a R_b + R_b R_c + R_c R_a}{R_c}, \quad R_{bc} = \frac{R_a R_b + R_b R_c + R_c R_a}{R_a}, \quad R_{ca} = \frac{R_a R_b + R_b R_c + R_c R_a}{R_b} Rab​=Rc​Ra​Rb​+Rb​Rc​+Rc​Ra​​,Rbc​=Ra​Ra​Rb​+Rb​Rc​+Rc​Ra​​,Rca​=Rb​Ra​Rb​+Rb​Rc​+Rc​Ra​​

对于平衡负载（Ra=Rb=Rc=RYR_a = R_b = R_c = R_YRa​=Rb​=Rc​=RY​），RΔ=3RYR_{\Delta} = 3 R_YRΔ​=3RY​。这就是本章 RΔ=300 ΩR_{\Delta} = 300 \text{ }\OmegaRΔ​=300 Ω 等效于 RY=100 ΩR_Y = 100 \text{ }\OmegaRY​=100 Ω 的由来。

5.3 不平衡负载与中线作用 ​

当三相负载不平衡（例如各相电阻不同），中线电流不再为零：

IN=Ia+Ib+Ic≠0I_N = I_a + I_b + I_c \neq 0 IN​=Ia​+Ib​+Ic​=0

中线的作用是负载中性点保持在地电位。如果中线断开（四线制变为三线制），不平衡负载下的中性点电压会"漂移"，导致各相电压不再相等——低负载相的电压可能飙升超过额定值，烧毁设备。

PySpice 可用于仿真这种故障场景：将三路负载电阻设为不同值，移除 RrnR_{rn}Rrn​（中性点电阻），观察中性点电压的偏移。

5.4 输电效率 ​

比较单相和三相输电的导线材料利用率：

  • 单相（两线）：两根导线传输功率 P=VlineIlineP = V_{line} I_{line}P=Vline​Iline​
  • 三相（三线）：三根导线传输功率 P=3VlineIlineP = \sqrt{3} V_{line} I_{line}P=3​Vline​Iline​

导线材料比：32/3≈0.866\frac{3}{2} / \sqrt{3} \approx 0.86623​/3​≈0.866。三相只用 87% 的导线材料传输相同的功率！如果以每单位导体截面传输的功率来衡量，三相比单相高效约 15%。
