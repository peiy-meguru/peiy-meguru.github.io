第14章 反馈与稳定性 ​

1. 本节你将学到 ​

  • 理解负反馈的基本原理：将输出信号的一部分（或全部）反相引回到输入端
  • 掌握闭环增益公式：ACL=AOL1+AOLβA_{CL} = \frac{A_{OL}}{1 + A_{OL}\beta}ACL​=1+AOL​βAOL​​，其中 AOLA_{OL}AOL​ 为开环增益，β\betaβ 为反馈系数
  • 理解**增益带宽积（GBW）**恒定性：负反馈以增益换取带宽，ACL×BW≈常数A_{CL} \times BW \approx \text{常数}ACL​×BW≈常数
  • 掌握Bode 图的绘制与解读：幅频曲线和相频曲线
  • 理解**相位裕度（Phase Margin）**的物理意义：PM=180∘+∠H(jω0)\text{PM} = 180^\circ + \angle H(j\omega_0)PM=180∘+∠H(jω0​)，ω0\omega_0ω0​ 为穿越频率
  • 学会用 PySpice 的 VCVS 和 .ac() 分析反馈深度对带宽的影响

2. 知识回顾/情景引入 ​

第 13 章我们学习了运算放大器，通过反馈电阻 RfR_fRf​ 和输入电阻 RiR_iRi​ 的比值精确设定了放大倍数。反相放大器的增益为 −Rf/Ri-R_f / R_i−Rf​/Ri​，同相放大器的增益为 1+Rf/Ri1 + R_f / R_i1+Rf​/Ri​——这些公式成立的前提是运放的开环增益非常大（理想情况下为无穷大）。

但为什么运放需要反馈？没有反馈会发生什么？

想象你用一个话筒对着音箱说话：如果话筒离音箱太近，输出声音会被话筒再次拾取、再次放大、再次输出——这就是正反馈，表现为尖锐的啸叫声（振荡）。在电路中，负反馈将输出的一部分反相叠加到输入端，从而稳定增益、降低失真、扩展带宽。但如果反馈设计不当——比如在某个频率上正反馈取代了负反馈——电路同样会振荡。

本章将用量化方法探讨反馈的核心概念：闭环增益公式、增益带宽权衡、以及稳定性判据。

2.1 负反馈的闭环增益 ​

考虑一个增益为 AOLA_{OL}AOL​ 的放大器，其输出电压 VoutV_{out}Vout​ 经过反馈网络 β\betaβ 衰减后与输入信号 VinV_{in}Vin​ 相减，形成误差信号：

Verr=Vin−βVoutV_{err} = V_{in} - \beta V_{out} Verr​=Vin​−βVout​

Vout=AOL⋅Verr=AOL(Vin−βVout)V_{out} = A_{OL} \cdot V_{err} = A_{OL}(V_{in} - \beta V_{out}) Vout​=AOL​⋅Verr​=AOL​(Vin​−βVout​)

整理得：

Vout(1+AOLβ)=AOLVinV_{out}(1 + A_{OL}\beta) = A_{OL} V_{in} Vout​(1+AOL​β)=AOL​Vin​

ACL=VoutVin=AOL1+AOLβA_{CL} = \frac{V_{out}}{V_{in}} = \frac{A_{OL}}{1 + A_{OL}\beta} ACL​=Vin​Vout​​=1+AOL​βAOL​​

当 AOLβ≫1A_{OL}\beta \gg 1AOL​β≫1 时（深度负反馈），ACL≈1/βA_{CL} \approx 1/\betaACL​≈1/β。这就是运放电路的增益由电阻比独立决定的原因——β\betaβ 由电阻分压网络定义，几乎不依赖 AOLA_{OL}AOL​ 本身！

2.2 增益带宽积 ​

实际运放的开环增益 AOL(jω)A_{OL}(j\omega)AOL​(jω) 随频率衰减（一阶低通特性）：

AOL(jω)=A01+jω/ωpA_{OL}(j\omega) = \frac{A_0}{1 + j\omega/\omega_p} AOL​(jω)=1+jω/ωp​A0​​

其中 A0A_0A0​ 为直流开环增益，ωp\omega_pωp​ 为开环极点（-3 dB 截止频率）。该放大器具有恒定增益带宽积：

GBW=A0⋅fp（单位：Hz 或 rad/s）\text{GBW} = A_0 \cdot f_p \quad \text{（单位：Hz 或 rad/s）} GBW=A0​⋅fp​（单位：Hz 或 rad/s）

闭环后，系统仍可近似为一阶低通，-3 dB 带宽从 fpf_pfp​ 扩展到 fp′=fp(1+A0β)≈GBW/ACLf_p' = f_p (1 + A_0\beta) \approx \text{GBW} / A_{CL}fp′​=fp​(1+A0​β)≈GBW/ACL​。增益越低，带宽越宽。这就是"以增益换带宽"的数学基础。

2.3 稳定性与相位裕度 ​

当频率上升时，信号通过放大器的相移会增大。如果总相移达到 −180∘-180^\circ−180∘，负反馈变成正反馈，电路振荡。稳定性由相位裕度衡量：

PM=180∘+∠AOL(jω0)β\text{PM} = 180^\circ + \angle A_{OL}(j\omega_0)\beta PM=180∘+∠AOL​(jω0​)β

其中 ω0\omega_0ω0​ 是 ∣AOL(jω)β∣=1|A_{OL}(j\omega)\beta| = 1∣AOL​(jω)β∣=1（0 dB）处的频率（穿越频率，UGF）。

  • PM>45∘\text{PM} > 45^\circPM>45∘：稳定，但阶跃响应可能有轻微过冲
  • PM≈60∘\text{PM} \approx 60^\circPM≈60∘：良好稳定性，快速建立时间
  • PM<30∘\text{PM} < 30^\circPM<30∘：接近振荡，阶跃响应有大幅度振铃
  • PM≤0∘\text{PM} \leq 0^\circPM≤0∘：不稳定，振荡

4. 用 Python 实现电路仿真 ​

4.1 负反馈放大器频率响应 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

AV_ol = 1e5

print(f"Op-amp model: A_ol={AV_ol:.0e}, GBW=1 MHz")
print()

# Part 1: Negative Feedback — Gain and Bandwidth
circuit_fb = Circuit('Negative Feedback Amp')
circuit_fb.SinusoidalVoltageSource('vin', 'in', circuit_fb.gnd, amplitude=0.1@u_V)
circuit_fb.R('R1', 'in', 'sum', 1@u_kΩ)
circuit_fb.R('R2', 'sum', 'out', 9@u_kΩ)
circuit_fb.VCVS('oa1', 'out', circuit_fb.gnd, circuit_fb.gnd, 'sum', voltage_gain=AV_ol/10)

sim_fb = circuit_fb.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_fb = sim_fb.ac(start_frequency=10@u_Hz, stop_frequency=1@u_MHz, number_of_points=500, variation='dec')

freq = np.array(an_fb.frequency)
v_out = np.array(an_fb['out'])
v_in = np.array(an_fb['in'])
Av_cl = np.abs(v_out / np.where(np.abs(v_in) > 0, v_in, 1e-12))
Av_cl_db = 20 * np.log10(Av_cl)

beta = 1000 / (1000 + 9000)
print(f"  Inverting amplifier: R1=1kΩ, R2=9kΩ")
print(f"  Feedback factor β = R1/(R1+R2) = {beta:.2f}")
print(f"  Closed-loop gain: -R2/R1 = -9.0")
mid_fb = len(freq) // 3
print(f"  Gain @ 1kHz: |Av| = {Av_cl[mid_fb]:.2f} ({Av_cl_db[mid_fb]:.1f} dB)")

idx_3db = np.argmin(np.abs(Av_cl - Av_cl[0] * 0.707))
bw_3db = freq[idx_3db]
print(f"  -3dB bandwidth: {bw_3db/1e3:.1f} kHz")
print(f"  Gain-bandwidth product: {Av_cl[0] * bw_3db/1e3:.0f} (≈ A_ol*BW)")
print()

代码解释：

  • VCVS('oa1', 'out', gnd, gnd, 'sum', voltage_gain=AV_ol/10)：构建一个电压控制电压源，增益为 AOL/10A_{OL}/10AOL​/10（10410^4104）。正输入端接地（反相模式），负输入端接求和节点 'sum'。
  • .ac(start_frequency=10@u_Hz, stop_frequency=1@u_MHz, ...)：执行交流小信号扫描，从 10 Hz 到 1 MHz，500 个对数分布点。
  • 反馈系数 β=R1/(R1+R2)\beta = R_1/(R_1 + R_2)β=R1​/(R1​+R2​) 由电阻分压网络决定——这是运放反相放大器中反馈网络的"分压比"。
  • 一阶低通模型在 GBW 频率处增益降至 1。

    c = Circuit('tmp')

    print(f"{r2_val/1e3:>10.1f} {beta_i:>8.3f} {av_dc:>8.1f} {bw_khz:>10.1f} {gbw/1000:>10.0f}")

4.3 稳定性分析 — Bode 图 ​

python
circuit_stab = Circuit('Stability Analysis')
circuit_stab.SinusoidalVoltageSource('vin', 'in', circuit_stab.gnd, amplitude=0.1@u_V)
circuit_stab.VCVS('oa1', 'out', circuit_stab.gnd, circuit_stab.gnd, 'in', voltage_gain=AV_ol/100)

sim_stab = circuit_stab.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_stab = sim_stab.ac(start_frequency=10@u_Hz, stop_frequency=10@u_MHz, number_of_points=500, variation='dec')

freq_stab = np.array(an_stab.frequency)
v_out_stab = np.array(an_stab['out'])
v_in_stab = np.array(an_stab['in'])
H = v_out_stab / np.where(np.abs(v_in_stab) > 0, v_in_stab, 1e-12)
mag_db = 20 * np.log10(np.abs(H))
phase_deg = np.angle(H, deg=True)

ugf_idx = np.argmin(np.abs(mag_db)) if np.any(mag_db > 0) else len(mag_db)-1
phase_margin = 180 + phase_deg[ugf_idx] if ugf_idx < len(phase_deg) else 0
ugf = freq_stab[ugf_idx]

print(f"Stability Analysis:")
print(f"  Unity gain frequency (0dB): {ugf/1e3:.1f} kHz")
print(f"  Phase at 0dB: {phase_deg[ugf_idx]:.1f}°")
print(f"  Phase margin = 180° + φ(0dB) = {phase_margin:.1f}°")
print(f"  Assessment: {'STABLE (PM > 45°)' if phase_margin > 45 else 'MARGINAL'}")

5. 深入理解 ​

5.1 负反馈的四大好处 ​

特性无反馈带负反馈改善因子
增益精度依赖 AOLA_{OL}AOL​ 容差由 β\betaβ（电阻比）决定1+AOLβ1 + A_{OL}\beta1+AOL​β
带宽fpf_pfp​fp(1+AOLβ)f_p(1 + A_{OL}\beta)fp​(1+AOL​β)1+AOLβ1 + A_{OL}\beta1+AOL​β
非线性失真大除以 1+AOLβ1 + A_{OL}\beta1+AOL​β1+AOLβ1 + A_{OL}\beta1+AOL​β
输入/输出阻抗固定可调节（反相降低 RinR_{in}Rin​，同相增大）—

"改善因子" 1+AOLβ1 + A_{OL}\beta1+AOL​β 是反馈中最核心的数值——环增益（Loop Gain）。

5.2 频率补偿 ​

如果放大器的开环传递函数包含多个极点（如两极点系统），相移可能在高频处迅速接近 −180∘-180^\circ−180∘，导致相位裕度不足。集成运放（如 μ\muμA741）内部有米勒补偿电容，主动引入一个主导极点，使幅频曲线以 -20 dB/dec 的斜率穿过 0 dB，从而保证足够的相位裕度。

在 SPICE 中，这可以建模为 VCVS 后接一个 RC 低通网络。

5.3 正反馈与振荡器 ​

将负反馈网络的符号反转（或引入额外 180∘180^\circ180∘ 的相移），负反馈变为正反馈。巴克豪森准则（Barkhausen criterion）指出，当环路增益满足：

∣AOL(jω)β∣≥1且∠AOL(jω)β=0∘（或 360∘）|A_{OL}(j\omega)\beta| \geq 1 \quad \text{且} \quad \angle A_{OL}(j\omega)\beta = 0^\circ \text{（或 } 360^\circ \text{）} ∣AOL​(jω)β∣≥1且∠AOL​(jω)β=0∘（或 360∘）

时，系统在频率 ω\omegaω 处振荡。Wien 桥振荡器、Colpitts 振荡器、晶体振荡器——都基于这个原理。

6. 本章小结 ​

  • 负反馈闭环增益：ACL=AOL/(1+AOLβ)≈1/βA_{CL} = A_{OL} / (1 + A_{OL}\beta) \approx 1/\betaACL​=AOL​/(1+AOL​β)≈1/β（深度负反馈时）
  • 增益带宽积恒定：ACL×BW≈GBWA_{CL} \times \text{BW} \approx \text{GBW}ACL​×BW≈GBW，增益降低 NNN 倍，带宽增加 NNN 倍
  • 反馈深度 β\betaβ 越小，闭环增益越高，带宽越窄，失真抑制效果越差
  • 相位裕度衡量稳定性：PM>45∘\text{PM} > 45^\circPM>45∘ 为安全，PM≤0∘\text{PM} \leq 0^\circPM≤0∘ 为振荡
  • 一阶系统固有稳定（最大相移 −90∘-90^\circ−90∘），二阶及以上需要频率补偿
  • PySpice 的 .ac() 分析和 VCVS 可用于搭建反馈系统的 Bode 图

反馈是模拟电路设计的核心思想——它用增益换取精度、带宽和线性度。从音频放大器到开关电源、从锁相环到 Sigma-Delta ADC，反馈原理无处不在。
