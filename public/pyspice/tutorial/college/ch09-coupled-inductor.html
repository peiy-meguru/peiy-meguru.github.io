第9章 耦合电感与变压器 ​

1. 本节你将学到 ​

  • 理解互感 MMM 及其与自感、耦合系数 kkk 的关系：M=kL1L2M = k\sqrt{L_1 L_2}M=kL1​L2​​
  • 掌握同名端（dot convention）规则及互感电压的符号：v2=Mdi1dtv_2 = M\frac{di_1}{dt}v2​=Mdtdi1​​
  • 理解匝数比 n=N1/N2=L1/L2n = N_1/N_2 = \sqrt{L_1/L_2}n=N1​/N2​=L1​/L2​​ 及其在理想变压器中的作用
  • 掌握阻抗反射原理：Zin=n2ZloadZ_{in} = n^2 Z_{load}Zin​=n2Zload​
  • 学会用 PySpice 的 K 元件建立耦合电感模型，并进行瞬态和 AC 分析

2. 知识回顾/情景引入 ​

第 4 章我们研究了独立电感——当电流变化时，电感两端产生感应电动势：v=Ldidtv = L\frac{di}{dt}v=Ldtdi​。但如果两个电感线圈靠近放置，一个线圈中变化的电流产生的磁通会穿过另一个线圈，在后者中感应出电压——这就是互感（mutual inductance）现象。

互感是变压器的物理基础。从手机充电器里的反激变压器，到电网中数百兆伏安的电力变压器，互感和变压器是电气工程最重要的概念之一。

2.1 互感的物理图像 ​

当两线圈通过磁通耦合时：

  • 初级线圈 L1L_1L1​：电流 i1i_1i1​ 产生磁通 ϕ1\phi_1ϕ1​
  • 次级线圈 L2L_2L2​：部分磁通 kϕ1k\phi_1kϕ1​ 穿过 L2L_2L2​（kkk 为耦合系数，0≤k≤10 \le k \le 10≤k≤1）
  • 次级感应电压：v2=Mdi1dtv_2 = M\frac{di_1}{dt}v2​=Mdtdi1​​，其中 M=kL1L2M = k\sqrt{L_1L_2}M=kL1​L2​​

2.2 同名端规则 ​

同名端（dot）用于确定互感电压的极性：

  • 如果初级电流从同名端流入且增加，则次级同名端感应出正电压（相对于异名端）
  • 在 SPICE 中，K 元件自动处理极性；两电感的名端由 .L() 的第一个节点定义

2.3 理想变压器 vs 非理想变压器 ​

特性理想变压器 (k=1k=1k=1)非理想变压器 (k<1k<1k<1)
耦合完美耦合，无漏感有漏感
电压比V2/V1=N2/N1V_2/V_1 = N_2/N_1V2​/V1​=N2​/N1​V2/V1≈N2/N1V_2/V_1 \approx N_2/N_1V2​/V1​≈N2​/N1​（近似）
阻抗反射精确 n2ZLn^2Z_Ln2ZL​有偏差，有漏阻抗影响
频率响应平坦（全频带）低频效率下降（电感感抗不足）

2.4 匝数比与电感比 ​

对于绕在同一磁芯上的两线圈，匝数比与电感比的关系为：

n=N1N2=L1L2n = \frac{N_1}{N_2} = \sqrt{\frac{L_1}{L_2}} n=N2​N1​​=L2​L1​​​

这是设计变压器时最基本的公式：绕 2 倍的匝数，电感变为 4 倍。

3. 动手设计电路 ​

3.1 本节电路 ​

耦合电感测试电路：

  • 初级电感 L1=100L_1 = 100L1​=100 mH，次级电感 L2=400L_2 = 400L2​=400 mH
  • 耦合系数 k=0.95k = 0.95k=0.95（非理想变压器，有少量漏感）
  • 匝数比：n=100/400=0.5n = \sqrt{100/400} = 0.5n=100/400​=0.5（N1:N2=1:2N_1:N_2 = 1:2N1​:N2​=1:2）

升压配置（次级匝数多于初级）意味着 V2/V1≈2V_2/V_1 \approx 2V2​/V1​≈2。

3.2 手工计算 ​

互感值：M=0.95×0.1×0.4=0.190M = 0.95 \times \sqrt{0.1 \times 0.4} = 0.190M=0.95×0.1×0.4​=0.190 H = 190 mH

理论电压比（理想情况，k=1k=1k=1）：V2V1=N2N1=10.5=2\frac{V_2}{V_1} = \frac{N_2}{N_1} = \frac{1}{0.5} = 2V1​V2​​=N1​N2​​=0.51​=2

由于 k=0.95<1k = 0.95 < 1k=0.95<1，实际比值会略有偏差——次级电压会略低于理想值。

阻抗反射：若次级接 RL=100 ΩR_L = 100\,\OmegaRL​=100Ω 负载，反射到初级的阻抗为：

Zin=n2×RL=0.52×100=25 ΩZ_{in} = n^2 \times R_L = 0.5^2 \times 100 = 25\,\Omega Zin​=n2×RL​=0.52×100=25Ω

4. 用 Python 实现电路仿真 ​

4.1 耦合电感完整分析 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

print("=== Chapter 9: Coupled Inductor & Transformer ===")
print()

L1_val = 100e-3
L2_val = 400e-3
k_val = 0.95
M_val = k_val * np.sqrt(L1_val * L2_val)
n = np.sqrt(L1_val / L2_val)

print(f"L1 = {L1_val*1e3} mH, L2 = {L2_val*1e3} mH, k = {k_val}")
print(f"M = k*sqrt(L1*L2) = {M_val*1e3:.1f} mH")
print(f"Ideal turns ratio n = sqrt(L1/L2) = {n:.3f} (N1:N2 = 1:{1/n:.3f})")
print()

print("--- Test 1: Mutual Inductance Coupling ---")
circuit1 = Circuit('Mutual Inductance')
circuit1.SinusoidalVoltageSource('v1', 1, circuit1.gnd, amplitude=10@u_V, frequency=50@u_Hz)
circuit1.R('R1', 1, 2, 10@u_Ω)
circuit1.L('L1', 2, circuit1.gnd, L1_val@u_H)
circuit1.L('L2', 3, circuit1.gnd, L2_val@u_H)
circuit1.R('R2', 3, circuit1.gnd, 1000@u_Ω)
circuit1.K('K1', 'L1', 'L2', k_val)

sim1 = circuit1.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an1 = sim1.transient(step_time=10@u_us, end_time=40@u_ms)

time = np.array(an1.time)
v_primary = np.array(an1['2']) - np.array(an1['1'])
v_secondary = np.array(an1['3'])

v_pri_rms = np.sqrt(np.mean(v_primary[len(v_primary)//2:]**2))
v_sec_rms = np.sqrt(np.mean(v_secondary[len(v_secondary)//2:]**2))
ratio = v_sec_rms / v_pri_rms if v_pri_rms > 0 else 0

print(f"  V_primary (RMS) = {v_pri_rms:.4f} V")
print(f"  V_secondary (RMS) = {v_sec_rms:.4f} V")
print(f"  V_secondary / V_primary = {ratio:.4f}")
print(f"  Theory sqrt(L2/L1) = {np.sqrt(L2_val/L1_val):.4f}")
print()

print("--- Test 2: Turns Ratio & Impedance Reflection ---")
R_load = 100
circuit_z = Circuit('Impedance Reflection')
circuit_z.SinusoidalVoltageSource('v1', 1, circuit_z.gnd, amplitude=10@u_V, frequency=50@u_Hz)
circuit_z.R('R1', 1, 2, 10@u_Ω)
circuit_z.L('L1', 2, circuit_z.gnd, L1_val@u_H)
circuit_z.L('L2', 3, circuit_z.gnd, L2_val@u_H)
circuit_z.R('RL', 3, circuit_z.gnd, R_load@u_Ω)
circuit_z.K('K1', 'L1', 'L2', k_val)

sim_z = circuit_z.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_z = sim_z.transient(step_time=10@u_us, end_time=40@u_ms)

v_pri_z = np.array(an_z['2']) - np.array(an_z['1'])
v_pri_z_rms = np.sqrt(np.mean(v_pri_z[len(v_pri_z)//2:]**2))
i_pri_z_rms = np.sqrt(np.mean(((np.array(an_z['1']) - np.array(an_z['2'])) / 10)[len(v_pri_z)//2:]**2))
Z_in = v_pri_z_rms / i_pri_z_rms if i_pri_z_rms > 0 else np.inf

Z_ref_theory = (n**2) * R_load
print(f"  R_load = {R_load} Ω on secondary")
print(f"  Reflected impedance: n² × R_load = {n**2:.3f} × {R_load} = {Z_ref_theory:.1f} Ω")
print(f"  Input impedance Z_in = {Z_in:.2f} Ω (includes R1=10Ω)")
print()

print("--- Frequency Response of Coupled Inductor ---")
circuit_f = Circuit('Coupled Freq Sweep')
circuit_f.SinusoidalVoltageSource('v1', 1, circuit_f.gnd, amplitude=1@u_V)
circuit_f.R('R1', 1, 2, 10@u_Ω)
circuit_f.L('L1', 2, circuit_f.gnd, L1_val@u_H)
circuit_f.L('L2', 3, circuit_f.gnd, L2_val@u_H)
circuit_f.R('RL', 3, circuit_f.gnd, 100@u_Ω)
circuit_f.K('K1', 'L1', 'L2', k_val)

sim_f = circuit_f.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_f = sim_f.ac(start_frequency=10@u_Hz, stop_frequency=1@u_kHz, number_of_points=200, variation='dec')

freq = np.array(an_f.frequency)
v_out_f = np.abs(np.array(an_f['3']))
db_f = 20 * np.log10(v_out_f)

plt.figure(figsize=(12, 6))
plt.subplot(1, 2, 1)
plt.semilogx(freq, db_f, 'b-', linewidth=1.5)
plt.xlabel('Frequency (Hz)')
plt.ylabel('Gain (dB)')
plt.title('Coupled Inductor Frequency Response')
plt.grid(True, which='both', alpha=0.3)

plt.subplot(1, 2, 2)
v_out_tf = np.abs(np.array(an_f['2']))
db_tf = 20 * np.log10(v_out_tf)
plt.semilogx(freq, db_f, 'b-', label='V_out (secondary)', linewidth=1.5)
plt.semilogx(freq, db_tf, 'r--', label='V_primary', linewidth=1.5, alpha=0.6)
plt.xlabel('Frequency (Hz)')
plt.ylabel('Gain (dB)')
plt.title('Primary vs Secondary Response')
plt.legend()
plt.grid(True, which='both', alpha=0.3)

plt.tight_layout()
plt.savefig('/workspace/ch09_coupled_inductor.png', dpi=150, bbox_inches='tight')
plt.close()

5. 深入理解 ​

5.1 耦合系数 k 的物理意义 ​

kkk 衡量两个线圈磁通耦合的紧密程度：

  • k=1k = 1k=1：完美耦合，所有初级磁通穿过次级（理想变压器）
  • k=0.9∼0.99k = 0.9 \sim 0.99k=0.9∼0.99：铁芯变压器——铁磁材料将磁通引导致磁芯内
  • k=0.3∼0.7k = 0.3 \sim 0.7k=0.3∼0.7：空心变压器——空气中耦合松散
  • k=0k = 0k=0：无耦合，两电感完全独立

k<1k < 1k<1 意味着存在漏电感（leakage inductance）：Lleak=(1−k2)LL_{leak} = (1-k^2)LLleak​=(1−k2)L。漏感在高频开关电源中非常关键，因为它在开关管关断时产生电压尖峰。

5.2 阻抗反射的应用 ​

阻抗反射是变压器最巧妙的应用之一。在音频放大器中，输出变压器将 8 Ω 的扬声器反射为数千欧姆的阻抗，与电子管的最佳负载匹配。在射频电路中，通过调节匝数比来实现阻抗匹配——将天线阻抗（通常 50 Ω）变换到放大器所需的负载阻抗。

反射公式 Zin=n2ZLZ_{in} = n^2 Z_LZin​=n2ZL​ 意味着：

  • 若 n<1n < 1n<1（升压变压器），Zin<ZLZ_{in} < Z_LZin​<ZL​——从初级"看"负载比实际小
  • 若 n>1n > 1n>1（降压变压器），Zin>ZLZ_{in} > Z_LZin​>ZL​——从初级"看"负载比实际大

5.3 在 PySpice 中使用耦合电感 ​

K('K1', 'L1', 'L2', k_val) 声明两个电感的耦合关系。PySpice 会自动处理同名端——L1 和 L2 的第一个节点（即节点 2 和节点 3）被视为同名端。如果需要反相耦合，只需交换其中一个电感的节点顺序。

K 元件是线性耦合元件——它建立的是线性互感关系。对于铁芯饱和等非线性行为，需要使用更复杂的模型（如 Jiles-Atherton 磁芯模型），这超出了 SPICE 的标准范围。

6. 本章小结 ​

  • 互感 M=kL1L2M = k\sqrt{L_1L_2}M=kL1​L2​​，耦合系数 kkk 在 0（无耦合）到 1（完美耦合）之间
  • 匝数比 n=L1/L2=N1/N2n = \sqrt{L_1/L_2} = N_1/N_2n=L1​/L2​​=N1​/N2​，决定了变压器的电压比和阻抗反射比
  • 同名端规则确定互感电压极性，PySpice 的 K 元件通过节点顺序隐式指定
  • 阻抗反射 Zin=n2ZLZ_{in} = n^2 Z_LZin​=n2ZL​ 是变压器最重要的工程应用——通过选择匝数比改变"看到"的阻抗
  • 频率响应显示耦合电感在低频时效率下降（感性电抗减小），呈带通特性

耦合电感在第 17 章的综合项目中会再次出现——变压器是 DC 电源的第一级，将 220 V 市电降为适合整流的低电压。

7. 练习 ​

  1. 改变耦合系数：修改脚本中的 kkk 为 0.3,0.7,0.9,1.00.3, 0.7, 0.9, 1.00.3,0.7,0.9,1.0，观察次级电压和频率响应的变化。kkk 从 0.95 降到 0.3 后，次级电压下降了大约多少倍？解释原因。
