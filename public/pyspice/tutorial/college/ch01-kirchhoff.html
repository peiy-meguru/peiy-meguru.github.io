第1章 基尔霍夫定律与节点分析 ​

1. 本节你将学到 ​

  • 掌握 基尔霍夫电流定律（KCL）：∑Iin=∑Iout\sum I_{in} = \sum I_{out}∑Iin​=∑Iout​，任一瞬间流入节点的电流之和等于流出节点的电流之和
  • 掌握 基尔霍夫电压定律（KVL）：∑Vloop=0\sum V_{loop} = 0∑Vloop​=0，任一瞬间沿闭合回路的电压代数和为零
  • 理解节点电压法的基本思想：以节点电压为未知量，利用 KCL 列写方程，系统求解多节点电路
  • 学会在 PySpice 中构建多节点电路并执行 operating_point() 直流工作点分析
  • 验证 KCL 和 KVL 在仿真中的精确成立

2. 知识回顾/情景引入 ​

初中篇里，我们用一个电池、一个电阻、几根导线就搭出了电路。那时候整个电路只有两个节点——电源正极和负极（地）。高中篇我们深入理解了电势、电场，以及闭合电路欧姆定律 I=E/(R+r)I = E/(R+r)I=E/(R+r)，但仍然主要处理单回路或简单串并联电路。

但现实中的电路远非如此简单。你的手机主板上有数百个元器件，路由器的 PCB 上有几十个 IC 芯片，任何一个集成电路内部都有数十亿个晶体管——这些元件之间的互连形成了成百上千个节点和网孔。

要分析这样复杂的电路，直觉上的串并联化简已经不够用了。我们需要一套系统的、普适的分析方法——这就是基尔霍夫定律。

2.1 基尔霍夫电流定律（KCL） ​

KCL 源于电荷守恒。电流是电荷的定向运动，电荷不会凭空产生或消失，所以流入一个节点的总电量必然等于流出该节点的总电量。

想象一个水管三通接头：两根水管把水送进来，一根水管把水送出去。进来的水量一定等于出去的水量。节点在电路中就是这样的"接头"。

数学表达：

∑k=1nIk=0\sum_{k=1}^n I_k = 0 k=1∑n​Ik​=0

其中流入节点的电流取正号，流出取负号（或反过来，只要一致即可）。等价地，可以写作 ∑Iin=∑Iout\sum I_{in} = \sum I_{out}∑Iin​=∑Iout​。

KCL 有一种重要的推广形式——广义节点（也叫超节点）：一个闭合面包围的若干节点，流入该闭合面的总电流等于流出的总电流。这在分析含电压源的节点时非常有用。

2.2 基尔霍夫电压定律（KVL） ​

KVL 源于能量守恒。电荷在电场中绕闭合回路一周回到出发点，电场力做的总功为零——电势的变化之和必须为零。

想象你爬山然后原路返回：上山时地势升高，下山时地势降低。回到出发点时，累计的高度变化为零。KVL 就是电路中的"高度守恒"：沿闭合回路绕一圈，电压升高的总和等于电压降低的总和。

数学表达：

∑k=1mVk=0\sum_{k=1}^m V_k = 0 k=1∑m​Vk​=0

沿着回路方向，电压升取正号，电压降取负号。通常我们沿顺时针方向遍历网孔。

2.3 节点电压法 ​

节点电压法（Nodal Analysis）是求解电路的三大方法之一（另两个是网孔电流法和叠加法）。它的核心思想是：

  1. 选择一个参考节点（通常取"地"节点，电压为零）
  2. 其余各节点相对于参考节点的电压为未知量
  3. 对每个非参考节点列写 KCL 方程
  4. 求解线性方程组得到各节点电压
  5. 根据节点电压推算各支路电流

对于含有 nnn 个节点的电路，节点电压法给出 n−1n-1n−1 个独立方程。这种方法系统、规整，特别适合计算机求解——实际上，SPICE 的核心算法就是基于改进节点分析法（MNA）。

4. 用 Python 实现电路仿真 ​

4.1 构建电路并执行直流工作点分析 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import numpy as np

circuit = Circuit('Kirchhoff Demo')
circuit.V('v1', 1, circuit.gnd, 10@u_V)
circuit.V('v2', 3, circuit.gnd, 5@u_V)
circuit.R('R1', 1, 2, 100@u_Ω)
circuit.R('R2', 2, 3, 200@u_Ω)
circuit.R('R3', 2, circuit.gnd, 150@u_Ω)

simulator = circuit.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
analysis = simulator.operating_point()

v1 = float(np.array(analysis['1']).flat[0])
v2 = float(np.array(analysis['2']).flat[0])
v3 = float(np.array(analysis['3']).flat[0])

print("基尔霍夫定律验证")
print(f"节点电压: V1={v1:.3f}V, V2={v2:.3f}V, V3={v3:.3f}V")
print()
print("KCL @ 节点 2: 流入=流出")
i_r1 = (v1 - v2) / 100
i_r2 = (v2 - v3) / 200
i_r3 = v2 / 150
print(f"  I_R1 = ({v1:.3f}-{v2:.3f})/100 = {i_r1*1000:.2f} mA")
print(f"  I_R2 = ({v2:.3f}-{v3:.3f})/200 = {i_r2*1000:.2f} mA")
print(f"  I_R3 = {v2:.3f}/150 = {i_r3*1000:.2f} mA")
print(f"  流入: {i_r1*1000:.2f} mA ≈ 流出: {(i_r2+i_r3)*1000:.2f} mA")
print()
print("KVL @ 网孔1: 10V = V_R1 + V_R3")
print(f"  V_R1+V_R3 = {v1-v2:.3f} + {v2:.3f} = {v1:.3f} V")
print(f"KVL @ 网孔2: 5V = V_R2 + V_R3")
print(f"  V_R2+V_R3 = {v3-v2:.3f} + {v2:.3f} = {v3:.3f} V")

代码解释：

  • Circuit('Kirchhoff Demo')：创建一个名为"Kirchhoff Demo"的电路对象，Ngspice 将以此名称生成网表（netlist）。
  • circuit.gnd：PySpice 中表示接地节点（节点 0），所有的电压都以它为参考。
  • 10@u_V：使用 PySpice 的 Unit 系统，@u_V 表示以伏特为单位的值。类似地，@u_Ω 是欧姆，@u_kΩ 是千欧，@u_mA 是毫安。
  • simulator.operating_point()：执行直流工作点分析（.OP），返回所有节点电压和支路电流。
  • np.array(analysis['2']).flat[0]：从分析结果中提取节点 2 的电压值（复数数组取其第一个元素的实部）。

5. 深入理解 ​

5.1 KCL 与 KVL 的物理本质 ​

KCL 的物理基础是电荷守恒——它是自然界最精确的守恒定律之一。节点上的"电荷堆积"会导致电势剧烈变化，电场会立刻重新分布以阻止堆积，所以电路的稳态中节点电荷净变化率为零。即使在暂态过程中（如电容充放电），KCL 的推广形式——包含位移电流的麦克斯韦-安培定律——仍然成立。

KVL 的物理基础是静电场环路定理：∮E⃗⋅dl⃗=0\oint \vec{E} \cdot d\vec{l} = 0∮E⋅dl=0。这是静电学的实验定律——电荷在静电场中绕闭合路径回到出发点，电场力做功为零。注意 KVL 只对保守场成立，在时变磁场中（如变压器绕组中）需要引入法拉第定律的修正。

5.2 节点电压法的系统化 ​

对于任意含有 nnn 个非参考节点的线性电阻电路，节点电压法给出如下标准矩阵方程：

GV=Is\mathbf{G} \mathbf{V} = \mathbf{I}_s GV=Is​

其中 G\mathbf{G}G 是电导矩阵（n×nn \times nn×n），V\mathbf{V}V 是节点电压向量，Is\mathbf{I}_sIs​ 是注入各节点的等效电流源向量。

电导矩阵的构造规则：

  • 对角线元素 GiiG_{ii}Gii​ = 连接到节点 iii 的所有电导之和（自电导）
  • 非对角线元素 GijG_{ij}Gij​ = 连接节点 iii 和 jjj 的电导之和的相反数（互电导，取负号）

这也解释了为什么 SPICE 被称为"仿真器"——它的核心就是高效地建立并求解这个矩阵方程。对于非线性元件（如二极管、晶体管），SPICE 使用牛顿-拉夫森迭代法，在每一步将非线性元件线性化，形成迭代版本的节点电压矩阵方程。

5.3 广义节点（超节点）技术 ​

当一个电压源（独立源或受控源）连接在两个非参考节点之间时，由于电压源支路电流未知，标准节点电压法会多出一个未知量。解决方法是引入超节点——将连接电压源的节点及其支路整体包围，对超节点列写 KCL，同时补充电压源两端的约束方程。

在 SPICE 的改进节点分析法（MNA）中，超节点被自然地处理：电压源支路的电流作为额外的未知量加入方程组，方程组从"纯电导矩阵"扩展为"混合矩阵"。

  • KCL：∑Iin=∑Iout\sum I_{in} = \sum I_{out}∑Iin​=∑Iout​，源于电荷守恒，适用于任意节点或广义节点
  • KVL：∑Vloop=0\sum V_{loop} = 0∑Vloop​=0，源于能量守恒（静电场环路定理），适用于任意闭合回路
  • 节点电压法是分析多节点电路的系统方法：以节点电压为未知量，利用 KCL 列写方程
  • PySpice 的 operating_point() 函数执行 Ngspice 的 .OP 分析，返回所有节点的直流偏置电压
  • 从 analysis['N'] 获取节点电压（N 为节点编号），从 analysis.branches['Vx'] 获取流过电压源 Vx 的电流

基尔霍夫定律和节点电压法是所有电路分析的基石。无论电路多么复杂——从简单的电阻网络到复杂的集成电路——KCL 和 KVL 都在背后保证了"电流不进则出、电压绕圈归零"。

7. 练习 ​

  1. 三网孔电路分析：设计一个包含三个网孔、四个节点（含地）的电路，使用三个电阻和三个电压源。手工列写节点电压方程求解，再用 PySpice 仿真验证。比较手工计算与仿真结果的时间耗用——你更倾向于哪种方法？

  2. 广义节点：在本章电路中，将 V2 和 R2 的支路替换为一个 5 V 的电压源直接接在节点 2 和节点 3 之间（没有 R2）。此时如何列写节点 2 的 KCL 方程？写出超节点方程并用仿真验证。

  3. 负电压源与 KVL 正负号：将 V2 的极性反转（正极接地，负极接节点 3，即 V2 = -5V 的方向）。重新计算节点 2 的电压并验证 KVL。提示：负电压源在绕网孔方向上的符号可能需要仔细考量。

  4. KCL 的推广：在三相电路（第 16 章将详细学习）中，三个负载的星形中点流入的三相电流之和是否为零？如果不为零，电流"去了哪里"？请从 KCL 的物理本质给出解释。
