第2章 叠加定理 ​

1. 本节你将学到 ​

  • 掌握叠加定理：线性电路中，任意支路的响应（电压或电流）等于每个独立源单独作用时在该支路产生的响应之和
  • 理解"独立源单独作用"的含义：其他电压源短路（V=0V=0V=0），其他电流源开路（I=0I=0I=0）
  • 学会对多源电路进行分步仿真——分别仅保留一个独立源，记录部分响应，最后叠加
  • 用 PySpice 同时验证叠加定理的正确性和 KCL 的一致性

2. 知识回顾/情景引入 ​

在第 1 章中，我们用基尔霍夫定律分析了一个双源电路——两个电压源、三个电阻。我们看到了 KCL 在节点 2 上精确成立。当时我们求解节点 2 的电压 V2V_2V2​ 的方法是：对节点 2 列一个 KCL 方程，解一个一元一次方程，直接求出了 V2V_2V2​。

但如果电路中每个支路都有多个独立源参与驱动呢？如果电路不是简单的两个网孔，而是十个网孔、二十个独立源呢？用基尔霍夫定律逐一列写方程当然可行，但有没有更直观的方法来理解每个独立源对最终响应的贡献？

叠加定理（Superposition Theorem）提供了一种"分而治之"的视角。

2.1 线性性的本质 ​

叠加定理依赖于电路的线性性。线性电路满足两个性质：

  1. 齐次性（比例性）：如果输入 xxx 产生输出 yyy，那么输入 kxkxkx 产生输出 kykyky（kkk 为任意常数）
  2. 可加性：如果输入 x1x_1x1​ 产生输出 y1y_1y1​，输入 x2x_2x2​ 产生输出 y2y_2y2​，那么输入 x1+x2x_1 + x_2x1​+x2​ 产生输出 y1+y2y_1 + y_2y1​+y2​

欧姆定律 V=IRV = IRV=IR 是线性的——电流翻倍，电压就翻倍。KCL 和 KVL 都是线性方程。由这些线性元件和线性定律构成的电路，其整体行为也是线性的。

因此，多个独立源同时激发的总效应，可以分解为各个独立源效应的代数和。先计算 V1 单独作用时的电压分布，再计算 V2 单独作用时的电压分布，最后两者相加——这就是叠加定理的核心操作。

2.2 独立源的"关闭"操作 ​

  • 关闭电压源：将其短路（V=0V = 0V=0），即用一根导线代替。等效于该电压源两端被一根导线短接。
  • 关闭电流源：将其开路（I=0I = 0I=0），即将该支路断开。

为什么电压源是"短路"？因为关闭一个电压源意味着它的输出电压为零——而零电压等价于一条导线（理想导线的两端电压降为零）。为什么电流源是"开路"？因为关闭一个电流源意味着它的输出电流为零——而零电流等价于断路。

注意：叠加定理仅适用于独立源。受控源（如 BJT 的受控电流源、运放的输出电压源）不参与叠加——它们在每一步分析中都要保留。

3. 动手设计电路 ​

3.1 本节电路 ​

我们设计一个双电压源三电阻电路，与第 1 章类似但参数不同，以便清晰地演示叠加过程：

  • V2 = 8 V，正端接节点 3，负端接地
  • R1 = 4 kΩ，连接节点 1 和节点 2
  • R2 = 6 kΩ，连接节点 2 和节点 3
  • R3 = 2 kΩ，连接节点 2 和地

4. 用 Python 实现电路仿真 ​

4.1 构建三个电路：两个单源电路和一个双源电路 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import numpy as np

print("叠加定理验证：双源电路")
print("电路: V1=12V → R1=4kΩ → [V2=8V(3) ← R2=6kΩ] → R3=2kΩ → GND")
print()

print("步骤1：仅 V1=12V 作用 (V2 短路为 0V)")
circuit1 = Circuit('Superposition V1 only')
circuit1.V('v1', 1, circuit1.gnd, 12@u_V)
circuit1.R('R1', 1, 2, 4@u_kΩ)
circuit1.R('R3', 2, circuit1.gnd, 2@u_kΩ)
circuit1.R('R2', 2, 3, 6@u_kΩ)
circuit1.V('v2_short', 3, circuit1.gnd, 0@u_V)
sim1 = circuit1.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an1 = sim1.operating_point()
v2_v1 = float(np.array(an1['2']).flat[0])
v3_v1 = float(np.array(an1['3']).flat[0])
print(f"  V2 (中间节点) = {v2_v1:.3f} V")
i_r2_v1 = v2_v1 / 6e3 * 1000
print(f"  I_R2 (V1→R2支路) = {v2_v1/6000*1000:.3f} mA")

print()
print("步骤2：仅 V2=8V 作用 (V1 短路为 0V)")
circuit2 = Circuit('Superposition V2 only')
circuit2.V('v1_short', 1, circuit2.gnd, 0@u_V)
circuit2.R('R1', 1, 2, 4@u_kΩ)
circuit2.R('R3', 2, circuit2.gnd, 2@u_kΩ)
circuit2.R('R2', 2, 3, 6@u_kΩ)
circuit2.V('v2', 3, circuit2.gnd, 8@u_V)
sim2 = circuit2.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an2 = sim2.operating_point()
v2_v2 = float(np.array(an2['2']).flat[0])
v3_v2 = float(np.array(an2['3']).flat[0])
print(f"  V2 (中间节点) = {v2_v2:.3f} V")
i_r2_v2 = (8 - v2_v2) / 6e3 * 1000
print(f"  I_R2 (V2→R2支路) = {(8-v2_v2)/6000*1000:.3f} mA")

print()
print("步骤3：叠加定理 — 响应 = 各独立源单独作用之和")
v2_superposed = v2_v1 + v2_v2
v3_superposed = v3_v1 + v3_v2
print(f"  V2(叠加) = {v2_v1:.3f} + {v2_v2:.3f} = {v2_superposed:.3f} V")
print(f"  V3(叠加) = {v3_v1:.3f} + {v3_v2:.3f} = {v3_superposed:.3f} V")

print()
print("步骤4：双源同时作用 (原始电路)")
circuit3 = Circuit('Superposition Both')
circuit3.V('v1', 1, circuit3.gnd, 12@u_V)
circuit3.R('R1', 1, 2, 4@u_kΩ)
circuit3.R('R3', 2, circuit3.gnd, 2@u_kΩ)
circuit3.R('R2', 2, 3, 6@u_kΩ)
circuit3.V('v2', 3, circuit3.gnd, 8@u_V)
sim3 = circuit3.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an3 = sim3.operating_point()
v2_real = float(np.array(an3['2']).flat[0])
v3_real = float(np.array(an3['3']).flat[0])
print(f"  V2 (原始电路) = {v2_real:.3f} V")
print(f"  V3 (原始电路) = {v3_real:.3f} V")

print()
print("验证叠加定理：")
match2 = abs(v2_superposed - v2_real) < 1e-6
match3 = abs(v3_superposed - v3_real) < 1e-6
print(f"  V2: 叠加值 {v2_superposed:.3f}V vs 真实值 {v2_real:.3f}V → {'PASS' if match2 else 'FAIL'}")
print(f"  V3: 叠加值 {v3_superposed:.3f}V vs 真实值 {v3_real:.3f}V → {'PASS' if match3 else 'FAIL'}")

print()
print("KCL 验证（原始电路 @ 节点2）：")
i_r1 = (12 - v2_real) / 4e3 * 1000
i_r2 = (8 - v2_real) / 6e3 * 1000
i_r3 = v2_real / 2e3 * 1000
print(f"  I_R1 = (12-{v2_real:.3f})/4k = {i_r1:.3f} mA")
print(f"  I_R2 = (8-{v2_real:.3f})/6k = {i_r2:.3f} mA")
print(f"  I_R3 = {v2_real:.3f}/2k = {i_r3:.3f} mA")
print(f"  ΣI_in = I_R1+I_R2 = {i_r1+i_r2:.3f} mA ≈ I_R3 = {i_r3:.3f} mA")

5. 深入理解 ​

5.1 叠加定理与线性代数的联系 ​

从线性代数角度看，叠加定理是线性方程组解的叠加性质的物理体现。节点电压法给出矩阵方程 GV=Is\mathbf{G}\mathbf{V} = \mathbf{I}_sGV=Is​。

如果右端向量 Is\mathbf{I}_sIs​ 可以分解为两个独立部分的贡献，即 Is=Is(1)+Is(2)\mathbf{I}_s = \mathbf{I}_s^{(1)} + \mathbf{I}_s^{(2)}Is​=Is(1)​+Is(2)​（分别对应 V1 和 V2 的等效电流源），那么：

GV=Is(1)+Is(2)\mathbf{G}\mathbf{V} = \mathbf{I}_s^{(1)} + \mathbf{I}_s^{(2)} GV=Is(1)​+Is(2)​

设 V(1)\mathbf{V}^{(1)}V(1) 满足 GV(1)=Is(1)\mathbf{G}\mathbf{V}^{(1)} = \mathbf{I}_s^{(1)}GV(1)=Is(1)​，V(2)\mathbf{V}^{(2)}V(2) 满足 GV(2)=Is(2)\mathbf{G}\mathbf{V}^{(2)} = \mathbf{I}_s^{(2)}GV(2)=Is(2)​，则：

G(V(1)+V(2))=Is(1)+Is(2)=Is\mathbf{G}(\mathbf{V}^{(1)} + \mathbf{V}^{(2)}) = \mathbf{I}_s^{(1)} + \mathbf{I}_s^{(2)} = \mathbf{I}_s G(V(1)+V(2))=Is(1)​+Is(2)​=Is​

所以 V=V(1)+V(2)\mathbf{V} = \mathbf{V}^{(1)} + \mathbf{V}^{(2)}V=V(1)+V(2)——叠加定理是线性方程组解的线性叠加。

5.2 功率不满足叠加定理 ​

一个常见的误区是以为功率也适用叠加定理。功率与电压或电流的平方成正比（P=V2/R=I2RP = V^2/R = I^2 RP=V2/R=I2R），是一个非线性函数，因此不满足叠加定理。

以本章电路为例：R3 上的功率在双源同时作用时为 P3=V22/R3=4.7272/2000=11.17 mWP_3 = V_2^2 / R_3 = 4.727^2 / 2000 = 11.17\text{ mW}P3​=V22​/R3​=4.7272/2000=11.17 mW。而 V1 单独作用时 R3 上的功率为 3.2732/2000=5.36 mW3.273^2 / 2000 = 5.36\text{ mW}3.2732/2000=5.36 mW，V2 单独作用时为 1.4552/2000=1.06 mW1.455^2 / 2000 = 1.06\text{ mW}1.4552/2000=1.06 mW。5.36+1.06=6.42≠11.175.36 + 1.06 = 6.42 \neq 11.175.36+1.06=6.42=11.17。

功率不满足叠加是因为它依赖于电压（或电流）的交叉项：(V1+V2)2=V12+V22+2V1V2(V_1 + V_2)^2 = V_1^2 + V_2^2 + 2V_1V_2(V1​+V2​)2=V12​+V22​+2V1​V2​，其中 2V1V22V_1V_22V1​V2​ 是交叉项，V1 和 V2 同时存在才会出现。

5.3 叠加定理的步骤要点 ​

  1. 每次只保留一个独立源：电压源短路（0 V 源），电流源开路（0 A 源）
  2. 受控源始终保留：受控源的输出取决于电路变量，不是独立激励，不能"关闭"
  3. 记录部分响应：对每个独立源单独作用下的电路，记录所关心的电压或电流
  4. 代数叠加：将所有部分响应按符号代数相加。注意电流的正方向——先定义参考方向，再叠加
  5. 使用 .op 分析验证：在 PySpice 中对每个单源电路执行 operating_point()，汇总结果

6. 本章小结 ​

  • 叠加定理：线性电路中，任意支路的响应 = 各独立源单独作用时的响应之和
  • 独立源"关闭"操作：电压源 → 短路（V=0V=0V=0），电流源 → 开路（I=0I=0I=0）
  • 受控源不参与叠加，所有分析步中都要保留
  • 功率不满足叠加定理（因为功率是电压/电流的二次函数）
  • PySpice 中通过构造多个单源电路执行 .op 分析，收集结果再代数相加，即可验证

叠加定理不仅仅是一个方便的计算方法——它揭示了线性电路"可以由简单的部分组合成复杂整体"的深层结构。在信号处理中，这就是傅里叶分析的基础：任意信号可以分解为若干正弦波之和，电路的响应就是这些正弦波各自响应的叠加。

7. 练习 ​

  1. 三源叠加：在本章电路基础上增加一个电流源 I3I_3I3​ 从节点 2 注入地（与 R3 并联）。计算三个独立源各自单独作用时的 V2，叠加后与三源同时作用的 V2 对比。

  2. 功率不可叠加的数值验证：手动计算 R1、R2、R3 在叠加方法与直接方法下的功率差，指出交叉项的物理含义。

  3. 含受控源的叠加：设计一个包含 VCCS（电压控制电流源）的电路。分析为什么受控源不能"关闭"，尝试"关闭"它并观察结果——你会发现叠加失效。

  4. 叠加定理与戴维南定理的联系：叠加定理可以用来求戴维南等效电阻吗？如何把戴维南定理看作叠加定理的一个特例？
