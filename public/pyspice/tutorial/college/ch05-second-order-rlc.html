第5章 二阶 RLC 动态电路 ​

1. 本节你将学到 ​

  • 掌握二阶 RLC 电路的三种阻尼状态：欠阻尼、临界阻尼、过阻尼
  • 理解阻尼比 ζ=R2CL\zeta = \frac{R}{2}\sqrt{\frac{C}{L}}ζ=2R​LC​​ 的物理意义及判断准则
  • 掌握临界阻尼电阻 Rcrit=2L/CR_{crit} = 2\sqrt{L/C}Rcrit​=2L/C​ 的概念
  • 学会用 PySpice 的 .transient() 分析二阶电路，观察电容电压的过渡过程
  • 能区分三种阻尼状态的波形特征：振荡衰减、单调无超调、快速无振荡

2. 知识回顾/情景引入 ​

第 4 章我们分析了一阶 RC/RL 电路——含一个储能元件的电路，响应是一条纯粹的指数曲线，单调地逼近终值（或从初值衰减到零）。虽然存在时间常数 τ 来控制"快慢"，但波形的形状总是单调的——不会出现振荡。

但现实中的电路振荡无处不在。你是否在插拔耳机时听到过"嘣"的一声？那是插头的瞬时接触让耳机线圈（电感）和电路板上的滤波电容形成了一个临时 LC 谐振回路。音响喇叭的分频器；开关电源的输出 LC 滤波网络；甚至一栋大楼的刚结构在地震中的摆动——都是二阶系统的典型行为。

2.1 从一阶到二阶 ​

在一阶电路中，电容充放电是单向的——电压只上升或只下降。但当电路中同时存在电容和电感时，能量可以在两种储能元件之间来回振荡：电容释放能量给电感（电容电压下降，电感电流上升），电感又释放能量给电容（电感电流下降，电容电压上升）——就像钟摆的动能和势能互相转换。

电阻 R 在这个振荡过程中扮演了"阻尼"的角色——消耗能量，阻碍振荡。R 的大小决定了振荡的剧烈程度，这正是本章的核心内容。

2.2 二阶微分方程 ​

串联 RLC 电路的微分方程：

LCd2vcdt2+RCdvcdt+vc=vsLC\frac{d^2v_c}{dt^2} + RC\frac{dv_c}{dt} + v_c = v_s LCdt2d2vc​​+RCdtdvc​​+vc​=vs​

标准形式：d2vcdt2+2αdvcdt+ω02vc=ω02vs\frac{d^2v_c}{dt^2} + 2\alpha\frac{dv_c}{dt} + \omega_0^2 v_c = \omega_0^2 v_sdt2d2vc​​+2αdtdvc​​+ω02​vc​=ω02​vs​

其中 α=R/(2L)\alpha = R/(2L)α=R/(2L)（阻尼系数），ω0=1/LC\omega_0 = 1/\sqrt{LC}ω0​=1/LC​（无阻尼自然频率）。

阻尼比 ζ\zetaζ 的定义为：

ζ=αω0=R2CL\zeta = \frac{\alpha}{\omega_0} = \frac{R}{2}\sqrt{\frac{C}{L}} ζ=ω0​α​=2R​LC​​

2.3 三种阻尼状态 ​

ζ\zetaζ 范围阻尼状态特征方程根波形特征
ζ<1\zeta < 1ζ<1欠阻尼一对共轭复根振荡衰减，有超调，有振铃
ζ=1\zeta = 1ζ=1临界阻尼两个相等实根单调逼近，无超调，响应最快
ζ>1\zeta > 1ζ>1过阻尼两个不等实根单调逼近，无超调，响应慢

临界阻尼电阻：Rcrit=2L/CR_{crit} = 2\sqrt{L/C}Rcrit​=2L/C​。当 R=RcritR = R_{crit}R=Rcrit​ 时 ζ=1\zeta = 1ζ=1。

临界阻尼（R ≈ 63 Ω，ζ≈1.0\zeta \approx 1.0ζ≈1.0）：

  • 响应最快到达终值，无超调，无振荡
  • 类似一阶响应但更快

过阻尼（R = 200 Ω，ζ=3.16\zeta = 3.16ζ=3.16）：

  • 两个衰减指数项叠加，慢的指数项主导
  • 到达终值比临界阻尼更慢

4. 用 Python 实现电路仿真 ​

4.1 三种阻尼状态的瞬态仿真 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

L_val = 10e-3
C_val = 10e-6
R_crit = 2 * np.sqrt(L_val / C_val)
omega0 = 1 / np.sqrt(L_val * C_val)

print("2nd-Order RLC Circuit Damping Analysis")
print(f"L = {L_val*1e3:.0f} mH, C = {C_val*1e6:.0f} uF")
print(f"Resonant freq w0 = 1/sqrt(LC) = {omega0:.1f} rad/s, f0 = {omega0/(2*np.pi):.1f} Hz")
print(f"Critical damping R = 2*sqrt(L/C) = {R_crit:.1f} Ω")
print()

results = {}
for r_val, label in [(20, 'Underdamped'), (63, 'Critically damped'), (200, 'Overdamped')]:
    circuit = Circuit(f'RLC {label}')
    circuit.V('pulse', 1, circuit.gnd, 10@u_V)
    circuit.R('R1', 1, 2, r_val@u_Ω)
    circuit.L('L1', 2, 3, 10@u_mH)
    circuit.C('C1', 3, circuit.gnd, 10@u_uF)

    sim = circuit.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
    analysis = sim.transient(step_time=50@u_us, end_time=10@u_ms)

    time = np.array(analysis.time) * 1000
    vc = np.array(analysis['3'])
    results[label] = (time, vc, r_val)
    print(f"R = {r_val} Ω ({label}): Vc steady = {vc[-1]:.3f} V, Vc peak = {np.max(vc):.3f} V")

print()
print("Theoretical damping analysis:")
for r_val, label in [(20, 'Underdamped'), (63, 'Critically damped'), (200, 'Overdamped')]:
    zeta = r_val / 2 * np.sqrt(C_val / L_val)
    alpha = r_val / (2 * L_val)
    if label == 'Underdamped':
        omega_d = np.sqrt(omega0**2 - alpha**2)
        print(f"  {label} (R={r_val}Ω): ζ={zeta:.2f}, α={alpha:.0f} rad/s, ωd={omega_d:.0f} rad/s")
    else:
        print(f"  {label} (R={r_val}Ω): ζ={zeta:.2f}, α={alpha:.0f} rad/s")

5. 深入理解 ​

5.1 ζ\zetaζ 的控制意义 ​

阻尼比 ζ\zetaζ 为什么定义为 R2CL\frac{R}{2}\sqrt{\frac{C}{L}}2R​LC​​？从特征方程 LCs2+RCs+1=0LCs^2 + RCs + 1 = 0LCs2+RCs+1=0 出发，判别式 Δ=R2C2−4LC\Delta = R^2C^2 - 4LCΔ=R2C2−4LC：

  • Δ<0\Delta < 0Δ<0 → ζ<1\zeta < 1ζ<1 → 共轭复根 → 振荡衰减 → 欠阻尼
  • Δ=0\Delta = 0Δ=0 → ζ=1\zeta = 1ζ=1 → 等实根 → 临界无超调 → 临界阻尼
  • Δ>0\Delta > 0Δ>0 → ζ>1\zeta > 1ζ>1 → 不等实根 → 缓慢趋近 → 过阻尼

注意 ζ\zetaζ 只取决于 RRR、LLL、CCC 三者的组合——改变任何一个都会改变阻尼特性。增大 R 总是使阻尼增强（ζ 上升），但这同时也增加了功耗。工程中需要在阻尼和功耗之间做折中。

5.2 临界阻尼 vs 欠阻尼：工程选择 ​

临界阻尼（ζ=1\zeta = 1ζ=1）提供最快无超调响应——对于伺服电机控制、电梯起停、主动悬架这类不允许振荡又追求快速响应的系统，ζ=1\zeta = 1ζ=1 是最优选择。

但有些应用故意选欠阻尼（ζ<1\zeta < 1ζ<1）——比如 LC 振荡器、射频调谐电路、压电蜂鸣器驱动。欠阻尼的超调和振铃在振荡电路中反而是"有用信号"。

过阻尼（ζ>1\zeta > 1ζ>1）常见于"宁慢勿振"的安全关键系统——比如核反应堆控制棒驱动、大型起重机负载摆动阻尼。

5.3 二阶电路与控制系统 ​

二阶 RLC 电路是经典控制理论中最基础的标准模型。DC 电机的传递函数、弹簧-质量-阻尼系统、甚至经济学中的库存波动模型，都可以映射到形式为 ω02s2+2ζω0s+ω02\frac{\omega_0^2}{s^2 + 2\zeta\omega_0 s + \omega_0^2}s2+2ζω0​s+ω02​ω02​​ 的二阶传递函数上。

这就是为什么电路理论的学习不只是"学会算电路"——它也是你步入控制工程、信号处理、电力系统分析等领域的通用语言。

5.4 .transient() 的精度与步长 ​

对于二阶电路尤其是欠阻尼情况，振荡频率可能高达数 kHz。仿真步长 step_time 需要至少比振荡周期的 1/101/101/10 更小才能准确捕捉波形。本章使用 step_time=50@u_us（50 μs），对于 500 Hz 的振荡频率（周期 2 ms）是足够精细的。

6. 本章小结 ​

  • 二阶 RLC 电路：当电路同时包含 L 和 C 时，产生二阶动态行为
  • 阻尼比 ζ=R2CL\zeta = \frac{R}{2}\sqrt{\frac{C}{L}}ζ=2R​LC​​ 决定阻尼状态
  • 欠阻尼（ζ<1\zeta<1ζ<1）：振荡衰减，有超调。欠阻尼自然频率 ωd=ω01−ζ2\omega_d = \omega_0\sqrt{1-\zeta^2}ωd​=ω0​1−ζ2​
  • 临界阻尼（ζ=1\zeta=1ζ=1）：最快无超调响应。Rcrit=2L/CR_{crit} = 2\sqrt{L/C}Rcrit​=2L/C​
  • 过阻尼（ζ>1\zeta>1ζ>1）：单调但缓慢，无超调
  • PySpice 的 .transient() 仿真配合不同 R 值可以清晰地展示三种阻尼状态的波形差异

二阶电路是电路分析的重要里程碑——从这里开始，电路不再只是单调的充放电曲线，而是展现出丰富的动态行为：振荡、阻尼、超调、振铃。这些概念在控制工程、电力电子、通信系统中都有广泛应用。

7. 练习 ​

  1. 阻尼比精确计算：对 R = 10 Ω 的情况（ζ ≈ 0.16），仿真电容电压波形。与 R = 20 Ω（ζ ≈ 0.32）对比：振荡频率和衰减速度有何变化？解释为什么 RRR 越小衰减反而越快（提示：电流越大）。

  2. 临界阻尼验证：通过二分搜索法（多次仿真，不断逼近），找到使电容电压刚好无超调的最小 R 值。这个值与理论值 Rcrit=2L/CR_{crit} = 2\sqrt{L/C}Rcrit​=2L/C​ 比较，误差来自哪里？

  3. LC 振荡器（R=0）：将 R 设为极小值（如 0.01 Ω），仿真纯 LC 电路的振荡行为。实测振荡频率是否等于 f0=1/(2πLC)f_0 = 1/(2\pi\sqrt{LC})f0​=1/(2πLC​)？注意 R=0 是理想情况，现实中的电感线圈总有寄生电阻（DCR）。
