2. 知识回顾/情景引入 ​

第 6 章我们引入了频率响应的概念——电路的输出随输入信号频率而变化。我们看到了 RC 串联电路输出电容电压时，高频信号被衰减而低频信号几乎完美通过——这就是低通滤波器的行为。

第 7 章我们研究了 RL 电路中的功率特性，注意到电感的高频阻抗导致了显著的相位滞后。

本章将频率响应的概念系统化——从传递函数出发，设计低通和高通两种 RC 滤波器，绘制它们的 Bode 图，并通过截止频率 fcf_cfc​ 量化"通带"和"阻带"的边界。

2.1 传递函数的系统视角 ​

一个线性时不变电路可以用其传递函数 H(jω)H(j\omega)H(jω) 完全描述：

H(jω)=Vout(jω)Vin(jω)H(j\omega) = \frac{V_{out}(j\omega)}{V_{in}(j\omega)} H(jω)=Vin​(jω)Vout​(jω)​

传递函数是频率的复函数——它包含两部分信息：

  • 幅频特性 ∣H(jω)∣|H(j\omega)|∣H(jω)∣：输出信号幅值相对于输入信号的缩放比例
  • 相频特性 ∠H(jω)\angle H(j\omega)∠H(jω)：输出信号相对于输入信号的相位偏移

在工程中，我们通常用Bode 图来呈现：横轴为频率（对数刻度），纵轴为增益 20log⁡10∣H(jω)∣20\log_{10}|H(j\omega)|20log10​∣H(jω)∣（dB）和相位（度）。Bode 图是分析和设计滤波器的标准工具。

2.2 低通滤波器（LPF） ​

将 RC 串联电路的输出取在电容两端：

HLP(jω)=1/(jωC)R+1/(jωC)=11+jωRCH_{LP}(j\omega) = \frac{1/(j\omega C)}{R + 1/(j\omega C)} = \frac{1}{1 + j\omega RC} HLP​(jω)=R+1/(jωC)1/(jωC)​=1+jωRC1​

在低频时（ω≪1/(RC)\omega \ll 1/(RC)ω≪1/(RC)），分母趋近于 1，∣H∣→1|H| \to 1∣H∣→1（0 dB）——信号通过。

在高频时（ω≫1/(RC)\omega \gg 1/(RC)ω≫1/(RC)），分母趋近于 jωRCj\omega RCjωRC，∣H∣→1/(ωRC)|H| \to 1/(\omega RC)∣H∣→1/(ωRC)——信号以 -20 dB/decade 的斜率衰减。

截止频率 fc=12πRCf_c = \frac{1}{2\pi RC}fc​=2πRC1​：∣H(fc)∣=1/2≈0.707|H(f_c)| = 1/\sqrt{2} \approx 0.707∣H(fc​)∣=1/2​≈0.707（-3.01 dB），∠H=−45∘\angle H = -45^\circ∠H=−45∘。

2.3 高通滤波器（HPF） ​

将 RC 滤波器的 R 和 C 交换位置（输出取在电阻两端），就得到高通滤波器：

HHP(jω)=RR+1/(jωC)=jωRC1+jωRCH_{HP}(j\omega) = \frac{R}{R + 1/(j\omega C)} = \frac{j\omega RC}{1 + j\omega RC} HHP​(jω)=R+1/(jωC)R​=1+jωRCjωRC​

在低频时（ω≪1/(RC)\omega \ll 1/(RC)ω≪1/(RC)），∣H∣→ωRC→0|H| \to \omega RC \to 0∣H∣→ωRC→0——信号被衰减。

在高频时（ω≫1/(RC)\omega \gg 1/(RC)ω≫1/(RC)），∣H∣→1|H| \to 1∣H∣→1——信号通过。

截止频率同样是 fc=1/(2πRC)f_c = 1/(2\pi RC)fc​=1/(2πRC)，但相位 ∠H(fc)=+45∘\angle H(f_c) = +45^\circ∠H(fc​)=+45∘（输出超前输入）。

4. 用 Python 实现电路仿真 ​

4.1 低通和高通滤波器的 .ac() 扫频 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

R = 1e3
C = 100e-9
fc = 1 / (2 * np.pi * R * C)

print("=== Frequency Response & Filters ===")
print(f"R = {R/1e3} kΩ, C = {C*1e9} nF")
print(f"Cutoff frequency fc = 1/(2πRC) = {fc:.1f} Hz")
print()

# Low-Pass Filter: output across capacitor
circuit_lp = Circuit('RC Low-Pass')
circuit_lp.SinusoidalVoltageSource('ac', 1, circuit_lp.gnd, amplitude=1@u_V)
circuit_lp.R('R1', 1, 2, R@u_Ω)
circuit_lp.C('C1', 2, circuit_lp.gnd, C@u_F)
sim_lp = circuit_lp.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_lp = sim_lp.ac(start_frequency=1@u_Hz, stop_frequency=1@u_MHz,
                   number_of_points=500, variation='dec')

freq_lp = np.array(an_lp.frequency)
v_out_lp = np.array(an_lp['2'])
mag_lp = np.abs(v_out_lp)
phase_lp = np.angle(v_out_lp, deg=True)
db_lp = 20 * np.log10(mag_lp)

idx_fc_lp = np.argmin(np.abs(freq_lp - fc))
print(f"Low-Pass @ fc={fc:.1f} Hz:")
print(f"  |H| = {mag_lp[idx_fc_lp]:.4f} (theory 1/√2 = {1/np.sqrt(2):.4f})")
print(f"  Gain = {db_lp[idx_fc_lp]:.2f} dB (theory -3.01 dB)")
print(f"  Phase = {phase_lp[idx_fc_lp]:.1f} deg (theory -45 deg)")

# High-Pass Filter: output across resistor
circuit_hp = Circuit('RC High-Pass')
circuit_hp.SinusoidalVoltageSource('ac', 1, circuit_hp.gnd, amplitude=1@u_V)
circuit_hp.C('C1', 1, 2, C@u_F)
circuit_hp.R('R1', 2, circuit_hp.gnd, R@u_Ω)
sim_hp = circuit_hp.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_hp = sim_hp.ac(start_frequency=1@u_Hz, stop_frequency=1@u_MHz,
                   number_of_points=500, variation='dec')

freq_hp = np.array(an_hp.frequency)
v_out_hp = np.array(an_hp['2'])
mag_hp = np.abs(v_out_hp)
phase_hp = np.angle(v_out_hp, deg=True)
db_hp = 20 * np.log10(mag_hp)

idx_fc_hp = np.argmin(np.abs(freq_hp - fc))
print(f"High-Pass @ fc={fc:.1f} Hz:")
print(f"  |H| = {mag_hp[idx_fc_hp]:.4f} (theory 1/√2 = {1/np.sqrt(2):.4f})")
print(f"  Gain = {db_hp[idx_fc_hp]:.2f} dB (theory -3.01 dB)")
print(f"  Phase = {phase_hp[idx_fc_hp]:.1f} deg (theory +45 deg)")

5. 深入理解 ​

5.1 Bode 图的频率轴和 dB 轴 ​

为什么 Bode 图用对数频率轴？因为在实际工程中我们关心从 Hz 到 MHz 甚至 GHz 的超宽频范围——用线性轴会导致低频区域被压缩得无法辨认。对数轴让每个十倍频程（decade）都占据相同的视觉宽度，这符合人耳对音高的感知（如 100 Hz 到 200 Hz 的提升与 1 kHz 到 2 kHz 的提升在听感上是等价的）。

为什么用 dB？因为信号幅值可能跨越几个数量级，直接用线性电压幅值绘图会让小值"贴在地板上"。20 dB/decade 的斜率（一阶滤波器的高频衰减率）在对数-对数坐标上表现为一条直线，非常直观。

5.2 -3dB 的"一半功率点" ​

当 ∣H∣=1/2|H| = 1/\sqrt{2}∣H∣=1/2​ 时，输出功率 Pout∝Vout2∝∣H∣2=1/2P_{out} \propto V_{out}^2 \propto |H|^2 = 1/2Pout​∝Vout2​∝∣H∣2=1/2——即输出功率恰好为输入功率的一半（-3 dB = 10log⁡10(1/2)10\log_{10}(1/2)10log10​(1/2)）。这就是截止频率被称为"半功率点"的原因。

在音频工程中，-3dB 截止频率决定了扬声器或耳机的频率响应范围。标称 "20 Hz - 20 kHz" 意味着在这两个频率处增益刚好下降 3 dB。

5.4 二阶滤波器与本节的关联 ​

一阶 RC 滤波器的高频衰减斜率为 -20 dB/decade（每十倍频程衰减到原值的十分之一）。如果需要更陡峭的衰减（如 -40 dB/decade），需要级联两个一阶滤波器——形成二阶滤波器。这将在后续章节的运放有源滤波器、LC 谐振滤波器中讨论。

6. 本章小结 ​

  • 传递函数 H(jω)H(j\omega)H(jω) 完整描述了电路在不同频率下的响应
  • 低通滤波器（LPF）：RC 串联，输出取电容电压。fc=1/(2πRC)f_c = 1/(2\pi RC)fc​=1/(2πRC)
  • 高通滤波器（HPF）：CR 串联，输出取电阻电压。fc=1/(2πRC)f_c = 1/(2\pi RC)fc​=1/(2πRC)
  • Bode 图：增益 20log⁡10∣H∣20\log_{10}|H|20log10​∣H∣ 和相位 ∠H\angle H∠H 随频率变化的两张图
  • fcf_cfc​ 是 -3dB 截止频率（半功率点）：∣H(fc)∣=1/2|H(f_c)| = 1/\sqrt{2}∣H(fc​)∣=1/2​
  • PySpice 的 .ac() 配合对数频率扫描是绘制 Bode 图的标准方法

滤波器是信号处理和电子系统的基石——从音频均衡器到无线通信的频道选择，从电源纹波抑制到传感器信号调理，无处不是滤波器。掌握频率响应分析的方法，你就掌握了从"时域直觉"迈向"频域思维"的关键钥匙。

7. 练习 ​

  1. RC 带通滤波器：将 LPF 和 HPF 串联（R-C-R-C 级联），取中间电阻的电压作为输出。扫描其频率响应，找到 -3dB 带宽。两个截止频率各自由哪一级决定？

  2. 截止频率的可调性：固定 R = 1 kΩ，变化 C 从 10 nF 到 1 μF，用仿真画出不同 C 值下的 LPF Bode 幅频图。观察 fcf_cfc​ 如何随 C 变化？这种变化在什么应用场景中是有用的？

  3. 相位差与滤波类型：对 LPF 和 HPF 分别提取 fc/10f_c/10fc​/10、fcf_cfc​、10fc10f_c10fc​ 三个频率处的相位值。验证 LPF 相位从 0° 渐近到 -90°，HPF 相位从 +90° 渐近到 0°。
