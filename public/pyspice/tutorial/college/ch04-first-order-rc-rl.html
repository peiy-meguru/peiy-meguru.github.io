第4章 一阶 RC/RL 动态电路 ​

1. 本节你将学到 ​

  • 掌握一阶电路的三种响应：零输入响应、零状态响应、全响应
  • 理解时间常数 τ\tauτ 的物理意义：RC 电路 τ=RC\tau = RCτ=RC，RL 电路 τ=L/R\tau = L/Rτ=L/R
  • 掌握三要素法 y(t)=y(∞)+[y(0)−y(∞)]e−t/τy(t) = y(\infty) + [y(0) - y(\infty)] e^{-t/\tau}y(t)=y(∞)+[y(0)−y(∞)]e−t/τ
  • 学会用 PySpice 的 .transient() 瞬态分析观察电容充放电和电感电流建立过程
  • 使用 PulseVoltageSource 产生阶跃信号，驱动动态电路

2. 知识回顾/情景引入 ​

前几章我们分析的都是直流稳态电路——开关闭合后经过足够长时间，所有电压和电流都不再变化。但开关闭合的那一瞬间呢？从"一切为零"到"稳定运行"之间，到底发生了什么？

高中篇我们学过电容的充放电——电容两端的电压不能突变，而是按指数规律逐渐逼近终值。但我们只看了简单的 RC 充电曲线，没有深入探讨"零输入、零状态、全响应"这三种经典情况，也没有涉及 RL 电路。

高校篇需要建立完整的一阶动态电路分析框架。

2.1 什么是一阶电路 ​

一阶电路是指仅含一个储能元件（一个电容 或 一个电感）的电路。这样的电路可以用一阶微分方程描述：

RC 电路：dvcdt+1RCvc=1RCvs(t)\frac{dv_c}{dt} + \frac{1}{RC}v_c = \frac{1}{RC}v_s(t)dtdvc​​+RC1​vc​=RC1​vs​(t)

RL 电路：diLdt+RLiL=1Lvs(t)\frac{di_L}{dt} + \frac{R}{L}i_L = \frac{1}{L}v_s(t)dtdiL​​+LR​iL​=L1​vs​(t)

这两个方程在数学上是完全同构的——只需将 vcv_cvc​ 换成 iLi_LiL​，RCRCRC 换成 L/RL/RL/R。

2.2 时间常数的物理意义 ​

时间常数 τ\tauτ 是衡量一阶电路响应快慢的核心参数：

  • RC 电路：τ=RC\tau = RCτ=RC（单位：秒）。τ 越大，充放电越慢。100 μF 的电容通过 1 kΩ 的电阻充电，τ = 100 ms——大约 0.1 秒达到 63.2%，约 0.5 秒基本充满。
  • RL 电路：τ=L/R\tau = L/Rτ=L/R（单位：秒）。τ 越大，电流建立越慢。0.1 H 的电感串联 100 Ω 电阻，τ = 1 ms——电感电流在 1 ms 内达到 63.2%。

在 t=τt = \taut=τ 时，响应到达终值的 (1−e−1)≈63.2%(1 - e^{-1}) \approx 63.2\%(1−e−1)≈63.2%（零状态）或初值的 e−1≈36.8%e^{-1} \approx 36.8\%e−1≈36.8%（零输入）。在 t=5τt = 5\taut=5τ 时，响应到达终值的 99.3%，工程上认为已进入"稳态"。

4. 用 Python 实现电路仿真 ​

4.1 零状态响应、零输入响应、RL 响应 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

print("=== First-Order RC/RL Dynamic Circuits ===")
print()

R = 1e3
C = 100e-6
tau_rc = R * C
print(f"RC Circuit: R = {R/1e3:.0f} kΩ, C = {C*1e6:.0f} μF, τ = RC = {tau_rc*1000:.1f} ms")

# RC 零状态响应（充电）
circuit_rc_zs = Circuit('RC Zero-State')
circuit_rc_zs.PulseVoltageSource('pulse', 1, circuit_rc_zs.gnd,
                                 initial_value=0@u_V, pulsed_value=5@u_V,
                                 delay_time=0, rise_time=1@u_us,
                                 fall_time=1@u_us,
                                 pulse_width=500@u_ms, period=1000@u_ms)
circuit_rc_zs.R('R1', 1, 2, R@u_Ω)
circuit_rc_zs.C('C1', 2, circuit_rc_zs.gnd, C@u_F)

sim_zs = circuit_rc_zs.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_zs = sim_zs.transient(step_time=1@u_ms, end_time=500@u_ms)

time_zs = np.array(an_zs.time) * 1000
vc_zs = np.array(an_zs['2'])

idx_tau = np.argmin(np.abs(time_zs - tau_rc*1000))
print(f"  t=τ={tau_rc*1000:.1f}ms: Vc = {vc_zs[idx_tau]:.3f} V")
print(f"  Theory Vc(τ) = 5*(1-e^-1) = {5*(1-np.exp(-1)):.3f} V")

# RC 零输入响应（放电）
circuit_rc_zi = Circuit('RC Zero-Input')
circuit_rc_zi.PulseVoltageSource('pulse', 1, circuit_rc_zi.gnd,
                                 initial_value=5@u_V, pulsed_value=0@u_V,
                                 delay_time=0, rise_time=1@u_us,
                                 fall_time=1@u_us,
                                 pulse_width=500@u_ms, period=1000@u_ms)
circuit_rc_zi.R('R1', 1, 2, R@u_Ω)
circuit_rc_zi.C('C1', 2, circuit_rc_zi.gnd, C@u_F)

sim_zi = circuit_rc_zi.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_zi = sim_zi.transient(step_time=1@u_ms, end_time=500@u_ms)

time_zi = np.array(an_zi.time) * 1000
vc_zi = np.array(an_zi['2'])
print(f"  t=τ={tau_rc*1000:.1f}ms: Vc = {vc_zi[idx_tau_zi]:.3f} V")
print(f"  Theory Vc(τ) = 5*e^-1 = {5*np.exp(-1):.3f} V")

# RL 零状态响应
RL, LL = 100, 0.1
tau_rl = LL / RL
circuit_rl = Circuit('RL Zero-State')
circuit_rl.PulseVoltageSource('pulse', 1, circuit_rl.gnd,
                              initial_value=0@u_V, pulsed_value=5@u_V,
                              delay_time=0, rise_time=1@u_ns,
                              fall_time=1@u_ns,
                              pulse_width=10@u_ms, period=20@u_ms)
circuit_rl.R('R1', 1, 2, RL@u_Ω)
circuit_rl.L('L1', 2, circuit_rl.gnd, LL@u_H)

sim_rl = circuit_rl.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_rl = sim_rl.transient(step_time=0.01@u_ms, end_time=5@u_ms)

time_rl = np.array(an_rl.time) * 1000
v_rl = np.array(an_rl['2'])
i_rl = (np.array(an_rl['1']) - v_rl) / RL
print(f"  t=τ={tau_rl*1000:.1f}ms: I = {i_rl[idx_tau_rl]:.3f} A")
print(f"  Steady state: I = {i_rl[-1]:.3f} A (theory: {5/RL:.3f} A)")

5. 深入理解 ​

5.1 时间常数 τ 的"63.2% 法则" ​

为什么偏偏是 63.2%？这源于自然常数 eee 的数学性质。在零状态响应中 y(τ)=y∞(1−e−1)y(\tau) = y_\infty(1 - e^{-1})y(τ)=y∞​(1−e−1)，e−1≈0.3679e^{-1} \approx 0.3679e−1≈0.3679，所以 1−e−1≈0.63211 - e^{-1} \approx 0.63211−e−1≈0.6321。

这个 63.2% 给了我们一个快速估算方法：测量电容充电到终值 63.2% 所需的时间，就是时间常数 τ。这个"63.2% 法则"在实验调试中非常实用——用示波器观察 RC 充电波形，找到 63.2% 对应的时间坐标，τ 就出来了。

5.2 RC 与 RL 的对偶关系 ​

RC 电路和 RL 电路之间存在完美的对偶关系：

物理量RC 电路RL 电路
储能元件电容 C电感 L
状态变量电压 vcv_cvc​电流 iLi_LiL​
不能突变vcv_cvc​（电压）iLi_LiL​（电流）
时间常数τ=RC\tau = RCτ=RCτ=L/R\tau = L/Rτ=L/R
零状态响应vc=Vs(1−e−t/τ)v_c = V_s(1-e^{-t/\tau})vc​=Vs​(1−e−t/τ)iL=(Vs/R)(1−e−t/τ)i_L = (V_s/R)(1-e^{-t/\tau})iL​=(Vs​/R)(1−e−t/τ)

对偶意味着：将 RC 电路中的 R 换成 1/R1/R1/R、电容 C 换成电感 L、串联换成并联、电压源换成电流源，就可以得到等效的 RL 电路行为。这种对偶性在电路设计中经常被利用——比如设计一个"快速充电"场景，在 RC 电路中需要减小 R 或 C，在 RL 电路中需要减小 L 或增大 R。

5.3 三要素法的推导 ​

三要素法 y(t)=y(∞)+[y(0)−y(∞)]e−t/τy(t) = y(\infty) + [y(0) - y(\infty)] e^{-t/\tau}y(t)=y(∞)+[y(0)−y(∞)]e−t/τ 的推导：

一阶线性微分方程 τdydt+y=y∞\tau \frac{dy}{dt} + y = y_\inftyτdtdy​+y=y∞​ 的通解为：

y(t)=y∞+Ae−t/τy(t) = y_\infty + A e^{-t/\tau} y(t)=y∞​+Ae−t/τ

代入初始条件 y(0)=y0y(0) = y_0y(0)=y0​，得 y0=y∞+Ay_0 = y_\infty + Ay0​=y∞​+A，解出 A=y0−y∞A = y_0 - y_\inftyA=y0​−y∞​。

∴y(t)=y∞+(y0−y∞)e−t/τ\therefore y(t) = y_\infty + (y_0 - y_\infty) e^{-t/\tau} ∴y(t)=y∞​+(y0​−y∞​)e−t/τ

三个要素是：初始值 y(0)y(0)y(0)、稳态值 y(∞)y(\infty)y(∞)、时间常数 τ\tauτ。给定这三者，任意时刻的响应就被完整确定了——不需要每次求解微分方程。

5.4 PulseVoltageSource 的使用 ​

PulseVoltageSource 是瞬态仿真中最常用的信号源。其参数含义：

参数含义本章取值
initial_value脉冲初始电压0 V
pulsed_value脉冲高电压5 V
delay_time延迟时间0
rise_time上升时间1 μs
fall_time下降时间1 μs
pulse_width脉冲宽度（高电平持续时间）500 ms
period脉冲周期1000 ms

对于阶跃响应，我们让 pulse_width 远大于 τ（如 5 倍），保证电路在脉冲高电平期间有足够时间到达稳态。rise_time 不能设得太短，否则可能引起收敛问题；1 μs 是一个安全的折中选择。

6. 本章小结 ​

  • 一阶电路：含一个电容或一个电感的动态电路，用一阶微分方程描述
  • 时间常数：RC 电路 τ=RC\tau = RCτ=RC，RL 电路 τ=L/R\tau = L/Rτ=L/R
  • 零输入响应 y(t)=y0e−t/τy(t) = y_0 e^{-t/\tau}y(t)=y0​e−t/τ，零状态响应 y(t)=y∞(1−e−t/τ)y(t) = y_\infty(1 - e^{-t/\tau})y(t)=y∞​(1−e−t/τ)
  • 三要素法：y(t)=y(∞)+[y(0)−y(∞)]e−t/τy(t) = y(\infty) + [y(0) - y(\infty)] e^{-t/\tau}y(t)=y(∞)+[y(0)−y(∞)]e−t/τ，统摄全部一阶电路问题
  • PulseVoltageSource + .transient() 是仿真一阶动态响应的标准方法

"电容电压不能突变，电感电流不能突变"——这句话是一阶电路分析的"直觉锚点"。从这出发，配合三要素法和 PySpice 仿真，你就能应对任何一阶电路问题。

7. 练习 ​

  1. 时间常数测量：修改仿真代码，让 pulse_width 仅为 50 ms（0.5τ）。在每次脉冲结束时，电容电压到达了终值的百分之多少？这种"脉冲宽度小于 5τ"的情况在数字电路（时钟信号驱动的 RC 网络）中很常见——研究一下它对信号完整性的影响。

  2. RL 放电响应：修改 RL 电路，将 PulseVoltageSource 设为从 5V 跳到 0V（initial=5V, pulsed=0V），观察电感电流的衰减。验证 iL(τ)=0.05×e−1=0.0184i_L(\tau) = 0.05 \times e^{-1} = 0.0184iL​(τ)=0.05×e−1=0.0184 A。

  3. 全响应手算与仿真：设 RC 电路初始 Vc(0)=3V_c(0) = 3Vc​(0)=3 V，电压源阶跃到 2 V。手工计算 Vc(t)V_c(t)Vc​(t) 的表达式（注意 y∞=2y_\infty = 2y∞​=2 V），然后用仿真验证 Vc(100 ms)V_c(100\text{ ms})Vc​(100 ms) 的值。

  4. 时间常数设计：你需要设计一个 RC 低通滤波器，要求其在 1 kHz 方波输入下，电容电压在 1 ms 内达到终值的 95% 以上。选择合适的 R 和 C 值，并用仿真验证你的设计。
