第11章 双极型晶体管 (BJT) ​

1. 本节你将学到 ​

  • 掌握 BJT 的三层半导体结构（NPN / PNP）及三个工作区域：截止、放大、饱和
  • 理解直流偏置的概念：用电阻分压网络将晶体管"固定"在放大区工作点（Q 点）
  • 掌握小信号参数：跨导 gm=IC/VTg_m = I_C / V_Tgm​=IC​/VT​，电流增益 β=IC/IB\beta = I_C / I_Bβ=IC​/IB​
  • 理解共发射极放大器（CE Amplifier）的工作原理及电压增益 Av≈−gmRCA_v \approx -g_m R_CAv​≈−gm​RC​
  • 学会用 PySpice 的 Q 元件建立晶体管电路，进行 DC 分析和瞬态分析

2. 知识回顾/情景引入 ​

第 10 章我们认识了二极管——一个 PN 结，电流只能单向流动。如果把两个背靠背的 PN 结"叠"在一起——N 型- P 型- N 型，或者 P 型- N 型- P 型——就得到了双极型晶体管（Bipolar Junction Transistor, BJT）。

BJT 是发明于 1947 年的第一种固态放大器件，它开启了半导体电子学的时代。虽然今天 MOSFET 在数字电路中占据主导地位，BJT 在模拟电路中（特别是音频放大器和射频电路）依然活跃——因为它的跨导 gmg_mgm​ 更高，噪声更低。

2.1 NPN 晶体管的结构和工作原理 ​

BJT 有三个端子：发射极（Emitter, E）、基极（Base, B）、集电极（Collector, C）。NPN 管的内部结构是 N-P-N——两个 N 型区夹着一个很薄的 P 型区。

基极-发射极之间的 PN 结是正向偏置的（VBE≈0.7V_{BE} \approx 0.7VBE​≈0.7 V），基极-集电极之间的 PN 结是反向偏置的。发射极注入的电子（少数载流子）穿过薄薄的基区，被集电极的反向偏压"扫"走——这就形成了从集电极到发射极的放大电流 ICI_CIC​。

核心关系：IC=βIBI_C = \beta I_BIC​=βIB​，其中 β\betaβ（hFEh_{FE}hFE​）是直流电流增益，典型值为 50~300。更基础的物理关系是：IC=ISeVBE/VTI_C = I_S e^{V_{BE}/V_T}IC​=IS​eVBE​/VT​——集电极电流由基极-发射极电压指数控制。

2.2 三个工作区域 ​

3. 动手设计电路 ​

3.1 本节电路 ​

共发射极放大器（CE Amplifier）——最经典的 BJT 放大电路：

  • 电源电压 VCC=12V_{CC} = 12VCC​=12 V
  • 偏置网络：RB1=47R_{B1} = 47RB1​=47 kΩ（到 VCCV_{CC}VCC​），RB2=10R_{B2} = 10RB2​=10 kΩ（到 GND），构成分压偏置
  • 集电极电阻 RC=2.2R_C = 2.2RC​=2.2 kΩ——将 ICI_CIC​ 的变化转化为电压变化
  • 发射极电阻 RE=470 ΩR_E = 470\,\OmegaRE​=470Ω——提供直流负反馈，稳定工作点
  • BJT 模型：NPN, IS=1e-14, BF=100, VAF=100

3.2 手工计算 ​

直流工作点：

  • VB=RB2RB1+RB2×VCC=1047+10×12≈2.105V_B = \frac{R_{B2}}{R_{B1}+R_{B2}} \times V_{CC} = \frac{10}{47+10} \times 12 \approx 2.105VB​=RB1​+RB2​RB2​​×VCC​=47+1010​×12≈2.105 V
  • VE=VB−VBE≈2.105−0.7=1.405V_E = V_B - V_{BE} \approx 2.105 - 0.7 = 1.405VE​=VB​−VBE​≈2.105−0.7=1.405 V
  • IE=VE/RE=1.405/470≈2.99I_E = V_E / R_E = 1.405 / 470 \approx 2.99IE​=VE​/RE​=1.405/470≈2.99 mA
  • IC≈IE=2.99I_C \approx I_E = 2.99IC​≈IE​=2.99 mA
  • VC=VCC−ICRC=12−2.99×2.2=5.42V_C = V_{CC} - I_C R_C = 12 - 2.99 \times 2.2 = 5.42VC​=VCC​−IC​RC​=12−2.99×2.2=5.42 V
  • VCE=VC−VE=5.42−1.41=4.01V_{CE} = V_C - V_E = 5.42 - 1.41 = 4.01VCE​=VC​−VE​=5.42−1.41=4.01 V（在放大区内）

小信号增益：

gm=ICVT=2.99×10−30.026≈115 mSg_m = \frac{I_C}{V_T} = \frac{2.99\times 10^{-3}}{0.026} \approx 115\text{ mS} gm​=VT​IC​​=0.0262.99×10−3​≈115 mS

Av≈−gmRC=−115×10−3×2200=−253A_v \approx -g_m R_C = -115 \times 10^{-3} \times 2200 = -253 Av​≈−gm​RC​=−115×10−3×2200=−253

实际增益远小于理论值，因为 RER_ERE​ 提供的负反馈降低了增益。考虑 RER_ERE​ 的退化效应：Av≈−RC/(RE+1/gm)A_v \approx -R_C / (R_E + 1/g_m)Av​≈−RC​/(RE​+1/gm​)，对 RE=470 ΩR_E=470\,\OmegaRE​=470Ω，Av≈−2200/(470+8.7)≈−4.6A_v \approx -2200/(470+8.7) \approx -4.6Av​≈−2200/(470+8.7)≈−4.6。若需提高增益，可在 RER_ERE​ 上并联旁路电容（在高频时"短路" RER_ERE​）。

4. 用 Python 实现电路仿真 ​

4.1 BJT 放大器完整分析 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

print("=== Chapter 11: Bipolar Junction Transistor (BJT) ===")

# --- Part 1: DC Operating Point ---
circuit = Circuit('Common-Emitter Amplifier')
circuit.model('NPN1', 'NPN', IS=1e-14, BF=100, VAF=100, ISE=1e-13, NE=1.5, BR=1, NR=1)
circuit.V('cc', 'vcc', circuit.gnd, 12@u_V)
circuit.R('c', 'vcc', 'collector', 2.2@u_kΩ)
circuit.Q('q1', 'collector', 'base', 'emitter', model='NPN1')
circuit.R('b1', 'vcc', 'base', 47@u_kΩ)
circuit.R('b2', 'base', circuit.gnd, 10@u_kΩ)
circuit.R('e', 'emitter', circuit.gnd, 470@u_Ω)

sim_op = circuit.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
analysis_op = sim_op.operating_point()

# --- Part 2: Output Characteristics I_C(V_CE) ---
vbe_levels = [0.65, 0.70, 0.72]
ic_data = {}
vce_common = np.linspace(0, 10, 51)

for vb in vbe_levels:
    c2 = Circuit('BJT Output')
    c2.model('NPN2', 'NPN', IS=1e-14, BF=100, VAF=100)
    c2.V('vce', 'collector', c2.gnd, 5@u_V)
    c2.V('vbe', 'base', c2.gnd, vb@u_V)
    c2.Q('q1', 'collector', 'base', c2.gnd, model='NPN2')
    s2 = c2.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
    a2 = s2.dc(Vvce=slice(0, 10, 0.2))
    ic_data[vb] = -np.array(a2.branches['Vvce'])

# --- Part 3: Small-Signal Voltage Gain ---
circuit_gain = Circuit('CE Amplifier AC')
circuit_gain.model('NPN3', 'NPN', IS=1e-14, BF=100, VAF=100)
circuit_gain.V('cc', 'vcc', circuit_gain.gnd, 12@u_V)
circuit_gain.R('c', 'vcc', 'collector', 2.2@u_kΩ)
circuit_gain.R('b1', 'vcc', 'base', 47@u_kΩ)
circuit_gain.R('b2', 'base', circuit_gain.gnd, 10@u_kΩ)
circuit_gain.R('e', 'emitter', circuit_gain.gnd, 470@u_Ω)
circuit_gain.Q('q1', 'collector', 'base', 'emitter', model='NPN3')
circuit_gain.SinusoidalVoltageSource('vin', 'base', circuit_gain.gnd, amplitude=0.001@u_V, frequency=1@u_kHz)

sim_gain = circuit_gain.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_gain = sim_gain.transient(step_time=1@u_us, end_time=2@u_ms)

time_g = np.array(an_gain.time)
v_out_g = np.array(an_gain['collector'])
v_in_g = np.array(an_gain['base'])
v_out_ac = v_out_g - np.mean(v_out_g)
v_in_ac = v_in_g - np.mean(v_in_g)
Av_measured = np.max(np.abs(v_out_ac)) / np.max(np.abs(v_in_ac))

5. 深入理解 ​

5.1 厄利效应 (Early Effect) ​

在输出特性曲线中，ICI_CIC​ 随 VCEV_{CE}VCE​ 增加而缓慢增加——这不是"理想"晶体管应有的行为。原因是厄利效应：VCEV_{CE}VCE​ 增加使基极-集电极结的耗尽层展宽，有效基区宽度减小，导致 ICI_CIC​ 增大。

厄利效应用厄利电压 VAV_AVA​ 量化——ICI_CIC​ 曲线外推到 IC=0I_C = 0IC​=0 时的 VCEV_{CE}VCE​（取负值）。VAV_AVA​ 越大，输出特性越平坦（输出阻抗越高）。在 SPICE 模型中，VAF 参数即厄利正向电压。

5.2 偏置的重要性 ​

BJT 是一种"偏心"的元件——VBEV_{BE}VBE​ 的微小变化（20 mV）就能导致 ICI_CIC​ 翻倍。这意味着温度变化（VBEV_{BE}VBE​ 的温度系数约 -2 mV/°C）会导致工作点严重漂移。

分压式偏置（由 RB1R_{B1}RB1​ 和 RB2R_{B2}RB2​ 构成）是解决之道：

  • 基极电压 VBV_BVB​ 由电阻分压比确定，几乎不受 IBI_BIB​ 影响（因为 IB≪IRB2I_B \ll I_{R_{B2}}IB​≪IRB2​​）
  • 发射极电阻 RER_ERE​ 提供直流负反馈——若温度升高使 ICI_CIC​ 增大，VE=IEREV_E = I_E R_EVE​=IE​RE​ 也增大，VBE=VB−VEV_{BE} = V_B - V_EVBE​=VB​−VE​ 减小，从而抑制了 ICI_CIC​ 的增长

这种自稳定的偏置方案是所有分立 BJT 放大器的标准配置。

5.3 C-E 放大器的输入输出相位关系 ​

共发射极放大器的输出与输入反相（相位差 180°）。直观理解：输入电压上升 → VBEV_{BE}VBE​ 上升 → ICI_CIC​ 上升 → RCR_CRC​ 上的压降增大 → VC=VCC−ICRCV_C = V_{CC} - I_C R_CVC​=VCC​−IC​RC​ 下降。因此，输入的正弦波在输出端得到一个上下颠倒的放大版本。

6. 本章小结 ​

  • BJT 是电流控制器件：IC=βIBI_C = \beta I_BIC​=βIB​，放大区域需要 VBE≈0.7V_{BE} \approx 0.7VBE​≈0.7 V（正向偏置）和 VCE>0.2V_{CE} > 0.2VCE​>0.2 V（非饱和）
  • 工作点（Q 点）由偏置网络决定——分压偏置（RB1,RB2R_{B1}, R_{B2}RB1​,RB2​）和发射极退化电阻 RER_ERE​ 确保温度稳定性
  • 输出特性 ICI_CIC​ vs VCEV_{CE}VCE​ 以 VBEV_{BE}VBE​ 为参数——饱和区（VCE<0.2V_{CE} < 0.2VCE​<0.2V，ICI_CIC​ 陡降）、放大区（ICI_CIC​ 近乎平坦）
  • 共发射极放大器的电压增益 Av≈−gmRCA_v \approx -g_m R_CAv​≈−gm​RC​（输出反相），加入 RER_ERE​ 后增益降低但线性度改善
  • SPICE BJT 模型的核心参数：IS, BF, VAF（饱和电流、正向 β、厄利电压）

BJT 和下一章的 MOSFET 是模拟集成电路的两大支柱。它们的比较是模拟设计中最经典的"二选一"问题。

7. 练习 ​

  1. 偏置点调整：修改 RB1R_{B1}RB1​ 为 222222 kΩ 和 100100100 kΩ，观察 VCV_CVC​ 的变化。哪种情况使晶体管进入了饱和区（VCE<0.3V_{CE} < 0.3VCE​<0.3 V）？哪种进入了截止区（IC≈0I_C \approx 0IC​≈0）？

  2. β 容差分析：将 BF 改为 505050 和 200200200，在分压偏置下，VCV_CVC​ 变化了多少？比较有无 RER_ERE​ 时 β 变化对工作点的影响——这就是负反馈稳定的效果。

  3. 增益验证：在 RER_ERE​ 上并联一个 CE=100C_E = 100CE​=100 μF 的电容（AC 短路 RER_ERE​），重新仿真 AC 增益。验证增益是否接近 −gmRC-g_m R_C−gm​RC​。

  4. PNP 晶体管：用 PNP 管（model='PNP'）设计一个 CE 放大器。注意 PNP 管的 VCCV_{CC}VCC​ 是负压（或对调电源和地的角色），VBE≈−0.7V_{BE} \approx -0.7VBE​≈−0.7 V，电流方向与 NPN 相反。
