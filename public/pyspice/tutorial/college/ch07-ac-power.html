第7章 交流功率与功率因数 ​

1. 本节你将学到 ​

  • 理解交流电路中的三种功率：视在功率 SSS（VA）、有功功率 PPP（W）、无功功率 QQQ（VAR）
  • 掌握功率三角形 S2=P2+Q2S^2 = P^2 + Q^2S2=P2+Q2 的关系
  • 掌握功率因数 cos⁡ϕ=P/S\cos \phi = P/Scosϕ=P/S 的定义及 ϕ\phiϕ 是电压与电流之间的相位角
  • 理解 RL 电路电流滞后电压导致功率因数小于 1 的物理机制
  • 学会用 PySpice 从瞬态仿真中计算 SSS、PPP、QQQ 和 cos⁡ϕ\cos\phicosϕ

2. 知识回顾/情景引入 ​

在直流世界里，功率只有一种——P=VIP = VIP=VI（瓦特 W）。电流方向恒定，电压极性不变，功率就是实打实的能量流动。

但在交流世界里，事情变复杂了。第 6 章我们学到：在 RL 或 RC 电路中，电流和电压之间存在相位差——它们不是同步变化的。当电压为正时，电流可能已经变为负；当电压达到峰值时，电流可能还远未到达峰值。

这就导致了一个有趣的现象：在每个交流周期中，有一部分时间电压和电流方向相反——电压在"推"正方向，电流却在往负方向流，这意味着能量从负载流回电源！

交流功率由此分为三种：真正消耗掉的是有功功率，在电源和负载之间来回振荡的是无功功率，两者的向量和是视在功率。

2.1 电感负载的物理直觉 ​

考虑一个 RL 串联电路（电阻 100 Ω、电感 0.3 H），由 10 V、50 Hz 的正弦电压源供电。

在半个周期中，电感在储存磁场能量（电流从零增大到最大），它从电源"借"能量并存为磁场。在下半个周期中，电感在释放磁场能量（电流从最大减小到零），它把这部分能量"还"给电源。这个过程在每个周期中反复进行，净效果是：电感不消耗能量（不计线圈的寄生电阻），但它不断在"借"和"还"能量，造成电流来回流动，这就是无功功率的来源。

电源需要在每个周期中提供电流来"来回搬运"能量——即使净功耗不到总电流 × 电压的产品。这就导致了功率因数 cos⁡ϕ<1\cos\phi < 1cosϕ<1。

4. 用 Python 实现电路仿真 ​

4.1 瞬态仿真并计算功率参数 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

circuit = Circuit('AC Power Demo')
circuit.SinusoidalVoltageSource('ac', 1, circuit.gnd, amplitude=10@u_V, frequency=50@u_Hz)
circuit.R('R1', 1, 2, 100@u_Ω)
circuit.L('L1', 2, circuit.gnd, 0.3@u_H)

sim = circuit.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
analysis = sim.transient(step_time=50@u_us, end_time=60@u_ms)

time = np.array(analysis.time)
v = np.array(analysis['1'])
i = (np.array(analysis['1']) - np.array(analysis['2'])) / 100

# 功率计算
p = v * i
S = np.sqrt(np.mean(v**2)) * np.sqrt(np.mean(i**2))  # Vrms * Irms
P = np.mean(p)                                         # 平均瞬时功率 = 有功功率
Q = np.sqrt(S**2 - P**2)                              # 无功功率
pf = P / S

R, L, f = 100, 0.3, 50
omega = 2 * np.pi * f
XL = omega * L
Z_mag = np.sqrt(R**2 + XL**2)
pf_theory = R / Z_mag
phi = np.arccos(pf)

print("AC Power Analysis: RL Series Circuit")
print(f"R = {R} Ω, L = {L} H, f = {f} Hz")
print(f"ZL = jwL = j{omega*L:.1f} Ω")
print(f"|Z| = √(R² + XL²) = {Z_mag:.1f} Ω")
print(f"Power Factor cosφ = R/|Z| = {pf_theory:.3f}")
print(f"Apparent Power S = {S:.2f} VA")
print(f"Active Power P = {P:.2f} W")
print(f"Reactive Power Q = {Q:.2f} VAR")
print(f"Power Factor PF = {pf:.3f}")
print(f"Phase angle φ = arccos(PF) = {np.degrees(phi):.1f}°")
print(f"Theory φ = arctan(XL/R) = {np.degrees(np.arctan2(XL, R)):.1f}°")
print(f"P^2 + Q^2 = {P**2 + Q**2:.3f}, S^2 = {S**2:.3f}")

5. 深入理解 ​

5.1 瞬时功率的"负值区间" ​

在 RL 电路中，瞬时功率 p(t)=v(t)⋅i(t)p(t) = v(t) \cdot i(t)p(t)=v(t)⋅i(t) 并不总是正数。在电压和电流符号相反的那段时间里，p(t)<0p(t) < 0p(t)<0——这意味着负载向电源回馈能量。对于纯电感（R=0R=0R=0），正负面积相等，P=0P=0P=0，S=QS=QS=Q——视在功率全部为无功功率，没有净能量消耗。

直流世界中没有"负功率"的概念——因为电压和电流方向不变。交流中的负功率区间是无功功率的来源，也是功率因数小于 1 的本质原因。

5.2 功率因数校正（PFC） ​

工业电力用户（如大型电机——感性负载）的功率因数通常较低（0.6-0.8），造成电网电流过大、线损增加。解决方案是并联电容器进行功率因数校正：

电容的无功功率为 QC=−V2ωCQ_C = -V^2 \omega CQC​=−V2ωC（负值，与感性的正无功相反）。适当选择 C 值使得 QC=−QLQ_C = -Q_LQC​=−QL​，则总的 Q=0Q = 0Q=0，cos⁡ϕ=1\cos\phi = 1cosϕ=1。这就是变电站中常见的大型电容柜的作用。

在 PySpice 中可以很容易地验证这一过程：在原 RL 负载两端并联一个合适的电容（C=1/(ω2L)=1/[(2π×50)2×0.3]≈33.8C = 1/(\omega^2 L) = 1/[(2\pi \times 50)^2 \times 0.3] \approx 33.8C=1/(ω2L)=1/[(2π×50)2×0.3]≈33.8 μF），重新运行瞬态分析，观察功率因数是否趋近于 1。

5.3 RMS 值的仿真计算 ​

本章使用 np.sqrt(np.mean(v**2)) 来计算电压的有效值（RMS），这是离散版本的 RMS 定义：

Vrms=1N∑k=1Nvk2V_{rms} = \sqrt{\frac{1}{N}\sum_{k=1}^N v_k^2} Vrms​=N1​k=1∑N​vk2​​

对于足够长时间的仿真（跨越多个完整周期），这个近似是精确的。但需要确保仿真包含整数个完整周期——否则 np.mean 会引入截断误差。优化做法是只取完整周期段进行计算。

6. 本章小结 ​

  • 视在功率 S=Vrms×IrmsS = V_{rms} \times I_{rms}S=Vrms​×Irms​：电源需要提供的总容量（单位 VA）
  • 有功功率 P=Scos⁡ϕ=Irms2RP = S\cos\phi = I_{rms}^2 RP=Scosϕ=Irms2​R：实际消耗的功率（单位 W）
  • 无功功率 Q=Ssin⁡ϕ=Irms2XQ = S\sin\phi = I_{rms}^2 XQ=Ssinϕ=Irms2​X：在储能元件与电源间振荡（单位 VAR）
  • 功率因数 cos⁡ϕ=P/S=R/∣Z∣\cos\phi = P/S = R/|Z|cosϕ=P/S=R/∣Z∣：有功在视在功率中的占比
  • S2=P2+Q2S^2 = P^2 + Q^2S2=P2+Q2（功率三角）
  • PySpice 从瞬态仿真的电压电流波形中通过数值积分计算 SSS、PPP、QQQ、cos⁡ϕ\cos\phicosϕ

功率因数是电力系统中最重要的经济技术指标之一——它直接影响输电线的载流能力、变压器的有效利用率和用户的电费（工业用电对低功率因数会额外收费）。理解三种功率的区别，是理解交流电力系统的核心。

7. 练习 ​

  1. 功率因数校正仿真：在原 RL 电路中并联一个电容器（从 10 μF 到 100 μF 扫描），找到使仿真 cos⁡ϕ\cos\phicosϕ 最接近 1 的电容值。验证它是否等于理论值 C=1/(ω2L)C = 1/(\omega^2 L)C=1/(ω2L)。

  2. RC 电路的功率分析：将电感换成电容（C=20C = 20C=20 μF），重复功率分析。此时 cos⁡ϕ=R/∣Z∣\cos\phi = R/|Z|cosϕ=R/∣Z∣ 的公式是否仍然有效？无功功率是感性还是容性？
