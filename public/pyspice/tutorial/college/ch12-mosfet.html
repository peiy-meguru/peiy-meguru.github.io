第12章 MOSFET 场效应管 ​

1. 本节你将学到 ​

  • 掌握 MOSFET 的四端子结构（G, S, D, B）及增强型 NMOS 的工作原理
  • 理解阈值电压 VTHV_{TH}VTH​：当 VGS>VTHV_{GS} > V_{TH}VGS​>VTH​ 时沟道形成，漏极电流开始流动
  • 掌握饱和区方程：ID=12knWL(VGS−VTH)2I_D = \frac{1}{2}k_n \frac{W}{L}(V_{GS} - V_{TH})^2ID​=21​kn​LW​(VGS​−VTH​)2（平方律）

2. 知识回顾/情景引入 ​

上一章的 BJT 是电流控制器件——基极电流 IBI_BIB​ 控制集电极电流 ICI_CIC​。但 MOSFET（Metal-Oxide-Semiconductor Field-Effect Transistor）完全不同——它是电压控制器件——栅极电压 VGSV_{GS}VGS​ 控制漏极电流 IDI_DID​，栅极几乎不消耗直流电流。

这个区别至关重要：MOSFET 的输入是电容性的，直流输入阻抗极高（>1012 Ω>10^{12}\,\Omega>1012Ω），不需要持续的基极电流来维持导通。这使得 MOSFET 在数字 CMOS 电路中几乎无懈可击——只有在信号翻转时才消耗能量。

2.1 NMOS 增强型工作原理 ​

增强型 NMOS 的 P 型衬底上有两个 N+ 扩散区（源极和漏极）。当栅极-源极电压 VGSV_{GS}VGS​ 超过阈值电压 VTHV_{TH}VTH​（通常 0.5~2 V）时：

  • 栅极的正电压吸引衬底中的电子（少数载流子）到表面
  • 在源极和漏极之间形成 N 型导电沟道
  • 若 VDS>0V_{DS} > 0VDS​>0，电子从源极流向漏极——漏极电流 IDI_DID​

如果 VGS<VTHV_{GS} < V_{TH}VGS​<VTH​，沟道消失，ID≈0I_D \approx 0ID​≈0——这就是 MOSFET 作为开关的"断开"状态。

4. 用 Python 实现电路仿真 ​

4.1 NMOS 完整分析 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

print("=== Chapter 12: MOSFET (NMOS) ===")

# Part 1: Transfer Characteristics I_D vs V_GS
circuit_t = Circuit('NMOS Transfer')
circuit_t.model('NM', 'NMOS', VTO=1.0, KP=0.5e-3, LAMBDA=0.02)
circuit_t.V('vdd', 'drain', circuit_t.gnd, 10@u_V)
circuit_t.V('vgs', 'gate', circuit_t.gnd, 0@u_V)
circuit_t.M('m1', 'drain', 'gate', circuit_t.gnd, circuit_t.gnd, model='NM', w=100e-6, l=4e-6)

sim_t = circuit_t.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
analysis_t = sim_t.dc(Vvgs=slice(0, 5, 0.05))

vgs = np.array(analysis_t['gate'])
id_t = -np.array(analysis_t.branches['Vvdd'])

id_sat = float(id_t[-1])
gm_meas = (float(id_t[-1]) - float(id_t[-2])) / (float(vgs[-1]) - float(vgs[-2]))
gm_theory = np.sqrt(2 * 0.5e-3 * 25 * id_sat)

print(f"Saturation I_D = {id_sat*1e6:.1f} uA at V_GS=5V")
print(f"gm = {gm_meas*1e3:.2f} mS (theory: {gm_theory*1e3:.2f} mS)")

# Part 2: Output Characteristics I_D vs V_DS
vgs_levels = [1.5, 2.0, 2.5, 3.0, 3.5, 4.0]
id_data = {}
vds_common = np.linspace(0, 10, 51)
for vb in vgs_levels:
    c_o = Circuit('NMOS Out')
    c_o.model('NM2', 'NMOS', VTO=1.0, KP=0.5e-3, LAMBDA=0.02)
    c_o.V('vds', 'drain', c_o.gnd, 5@u_V)
    c_o.V('vgs', 'gate', c_o.gnd, vb@u_V)
    c_o.M('m1', 'drain', 'gate', c_o.gnd, c_o.gnd, model='NM2', w=100e-6, l=4e-6)
    s_o = c_o.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
    a_o = s_o.dc(Vvds=slice(0, 10, 0.2))
    id_data[vb] = -np.array(a_o.branches['Vvds'])

# Part 3: Common-Source Amplifier Bias
circuit_amp = Circuit('NMOS Amplifier')
circuit_amp.model('NM3', 'NMOS', VTO=1.0, KP=0.5e-3, LAMBDA=0.02)
circuit_amp.V('vdd', 'vdd', circuit_amp.gnd, 10@u_V)
circuit_amp.R('rd', 'vdd', 'drain', 5@u_kΩ)
circuit_amp.R('rs', 'source', circuit_amp.gnd, 1@u_kΩ)
circuit_amp.R('rg1', 'vdd', 'gate', 500@u_kΩ)
circuit_amp.R('rg2', 'gate', circuit_amp.gnd, 500@u_kΩ)
circuit_amp.M('m1', 'drain', 'gate', 'source', circuit_amp.gnd, model='NM3', w=100e-6, l=4e-6)

sim_amp = circuit_amp.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_op_amp = sim_amp.operating_point()

5. 深入理解 ​

5.1 宽长比 W/LW/LW/L 的意义 ​

W/LW/LW/L 是 MOSFET 设计中最重要的几何参数：

  • ID∝W/LI_D \propto W/LID​∝W/L——宽沟道意味着更大的电流承载能力
  • gm∝W/Lg_m \propto \sqrt{W/L}gm​∝W/L​——跨导随宽长比增加而增加
  • 在数字 IC 中，W/LW/LW/L 决定逻辑门的驱动强度——更大的 W/LW/LW/L 意味着更快的充放电速度
  • 在模拟 IC 中，W/LW/LW/L 是调整 gmg_mgm​（进而调整增益和噪声）的主要"旋钮"

5.2 平方律与 BJT 指数律的对比 ​

特性BJTMOSFET
控制关系IC=ISeVBE/VTI_C = I_S e^{V_{BE}/V_T}IC​=IS​eVBE​/VT​（指数）ID=k2WL(VGS−VTH)2I_D = \frac{k}{2}\frac{W}{L}(V_{GS}-V_{TH})^2ID​=2k​LW​(VGS​−VTH​)2（平方）
跨导gm=IC/VTg_m = I_C/V_Tgm​=IC​/VT​gm=2kWLIDg_m = \sqrt{2k\frac{W}{L}I_D}gm​=2kLW​ID​​
给定 IDI_DID​ 时的 gmg_mgm​更大（1/VT≈38.5 S/A1/V_T \approx 38.5\text{ S/A}1/VT​≈38.5 S/A）更小（∝1/ID\propto 1/\sqrt{I_D}∝1/ID​​）

噪声较低（散弹噪声为主）较高（闪烁噪声 1/f1/f1/f）

这也是为什么 BJT 在低噪声放大器（LNA）、高精度运放输入级中更受青睐，而 MOSFET 在数字电路和高阻抗传感器接口中占优。

5.3 体效应 (Body Effect) ​

在共源放大器中，源极和衬底不总是同一电位——源极有 RSR_SRS​ 上的压降，而衬底通常接地。这使得源极-衬底结反偏，导致阈值电压升高：

VTH=VTH0+γ(2ϕF+VSB−2ϕF)V_{TH} = V_{TH0} + \gamma(\sqrt{2\phi_F + V_{SB}} - \sqrt{2\phi_F}) VTH​=VTH0​+γ(2ϕF​+VSB​​−2ϕF​​)

体效应是模拟 IC 设计中不可忽略的效应——它降低了有效 VGS−VTHV_{GS}-V_{TH}VGS​−VTH​，从而降低跨导和增益。

6. 本章小结 ​

  • MOSFET 是电压控制器件，栅极由绝缘的氧化层隔离，输入阻抗极高
  • VGSV_{GS}VGS​ 低于 VTHV_{TH}VTH​ 时 ID=0I_D=0ID​=0（截止）；高于 VTHV_{TH}VTH​ 时，依 VDSV_{DS}VDS​ 大小工作在线性区或饱和区
  • 饱和区 IDI_DID​ 与 VGSV_{GS}VGS​ 成平方关系：ID=k2WL(VGS−VTH)2(1+λVDS)I_D = \frac{k}{2}\frac{W}{L}(V_{GS}-V_{TH})^2(1+\lambda V_{DS})ID​=2k​LW​(VGS​−VTH​)2(1+λVDS​)
  • 跨导 gmg_mgm​ 随 IDI_DID​ 增加而增大（∝ID\propto \sqrt{I_D}∝ID​​），在相同电流下通常小于 BJT 的 gmg_mgm​
  • W/LW/LW/L 是调整 MOSFET 电特性的首要设计参数
  • 共源放大器的电压增益 Av≈−gmRDA_v \approx -g_m R_DAv​≈−gm​RD​（输出反相）

MOSFET 是第 15 章数字逻辑 CMOS 门的基础——NMOS+PMOS 互补对构成了现代数字 IC 的核心。
