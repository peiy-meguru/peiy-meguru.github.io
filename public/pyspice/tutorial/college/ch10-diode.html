第10章 二极管电路 ​

1. 本节你将学到 ​

  • 掌握二极管I-V 特性的指数模型：ID=IS(eVD/nVT−1)I_D = I_S(e^{V_D/nV_T} - 1)ID​=IS​(eVD​/nVT​−1)
  • 理解正向导通电压（硅管 ≈ 0.7 V，肖特基 ≈ 0.3 V）的物理来源
  • 掌握半波整流和全波整流（桥式）的工作原理和输出波形
  • 理解滤波电容的充放电过程及纹波电压计算：ΔV=IL/(4fC)\Delta V = I_L/(4fC)ΔV=IL​/(4fC)（全波）
  • 学习电压限幅器（clipper）的设计，通过二极管+直流偏压限制信号幅值

2. 知识回顾/情景引入 ​

前面的章节中，所有元件（电阻、电容、电感）都是线性和双向的——电流可以双向流动，且电压-电流关系成正比。但真实电子电路中最重要的元件——二极管和晶体管——是非线性和单向的。

想象你需要给手机充电——手机电池需要 5 V 直流（DC），但墙上插座提供的是 220 V 交流（AC）。如何将交流电"转化"为直流电？答案就是整流——一种使用二极管的电路，它只允许电流向一个方向流动，从而把正负交替的交流电"切"成单向脉动直流。

2.1 二极管物理 ​

二极管的核心是一个 PN 结——P 型半导体和 N 型半导体的交界面。其 I-V 关系为：

ID=IS(eVD/nVT−1)I_D = I_S(e^{V_D / nV_T} - 1) ID​=IS​(eVD​/nVT​−1)

其中 ISI_SIS​ 为反向饱和电流（10−12∼10−1510^{-12} \sim 10^{-15}10−12∼10−15 A），nnn 为理想因子（1~2），VT=kT/q≈26V_T = kT/q \approx 26VT​=kT/q≈26 mV（室温）。

当 VD>0V_D > 0VD​>0 且远大于 VTV_TVT​ 时，eVD/nVT≫1e^{V_D/nV_T} \gg 1eVD​/nVT​≫1，电流随电压呈指数增长——电压每增加约 60 mV（nVTln⁡10nV_T \ln 10nVT​ln10），电流增加 10 倍。这就是为什么二极管的正向导通电压"看起来"几乎是固定的 ~0.7 V——微小的电压变化导致巨大的电流变化。

2.2 整流的基本思路 ​

整流类型导通时段输出频率VavgV_{avg}Vavg​（无滤波）
半波整流正半周期fff（50 Hz）Vpeak/πV_{peak}/\piVpeak​/π
全波整流（桥式）整个周期（正负各一次）2f2f2f（100 Hz）2Vpeak/π2V_{peak}/\pi2Vpeak​/π

全波整流利用二极管的单向性，将交流信号的负半周"翻转"为正半周，使输出永远为正。加上滤波电容后，电容器在二极管导通时充电、在二极管截止时放电，维持输出电压在峰值附近，从而产生脉动很小的直流电压。

3. 动手设计电路 ​

3.1 本节电路 ​

三种经典二极管电路：

  • I-V 特性测试：串联 1 Ω 限流电阻，DC 扫描 0→1 V
  • 半波整流+滤波：单二极管 + 100 μF 滤波电容 + 1 kΩ 负载，Vac=5VampV_{ac} = 5V_{amp}Vac​=5Vamp​, 50 Hz
  • 电压限幅器：两个反向二极管 + ±2 V 偏压，限幅 ±2.7 V（2V + 0.7V 二极压降）

4. 用 Python 实现电路仿真 ​

4.1 二极管 I-V 特性、整流、限幅 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

print("=== Chapter 10: Diode Circuits ===")

# Part 1: Diode I-V Characteristic
circuit = Circuit('Diode I-V Curve')
circuit.V('input', 'in', circuit.gnd, 1@u_V)
circuit.R('limit', 'in', 'out', 1@u_Ω)
circuit.model('MyDiode', 'D', IS=1e-12, N=1.0, RS=0.1)
circuit.D('D1', 'out', circuit.gnd, model='MyDiode')

simulator = circuit.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
analysis = simulator.dc(Vinput=slice(0, 1, 0.01))

voltage = np.array(analysis['out'])
current = -np.array(analysis.branches['Vinput'])

threshold_idx = np.argmin(np.abs(current * 1000 - 1))
v_th = float(voltage[threshold_idx])
print(f"Forward threshold voltage (I~1mA): Vf ≈ {v_th:.3f} V")

# Part 2: Half-Wave Rectifier with Filter
circuit_rect = Circuit('Half-Wave Rectifier')
circuit_rect.SinusoidalVoltageSource('vac', 'in', circuit_rect.gnd, amplitude=5@u_V, frequency=50@u_Hz)
circuit_rect.model('MyDiode2', 'D', IS=1e-12, N=1.0, RS=0.1)
circuit_rect.D('D1', 'in', 'out', model='MyDiode2')
circuit_rect.R('RL', 'out', circuit_rect.gnd, 1@u_kΩ)
circuit_rect.C('C1', 'out', circuit_rect.gnd, 100@u_uF)

sim_rect = circuit_rect.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_rect = sim_rect.transient(step_time=10@u_us, end_time=60@u_ms)

time_rect = np.array(an_rect.time) * 1000
v_out_rect = np.array(an_rect['out'])

v_peak = np.max(v_out_rect)
v_avg = np.mean(v_out_rect[len(v_out_rect)//2:])
ripple = np.max(v_out_rect[len(v_out_rect)//2:]) - np.min(v_out_rect[len(v_out_rect)//2:])
print(f"  V_peak = {v_peak:.3f} V")
print(f"  V_avg  = {v_avg:.3f} V")
print(f"  Ripple = {ripple*1000:.1f} mV")

# Part 3: Voltage Limiter (Clipper)
circuit_clip = Circuit('Voltage Limiter')
circuit_clip.SinusoidalVoltageSource('vac', 'in', circuit_clip.gnd, amplitude=5@u_V, frequency=1@u_kHz)
circuit_clip.R('R1', 'in', 'out', 1@u_kΩ)
circuit_clip.model('DiodeZ1', 'D', IS=1e-12)
circuit_clip.D('D_up', 'out', 'clip_pos', model='DiodeZ1')
circuit_clip.D('D_dn', 'clip_neg', 'out', model='DiodeZ1')
circuit_clip.V('vpos', 'clip_pos', circuit_clip.gnd, 2@u_V)
circuit_clip.V('vneg', circuit_clip.gnd, 'clip_neg', 2@u_V)

sim_clip = circuit_clip.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_clip = sim_clip.transient(step_time=1@u_us, end_time=3@u_ms)

time_clip = np.array(an_clip.time) * 1000
v_out_clip = np.array(an_clip['out'])

v_out_max = np.max(v_out_clip)
v_out_min = np.min(v_out_clip)
print(f"  V_out max = {v_out_max:.3f} V")
print(f"  V_out min = {v_out_min:.3f} V")

5. 深入理解 ​

5.1 二极管模型的 SPICE 参数 ​

PySpice 中的二极管模型参数：

参数含义典型值
IS反向饱和电流10−1210^{-12}10−12 A（信号二极管）
N理想因子1.0~2.0
RS串联寄生电阻0.1~10 Ω
BV反向击穿电压（见第 17 章的稳压管）
IBV击穿电流10 mA（典型值）

增大 IS 会降低正向导通电压（Vf∝ln⁡(1/IS)V_f \propto \ln(1/I_S)Vf​∝ln(1/IS​)）。减小 N 会使 I-V 曲线变得更"陡峭"。RS 在大电流时产生额外的电压降——当 IDI_DID​ 为 100 mA 时，RS=1 Ω 意味着额外的 0.1 V 压降。

5.2 纹波与滤波电容的关系 ​

纹波公式 ΔV=IL/(4fC)\Delta V = I_L / (4fC)ΔV=IL​/(4fC)（全波整流）或 ΔV=IL/(2fC)\Delta V = I_L / (2fC)ΔV=IL​/(2fC)（半波整流）告诉我们：

  • 电容越大，纹波越小——C=1000C=1000C=1000 μF 比 C=100C=100C=100 μF 的纹波小 10 倍
  • 负载电流越大，纹波越大——重载时电容放电更快
  • 全波整流的纹波只有半波的一半——因为每个周期充电两次

但电容不能无限增大——大电容意味着更大的浪涌电流（充电瞬间电容相当于短路），需要更粗的走线和更贵的元件。

5.3 限幅器的应用 ​

二极管限幅器广泛应用于：

  • 过压保护：防止信号超过 ADC 的参考电压（Arduino 的 5 V 输入保护常用 5.1 V 稳压管限幅）
  • 音频削波：吉他效果器中的"distortion"效果——将正弦波"削"成方波，产生粗粝的失真音色
  • ESD 保护：CMOS 芯片的输入引脚通常内置二极管对（到 VDD 和 GND），将静电放电钳位在安全范围

6. 本章小结 ​

  • 二极管是非线性、单向元件，I-V 关系为指数函数：ID=IS(eVD/nVT−1)I_D = I_S(e^{V_D/nV_T} - 1)ID​=IS​(eVD​/nVT​−1)
  • 硅二极管的正向导通电压 ≈ 0.6~0.7 V（1 mA 时），肖特基管 ≈ 0.3 V
  • 半波整流仅利用正半周，输出频率 = 输入频率；全波整流利用正负半周，输出频率 = 2× 输入频率
  • 滤波电容将脉动 DC 平滑化，纹波 ΔV=IL/(4fC)\Delta V = I_L / (4fC)ΔV=IL​/(4fC)（全波）
  • 电压限幅器利用二极管的正向压降和直流偏压，将信号限制在指定范围内

二极管是第 17 章电源链路中的第 2 级（整流），也是后续章节中 BJT 和 MOSFET 放大器的核心结构（PN 结或 PN 结的组合）。

7. 练习 ​

  1. I-V 曲线对比：修改二极管模型参数，设置 IS=1e-11 和 IS=1e-13，比较两种情况下 1 mA 对应的正向电压。每次 ISI_SIS​ 改变 10 倍，VfV_fVf​ 大约变化多少 mV？

  2. 纹波验证：保持 C=100C=100C=100 μF，改变 RloadR_{load}Rload​ 为 500 Ω500\,\Omega500Ω 和 2 kΩ2\,\text{k}\Omega2kΩ，记录纹波电压。验证 ΔV∝1/Rload\Delta V \propto 1/R_{load}ΔV∝1/Rload​（或等价地 ΔV∝IL\Delta V \propto I_LΔV∝IL​）。

  3. 全波桥式整流：用四个二极管设计一个桥式整流电路（类似第 17 章），添加 C=470C=470C=470 μF 滤波电容，比较与半波整流的纹波大小。

  4. 可调限幅器：将限幅器的偏压 VposV_{pos}Vpos​ 和 VnegV_{neg}Vneg​ 改为 111 V 和 333 V，验证限幅阈值的变化是否等于（偏压 + 二极管压降）。解释为何偏压为 0 时仍有约 ±0.7 V 的限幅。
