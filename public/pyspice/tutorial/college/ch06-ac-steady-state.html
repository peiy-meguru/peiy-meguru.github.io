第6章 正弦稳态分析 ​

1. 本节你将学到 ​

  • 掌握相量法（Phasor Method）——将正弦交流电路的分析转换为复数代数运算
  • 理解 RRR、LLL、CCC 三种元件的阻抗（Impedance）：ZR=RZ_R = RZR​=R，ZL=jωLZ_L = j\omega LZL​=jωL，ZC=1/(jωC)Z_C = 1/(j\omega C)ZC​=1/(jωC)
  • 掌握频率响应的概念：元件阻抗随频率变化，电路的输出幅值和相位都依赖于频率
  • 学会用 PySpice 的 .ac() 交流分析进行频率扫描，获取电路的幅频和相频特性

2. 知识回顾/情景引入 ​

前五章我们在直流世界中建立了电路分析的基础。直流电路的分析对象是"不变的电压和电流"——电阻分压、KCL/KVL 方程、叠加定理、等效电路，一切都是实数运算。

但一个最基本的物理事实是：我们生活中使用的电，绝大多数是交流电。墙上的 220 V/50 Hz 插座、手机充电器内部的开关电源（通常以数十 kHz 到 MHz 工作）、WiFi 的 2.4 GHz 射频信号——这些都是交变信号。

在交流世界里，电压和电流随时间按正弦规律变化，并且它们之间可能不同步（有相位差）。第 4 章的一阶电路已经揭示了相位差的存在——交流源通过 RC 电路时，电容电压滞后于电源电压。

2.1 相量法的动机 ​

处理正弦函数 v(t)=Vmsin⁡(ωt+ϕ)v(t) = V_m \sin(\omega t + \phi)v(t)=Vm​sin(ωt+ϕ) 的微分和积分涉及三角函数变换，繁琐易错。发明家 Steinmetz 在 1893 年引入了一种革命性的方法：用复数来表示正弦量。

一个正弦量 v(t)=Vmcos⁡(ωt+ϕ)v(t) = V_m \cos(\omega t + \phi)v(t)=Vm​cos(ωt+ϕ) 可以看作复数 V~=Vmejϕ\tilde{V} = V_m e^{j\phi}V~=Vm​ejϕ 在复平面上以角速度 ω\omegaω 旋转时在实轴上的投影（欧拉公式 ejθ=cos⁡θ+jsin⁡θe^{j\theta} = \cos\theta + j\sin\thetaejθ=cosθ+jsinθ）。

相量 V~\tilde{V}V~（通常记为 V˙\dot{V}V˙ 或 V∠ϕV\angle\phiV∠ϕ）携带了正弦量的幅值和相位信息。

2.2 三种基本元件的阻抗 ​

在相量域中，三种元件都可以用一个复阻抗 ZZZ 来描述：

元件时域关系相量域关系阻抗 ZZZ
电阻 Rv=iRv = iRv=iRV˙=I˙R\dot{V} = \dot{I}RV˙=I˙RZR=RZ_R = RZR​=R（纯实数，零相位）
电感 Lv=Ldidtv = L\frac{di}{dt}v=Ldtdi​V˙=jωLI˙\dot{V} = j\omega L\dot{I}V˙=jωLI˙ZL=jωLZ_L = j\omega LZL​=jωL（正虚数，+90°）
电容 Ci=Cdvdti = C\frac{dv}{dt}i=Cdtdv​I˙=jωCV˙\dot{I} = j\omega C\dot{V}I˙=jωCV˙ZC=1/(jωC)=−j/(ωC)Z_C = 1/(j\omega C) = -j/(\omega C)ZC​=1/(jωC)=−j/(ωC)（负虚数，-90°）

在相量域中，KCL、KVL、欧姆定律的形式完全保留，只是所有量都变成了复数。这使得交流电路的分析和直流电路完全同构——你只需要把"电阻"替换成"阻抗"，"实数"替换成"复数"。

2.3 阻抗的频率依赖性 ​

ZR=RZ_R = RZR​=R 与频率无关——电阻对直流和交流一视同仁。

ZL=jωLZ_L = j\omega LZL​=jωL 的大小 XL=ωLX_L = \omega LXL​=ωL 随频率线性增大——电感对高频信号呈高阻抗，对直流（ω=0\omega=0ω=0）呈短路（XL=0X_L = 0XL​=0）。

ZC=1/(jωC)Z_C = 1/(j\omega C)ZC​=1/(jωC) 的大小 XC=1/(ωC)X_C = 1/(\omega C)XC​=1/(ωC) 随频率增大而减小——电容对高频信号呈低阻抗，对直流呈开路（XC→∞X_C \to \inftyXC​→∞）。

2.4 传递函数与截止频率 ​

RC 串联电路（输出取电容电压）的传递函数为：

H(jω)=V˙outV˙in=1/(jωC)R+1/(jωC)=11+jωRCH(j\omega) = \frac{\dot{V}_{out}}{\dot{V}_{in}} = \frac{1/(j\omega C)}{R + 1/(j\omega C)} = \frac{1}{1 + j\omega RC} H(jω)=V˙in​V˙out​​=R+1/(jωC)1/(jωC)​=1+jωRC1​

这是一个一阶低通滤波器。其幅频特性 ∣H(jω)∣=1/1+(ωRC)2|H(j\omega)| = 1/\sqrt{1 + (\omega RC)^2}∣H(jω)∣=1/1+(ωRC)2​。

当 ω=ωc=1/(RC)\omega = \omega_c = 1/(RC)ω=ωc​=1/(RC) 时，∣H∣=1/2≈0.707|H| = 1/\sqrt{2} \approx 0.707∣H∣=1/2​≈0.707，即 −3.01-3.01−3.01 dB。ωc\omega_cωc​ 称为 -3dB 截止频率（Cutoff Frequency）。

4.1 阻抗频率扫描和 RC 频率响应 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()
from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

R_val = 1e3; C_val = 100e-9; L_val = 10e-3

# RL 串联电路 阻抗扫描
circuit_rl = Circuit('RL AC')
circuit_rl.SinusoidalVoltageSource('ac', 1, circuit_rl.gnd, amplitude=1@u_V)
circuit_rl.R('R1', 1, 2, R_val@u_Ω)
circuit_rl.L('L1', 2, circuit_rl.gnd, L_val@u_H)
sim_rl = circuit_rl.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_rl = sim_rl.ac(start_frequency=100@u_Hz, stop_frequency=100@u_kHz,
                  number_of_points=100, variation='dec')

# RC 串联电路 阻抗扫描
circuit_rc = Circuit('RC AC')
circuit_rc.SinusoidalVoltageSource('ac', 1, circuit_rc.gnd, amplitude=1@u_V)
circuit_rc.R('R1', 1, 2, R_val@u_Ω)
circuit_rc.C('C1', 2, circuit_rc.gnd, C_val@u_F)
sim_rc = circuit_rc.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_rc = sim_rc.ac(start_frequency=100@u_Hz, stop_frequency=100@u_kHz,
                  number_of_points=100, variation='dec')

freq = np.array(an_rl.frequency)
vr_rl = np.abs(np.array(an_rl['1']) - np.array(an_rl['2']))
vr_rc = np.abs(np.array(an_rc['1']) - np.array(an_rc['2']))
z_rl = R_val / vr_rl  # |Z| = R * |Vs| / |VR|
z_rc = R_val / vr_rc

# RC 宽带频率响应
circuit_rc_wb = Circuit('RC AC Wideband')
circuit_rc_wb.SinusoidalVoltageSource('ac', 1, circuit_rc_wb.gnd, amplitude=1@u_V)
circuit_rc_wb.R('R1', 1, 2, R_val@u_Ω)
circuit_rc_wb.C('C1', 2, circuit_rc_wb.gnd, C_val@u_F)
sim_rc_wb = circuit_rc_wb.simulator(temperature=25, nominal_temperature=25, simulator='ngspice-subprocess')
an_rc_wb = sim_rc_wb.ac(start_frequency=10@u_Hz, stop_frequency=1@u_MHz,
                         number_of_points=200, variation='dec')

freq_rc = np.array(an_rc_wb.frequency)
vc_mag = np.abs(np.array(an_rc_wb['2']))
phase = np.angle(np.array(an_rc_wb['2']), deg=True)

fc = 1 / (2 * np.pi * R_val * C_val)
idx_fc = np.argmin(np.abs(freq_rc - fc))
print(f"R = {R_val/1e3} kΩ, C = {C_val*1e9} nF")
print(f"Cutoff frequency fc = 1/(2πRC) = {fc:.1f} Hz")
print(f"At fc: |Vc| = {vc_mag[idx_fc]:.4f} V (theory: 1/√2 = {1/np.sqrt(2):.4f} V)")
print(f"At fc: |H|_dB = {20*np.log10(vc_mag[idx_fc]):.2f} dB (theory: -3.01 dB)")
print(f"At fc: phase = {phase[idx_fc]:.1f} deg (theory: -45 deg)")

5. 深入理解 ​

5.1 .ac() 分析的工作原理 ​

SPICE 的 .ac() 分析在频域中工作：它首先对电路进行线性化（在工作点附近将非线性元件近似为线性小信号模型），然后在指定的频率范围内扫描，对每个频率点求解复数矩阵方程。

.ac() 分析的核心参数：

  • start_frequency / stop_frequency：频率范围
  • number_of_points：扫描点数（越多曲线越平滑，但耗时越长）
  • variation='dec'（decade）：频率在对数刻度上均匀分布——每十倍频程取等量点。也可用 'oct'（octave，每二倍频程）或 'lin'（线性频率间隔）

5.2 阻抗测量的工程方法 ​

在仿真中我们可以直接提取复数电压和电流来计算阻抗。但在实际实验测量中（用示波器和信号发生器），通常使用"电压比例法"：串联一个已知电阻 RsenseR_{sense}Rsense​，测量其两端的电压 VRV_RVR​，则电流 I=VR/RsenseI = V_R / R_{sense}I=VR​/Rsense​，电路总阻抗 ∣Z∣=∣VS∣/∣I∣=∣VS∣⋅Rsense/∣VR∣|Z| = |V_S| / |I| = |V_S| \cdot R_{sense} / |V_R|∣Z∣=∣VS​∣/∣I∣=∣VS​∣⋅Rsense​/∣VR​∣。

这正是本章代码中 z_rl = R_val / vr_rl 的原理：VS=1 VV_S = 1\text{ V}VS​=1 V，VRV_RVR​ 是已知电阻上的电压，所以 ∣Z∣=R/∣VR∣|Z| = R / |V_R|∣Z∣=R/∣VR​∣。

5.3 相位在电路中的角色 ​

相位不仅仅是一个"角度数"。相位差在物理上意味着电压和电流不同步：

  • RL 电路：电流滞后电压（电感中的电流不能突变），相位角 ϕ=arctan⁡(ωL/R)\phi = \arctan(\omega L / R)ϕ=arctan(ωL/R) 为正（0° 到 90°）
  • RC 电路：电流超前电压（电容电压不能突变），相位角 ϕ=−arctan⁡(1/(ωRC))\phi = -\arctan(1/(\omega RC))ϕ=−arctan(1/(ωRC)) 为负（0° 到 -90°）
  • RLC 谐振：在谐振频率 ω0=1/LC\omega_0 = 1/\sqrt{LC}ω0​=1/LC​ 处，XL=XCX_L = X_CXL​=XC​，相位角恰为零——电路呈纯电阻特性

6. 本章小结 ​

  • 相量法将正弦稳态分析转换为复数代数运算
  • ZR=RZ_R = RZR​=R，ZL=jωLZ_L = j\omega LZL​=jωL，ZC=1/(jωC)Z_C = 1/(j\omega C)ZC​=1/(jωC)

  • PySpice 的 .ac() 分析提供频率扫描，返回复数电压/电流，从中可提取幅值和相位

从本章开始，电路分析从"直流世界"迈向"交流频域"。阻抗、传递函数、频率响应——这些概念是后续滤波器设计、放大器频率补偿、射频电路分析的基础。

7. 练习 ​
