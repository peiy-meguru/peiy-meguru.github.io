第5章 电功与电功率 ​

1. 本节你将学到 ​

  • 理解电功的物理意义：电流通过用电器时，电能转化为其他形式能量的过程
  • 掌握电功率的定义和计算公式：P=UIP = UIP=UI、P=I2RP = I^2RP=I2R、P=U2RP = \frac{U^2}{R}P=RU2​
  • 理解功率与电压的平方关系：电阻固定时，P=U2RP = \frac{U^2}{R}P=RU2​，功率随电压的平方增长
  • 学会用 PySpice 的 DC 扫描计算功率，并绘制功率-电压曲线

2. 知识回顾/情景引入 ​

2.1 什么是电功 ​

电流通过导体时，电场力推动电荷定向移动，将电能转化为其他形式的能量——这个过程中电流做了功，称为电功，用 WWW 表示。电功的大小取决于电压、电流和通电时间：

W=UItW = UIt W=UIt

其中 UUU 是电压（伏特 V），III 是电流（安培 A），ttt 是通电时间（秒 s）。电功的单位是焦耳（J）。

一个简单的例子：手机充电器输出 5V、1A，充电 1 小时（3600 秒），电功 W=5×1×3600=18000JW = 5 \times 1 \times 3600 = 18000JW=5×1×3600=18000J。这部分电能转化为了手机电池的化学能和少许热能。

2.2 什么是电功率 ​

电功率描述的是电流做功的快慢——单位时间内消耗的电能：

P=Wt=UIP = \frac{W}{t} = UI P=tW​=UI

功率的单位是瓦特（W），1W=1J/s1W = 1J/s1W=1J/s。日常生活中的"100W 灯泡"就是指灯泡每秒消耗 100 焦耳电能。

结合欧姆定律 I=URI = \frac{U}{R}I=RU​，可以得到功率的两种变形：

P=I2R（已知电流和电阻）P = I^2 R \quad \text{（已知电流和电阻）} P=I2R（已知电流和电阻）

P=U2R（已知电压和电阻）P = \frac{U^2}{R} \quad \text{（已知电压和电阻）} P=RU2​（已知电压和电阻）

这三个公式是等价的，可以根据已知条件灵活选用。

2.3 额定功率与实际功率 ​

电器铭牌上标明的功率叫额定功率——在额定电压下工作时的功率。例如灯泡标"220V 100W"，意思是接在 220V 电压下时，它恰好消耗 100W 功率。如果电压低于 220V（比如电压降到 110V），根据 P=U2RP = \frac{U^2}{R}P=RU2​，功率会降为原来的 14\frac{1}{4}41​，灯泡变暗。

这正是 P∝U2P \propto U^2P∝U2 平方关系在生活中的体现。本章将用一个 100Ω100\Omega100Ω 电阻，通过 DC 扫描从 0V 到 10V，直观展示功率随电压的平方增长规律。

3. 动手设计电路 ​

3.1 本节电路 ​

我们要研究的电路非常简单：一个电压可调的电源，连接一个 100Ω100\Omega100Ω 的固定电阻。电路图如下：

虽然电路和第 3 章（欧姆定律）完全相同，但本章的视角不同——我们关注的不再是电流随电压的线性变化，而是功率随电压的平方变化。

3.2 公式推导 ​

当 R=100ΩR = 100\OmegaR=100Ω 固定时，根据 P=U2RP = \frac{U^2}{R}P=RU2​：

P=U2100P = \frac{U^2}{100} P=100U2​

几点分析：

  • 当 U=0VU = 0VU=0V 时，P=0WP = 0WP=0W——没有电压，没有功率消耗
  • 当 U=5VU = 5VU=5V 时，P=25100=0.25W=250mWP = \frac{25}{100} = 0.25W = 250mWP=10025​=0.25W=250mW
  • 当 U=10VU = 10VU=10V 时，P=100100=1.0W=1000mWP = \frac{100}{100} = 1.0W = 1000mWP=100100​=1.0W=1000mW

注意：电压从 5V 加倍到 10V（2 倍），功率从 0.25W 变为 1.0W（4 倍 = 2² 倍）。这就是平方关系。

4. 用 Python 实现电路仿真 ​

4.1 构建电路并执行 DC 扫描 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

circuit = Circuit('Power Demo')
circuit.V('input', 1, circuit.gnd, 1@u_V)
circuit.R(1, 1, circuit.gnd, 100@u_Ω)

simulator = circuit.simulator(temperature=25, nominal_temperature=25,
                              simulator='ngspice-subprocess')

analysis = simulator.dc(Vinput=slice(0, 10, 0.1))

voltage = analysis['1']
current = -analysis.branches['Vinput']
power = [float(v) * float(c) for v, c in zip(voltage, current)]

代码解释：

  • analysis.branches['Vinput']：获取流过电压源的电流。注意电流符号——电压从电源正极流出，与 Ngspice 的默认电流方向相反，因此加负号。
  • power = [float(v) * float(c) for v, c in zip(voltage, current)]：使用列表解析式，逐个计算每个电压扫描点对应的瞬时功率 P=UIP = UIP=UI。
  • 这里我们没有使用 P=U2/RP = U^2/RP=U2/R 直接计算，而是用 P=UIP = UIP=UI 从仿真数据中验证——结果应该与 P=U2/RP = U^2/RP=U2/R 完全一致。

4.3 功率曲线 ​

仿真绘制了两张子图：

  • 左侧（蓝线）：电流-电压关系 I=U/RI = U/RI=U/R，呈现线性增长——一条过原点的直线。
  • 右侧（红线）：功率-电压关系 P=U2/RP = U^2/RP=U2/R，呈现二次函数（抛物线）的上升趋势——电压越大，功率增长越快。

两张图的对比鲜明地展示了电流的线性增长 vs 功率的平方增长。这也是为什么在分析电路功率和发热时，电压的变化的影响远比表面看起来更剧烈。

5. 深入理解 ​

5.1 三种功率公式的由来 ​

三种功率公式从数学上完全等价，但物理思路不同：

  • P=UIP = UIP=UI 是功率的定义式：功率就是电压和电流的乘积，由 W=UItW = UItW=UIt 除以 ttt 直接得出。
  • P=I2RP = I^2 RP=I2R 从电流和电阻的角度看功率：将 U=IRU = IRU=IR 代入 P=UIP = UIP=UI 得出。这说明了为什么大电流流过小电阻也会产生大量热——电流以平方出现在公式中。
  • P=U2RP = \frac{U^2}{R}P=RU2​ 从电压和电阻的角度看功率：将 I=U/RI = U/RI=U/R 代入 P=UIP = UIP=UI 得出。这解释了为什么同一用电器在不同电压下功率相差悬殊。

根据不同场景选用最方便的公式，是解题和分析的关键技巧。

5.2 平方关系的直观验证 ​

从仿真数据中，选取电压 U=5VU = 5VU=5V 和 U=10VU = 10VU=10V 两个点：

P10VP5V=1.0000.250=4.00\frac{P_{10V}}{P_{5V}} = \frac{1.000}{0.250} = 4.00 P5V​P10V​​=0.2501.000​=4.00

而 105=2\frac{10}{5} = 2510​=2，22=42^2 = 422=4。验证了 P∝U2P \propto U^2P∝U2。再取 U=2VU = 2VU=2V 和 U=8VU = 8VU=8V：

P8VP2V=0.6400.040=16.00=42\frac{P_{8V}}{P_{2V}} = \frac{0.640}{0.040} = 16.00 = 4^2 P2V​P8V​​=0.0400.640​=16.00=42

电压增大 4 倍，功率增大 16 倍——平方关系精确成立。

5.3 电能与电功 ​

电功 W=PtW = PtW=Pt 提醒我们，能耗不仅取决于功率大小，还取决于使用时间。一个 5W 的 LED 灯泡连续点亮 10 小时，消耗的电能 W=5×10×3600=180000J=0.05kWhW = 5 \times 10 \times 3600 = 180000J = 0.05kWhW=5×10×3600=180000J=0.05kWh。而一个 2000W 的电热水器工作 6 分钟（0.1 小时），W=2000×0.1×3600=720000J=0.2kWhW = 2000 \times 0.1 \times 3600 = 720000J = 0.2kWhW=2000×0.1×3600=720000J=0.2kWh——虽然只用了 6 分钟，耗电却是 LED 灯泡 10 小时的 4 倍。

6. 本章小结 ​

  • 电功 W=UItW = UItW=UIt 是电能转化为其他形式能量的量度，单位是焦耳（J）。
  • 电功率 P=UIP = UIP=UI 是电流做功的快慢，单位是瓦特（W），1W=1J/s1W = 1J/s1W=1J/s。
  • 结合欧姆定律，功率有三种等价形式：P=UIP = UIP=UI、P=I2RP = I^2 RP=I2R、P=U2RP = \frac{U^2}{R}P=RU2​。
  • 对于固定电阻，功率与电压的平方成正比：P∝U2P \propto U^2P∝U2。电压加倍，功率变为 4 倍——这比线性关系剧烈得多。
  • PySpice 的 DC 扫描可以通过 P=UIP = UIP=UI 逐点计算功率，一次性绘制完整的功率-电压曲线。

7. 练习 ​

  1. 验证平方关系：把代码中的电阻从 100Ω100\Omega100Ω 改为 50Ω50\Omega50Ω，重新运行仿真。观察 P=U2/50P = U^2/50P=U2/50 与仿真结果是否一致，验证 U=2VU = 2VU=2V 和 U=6VU = 6VU=6V 时的功率比例是否为 999 倍（323^232）。

  2. 功率公式互验：在代码中增加一组验证——同时用 P=UIP = UIP=UI、P=I2RP = I^2 RP=I2R 和 P=U2/RP = U^2/RP=U2/R 三种方式计算功率，确认三个结果在任意电压下都完全相同。

  3. 计算电功：一个 100Ω100\Omega100Ω 电阻接在 5V 电压下，通电 2 分钟。求电功 WWW 是多少焦耳？（提示：先算功率 P=52100=0.25WP = \frac{5^2}{100} = 0.25WP=10052​=0.25W，W=Pt=0.25×120=30JW = Pt = 0.25 \times 120 = 30JW=Pt=0.25×120=30J。）

  4. 实际功率 vs 额定功率：灯泡标有"220V 100W"，求它的电阻 R=U2P=2202100=484ΩR = \frac{U^2}{P} = \frac{220^2}{100} = 484\OmegaR=PU2​=1002202​=484Ω。如果把它接在 110V 电压上，实际功率是多少？用手工计算，再修改代码电路参数验证。

  5. 思考题：为什么输电线路要使用高压（如 110kV、220kV）而不是低压进行远距离传输？提示：考虑 P=I2RP = I^2 RP=I2R，在输送相同功率时，电压越高则电流越小，线路上的功率损耗（发热）也就越小。
