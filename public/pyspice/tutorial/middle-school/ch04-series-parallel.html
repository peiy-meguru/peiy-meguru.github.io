第4章 串并联电路 ​

1. 本节你将学到 ​

  • 理解串联电路和并联电路的连接方式与基本特征
  • 掌握串联电路的等效电阻公式：R=R1+R2R = R_1 + R_2R=R1​+R2​
  • 掌握并联电路的等效电阻公式：1R=1R1+1R2\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2}R1​=R1​1​+R2​1​
  • 学会用 PySpice 同时构建串联和并联电路，对比两者的电流、电压分布

2. 知识回顾/情景引入 ​

2.1 什么是串联 ​

把两个或更多元件首尾相接、排成一串，电流只有一条路可以走，这种连接方式叫串联。串联电路有三个重要特点：

  1. 电流处处相等：流过每个元件的电流大小相同
  2. 电压按电阻比例分配：电阻大的元件分到的电压多，电阻小的分到的电压少
  3. 等效电阻增大：总电阻等于各个电阻之和：R总=R1+R2+…R_{总} = R_1 + R_2 + \dotsR总​=R1​+R2​+…

2.2 什么是并联 ​

把两个或更多元件的两端分别连在一起，电流有多条路可以走，这种连接方式叫并联。并联电路也有三个重要特点：

  1. 电压处处相等：每个支路两端的电压都等于电源电压
  2. 电流按电阻反比分配：电阻小的支路电流大，电阻大的支路电流小
  3. 等效电阻减小：总电阻的倒数等于各个电阻倒数之和：1R总=1R1+1R2+…\frac{1}{R_{总}} = \frac{1}{R_1} + \frac{1}{R_2} + \dotsR总​1​=R1​1​+R2​1​+…

2.3 生活中的例子 ​

老式圣诞灯串是串联的——只要一颗灯泡烧坏，整串灯都会熄灭，因为电流的通道断了。

家里的电灯、冰箱、电视都是并联的——关掉其中一个，其他电器照样工作，因为它们各有独立的电流通道。

串联和并联的规律不仅解释了我们身边的现象，更是电路分析的基本功。本章将用 12V 电源和两个电阻（100Ω100\Omega100Ω 和 200Ω200\Omega200Ω），分别搭建串联和并联电路，用仿真验证这些规律。

3. 动手设计电路 ​

3.1 串联电路 ​

将 R1=100ΩR_1 = 100\OmegaR1​=100Ω 和 R2=200ΩR_2 = 200\OmegaR2​=200Ω 首尾相接，连接到 12V 电源两端：

手算预期：

  • 等效电阻 R总=R1+R2=100Ω+200Ω=300ΩR_{总} = R_1 + R_2 = 100\Omega + 200\Omega = 300\OmegaR总​=R1​+R2​=100Ω+200Ω=300Ω
  • 电路总电流 I=VR总=12300=0.04A=40mAI = \frac{V}{R_{总}} = \frac{12}{300} = 0.04A = 40mAI=R总​V​=30012​=0.04A=40mA
  • R1R_1R1​ 两端电压 V1=I×R1=0.04×100=4VV_1 = I \times R_1 = 0.04 \times 100 = 4VV1​=I×R1​=0.04×100=4V
  • R2R_2R2​ 两端电压 V2=I×R2=0.04×200=8VV_2 = I \times R_2 = 0.04 \times 200 = 8VV2​=I×R2​=0.04×200=8V

验证分压比例：V1:V2=4:8=100:200=R1:R2V_1 : V_2 = 4 : 8 = 100 : 200 = R_1 : R_2V1​:V2​=4:8=100:200=R1​:R2​，电压确实按电阻比例分配。

3.2 并联电路 ​

将 R1=100ΩR_1 = 100\OmegaR1​=100Ω 和 R2=200ΩR_2 = 200\OmegaR2​=200Ω 的两端分别并联，连接到 12V 电源两端：

手算预期：

  • 等效电阻 1R总=1100+1200=2200+1200=3200\frac{1}{R_{总}} = \frac{1}{100} + \frac{1}{200} = \frac{2}{200} + \frac{1}{200} = \frac{3}{200}R总​1​=1001​+2001​=2002​+2001​=2003​，所以 R总=2003≈66.67ΩR_{总} = \frac{200}{3} \approx 66.67\OmegaR总​=3200​≈66.67Ω
  • 流过 R1R_1R1​ 的电流 I1=12100=0.12A=120mAI_1 = \frac{12}{100} = 0.12A = 120mAI1​=10012​=0.12A=120mA
  • 流过 R2R_2R2​ 的电流 I2=12200=0.06A=60mAI_2 = \frac{12}{200} = 0.06A = 60mAI2​=20012​=0.06A=60mA
  • 总电流 I总=I1+I2=0.18A=180mAI_{总} = I_1 + I_2 = 0.18A = 180mAI总​=I1​+I2​=0.18A=180mA

验证分流反比：I1:I2=120:60=2:1=200:100=R2:R1I_1 : I_2 = 120 : 60 = 2 : 1 = 200 : 100 = R_2 : R_1I1​:I2​=120:60=2:1=200:100=R2​:R1​，电流确实与电阻成反比。

4. 用 Python 实现电路仿真 ​

4.1 串联电路仿真 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

vsupply = 12@u_V
r1_val = 100@u_Ω
r2_val = 200@u_Ω

circuit_series = Circuit('Series Circuit')
circuit_series.V('input', 1, circuit_series.gnd, vsupply)
circuit_series.R(1, 1, 2, r1_val)
circuit_series.R(2, 2, circuit_series.gnd, r2_val)

sim_series = circuit_series.simulator(temperature=25, nominal_temperature=25,
                                      simulator='ngspice-subprocess')
analysis_series = sim_series.operating_point()

代码解释：

  • circuit_series.V('input', 1, circuit_series.gnd, vsupply)：在节点 1 和地（gnd）之间放置一个 12V 的电压源。
  • circuit_series.R(1, 1, 2, r1_val)：在节点 1 和节点 2 之间放置 R1R_1R1​（100Ω100\Omega100Ω）。
  • circuit_series.R(2, 2, circuit_series.gnd, r2_val)：在节点 2 和地之间放置 R2R_2R2​（200Ω200\Omega200Ω）。
  • 这样 R1R_1R1​ 和 R2R_2R2​ 首尾相接——节点 2 是它们的公共连接点，构成串联。
  • .operating_point() 计算直流工作点，得出各节点电压和支路电流。

终端输出：

text
==================================================
串联电路分析 (12V, R1=100Ω, R2=200Ω)
==================================================
节点 1 电压: 12.00 V
节点 2 电压: 8.00 V
R1 两端电压: 4.00 V
R2 两端电压: 8.00 V
串联电流: 0.040 A = 40.0 mA
等效电阻 (串联): 100 Ω + 200 Ω = 300 Ω

仿真结果与手算完全吻合：R1R_1R1​ 分到 4V（13\frac{1}{3}31​），R2R_2R2​ 分到 8V（23\frac{2}{3}32​），比例恰为 100:200100:200100:200。电流 40mA 与 12/30012/30012/300 一致。

4.2 并联电路仿真 ​

python
circuit_parallel = Circuit('Parallel Circuit')
circuit_parallel.V('input', 1, circuit_parallel.gnd, vsupply)
circuit_parallel.R(1, 1, circuit_parallel.gnd, r1_val)
circuit_parallel.R(2, 1, circuit_parallel.gnd, r2_val)

sim_parallel = circuit_parallel.simulator(temperature=25, nominal_temperature=25,
                                          simulator='ngspice-subprocess')
analysis_parallel = sim_parallel.operating_point()

代码解释：

  • circuit_parallel.R(1, 1, circuit_parallel.gnd, r1_val)：R1R_1R1​ 直接跨接在节点 1 和地之间。
  • circuit_parallel.R(2, 1, circuit_parallel.gnd, r2_val)：R2R_2R2​ 也直接跨接在节点 1 和地之间。
  • 两个电阻共享相同的两个节点（节点 1 和地），构成并联。它们的电压相等，都等于 12V。
  • 电流分别用 I=V/RI = V/RI=V/R 计算，总电流是两者之和。

终端输出：

text
==================================================
并联电路分析 (12V, R1=100Ω, R2=200Ω)
==================================================
节点 1 电压: 12.00 V
流过 R1 (100Ω) 的电流: 0.120 A = 120.0 mA
流过 R2 (200Ω) 的电流: 0.060 A = 60.0 mA
总电流: 0.180 A = 180.0 mA
等效电阻 (并联): 1/(1/100 + 1/200) = 66.67 Ω

仿真再次验证了手算：R1R_1R1​（100Ω100\Omega100Ω）电流 120mA120mA120mA，R2R_2R2​（200Ω200\Omega200Ω）电流 60mA60mA60mA，比值为 2:12:12:1，恰好是电阻的反比 200:100200:100200:100。总电流 180mA=12/66.67180mA = 12/66.67180mA=12/66.67。

4.3 对比总结 ​

将两组数据放在一起对比，规律一目了然：

特性串联电路并联电路
连接方式首尾相接，一条路两端并接，多条路
电压规律各元件电压之和 = 总电压各支路电压相等
电流规律各处电流相等总电流 = 各支路电流之和
等效电阻R总=300ΩR_{总} = 300\OmegaR总​=300Ω（增大）R总=66.67ΩR_{总} = 66.67\OmegaR总​=66.67Ω（减小）
电阻比与分配V1:V2=R1:R2V_1:V_2 = R_1:R_2V1​:V2​=R1​:R2​（分压）I1:I2=R2:R1I_1:I_2 = R_2:R_1I1​:I2​=R2​:R1​（分流）

5. 深入理解 ​

5.1 为什么串联分压 ​

从微观角度看，串联电路中电流只有一条通道。电子依次通过 R1R_1R1​ 和 R2R_2R2​，每经过一个电阻，电势就下降一部分——类似水流过一个接一个的水车，每个水车都消耗一部分水压。电阻越大，对电势的"消耗"就越多，分到的电压也就越大，因此 V1:V2=R1:R2V_1 : V_2 = R_1 : R_2V1​:V2​=R1​:R2​。

5.2 为什么并联分流 ​

并联电路给电子提供了多条通道。电压相同（都是 12V），根据 I=V/RI = V/RI=V/R，电阻越小的通道"门槛越低"，通过的电子就越多。因此 I1:I2=1/R1:1/R2=R2:R1I_1 : I_2 = 1/R_1 : 1/R_2 = R_2 : R_1I1​:I2​=1/R1​:1/R2​=R2​:R1​，电流与电阻成反比。总电流等于各通道电流之和——就像多开了一个水龙头，总出水量变大。

5.3 等效电阻的变化规律 ​

  • 串联等同于加长导线：电阻串联起来，相当于增加了导线的长度，阻碍增大，总电阻必然大于其中任何一个。R总=R1+R2=300Ω>200ΩR_{总} = R_1 + R_2 = 300\Omega > 200\OmegaR总​=R1​+R2​=300Ω>200Ω。
  • 并联等同于加粗导线：电阻并联起来，相当于增加了导线的横截面积，阻碍减小，总电阻必然小于其中任何一个。R总=66.67Ω<100ΩR_{总} = 66.67\Omega < 100\OmegaR总​=66.67Ω<100Ω。

这个规律在工程中非常实用：需要大电阻时串联两个较小的电阻；需要小电阻或大功率散热时并联多个电阻分担电流。

5.4 仿真 vs 手工 ​

我们手工计算时，需要一步步按照公式推导；而仿真中只需用 .operating_point() 一行指令，Ngspice 就在瞬间完成了所有节点电压和支路电流的计算。更妙的是，只要修改 r1_val 或 r2_val 的值（甚至只改一行代码），整个分析结果会自动更新，省去重新手算的麻烦。这正是仿真工具的魅力所在。

6. 本章小结 ​

  • 串联：电流一条路，电流相等，电压按电阻比例分配，R总=R1+R2R_{总} = R_1 + R_2R总​=R1​+R2​，总电阻增大。
  • 并联：电流多条路，电压相等，电流按电阻反比分配，1R总=1R1+1R2\frac{1}{R_{总}} = \frac{1}{R_1} + \frac{1}{R_2}R总​1​=R1​1​+R2​1​，总电阻减小。
  • 串联分压、并联分流是电路分析中最基础的两大规律，理解了它们就掌握了直流电路的核心。
  • PySpice 的 operating_point() 仿真可以轻松验证串并联的所有理论计算，一行为你算出所有节点电压。

7. 练习 ​

  1. 验证分压规律：将 R2R_2R2​ 改为 300Ω300\Omega300Ω，保持 R1=100ΩR_1 = 100\OmegaR1​=100Ω 和电源 12V 不变，重新运行串联仿真。计算 R1R_1R1​ 和 R2R_2R2​ 各自分到的电压，验证 V1:V2=R1:R2V_1 : V_2 = R_1 : R_2V1​:V2​=R1​:R2​ 是否依然成立。
