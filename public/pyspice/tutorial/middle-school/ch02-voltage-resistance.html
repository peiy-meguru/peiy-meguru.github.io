第2章 电压与电阻 ​

1. 本节你将学到 ​

  • 理解电压的物理意义：电压是推动电荷流动的"电压力"，单位是伏特（V）
  • 掌握电阻的概念：电阻是导体对电流的阻碍作用，单位是欧姆（Ω\OmegaΩ）
  • 学会用 Python + PySpice 构建串联电路，验证分压公式 VR2=Vin×R2R1+R2V_{R2} = V_{in} \times \frac{R_2}{R_1+R_2}VR2​=Vin​×R1​+R2​R2​​

2. 知识回顾/情景引入 ​

在第 1 章中，我们搭建了一个简单的电路：一节 10V 的电池连接一个 100Ω100\Omega100Ω 的电阻（灯泡），并用仿真算出了电流是 0.1A。但你有没有想过：为什么电池是 10V 而不是 8V 或 12V？那个"V"到底是什么意思？

2.1 电压——电的"推力" ​

想象一下水管里的水：水从高处流向低处，是因为有高度差（或者说水位差）。同样的道理，电荷在导线中流动，也是因为两端存在电位差——也就是我们常说的电压。

电压用字母 VVV 表示（有时也记作 UUU），单位是伏特（V），简称"伏"。这个单位以意大利物理学家亚历山德罗·伏特（Alessandro Volta）的名字命名——正是他在 1800 年发明了世界上第一个电池（伏打电堆）。

常见的电压值：

场景电压
一节干电池（AA/AAA）1.5V
手机锂电池3.7V
USB 接口5V
汽车电瓶12V
家用插座（中国）220V

电压越大，推动电荷流动的"力量"就越强。 在后续章节中你会看到，电压 VVV、电流 III 和电阻 RRR 之间存在精确的数学关系——这就是著名的欧姆定律。

2.2 电阻——电的"阻力" ​

如果把电压比作水管中的水压，那么电阻就像是水管内壁的粗糙程度——粗糙的管壁会让水流起来更费劲，同样，高电阻的导体也会让电流更难以通过。

电阻用字母 RRR 表示，单位是欧姆（Ω\OmegaΩ），以德国物理学家乔治·欧姆（Georg Ohm）命名。1Ω1\Omega1Ω 的定义是：在导体两端加上 1V 电压时，如果流过导体的电流恰好是 1A，这个导体的电阻就是 1Ω1\Omega1Ω。

不同材料的导电能力差异巨大：

  • 铜（1.68×10−8Ω⋅m1.68 \times 10^{-8} \Omega \cdot m1.68×10−8Ω⋅m）：电阻率很小，常用作导线，让电流顺畅通过。
  • 橡胶/塑料：电阻极大，接近无穷大，用作绝缘层包裹在导线外面，防止触电。
  • 电阻器：专门设计的元件，有固定的电阻值（如 100Ω100\Omega100Ω、1kΩ1k\Omega1kΩ），用来控制电路中的电流大小。

每个用电器都有一定的电阻。灯泡的灯丝（通常是钨丝）电阻约为几十到几百欧姆；手机芯片的电阻则更复杂，因为半导体不是简单的线性电阻。

3. 动手设计电路 ​

3.1 本节电路 ​

在本节中，我们要搭建两个电路：

  1. 电路1：一个 12V 电池连接一个 100Ω100\Omega100Ω 的电阻。用来验证电压和电流的基本关系。
  2. 电路2：一个 12V 电池连接两个串联电阻——R1=200ΩR_1 = 200\OmegaR1​=200Ω 和 R2=100ΩR_2 = 100\OmegaR2​=100Ω。用来探究串联电路中电压是如何分配的。

电路图如下：

3.2 手工计算电路1 ​

根据欧姆定律（第 3 章会有详细推导，此处直接使用）：

I=VRI = \frac{V}{R} I=RV​

对于电路1，V=12VV = 12\text{V}V=12V，R=100ΩR = 100\OmegaR=100Ω：

I=12100=0.12A=120mAI = \frac{12}{100} = 0.12\text{A} = 120\text{mA} I=10012​=0.12A=120mA

整个 12V 电压全部加在唯一的电阻上，所以电阻两端电压就是 12V。

3.3 手工计算电路2 —— 串联分压 ​

两个电阻串联意味着电流只有一条路径：从电池正极出发 → R1R_1R1​ → R2R_2R2​ → 回到电池负极。因为是同一条路径，流过 R1R_1R1​ 和 R2R_2R2​ 的电流是一样的。

串联电路的总电阻：

Rtotal=R1+R2=200+100=300ΩR_{total} = R_1 + R_2 = 200 + 100 = 300\Omega Rtotal​=R1​+R2​=200+100=300Ω

总电流：

I=VinRtotal=12300=0.04A=40mAI = \frac{V_{in}}{R_{total}} = \frac{12}{300} = 0.04\text{A} = 40\text{mA} I=Rtotal​Vin​​=30012​=0.04A=40mA

现在来看每个电阻两端的电压。根据欧姆定律 V=IRV = IRV=IR：

  • R1R_1R1​ 两端电压：VR1=I×R1=0.04×200=8VV_{R1} = I \times R_1 = 0.04 \times 200 = 8\text{V}VR1​=I×R1​=0.04×200=8V
  • R2R_2R2​ 两端电压：VR2=I×R2=0.04×100=4VV_{R2} = I \times R_2 = 0.04 \times 100 = 4\text{V}VR2​=I×R2​=0.04×100=4V

注意：8V+4V=12V8\text{V} + 4\text{V} = 12\text{V}8V+4V=12V，恰好等于电池电压！这就是串联分压原理——电池总电压被分配给各个电阻，分配比例等于各电阻值与总电阻的比值。

推广到一般情况，对于两个串联电阻 R1R_1R1​ 和 R2R_2R2​，每个电阻上分到的电压为：

VR1=Vin×R1R1+R2V_{R1} = V_{in} \times \frac{R_1}{R_1 + R_2} VR1​=Vin​×R1​+R2​R1​​

VR2=Vin×R2R1+R2V_{R2} = V_{in} \times \frac{R_2}{R_1 + R_2} VR2​=Vin​×R1​+R2​R2​​

代入验证：VR2=12×100200+100=12×100300=4VV_{R2} = 12 \times \frac{100}{200 + 100} = 12 \times \frac{100}{300} = 4\text{V}VR2​=12×200+100100​=12×300100​=4V ✓ 完全一致！

💡 直观理解：电阻越大，分到的电压越多。这就像两个人一起抬一块大石头——力气大的人（大电阻）承担了更多的重量（电压）。在电路2中，R1=200ΩR_1 = 200\OmegaR1​=200Ω 是 R2=100ΩR_2 = 100\OmegaR2​=100Ω 的两倍，所以 R1R_1R1​ 分到的电压（8V）恰好也是 R2R_2R2​（4V）的两倍。

4. 用 Python 实现电路仿真 ​

4.1 电路1：单个电阻 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

# 电路1：单个电阻
circuit1 = Circuit('Single Resistor')
circuit1.V('input', 1, circuit1.gnd, 12@u_V)
circuit1.R(1, 1, circuit1.gnd, 100@u_Ω)

sim1 = circuit1.simulator(temperature=25, nominal_temperature=25,
                          simulator='ngspice-subprocess')
analysis1 = sim1.operating_point()

print("=" * 50)
print("电路1：单个 100Ω 电阻，12V 电源")
print("=" * 50)
v = float(analysis1.nodes['1'][0])
print("电阻两端电压: {:.2f} V".format(v))
print("流过电阻的电流: {:.3f} A = {:.1f} mA".format(v/100, v/100*1000))

代码解释：

  • circuit1.V('input', 1, circuit1.gnd, 12@u_V)：添加一个 12V 的电压源，正极接节点 1，负极接地。
  • circuit1.R(1, 1, circuit1.gnd, 100@u_Ω)：在节点 1 和地之间添加一个 100Ω100\Omega100Ω 的电阻。
  • sim1.operating_point()：计算电路的直流工作点，得到每个节点的电压。

4.2 电路2：两个电阻串联 ​

python
# 电路2：两个电阻串联
circuit2 = Circuit('Two Resistors in Series')
circuit2.V('input', 1, circuit2.gnd, 12@u_V)
circuit2.R(1, 1, 2, 200@u_Ω)
circuit2.R(2, 2, circuit2.gnd, 100@u_Ω)

sim2 = circuit2.simulator(temperature=25, nominal_temperature=25,
                          simulator='ngspice-subprocess')
analysis2 = sim2.operating_point()

print("\n" + "=" * 50)
print("电路2：两个电阻串联 (200Ω + 100Ω)，12V 电源")
print("=" * 50)
v1 = float(analysis2.nodes['1'][0])
v2 = float(analysis2.nodes['2'][0])
print("节点 1 (电源端) 电压: {:.2f} V".format(v1))
print("节点 2 (两电阻之间) 电压: {:.2f} V".format(v2))
print("R1 (200Ω) 两端电压差: {:.2f} V".format(v1 - v2))
print("R2 (100Ω) 两端电压差: {:.2f} V".format(v2))
print("验证分压公式: V_R2 = Vin * R2/(R1+R2) = 12 * 100/300 = {:.2f} V".format(12*100/300))

代码解释：

  • 在 R1R_1R1​（200Ω200\Omega200Ω）和 R2R_2R2​（100Ω100\Omega100Ω）之间引入了节点 2。节点 2 不是直接接地，而是连接在 R1R_1R1​ 的下端和 R2R_2R2​ 的上端之间。
  • analysis2.nodes[’2’][0]\text{analysis2.nodes['2'][0]}analysis2.nodes[’2’][0] 读取的就是节点 2 的电压——也就是 R2R_2R2​ 两端的电压（因为 R2R_2R2​ 的下端接地，电压为 0V）。

4.3 仿真结果 ​

运行上述代码，终端输出：

text
==================================================
电路1：单个 100Ω 电阻，12V 电源
==================================================
电阻两端电压: 12.00 V
流过电阻的电流: 0.120 A = 120.0 mA

==================================================
电路2：两个电阻串联 (200Ω + 100Ω)，12V 电源
==================================================
节点 1 (电源端) 电压: 12.00 V
节点 2 (两电阻之间) 电压: 4.00 V
R1 (200Ω) 两端电压差: 8.00 V
R2 (100Ω) 两端电压差: 4.00 V
验证分压公式: V_R2 = Vin * R2/(R1+R2) = 12 * 100/300 = 4.00 V

结果解读：

  • 电路1：Ngspice 算出电阻两端电压为 12.00V，与电池电压一致。根据 I=V/R=12/100I = V/R = 12/100I=V/R=12/100，电流为 0.120A（120mA）。
  • 电路2：节点 2 的电压是 4.00V——这正是 R2R_2R2​ 分到的电压。验证分压公式计算出的结果恰好也是 4.00V，仿真与理论完全吻合。
  • 串联分压成立：R1R_1R1​ 两端压在 8V，R2R_2R2​ 两端压在 4V，8V+4V=12V8V + 4V = 12V8V+4V=12V，总电压等于各分电压之和。

🎉 恭喜！ 你已经掌握了串联分压的原理。这个原理在电子电路中无处不在——很多传感器（如光敏电阻、热敏电阻）就是利用分压原理把"光线强弱"或"温度高低"转换成"电压高低"，然后送给微控制器去读取。

分压原理的应用 ​

串联分压是一个非常实用的电路技巧。当你手头只有一个 12V 电源，但需要供给一个 5V 的单片机时，就可以用两个电阻做一个"分压器"，把 12V 降到 5V（当然实际工程中还需要考虑负载效应和功率，这些在后续章节会讲到）。

分压器的设计思路很简单：如果你希望从 VinV_{in}Vin​ 得到一个目标电压 VoutV_{out}Vout​，只需选择两个电阻满足：

R2R1+R2=VoutVin\frac{R_2}{R_1 + R_2} = \frac{V_{out}}{V_{in}} R1​+R2​R2​​=Vin​Vout​​

比如要从 12V 分出 3V，可以让 R1=300ΩR_1 = 300\OmegaR1​=300Ω，R2=100ΩR_2 = 100\OmegaR2​=100Ω，因为 100400=0.25\frac{100}{400} = 0.25400100​=0.25，12×0.25=3V12 \times 0.25 = 3\text{V}12×0.25=3V。你可以自己修改仿真代码验证一下！

电阻的物理本质 ​

从微观角度来看，电阻源于自由电子在导体中运动时与原子之间的碰撞。电子在电场驱动下加速前进，但每飞行一小段距离就会与金属原子发生碰撞，损失能量（这些能量转化成了热能——这就是电阻发热的原因）。不同材料的原子排列方式不同，电子碰撞的频繁程度也不同，因此电阻率各异。铜的原子排列非常整齐，电子可以相对顺畅地穿行，所以铜的电阻很小；而像橡胶这样的绝缘体，几乎所有电子都被原子牢牢束缚住，几乎没有自由电子可以移动，因此电阻极大。

6. 本章小结 ​

  • 电压 VVV 是驱动电荷流动的"电压力"，单位是伏特（V）。12V 的电池比 10V 的电池提供的"推力"更大。
  • 电阻 RRR 是导体阻碍电流的能力，单位是欧姆（Ω\OmegaΩ）。100Ω100\Omega100Ω 的电阻对电流的阻碍是 50Ω50\Omega50Ω 的两倍。
  • 串联分压原理：在串联电路中，总电压按电阻比例分配给各个电阻。公式为 VRn=Vin×RnRtotalV_{Rn} = V_{in} \times \frac{R_n}{R_{total}}VRn​=Vin​×Rtotal​Rn​​。
  • PySpice 可以通过多节点的电路来验证分压公式，仿真结果与手工计算完全吻合。
