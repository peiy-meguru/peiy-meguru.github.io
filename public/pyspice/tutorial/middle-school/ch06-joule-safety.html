第6章 焦耳定律与安全用电 ​

1. 本节你将学到 ​

  • 理解焦耳定律的物理意义：电流通过导体时产生的热量 Q=I2RtQ = I^2RtQ=I2Rt
  • 认识热效应的平方关系：热量与电流的平方成正比，电流增大，发热急剧增加
  • 掌握短路的概念及其极端危害：短路时电阻极小 → 电流极大 → 发热剧烈
  • 理解保险丝和断路器的保护原理：通过自动断开电路防止过载
  • 学会用 PySpice 仿真正常电路和短路电路，对比两者的电流和功率差异

2. 知识回顾/情景引入 ​

2.1 焦耳定律的发现 ​

1840 年，英国物理学家詹姆斯·焦耳（James Prescott Joule）通过大量实验发现：电流通过导体产生的热量，与电流的平方、导体的电阻和通电时间成正比。用数学公式表达：

Q=I2RtQ = I^2 Rt Q=I2Rt

其中 QQQ 是热量（焦耳 J），III 是电流（安培 A），RRR 是电阻（欧姆 Ω\OmegaΩ），ttt 是通电时间（秒 s）。

焦耳并不满足于只发现规律，他还想验证"热是能量的一种形式"。他设计了一个经典实验：用重物下落带动桨叶搅动水，测量水温升高，从而证明机械功可以转化为热量。他还测得 4.18J4.18J4.18J 的机械功能使 1g1g1g 水升温 1∘C1^{\circ}C1∘C——这就是"热功当量"，今天我们知道这个值是 4.186J≈1cal4.186J \approx 1cal4.186J≈1cal。

2.2 热效应的双重面孔 ​

电流的热效应是一把双刃剑：

  • 利用热效应：电饭煲、电热水器、电暖气、白炽灯——这些电器把电能转化为热能，让我们的日常生活更加便利。
  • 防止热效应：输电线路、充电器、电脑、手机——这些设备不希望发热，发热意味着能量损耗和设备老化。

2.3 短路——看不见的危险 ​

当电路中的火线和零线不经过用电器直接相连（电阻极小），就会发生短路。短路时：

  1. 根据欧姆定律 I=URI = \frac{U}{R}I=RU​，RRR 极小（如导线 0.1Ω），III 就会极大（如 220V/0.1Ω = 2200A）
  2. 根据焦耳定律 Q=I2RtQ = I^2RtQ=I2Rt，III 以平方形式出现——电流增大到正常值的 nnn 倍，发热就增大到 n2n^2n2 倍

这就是为什么短路极其危险——导线会在极短时间内产生大量热量，足以熔毁绝缘层、引发火灾。

3. 动手设计电路 ​

3.1 正常电路：家用电器 ​

模拟一个典型家用电器：标有"220V 100W"的灯泡。通过它的电阻来构造电路。

先求灯泡电阻：

R=U2P=2202100=484ΩR = \frac{U^2}{P} = \frac{220^2}{100} = 484\Omega R=PU2​=1002202​=484Ω

电路为：220V 电源 → 484Ω484\Omega484Ω 电阻（灯泡）→ 地。

手算预期：

  • 电流 I=UR=220484≈0.45AI = \frac{U}{R} = \frac{220}{484} \approx 0.45AI=RU​=484220​≈0.45A
  • 功率 P=UI=220×0.45=100WP = UI = 220 \times 0.45 = 100WP=UI=220×0.45=100W
  • 每秒发热 Q=P×1s=100JQ = P \times 1s = 100JQ=P×1s=100J

3.2 短路电路：可怕的对决 ​

如果火线和零线之间被一段导线直接连接（假设导线电阻为 0.1Ω0.1\Omega0.1Ω），这就是短路：

  • 电流 I=UR=2200.1=2200AI = \frac{U}{R} = \frac{220}{0.1} = 2200AI=RU​=0.1220​=2200A
  • 功率 P=UI=220×2200=484000W=484kWP = UI = 220 \times 2200 = 484000W = 484kWP=UI=220×2200=484000W=484kW

484kW 意味着什么？普通家庭入户总功率通常在 6kW~12kW。短路的功率是一个家庭总负荷的 40 到 80 倍！这样的巨大能量集中在小小的一段导线上，结果可想而知——导线瞬间熔断，产生电弧和高温，极易点燃周围可燃物。

3.3 安全装置的作用 ​

保险丝（熔断器）和断路器（空气开关）的作用就是：当电流超过安全阈值时，自动切断电路。保险丝利用电流热效应本身——一段低熔点合金丝，大电流通过时自身发热熔断。断路器利用电磁效应或热效应驱动机械开关跳开。两者的共同目标都是：在导线熔化之前切断电源。

4. 用 Python 实现电路仿真 ​

4.1 正常电路仿真 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

circuit_normal = Circuit('Normal Circuit')
circuit_normal.V('input', 1, circuit_normal.gnd, 220@u_V)
circuit_normal.R('load', 1, circuit_normal.gnd, 484@u_Ω)

sim = circuit_normal.simulator(temperature=25, nominal_temperature=25,
                               simulator='ngspice-subprocess')
analysis = sim.operating_point()

代码解释：

  • 电压源设为 220V——中国家庭用电标准电压。
  • 负载电阻 484Ω——相当于 100W 灯泡的等效电阻。
  • .operating_point() 计算直流工作点，得到节点电压值。电流和功率通过 I=V/RI = V/RI=V/R 和 P=VIP = VIP=VI 计算。

4.2 短路电路仿真 ​

python
circuit_short = Circuit('Short Circuit')
circuit_short.V('input', 1, circuit_short.gnd, 220@u_V)
circuit_short.R('wire', 1, circuit_short.gnd, 0.1@u_Ω)

sim2 = circuit_short.simulator(temperature=25, nominal_temperature=25,
                               simulator='ngspice-subprocess')
analysis2 = sim2.operating_point()

代码解释：

  • 电阻值 0.1Ω0.1\Omega0.1Ω 模拟短路导线——实际导线有一定电阻，不会真的为零，但已经足够小来展示短路危害。
  • 除电阻值外，电路拓扑与正常电路完全相同——两个电路的区别仅在于负载电阻从 484Ω 猛降到 0.1Ω，而后果却天差地别。

5. 深入理解 ​

5.1 焦耳定律的微观解释 ​

从微观角度看，金属导体中存在大量自由电子。这些电子在电场驱动下定向移动（形成电流），沿途不断撞击金属晶格中的原子。每一次撞击都将电子的动能转化为原子的振动能（宏观上就是热能）。电流越大，意味着单位时间内通过截面的电子越多、速度越快，撞击也就越频繁、越剧烈——因此热量 Q∝I2Q \propto I^2Q∝I2。

电阻 RRR 越大，意味着导体对电子的"阻碍"越强——电子在同样的距离内遭受更多撞击，因此 Q∝RQ \propto RQ∝R。通电时间 ttt 越长，撞击发生的总次数越多，因此 Q∝tQ \propto tQ∝t。三个因素合在一起，就是 Q=I2RtQ = I^2RtQ=I2Rt。

5.2 为什么是 I2I^2I2 而不是 III ​

这是焦耳定律最关键的特征：电流以平方形式出现。这意味着：

  • 电流为正常的 2 倍 → 发热为 4 倍
  • 电流为正常的 10 倍 → 发热为 100 倍
  • 电流为正常的 100 倍 → 发热为 10000 倍

在短路仿真中，电流从 0.45A 增大到 2200A（近 5000 倍），每秒发热从 100J 增大到 484000J（近 5000 倍）。注意发热倍数 ≈ 电流倍数（不是平方！），这是因为电阻同时也变了（484Ω → 0.1Ω，减小了 4840 倍）。如果电阻不变，Q∝I2Q \propto I^2Q∝I2 的平方关系就会清楚地体现出来。

5.3 保险丝的工作原理 ​

保险丝是一段特殊设计的金属丝，放在电路的干路中，所有电流都要经过它。它的材料具有：

  • 低熔点：铅锡合金，大约在 200°C~300°C 就会熔断
  • 电阻适中：比铜导线电阻大，确保相同电流下发热更多

正常电流下，保险丝的发热与散热达到平衡，温度保持稳定。一旦发生过载或短路，电流急剧增大 → 保险丝发热剧烈增加 → 温度迅速超过熔点 → 保险丝熔断 → 电路断开。整个过程可能在 0.01 秒内完成，远快于导线本身的熔断速度——这就是保险丝"牺牲自己，保护全局"的原理。

5.4 安全用电要点 ​

从仿真中我们可以总结几条家庭用电安全规则：

  1. 不超负荷：一个插座不要同时插太多大功率电器（电热水器、空调、微波炉等），避免总电流超过线路承载能力。
  2. 不用裸导线：确保所有导线都有完好的绝缘层，防止火线与零线意外接触造成短路。
  3. 保持保险装置完好：不要用铜丝、铁丝等替代烧断的保险丝——它们熔点太高，可能到线路烧毁都不熔断。
  4. 发现异常立即断电：如果闻到焦味、看到插座冒烟、或断路器反复跳闸，立即切断总电源并请专业电工检查。

6. 本章小结 ​

  • 焦耳定律 Q=I2RtQ = I^2RtQ=I2Rt：电流通过导体产生的热量，与电流的平方、电阻和通电时间成正比。
  • 电流的热效应既能被利用（电热器、电饭煲），也能造成危害（线路过热、火灾），关键是控制电流大小。
  • 短路是最危险的电路故障：火线零线不经用电器直接相连，电阻极小导致电流极大，发热剧烈（P=484000WP = 484000WP=484000W！）。
  • 保险丝和断路器利用电流热效应或电磁效应在电流过载时自动切断电路，是家庭安全用电的"守门卫士"。
  • PySpice 的 .operating_point() 仿真可以快速对比正常电路和短路电路的电压、电流和功率，直观感受短路危害。

7. 练习 ​

  1. 焦耳定律计算：一个 50Ω50\Omega50Ω 的电阻通以 2A 的电流，求通电 10 秒后产生的热量。用手工计算（Q=I2Rt=22×50×10=400JQ = I^2Rt = 2^2 \times 50 \times 10 = 400JQ=I2Rt=22×50×10=400J），然后思考：如果电流变为 4A（2 倍），通电时间不变，热量会变为多少？为什么不是 2 倍而是 4 倍？

  2. 改变短路电阻：将短路仿真中的导线电阻从 0.1Ω0.1\Omega0.1Ω 改为 0.5Ω0.5\Omega0.5Ω，重新运行仿真。计算电流和功率，与 0.1Ω0.1\Omega0.1Ω 的结果对比。为什么阻值大了 5 倍，电流"只"小了 5 倍，但危险程度仍然极高？

  3. 设计安全阈值：假设一段铜导线的安全电流是 10A（超过此值导线会过热损坏）。如果家庭电压为 220V，要防止短路时电流超过 10A，保险丝应该选多大阻值？这种保险丝是否可行？（提示：R=U/I=220/10=22ΩR = U/I = 220/10 = 22\OmegaR=U/I=220/10=22Ω，但正常工作时串联 22Ω 的保险丝会消耗大量电压和功率，不可行。因此实际保险丝的阻值非常小——通常毫欧级别——靠熔断温度而不是欧姆定律来保护电路。）

  4. 比较两种保护方式：查阅资料，说说保险丝和断路器（空气开关）各自的优缺点。为什么现代家庭越来越多地使用断路器替代老式保险丝？

  5. 综合计算题：一个标有"220V 2000W"的电热水器正常工作了 15 分钟。求：(1) 热水器的电阻；(2) 工作时流过的电流；(3) 总消耗电能是多少 kWh？(4) 如果供电电压突然降到 180V，这时的实际功率是多少？
