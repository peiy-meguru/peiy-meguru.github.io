第1章 电路与电流 ​

1. 本节你将学到 ​

  • 理解电路的基本概念：电源、用电器、导线、开关是怎么组成一个完整回路的
  • 掌握电流的定义公式 I=QtI = \frac{Q}{t}I=tQ​，知道电流的方向和单位
  • 学会用 Python + PySpice 构建第一个电路，用仿真验证欧姆定律 I=VRI = \frac{V}{R}I=RV​

2. 知识回顾/情景引入 ​

你有没有想过：当你按下手电筒的开关，灯光在那一瞬间点亮，背后到底发生了什么？或者当你把手机充电器插上插座，看不见的"电"是怎么流进电池里的？

其实，这些现象都离不开一个最基本的概念——电路。

什么是电路？ ​

电路就是让电流流动的闭合路径。一个最简单的电路由四个部分组成：

  • 电源：提供电能的装置。比如手电筒里的干电池、手机充电器插的那个 USB 口、发电站送来的市电插座。电源的作用是"推动"电荷在导体中流动，就像水泵推动水管里的水流动一样。
  • 用电器：消耗电能的装置。灯泡把电能变成光，电风扇把电能变成机械运动，手机芯片把电能变成计算能力——这些都是用电器的例子。
  • 导线：连接电源和用电器的金属线。它们通常是铜做的，因为铜对电流的阻碍很小，电荷可以在里面顺畅地流动。
  • 开关：控制电路通断的装置。开关合上，电路就"通"了，电流开始流动；开关断开，电路就"断"了，电流停止流动。

把这四个部分首尾相连，形成一个闭合回路，电流就能持续不断地流动。缺少任何一个部分，或者回路在某处断开，电流就会停止——这也就是为什么如果手电筒的灯泡坏了（用电器断开），手电筒就不会亮。

💡 思考一下：如果直接把导线两端接到电池的 +、- 极，中间不接任何用电器，会发生什么？这叫短路——导线电阻极小，电流会非常大，电池会迅速发热甚至损坏。在第 6 章我们会详细讨论短路和安全用电。

3. 动手设计电路 ​

3.1 电路原理 ​

电流是电荷的定向移动。我们用字母 III 来表示电流，它的定义是：

I=QtI = \frac{Q}{t} I=tQ​

其中 QQQ 是通过导体截面的电荷量（单位：库仑 C），ttt 是流过这些电荷所用的时间（单位：秒 s）。电流的单位是安培（A），简称"安"。1A=1C/s1\text{A} = 1\text{C/s}1A=1C/s，也就是说每秒有 1 库仑的电荷流过。

在本章中，我们要搭建一个最简单的电路：一个 10V 的干电池，用导线连接一个"灯泡"（在仿真中我们用 100Ω100\Omega100Ω 的电阻来代替灯泡）。电路图如下：

3.2 画出电路图 ​

这张电路图上有几个电路符号你需要认识：

  • 电池：两条长短不一的平行线。长线代表正极（+），短线代表负极（-）。电流的方向是从正极出发，经过外电路，流回负极。图中标注了 10V，表示这个电池的电压是 10 伏特。
  • 电阻：锯齿状折线。在电路图中代表用电器。我们这里用一个 100Ω100\Omega100Ω 的电阻来模拟一个灯泡。电阻的单位是欧姆（Ω\OmegaΩ），读作"欧"。
  • 导线：简单的直线，把各个元件连接起来，形成闭合回路。

在这张图中，从电池正极出发，顺时针经过电阻，再沿导线回到电池负极，就形成了一个完整的回路。

3.3 手工计算预期结果 ​

在学习仿真之前，我们先用手算一遍，这样以后看到仿真结果的时候就知道它对不对了。

根据欧姆定律（这条定律在第 3 章会详细讲解，这里先简单使用）：

I=VRI = \frac{V}{R} I=RV​

代入我们的数值：

I=10V100Ω=0.1A=100mAI = \frac{10\text{V}}{100\Omega} = 0.1\text{A} = 100\text{mA} I=100Ω10V​=0.1A=100mA

所以预期结果：流经灯泡的电流应该是 0.1 安培，或者说 100 毫安。

💡 毫安（mA）到安（A）的换算：1A=1000mA1\text{A} = 1000\text{mA}1A=1000mA，所以 0.1A=100mA0.1\text{A} = 100\text{mA}0.1A=100mA。在实际生活中，手机充电电流通常在 500mA 到 2000mA 之间，手电筒的电流则在 100mA 到 500mA 左右。

4. 用 Python 实现电路仿真 ​

现在，让我们用 Python 和 PySpice 来搭建上面这个电路，看看仿真结果和手算是否一致。

4.1 构建电路 ​

下面的代码创建了一个名为 Simple Circuit 的电路对象，然后往里面添加了一个 10V 的电压源和一个 100Ω100\Omega100Ω 的电阻。

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

circuit = Circuit('Simple Circuit')

# 10V 电池，正极连节点 1，负极连地（节点 0）
circuit.V('input', 1, circuit.gnd, 10@u_V)

# 灯泡可以看作一个电阻，我们用一个 100Ω 的电阻表示
circuit.R('lamp', 1, circuit.gnd, 100@u_Ω)

代码解释：

  • Circuit('Simple Circuit')：创建一个新的电路，给它取名为 "Simple Circuit"。
  • circuit.V(...)：向电路添加一个电压源（Voltage source）。第一个参数 'input' 是给它起的名字。后面两个数字 1 和 circuit.gnd 表示它连接在节点 1 和地（节点 0）之间。最后的 10@u_V 是 PySpice 的特殊写法：把数值 10 和单位 u_V（伏特）绑定在一起。PySpice 会自动给你带单位，既直观又不容易出错。
  • circuit.R(...)：向电路添加一个电阻（Resistor）。名称是 'lamp'，连接在节点 1 和地之间，阻值是 100Ω100\Omega100Ω。
  • 节点 1 是电池正极和电阻之间的连接点。节点 0（即 circuit.gnd）是参考点（地），所有电压都是相对于它来测量的。

4.2 运行仿真 ​

电路搭好之后，我们要让 Ngspice 引擎来"算一算"这个电路的直流工作状态。这种分析叫工作点分析（Operating Point Analysis）。

python
simulator = circuit.simulator(temperature=25, nominal_temperature=25,
                              simulator='ngspice-subprocess')
analysis = simulator.operating_point()

print("=" * 50)
print("电路仿真结果：简单电路")
print("=" * 50)
for node in analysis.nodes.values():
    voltage = float(node[0])
    print("节点 {} 的电压: {:6.2f} V".format(str(node), voltage))

voltage = float(analysis.nodes['1'][0])
resistance = 100
current = voltage / resistance
print("\n根据欧姆定律 I = V / R:")
print("电流 I = {:.2f} V / {} Ω = {:.3f} A".format(voltage, resistance, current))
print("电流 I = {:.2f} mA".format(current * 1000))

代码解释：

  • simulator.operating_point() 告诉 Ngspice："请计算电路中所有节点的电压和所有支路的电流"。这就像用万用表去量每个电路节点的电压一样。
  • analysis.nodes 是一个字典，里面装着所有节点的电压值。我们用 for 循环把它们一个个打印出来。
  • 打印完电压后，我们再用欧姆定律手算一遍电流。注意这并不是"闲着没事干"——比较手算结果和仿真结果的一致性，是验证电路是否正确的关键步骤。

4.3 查看结果 ​

运行上面的代码，终端会输出：

text
==================================================
电路仿真结果：简单电路
==================================================
节点 1 的电压:  10.00 V

根据欧姆定律 I = V / R:
电流 I = 10.00 V / 100 Ω = 0.100 A
电流 I = 100.00 mA

结果解读：

  • 节点 1 的电压是 10.00V：节点 1 是电池正极和电阻的连接点。Ngspice 算出的电压正好是 10V，和我们电池铭牌上标的完全一致——这说明电路构建正确。
  • 电流是 0.100A = 100mA：根据欧姆定律 I=10/100=0.1AI = 10/100 = 0.1\text{A}I=10/100=0.1A，计算出来的电流和手工预期完全吻合。

🎉 恭喜！ 你刚才成功地用计算机仿真了一个真实电路。虽然这只是最简单的单灯电路，但万里长征的第一步已经迈出去了。

4.4 绘制图表 ​

本章的图表就是上面那张电路图。我们使用了一个叫 schemdraw 的 Python 库来自动绘制电路图。等你学完后面的章节，你会发现用代码画电路图比手工拿尺子画要快得多，而且改动参数后图片会自动更新。

画这张图的代码也很简单：

python
import schemdraw
import schemdraw.elements as elm

with schemdraw.Drawing() as d:
    elm.Battery().up().label('10V', loc='bot')
    elm.Resistor().right().label('100Ω')
    elm.Line().down()
    elm.Line().left()

d.save('ch01_circuit.svg')

5. 深入理解 ​

让我们来深入思考一下刚才的仿真结果。

手工计算 vs 仿真结果 ​

比较项目手工计算仿真结果
节点 1 电压10.00V10.00V
流过电阻的电流0.100A0.100A（从电压算出）

两者完全一致。这不是巧合——因为我们用的是一个非常简单的电路，没有复杂的非线性元件，所以欧姆定律 I=V/RI = V/RI=V/R 能给出精确的预测。

为什么电流是 0.1A 而不是别的值？ ​

电流的大小取决于两个因素：

  1. 电压（V）：是"推力"。电压越大，相同电阻下电流越大。如果电池是 20V，电流就会变成 0.2A。
  2. 电阻（R）：是"阻力"。电阻越大，相同电压下电流越小。如果灯泡是 200Ω200\Omega200Ω，电流就只有 0.05A。

💡 你可以试着在脑海中改一下参数：如果电池是 5V、电阻是 50Ω50\Omega50Ω，电流会是多少？（答案：I=5/50=0.1AI = 5/50 = 0.1\text{A}I=5/50=0.1A——还是 0.1A！这就是电压和电阻"等比例变化"时，电流保持不变的有趣现象。）

电流的物理意义 ​

0.1A 到底意味着什么？让我们回到电流的定义 I=Q/tI = Q/tI=Q/t：

0.1A=0.1C/s0.1\text{A} = 0.1\text{C/s} 0.1A=0.1C/s

这意味着每秒钟有 0.1 库仑的电荷通过电阻的任意截面。1 库仑大约等于 6.24×10186.24 \times 10^{18}6.24×1018 个电子所带的电荷量。也就是说，每秒大约有 6.24×10176.24 \times 10^{17}6.24×1017 个电子（约 624,000,000,000,000,000 个！）在导线中漂移。虽然每个电子漂移的速度其实很慢（大约每秒几毫米），但因为导线里到处都是电子，所以开关一合上，整个回路几乎瞬间就有电流流过——就像一根灌满了水的水管，打开龙头时水立刻就从另一端流出来。

6. 本章小结 ​

  • 电路是由电源、用电器、导线、开关组成的闭合回路。四者缺一不可。
  • 电流 III 表示电荷流动的快慢，定义是 I=Q/tI = Q/tI=Q/t，单位是安培（A）。
  • PySpice 通过 Circuit、.V()、.R() 等方法来构建电路，通过 operating_point() 来计算直流工作点。
  • 欧姆定律 I=V/RI = V/RI=V/R 在简单电阻电路中给出了精确的电流预测，仿真结果与手工计算完全吻合。

7. 练习 ​

  1. 修改参数并预测结果：如果电池电压改为 5V5\text{V}5V，电阻改为 50Ω50\Omega50Ω，电流会变吗？为什么？用 Python 改一下代码中的数值，重新运行仿真，看看你的预测对不对。

  2. 思考题：在本章的电路中，如果导线在某处断开了（形成"断路"），Ngspice 会输出什么结果？试着在代码中把电阻断开（比如删掉 circuit.R(...) 这行），看看会发生什么。（提示：一个有电池但没有闭合回路的电路，电流会是 0。）
