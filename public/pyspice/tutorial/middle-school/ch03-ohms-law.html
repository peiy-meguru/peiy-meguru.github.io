第3章 欧姆定律 ​

1. 本节你将学到 ​

  • 理解欧姆定律的物理意义：I=VRI = \frac{V}{R}I=RV​，电流与电压成正比，与电阻成反比
  • 掌握欧姆定律三种变形：V=IRV = IRV=IR、I=VRI = \frac{V}{R}I=RV​、R=VIR = \frac{V}{I}R=IV​
  • 学会用 Python + PySpice 进行 DC 扫描，绘制电阻的 I-V 特性曲线

2. 知识回顾/情景引入 ​

在第 2 章中，我们学习了电压是推动电荷流动的"推力"，电阻是导体阻碍电流的"阻力"。那么两者放在一起，电流到底有多大？这就要说到电学中最重要的一条定律——欧姆定律。

2.1 欧姆的发现 ​

1826 年，德国物理学家乔治·西蒙·欧姆（Georg Simon Ohm）做了一个巧妙的实验。他用不同材料的导线连接电池（当时用的是温差电池，电压不稳定），仔细测量导线两端的电压和流过导线的电流。他发现了一个简单却美妙的规律：

流过导体的电流 III 与导体两端的电压 VVV 成正比。

用数学公式来表达：

I∝VI \propto V I∝V

写成等式，就是著名的欧姆定律：

I=VRI = \frac{V}{R} I=RV​

其中 RRR 是比例常数——也就是电阻。电阻越大，同样的电压下电流越小；电阻越小，同样的电压下电流越大。

💡 有趣的历史：欧姆最初发表他的发现时，并没有立刻被科学界接受。当时的德国物理界盛行"自然哲学"，轻视实验测量。欧姆为此丢了教职，直到 1841 年英国皇家学会授予他科普利奖章，他的贡献才得到公认。今天，电阻的单位"欧姆"（Ω\OmegaΩ）就是以他的名字命名的。

2.2 三种形式的理解 ​

欧姆定律有三种等价的写法，分别回答三个问题：

V=I×R（已知电流和电阻，求电压）V = I \times R \quad \text{（已知电流和电阻，求电压）} V=I×R（已知电流和电阻，求电压）

I=VR（已知电压和电阻，求电流）I = \frac{V}{R} \quad \text{（已知电压和电阻，求电流）} I=RV​（已知电压和电阻，求电流）

R=VI（已知电压和电流，求电阻）R = \frac{V}{I} \quad \text{（已知电压和电流，求电阻）} R=IV​（已知电压和电流，求电阻）

你可以把这三个公式想象成一个三元一次方程式——只要知道其中任意两个量，就能求出第三个量。

用一个生活中的比喻来帮助记忆：

  • 电压 VVV → 水管里的水压（推力）
  • 电流 III → 水管里的水流速（单位时间内流过的水量）
  • 电阻 RRR → 水管的粗细（越细阻力越大）

水压越大、水管越粗，水流越快——对应着 I=VRI = \frac{V}{R}I=RV​，电压越大、电阻越小，电流越大。

3.2 公式推导 ​

根据欧姆定律 I=VRI = \frac{V}{R}I=RV​，当 R=100ΩR = 100\OmegaR=100Ω 固定时：

I=V100I = \frac{V}{100} I=100V​

这说明电流 III 与电压 VVV 之间是严格的线性关系——电压每增加 1V，电流就增加 0.01A（即 10mA）。

如果把 VVV 和 III 画在坐标图上（电压 VVV 为横轴，电流 III 为纵轴），应该得到一条过原点的直线，斜率就是 1R=1100=0.01\frac{1}{R} = \frac{1}{100} = 0.01R1​=1001​=0.01 Ω⁻¹。

4. 用 Python 实现电路仿真 ​

在本节中，我们不只仿真一个电压点，而是让 Ngspice 自动扫描从 0V 到 10V 的所有电压值，一次性得到完整的 I-V 曲线。这种技术叫 DC Sweep（直流扫描）。

4.1 构建电路并执行 DC 扫描 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# 构建电路
circuit = Circuit('Ohms Law Demo')
circuit.V('input', 1, circuit.gnd, 1@u_V)
circuit.R(1, 1, circuit.gnd, 100@u_Ω)

simulator = circuit.simulator(temperature=25, nominal_temperature=25,
                              simulator='ngspice-subprocess')

# DC 扫描：电压从 0V 到 10V，步长 0.1V
analysis = simulator.dc(Vinput=slice(0, 10, 0.1))

# 提取数据
voltage = analysis['1']
current = -analysis['vinput']

代码解释：

  • circuit.V('input', 1, circuit.gnd, 1@u_V)：电压源的初始值设置为 1V（实际扫描时会覆盖这个值）。
  • simulator.dc(Vinput=slice(0, 10, 0.1))：对 Vinput（电压源 V1）进行 DC 扫描，从 0V 开始，以 0.1V 为步长，一直扫到 10V。总共会仿真 101 个点。
  • analysis['1']：读取节点 1 在每个扫描点的电压（也就是电阻两端的电压）。
  • -analysis['vinput']：读取流过电压源的电流。加负号是因为 Ngspice 默认电流方向为流入电压源正极，而我们习惯的电流方向是流出正极。

5. 深入理解 ​

5.1 线性关系的验证 ​

欧姆定律最核心的特征是线性关系。从仿真数据中，任取两点验证斜率：

斜率=I2−I1V2−V1=0.10−0.0210−2=0.088=0.01=1100\text{斜率} = \frac{I_2 - I_1}{V_2 - V_1} = \frac{0.10 - 0.02}{10 - 2} = \frac{0.08}{8} = 0.01 = \frac{1}{100} 斜率=V2​−V1​I2​−I1​​=10−20.10−0.02​=80.08​=0.01=1001​

这个斜率恰好等于 1R\frac{1}{R}R1​。换句话说，电阻 RRR 就是 I-V 曲线斜率的倒数：

R=ΔVΔIR = \frac{\Delta V}{\Delta I} R=ΔIΔV​

如果电阻 RRR 越大，I-V 曲线就越"平缓"（同样的电压变化引起更小的电流变化）；电阻 RRR 越小，I-V 曲线就越"陡峭"（小小的电压变化就能引起很大的电流变化）。你可以把 RRR 改小试试看，比如改成 10Ω10\Omega10Ω，观察曲线的斜率变化。

5.2 欧姆定律的适用条件 ​

并非所有元件都服从欧姆定律。像电阻器这样的线性元件，它的 I-V 曲线是一条直线；但二极管、LED 等非线性元件，它们的 I-V 曲线是弯曲的，欧姆定律不再直接适用。中学生常见的灯泡（白炽灯）其实也不严格遵循欧姆定律——灯丝发热后电阻会变大，I-V 曲线在高温段会微微弯曲。这也就是为什么我们用仿真中的理想电阻来学习欧姆定律：理想电阻在任何电压下阻值都不变，I-V 曲线是完美的直线。

6. 本章小结 ​

  • 欧姆定律 I=VRI = \frac{V}{R}I=RV​ 是电学中最基础的定律：流过导体的电流与两端电压成正比，与电阻成反比。
  • 欧姆定律有三种等价形式——V=IRV = IRV=IR、I=V/RI = V/RI=V/R、R=V/IR = V/IR=V/I，知道任意两个量就能求第三个。
  • 在 I-V 坐标图中，线性电阻的曲线是一条过原点的直线，斜率等于 1/R1/R1/R。
  • PySpice 的 DC 扫描（simulator.dc()）可以自动扫描一个电压范围，快速生成完整的 I-V 特性数据。

7. 练习 ​

  1. 验证不同电阻值：把代码中的电阻从 100Ω100\Omega100Ω 改为 50Ω50\Omega50Ω，重新运行仿真。观察 I-V 曲线的斜率变成了多少？和 1/R=1/50=0.021/R = 1/50 = 0.021/R=1/50=0.02 对比一下。

  2. 反向验证：如果知道一个电阻在 6V 时流过 0.03A 的电流，这个电阻的阻值是多少？用手工计算验证，再用仿真验证（提示：电阻值 R=VI=60.03=200ΩR = \frac{V}{I} = \frac{6}{0.03} = 200\OmegaR=IV​=0.036​=200Ω）。

  3. 预测与验证：把扫描电压范围改为 0V 到 20V（步长 0.2V），电阻保持 100Ω100\Omega100Ω 不变。先预测在 15V 和 20V 时的电流值，再运行仿真验证你的预测对不对。

  4. 思考题：为什么说"电阻 RRR 是 I-V 曲线斜率的倒数"？如果两条 I-V 直线，一条斜率大、一条斜率小，哪条对应的电阻更大？为什么？
