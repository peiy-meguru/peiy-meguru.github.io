第3章 欧姆定律（SkiDL版） ​

要点 ​

  • 欧姆定律：I=V/RI = V/RI=V/R（电流 = 电压 ÷ 电阻），V=IRV = IRV=IR（电压 = 电流 × 电阻）
  • SkiDL 零件创建：V(ref='VS', dc_value=...)、R(value=...)
  • SkiDL 接线：& 串联链（自动创建中间节点）与 += 多引线汇接
  • DC 扫描：analysis.dc(VS=slice(0, 10, 0.1)) — 对电压源进行 0→10V 步进扫描
  • 结果访问：result[node(pin)] 读取节点电压，result['VS'] 读取分支电流

示例1：最小回路——工作点分析 ​

这是可运行仿真的最简电路：一个直流电压源串联一个电阻，形成闭合回路。用工作点分析（Operating Point，简称 OP）计算稳态下的电压和电流。

python
from skidl.pyspice import *

# ── ① 创建零件 ──
vs = V(ref='VS', dc_value=5@u_V)   # 电压源 VS，直流 5V
r1 = R(value=100@u_Ohm)            # 电阻 R1，100Ω

# ── ② 接线 ──
vs['p'] & r1 & gnd                 # VS 正极 → R1 → 地线（& 串联链）
vs['n'] += gnd                     # VS 负极接 gnd（+= 汇接）

# ── ③ 生成网表 ──
circ = generate_netlist()

# ── ④ 创建仿真器 ──
sim = Simulator.factory(simulator='ngspice-subprocess')
analysis = sim.simulation(circ, temperature=25, nominal_temperature=25)

# ── ⑤ 运行工作点分析 ──
analysis.operating_point(run=False)
result = sim.run(analysis)

# ── ⑥ 读取结果 ──
v_node = float(result[node(vs['p'])])   # 节点电压（V）
i_branch = float(result['VS'])          # 通过 VS 的电流（A），负值 = 流出正极

print(f"V = {v_node:.3f} V")
print(f"I = {abs(i_branch):.4f} A = {abs(i_branch)*1000:.1f} mA")
print(f"验证 V = IR: {v_node:.3f} = {abs(i_branch):.4f} × 100 = {abs(i_branch)*100:.3f}")

① 创建零件 ​

V(ref='VS', dc_value=5@u_V) 这条语句做了三件事：

  1. 创建了一个电压源。SkiDL 自动给它分配内部引用名（如 V1），但 ref='VS' 把它覆写为 VS——这个名字会出现在仿真结果中，让你用 result['VS'] 读取通过该源的电流。
  2. 设置了 DC 值。dc_value=5@u_V 表示直流 5V。@ 是 SkiDL 的单位运算符：5@u_V = 5V，100@u_Ohm = 100Ω，1@u_kOhm = 1000Ω。
  3. 注册到默认电路中。创建的零件自动加入 default_circuit，不需要显式 add。

R(value=100@u_Ohm) 同理。电阻通常不需要 ref 参数（多数情况下不需要读取电阻电流），若需要也可指定 ref='RLOAD'。

② 接线：& 与 += ​

SkiDL 提供了两种接线算子，适用场景不同：

算子含义适用场景
&串联链：A & B & C 把 A、B、C 首尾相连两个元件一对一连线（最常见的场景）
+=汇接：net += pin1, pin2, pin3 把多个引脚接到同一个 net多引脚接同一点（地线、电源轨、总线）

vs['p'] & r1 & gnd 意为"VS 的正极 → R1 → 地"：

  • vs['p'] 返回电压源的正极引脚。'p' 是 positive 的缩写，也可以用 '+' 或 'plus' 或 1（引脚编号）。
  • r1 作为电阻有两个引脚 1 和 2（电阻无极性，哪端先接不影响仿真结果）。& r1 没有指定引脚时，SkiDL 按顺序使用未连接的引脚：第一次用引脚 1，第二次用引脚 2。
  • gnd 是 SkiDL pyspice 预定义的地线 net，内部 net 名为 "0"（SPICE 标准）。

& 链的返回值是整条链，可继续追加 & 连接。上面这行实际等价于：

python
n1 = Net()          # SkiDL 自动创建的中间节点（你看不到）
vs['p'] += n1       # VS 正极 → n1
r1[1] += n1         # n1 ← R1 引脚 1
r1[2] += gnd        # R1 引脚 2 → 地

四行合并为一行 vs['p'] & r1 & gnd。

vs['n'] += gnd 把 VS 负极也接到地。vs['n'] 返回负极引脚（negative）。这里用 += 而不是 &，因为不需要串联——只是多加一个引脚到已有 net 上。

⚠️ 常见遗漏：初学者常忘记 vs['n'] += gnd。没有这一行，VS 的负极悬空，仿真会报错"no DC path to ground"。

③ 生成网表：generate_netlist() ​

SkiDL 的 generate_netlist() 是两栖函数：

  • 在标准 SkiDL 中（from skidl import *），它生成 KiCad PCB 网表文件。
  • 在 pyspice 模式下（from skidl.pyspice import *），它返回一个 InSpice Circuit 对象，可直接传递给仿真器。

这里返回的 circ 是 InSpiceCircuit 实例。可通过 print() 查看生成的 SPICE 代码：

python
print(circ.to_spice())
# 输出:
# .title
# VS N_1 0 DC 5V
# R1 N_1 0 100Ohm

N_1 是 SkiDL 自动生成的中间节点名。0 是地线。这就是 Ngspice 实际执行的网表。

④ 创建仿真器 ​

python
sim = Simulator.factory(simulator='ngspice-subprocess')

Simulator.factory() 是一个工厂方法。simulator='ngspice-subprocess' 选择子进程模式——每次仿真启动一个独立的 Ngspice 进程，兼容性最好。

python
analysis = sim.simulation(circ, temperature=25, nominal_temperature=25)

这把电路 circ 绑定到仿真器，同时设置仿真温度为 25°C。analysis 是 Simulation 对象，后续的分析指令（OP、DC、AC、瞬态）均在其上配置。

⑤ 运行工作点分析 ​

python
analysis.operating_point(run=False)
result = sim.run(analysis)

两行各司其职：

  • operating_point(run=False) 表示需要执行 OP 分析，但先不运行。run=False 是 Ngspice 子进程模式的要求：配置和运行必须分开。
  • sim.run(analysis) 启动 Ngspice，传入 SPICE 网表，等待仿真完成，返回结果。

如果只有一个分析要跑，可以链式调用：

python
result = sim.run(sim.simulation(circ).operating_point(run=False))

但分两行写更清晰。

⑥ 读取结果 ​

python
v_node = float(result[node(vs['p'])])
  • result[node(vs['p'])]：node() 接收一个引脚或 Net 对象，返回该节点在仿真结果中的电压波形。对于 OP 分析，波形只有一个值，用 float() 转为 Python 浮点数。
  • 电路中有多个节点时，可用同样方式访问：result[node(r1[2])] 读取 R1 引脚 2 的电压。
python
i_branch = float(result['VS'])
  • result['VS']：'VS' 是电压源的 ref 名。SkiDL 把每个电压源的分支电流以 ref 名为键存储。对于 OP 分析，它也是单值。
  • 返回值通常是负数（约 -0.05A）：Ngspice 定义流入正极为正方向，而习惯上"电流从正极流出"与之相反，故结果需取负号。

终端输出：

text
V = 5.000 V
I = 0.0500 A = 50.0 mA
验证 V = IR: 5.000 = 0.0500 × 100 = 5.000

5V 加在 100Ω 上，电流 50mA。V=IRV = IRV=IR 精确成立。

示例2：DC 扫描——I-V 特性曲线 ​

工作点分析只计算单个直流工作点。要观察 III-VVV 的完整关系，需使用DC 扫描（DC Sweep）：将电压从 0V 逐步扫描至 10V，在每个电压点计算电路，所得数据点连接即为 I-V 特性曲线。

python
from skidl.pyspice import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# ── 创建零件并接线（同示例1）──
vs = V(ref='VS', dc_value=1@u_V)    # 初始值无所谓，扫描时会覆盖
r1 = R(value=100@u_Ohm)
vs['p'] & r1 & gnd
vs['n'] += gnd

# ── 生成网表 + 创建仿真器 ──
circ = generate_netlist()
sim = Simulator.factory(simulator='ngspice-subprocess')
analysis = sim.simulation(circ, temperature=25, nominal_temperature=25)

# ── DC 扫描：扫 VS，从 0V 到 10V，步长 0.1V ──
analysis.dc(VS=slice(0, 10, 0.1), run=False)
result = sim.run(analysis)

# ── 提取数据（numpy 数组）──
voltage = result[node(vs['p'])].as_ndarray()
current = -result['VS'].as_ndarray()           # 取负：让电流为正值

# ── 打印表格 ──
print("电压(V)   电流(A)     公式验证 I=V/R")
print("-" * 45)
for i in range(0, len(voltage), 10):           # 每 10 个点取一个，避免输出太长
    v = float(voltage[i])
    c = float(current[i])
    print(f"{v:6.2f}    {c:10.6f}   {v/100:10.6f}")

# ── 绘图 ──
plt.figure(figsize=(8, 5))
plt.plot(voltage, current * 1000, 'b-', linewidth=2, label='simulation')
plt.plot(voltage, voltage / 100 * 1000, 'r--', linewidth=1, label='theory I=V/100Ω')
plt.xlabel('Voltage (V)')
plt.ylabel('Current (mA)')
plt.grid(True, alpha=0.3)
plt.legend()
plt.savefig('ch03_ohms_law.png', dpi=150)

dc() 扫描参数详解 ​

python
analysis.dc(VS=slice(0, 10, 0.1), run=False)
  • VS 是关键字参数名——它必须跟电压源的 ref 名完全一致。这里 ref='VS'，所以参数名是 VS。如果 ref='VIN'，参数名就是 VIN。
  • slice(0, 10, 0.1) 是 Python 标准写法：start=0V, stop=10V, step=0.1V。总共 101 个扫描点。
  • 步长越小 → 曲线越平滑，但仿真时间越长。0.1V 在 10V 范围内是合理的折中。

⚠️ 常见错误：analysis.dc(V1=slice(...)) — 参数名 V1 跟 ref='VS' 不匹配。Ngspice 会报"VS not in the circuit"。务必保持 ref 名和 dc() 参数名一致。

.as_ndarray() 转数组 ​

python
voltage = result[node(vs['p'])].as_ndarray()

result[node(vs['p'])] 返回的是一个 WaveForm 对象——它不是 Python 列表，无法直接用于 matplotlib 或 numpy 运算。.as_ndarray() 将它转为 numpy 数组：

python
type(result[node(vs['p'])]))         # <class 'InSpice.Probe.WaveForm.WaveForm'>
type(result[node(vs['p'])]).as_ndarray())  # <class 'numpy.ndarray'>

此后可像普通 numpy 数组一样进行切片、运算、绘图。

电流取负号 ​

python
current = -result['VS'].as_ndarray()

不取负号时，result['VS'] 的值约为 -0.05A。取负后变成 +0.05A，表示从 VS 正极流出 50mA——即常规的电流方向。

不取负号会导致打印输出显示负值，不便阅读。

终端输出（部分行）：

text
电压(V)   电流(A)     公式验证 I=V/R
---------------------------------------------
  0.00      0.000000     0.000000
  1.00      0.010000     0.010000
  5.00      0.050000     0.050000
 10.00      0.100000     0.100000

每一行"电流"列 = "公式验证"列，证明 I=V/RI = V/RI=V/R 精确成立。

蓝色仿真线和红色理论线完全重合。这是一条过原点的直线——线性电阻的 I-V 特性就是一条直线，斜率 =1/R=0.01 Ω−1= 1/R = 0.01\text{ } \Omega^{-1}=1/R=0.01 Ω−1。

示例3：对比不同阻值 ​

根据欧姆定律，在相同电压下电阻越大，电流越小。用循环同时测试 50Ω、100Ω、200Ω，可直观验证这一关系。

python
from skidl.pyspice import *

for r_val in [50, 100, 200]:
    reset()                          # ★ 清空之前的电路，否则零件会累积！
    vs = V(ref='VS', dc_value=5@u_V)
    r1 = R(value=r_val@u_Ohm)       # 用 Python 变量动态设置阻值

    vs['p'] & r1 & gnd
    vs['n'] += gnd

    circ = generate_netlist()
    sim = Simulator.factory(simulator='ngspice-subprocess')
    analysis = sim.simulation(circ, temperature=25, nominal_temperature=25)
    analysis.operating_point(run=False)
    result = sim.run(analysis)

    v = float(result[node(vs['p'])])
    i = abs(float(result['VS']))
    print(f"R = {r_val:3d}Ω  →  V = {v:.1f}V,  I = {i*1000:5.1f}mA,  V/I = {v/i:6.1f}Ω")

reset()：为什么每次循环必须调用 ​

reset() 清空 default_circuit 中所有零件和接线，恢复到初始状态。如果不调用：

  • 第 1 次循环：创建 VS、R1（50Ω）——正常。
  • 第 2 次循环：创建 VS、R1（100Ω）——但之前的 VS、R1 仍然存在，电路里有两个电压源、两个电阻。SPICE 网表会包含多余元件，仿真结果出错。

reset() 的开销很小（仅清理 Python 对象），循环里调用完全没问题。它是批量仿真中最重要的防线。

动态参数 ​

R(value=r_val@u_Ohm) 中 r_val 是普通 Python 变量。SkiDL 的所有参数都接受 Python 表达式：

python
R(value=100 * 2 @ u_Ohm)          # 200Ω
R(value=1 / (1/100 + 1/200) @ u_Ohm)  # 66.67Ω（并联等效电阻）

这让你可以用 Python 的循环、条件、函数来参数化电路设计——这是文本式电路描述相比 GUI 原理图编辑器的核心优势。

输出分析 ​

text
R =  50Ω  →  V = 5.0V,  I = 100.0mA,  V/I =   50.0Ω
R = 100Ω  →  V = 5.0V,  I =  50.0mA,  V/I =  100.0Ω
R = 200Ω  →  V = 5.0V,  I =  25.0mA,  V/I =  200.0Ω
  • 电阻从 50Ω 增加到 100Ω → 电流从 100mA 减半到 50mA，体现反比关系。
  • V/I 列始终等于电阻值——欧姆定律的 R=V/IR = V/IR=V/I 形式。

示例4：串联分压 ​

两个电阻串联在 12V 电源上。& 链以简洁的语法描述完整拓扑。串联电路的中间节点即"分压点"——该点电压由两个电阻的比值决定。

python
from skidl.pyspice import *

vs = V(ref='VS', dc_value=12@u_V)
r1 = R(value=100@u_Ohm)
r2 = R(value=200@u_Ohm)

# 串联链：VS(+) → R1 → R2 → GND
vs['p'] & r1 & r2 & gnd
vs['n'] += gnd

circ = generate_netlist()
sim = Simulator.factory(simulator='ngspice-subprocess')
analysis = sim.simulation(circ, temperature=25, nominal_temperature=25)
analysis.operating_point(run=False)
result = sim.run(analysis)

# 读取三个关键点的电压
v_top = float(result[node(r1[1])])    # R1 上端 = VS 正极
v_mid = float(result[node(r1[2])])    # R1 下端 = R2 上端（分压点！）
i     = abs(float(result['VS']))

print(f"V(R1上端)  = {v_top:6.1f} V")
print(f"V(分压点)  = {v_mid:6.1f} V  ← 关键：串联分压结果")
print(f"V(R2下端)  =   0.0  V  (接地)")
print(f"I(回路)    = {i*1000:5.1f} mA")
print()
print(f"分压公式：Vmid = Vsupply × R2/(R1+R2)")
print(f"        = 12 × 200/(100+200)")
print(f"        = {12*200/300:.1f} V")
print(f"  仿真值 = {v_mid:.1f} V  ✓")

用引脚定位节点 ​

r1[2] 是 R1 的引脚 2。在 & 链中，r1 的两个引脚被自动分配：r1[1] 接 VS 正极，r1[2] 接 R2。r1[2] 即 R1 和 R2 的交点——串联分压点。

这就是 SkiDL 相对于 PySpice 的一项重要便利：你不需要记住"节点 2"是哪个。在 PySpice 中：

python
# PySpice：节点号是手写的，容易搞混
circuit.R(1, 1, 2, 100@u_Ω)    # R1 在节点 1 和 2 之间
circuit.R(2, 2, circuit.gnd, 200@u_Ω)  # R2 在节点 2 和地之间
v_mid = analysis['2']           # 节点 2 是哪个？得回头查

SkiDL 中：

python
# SkiDL：用零件和引脚表达位置
r1 & r2                          # R1 连 R2
v_mid = result[node(r1[2])]     # R1 的第二脚 = 它们的交点

引脚引用本身就是电路拓扑的一部分，不需要额外的"节点号"概念。

输出 ​

text
V(R1上端)  =   12.0 V
V(分压点)  =    8.0 V  ← 关键：串联分压结果
V(R2下端)  =    0.0 V  (接地)
I(回路)    =  40.0 mA

分压公式：Vmid = Vsupply × R2/(R1+R2)
        = 12 × 200/(100+200)
        = 8.0 V
  仿真值 = 8.0 V  ✓

12V 电源，R1=100Ω、R2=200Ω。分压点 = 12 × 200/300 = 8V。仿真与理论一致。

示例5：并联电路 ​

串联是元件首尾相连以分压，并联是元件端端相连以分流。两个电阻的上端一同接电源正极，下端一同接地。

python
from skidl.pyspice import *

vs = V(ref='VS', dc_value=12@u_V)
r1 = R(value=100@u_Ohm)
r2 = R(value=200@u_Ohm)

# 并联：两条 & 链共享起点和终点
vs['p'] & r1 & gnd       # 第一条路径：VS → R1 → GND
vs['p'] & r2 & gnd       # 第二条路径：VS → R2 → GND
vs['n'] += gnd

circ = generate_netlist()
sim = Simulator.factory(simulator='ngspice-subprocess')
analysis = sim.simulation(circ, temperature=25, nominal_temperature=25)
analysis.operating_point(run=False)
result = sim.run(analysis)

v = float(result[node(vs['p'])])
i_total = abs(float(result['VS']))    # 总电流 = 两个电阻电流之和
i_r1 = v / 100                         # 手工算：I_R1 = V/R1
i_r2 = v / 200                         # 手工算：I_R2 = V/R2

print(f"V(电源) = {v:.1f} V")
print(f"I(R1)   = {i_r1*1000:.1f} mA  ( = V / 100Ω )")
print(f"I(R2)   = {i_r2*1000:.1f} mA  ( = V / 200Ω )")
print(f"I(total)= {i_total*1000:.1f} mA  ( = I_R1 + I_R2 = { (i_r1+i_r2)*1000:.1f} mA )")
print()
print(f"并联等效电阻：1/(1/100 + 1/200) = {1/(1/100+1/200):.1f} Ω")
print(f"验证：V / I_total = {v/i_total:.1f} Ω  ✓")

并联的 & 写法 ​

两条 & 链都从 vs['p'] 出发，都终于 gnd。SkiDL 会正确生成两个独立的电流路径。生成的 SPICE 网表是：

text
VS N_1 0 DC 12V
R1 N_1 0 100Ohm
R2 N_1 0 200Ohm

N_1 是两个电阻共同的"上端"节点。这是并联的 SPICE 表达。

注意：不能写成 vs['p'] & r1 & r2 & gnd 来实现并联——那会把 R1 和 R2 串联起来。& 链中的顺序即电流路径的顺序。并联必须用两条独立的 & 链。

输出 ​

text
V(电源) = 12.0 V
I(R1)   = 120.0 mA  ( = V / 100Ω )
I(R2)   =  60.0 mA  ( = V / 200Ω )
I(total)= 180.0 mA  ( = I_R1 + I_R2 = 180.0 mA )

并联等效电阻：1/(1/100 + 1/200) = 66.7 Ω
验证：V / I_total = 66.7 Ω  ✓

基尔霍夫电流定律：总电流 180mA = 120mA + 60mA。并联电路的电流按电阻反比分配。
