Python 速成入门 ​

欢迎来到 Python 速成入门章节！在正式开始用 PySpice 仿真电路之前，我们需要掌握一些 Python 编程的基础知识。你可能会想："我只是想学电路，为什么还要学编程？"好问题。答案是：PySpice 是一套用 Python 语言来操控电路仿真引擎的工具箱。就像你要开车必须先学会踩油门和转方向盘一样，要让 PySpice 听你的指挥，你必须懂一点 Python。

本章将带你从零开始，快速掌握 Python 最核心的语法。我们不会讲那些晦涩难懂的理论，也不会让你去做枯燥的练习题。相反，每一节都有简短易懂的代码示例，你照着敲一遍就能看到结果。如果你之前完全没有接触过编程，完全不用担心——本章就是为像你这样的初学者准备的。好，深呼吸，我们开始吧！

变量和数据类型 ​

什么是变量？ ​

变量是编程中最基础的概念。你可以把变量想象成一个"带标签的盒子"：你往盒子里面放一个东西（比如数字 15），然后给盒子贴上一个标签（比如 age）。以后你想用这个数字的时候，只需要喊它的标签名，计算机就会自动帮你从盒子里取出来。

在 Python 里，创建变量非常简单——你不需要事先声明"我要创建一个盒子"，直接写 变量名 = 值 就可以了。比如 age = 15 这行代码的意思是：创建一个盒子，贴上 age 的标签，然后把 15 放进去。

Python 的四种基本数据类型 ​

Python 里最常用的四种数据类型分别是：

  • 整数（int）：没有小数点的数字。比如 15、-3、2026。生活中我们数东西的个数、算年龄、计页码，用的都是整数。
  • 浮点数（float）：带小数点的数字。比如 1.75、3.14、-0.5。测量身高、记录温度、计算平均值，都会用到浮点数。
  • 字符串（str）：用引号包裹起来的文字。比如 "小华"、"你好"。字符串可以包含中文、英文、数字，甚至标点符号。
  • 布尔值（bool）：只有 True（真）和 False（假）两个值。布尔值就像是"是/否"开关，后面讲条件判断的时候你会经常用到它。

你可以用 type() 函数来查看某个变量到底是什么类型。

print() 函数：在屏幕上显示内容 ​

print() 是 Python 里最常用的函数之一——它把括号里的内容显示在屏幕上。在学习过程中，我们几乎每写一行代码都要用 print() 来确认结果对不对。

python
age = 15
print("整数 (int):", age, "-> 类型:", type(age))

height = 1.75
print("浮点数 (float):", height, "-> 类型:", type(height))

name = "小华"
print("字符串 (str):", name, "-> 类型:", type(name))

is_student = True
print("布尔值 (bool):", is_student, "-> 类型:", type(is_student))

a, b, c = 10, 3.14, "你好"
print("多变量赋值:", a, b, c)
text
整数 (int): 15 -> 类型: <class 'int'>
浮点数 (float): 1.75 -> 类型: <class 'float'>
字符串 (str): 小华 -> 类型: <class 'str'>
布尔值 (bool): True -> 类型: <class 'bool'>
多变量赋值: 10 3.14 你好

注意上面最后一行代码 a, b, c = 10, 3.14, "你好"——Python 允许你一次性给多个变量赋值，写起来很方便。每个变量的类型可以不同，Python 会自动帮你识别。

基本运算 ​

算术运算 ​

Python 支持所有我们熟悉的数学运算。下面是最常用的七种算术运算符：

运算符名称示例说明
+加法3 + 2 = 5两数相加
-减法5 - 3 = 2两数相减
*乘法4 * 3 = 12两数相乘
/除法10 / 4 = 2.5除法，结果始终是浮点数
**幂运算2 ** 3 = 82 的 3 次方
//整除10 // 4 = 2除法后只保留整数部分
%取余10 % 4 = 2除法后的余数
python
x, y = 17, 5

print("算术运算:")
print("  加法 (+):", x, "+", y, "=", x + y)
print("  减法 (-):", x, "-", y, "=", x - y)
print("  乘法 (*):", x, "*", y, "=", x * y)
print("  除法 (/):", x, "/", y, "=", x / y)
print("  幂运算 (**):", x, "**", y, "=", x ** y)
print("  整除 (//):", x, "//", y, "=", x // y)
print("  取余 (%):", x, "%", y, "=", x % y)
text
算术运算:
  加法 (+): 17 + 5 = 22
  减法 (-): 17 - 5 = 12
  乘法 (*): 17 * 5 = 85
  除法 (/): 17 / 5 = 3.4
  幂运算 (**): 17 ** 5 = 1419857
  整除 (//): 17 // 5 = 3
  取余 (%): 17 % 5 = 2

/ 和 // 的区别需要特别留意：17 / 5 给你精确的 3.4，而 17 // 5 直接扔掉小数部分得到 3。取余运算 % 在循环和判断"能否整除"时非常实用。

比较运算 ​

比较运算用来比较两个值的大小关系，结果永远是一个布尔值——要么 True，要么 False。

运算符含义
==等于
!=不等于
<小于
>大于
<=小于等于
>=大于等于
python
x, y = 17, 5

print("比较运算:")
print("  等于 (==):", x, "==", y, "->", x == y)
print("  不等于 (!=):", x, "!=", y, "->", x != y)
print("  小于 (<):", x, "<", y, "->", x < y)
print("  大于 (>):", x, ">", y, "->", x > y)
print("  小于等于 (<=):", x, "<=", y, "->", x <= y)
print("  大于等于 (>=):", x, ">=", y, "->", x >= y)
text
比较运算:
  等于 (==): 17 == 5 -> False
  不等于 (!=): 17 != 5 -> True
  小于 (<): 17 < 5 -> False
  大于 (>): 17 > 5 -> True
  小于等于 (<=): 17 <= 5 -> False
  大于等于 (>=): 17 >= 5 -> True

特别注意：判断"等于"用的是两个等号 ==，一个等号 = 是赋值，千万不要搞混了。初学者最常见的错误就是写 if x = 5 而不是 if x == 5。

列表与索引 ​

列表：存一组数据的"号码箱" ​

如果变量是一个装一件东西的盒子，那么列表就是一个有很多小格的"号码箱"。每个小格有自己固定的编号（从 0 开始！），你可以通过编号来存取其中的内容。

列表用方括号 [] 来创建，里面的元素用逗号隔开。比如 fruits = ["苹果", "香蕉", "橘子", "葡萄", "西瓜"] 创建了一个包含五种水果的列表。

索引：用编号定位 ​

列表的编号（也叫"索引"）是从 0 开始数的。这意味着第一个元素的索引是 0，第二个元素的索引是 1，以此类推。听起来可能有点反直觉，但几乎所有编程语言都是这么设计的，习惯就好。

Python 还支持负数索引——-1 表示最后一个元素，-2 表示倒数第二个，以此类推。当你不知道列表有多长但又想取最后一个元素时，负数索引简直太方便了。

切片：取一段连续的元素 ​

切片语法是 列表[起始索引:结束索引]，它会返回从起始索引到结束索引之前的所有元素（不包括结束索引本身）。比如 fruits[0:3] 取索引 0、1、2 这三个元素。省略起始索引表示"从开头取"，省略结束索引表示"取到末尾"。你还可以在第三个冒号后面写一个步长来控制每隔几个取一个。

python
fruits = ["苹果", "香蕉", "橘子", "葡萄", "西瓜"]
print("列表:", fruits)
print("列表长度:", len(fruits))

print()
print("索引访问:")
print("  fruits[0] =", fruits[0])
print("  fruits[1] =", fruits[1])
print("  fruits[-1] =", fruits[-1])
print("  fruits[-2] =", fruits[-2])

print()
print("切片操作:")
print("  fruits[0:3] =", fruits[0:3])
print("  fruits[1:4] =", fruits[1:4])
print("  fruits[:3] =", fruits[:3])
print("  fruits[2:] =", fruits[2:])
print("  fruits[::2] =", fruits[::2])
print("  fruits[::-1] =", fruits[::-1])
text
列表: ['苹果', '香蕉', '橘子', '葡萄', '西瓜']
列表长度: 5

索引访问:
  fruits[0] = 苹果
  fruits[1] = 香蕉
  fruits[-1] = 西瓜
  fruits[-2] = 葡萄

切片操作:
  fruits[0:3] = ['苹果', '香蕉', '橘子']
  fruits[1:4] = ['香蕉', '橘子', '葡萄']
  fruits[:3] = ['苹果', '香蕉', '橘子']
  fruits[2:] = ['橘子', '葡萄', '西瓜']
  fruits[::2] = ['苹果', '橘子', '西瓜']
  fruits[::-1] = ['西瓜', '葡萄', '橘子', '香蕉', '苹果']

输出中 fruits[::-1] 的结果很有意思——它把整个列表反转了过来。这是因为 [::-1] 的步长是 -1，表示"倒着走"。这个小技巧在以后处理数据时会经常用到。

条件判断 ​

if、elif、else：让程序学会"做选择" ​

条件判断是程序"智能"的基础。有了条件判断，程序就可以根据不同的情况执行不同的代码，而不是死板地一条路走到黑。

if 后面跟一个条件表达式（结果必须是一个布尔值），如果条件为 True，就执行紧跟在它后面缩进的代码块。如果条件为 False，if 下面的代码块会被跳过。你还可以用 elif（else if 的缩写）来追加更多判断条件，用 else 来处理"以上条件都不满足"的情况。

python
score = 85
print("当前分数:", score)

if score >= 90:
    grade = "优秀"
elif score >= 80:
    grade = "良好"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"

print("等级:", grade)
text
当前分数: 85
等级: 良好

Python 靠缩进（行首的空格）来判断哪些代码属于同一个 if 块。标准的缩进是 4 个空格。如果缩进不统一，程序会报错甚至执行出完全不一样的结果，所以敲代码时要特别留意这一点。

布尔运算符：组合多个条件 ​

有时候你需要同时检查多个条件，比如"分数大于 60 而且小于 100"。Python 提供了三个布尔运算符来帮你做这件事：

  • and：所有条件都为 True 时，结果才为 True（"并且"）
  • or：只要任意一个条件为 True，结果就为 True（"或者"）
  • not：把 True 变成 False，False 变成 True（"取反"）
python
a_flag = True
b_flag = False
print("a_flag:", a_flag, ", b_flag:", b_flag)
print("a_flag and b_flag =", a_flag and b_flag)
print("a_flag or b_flag =", a_flag or b_flag)
print("not a_flag =", not a_flag)
print("(10 > 5) and (3 < 8) =", (10 > 5) and (3 < 8))
text
a_flag: True , b_flag: False
a_flag and b_flag = False
a_flag or b_flag = True
not a_flag = False
(10 > 5) and (3 < 8) = True

循环 ​

循环是什么？ ​

循环让计算机重复执行一段代码。这在处理大量数据时特别有用——你不需要把同一段逻辑写一百遍，只要写一遍然后用循环控制它重复一百次就可以了。Python 中最常用的两种循环是 for 循环和 while 循环。

for 循环和 range() ​

for 循环用于"遍历"一组东西——可以是列表、字符串，或者 range() 生成的数字序列。循环每走一次，就把当前元素赋值给循环变量，然后执行一遍代码块。

range() 函数专门用来生成整数序列：

  • range(5) 生成 0, 1, 2, 3, 4（注意：不包含 5）
  • range(3, 8) 生成 3, 4, 5, 6, 7（从 3 到 8 之前）
  • range(0, 10, 2) 生成 0, 2, 4, 6, 8（步长为 2，即隔一个取一个）
python
print("for 循环 (range):")
for i in range(5):
    print("  第", i, "次迭代 (从 0 开始)")

print()
print("for 循环 (range 带起止):")
for i in range(3, 8):
    print("  i =", i)

print()
print("for 循环 (range 带步长):")
for i in range(0, 10, 2):
    print("  i =", i)
text
for 循环 (range):
  第 0 次迭代 (从 0 开始)
  第 1 次迭代 (从 0 开始)
  第 2 次迭代 (从 0 开始)
  第 3 次迭代 (从 0 开始)
  第 4 次迭代 (从 0 开始)

for 循环 (range 带起止):
  i = 3
  i = 4
  i = 5
  i = 6
  i = 7

for 循环 (range 带步长):
  i = 0
  i = 2
  i = 4
  i = 6
  i = 8

while 循环 ​

while 循环会不断地重复一个代码块，只要它后面的条件保持为 True。一旦条件变为 False，循环立刻停止。写 while 循环时务必确保循环条件最终能变成 False，否则程序就会陷入"死循环"永远停不下来——虽然它不会伤你的电脑，但会一直占着 CPU 不放。

python
count = 0
while count < 4:
    print("  count =", count)
    count += 1
text
while 循环:
  count = 0
  count = 1
  count = 2
  count = 3

注意：count += 1 是 count = count + 1 的简写形式，意思是"把 count 的当前值加 1，再存回 count"。Python 也支持 -=、*= 等类似的简写运算符。

函数 ​

函数：把一段逻辑打包成"积木块" ​

函数是组织代码的基本单元。你可以把一段常用的逻辑封装成一个函数，给它取个名字，以后想用的时候直接喊名字就行了，不用重写一遍。这就像你把自己的拿手菜的做法写成食谱——以后每次要做这道菜，照着食谱来就行，不用每次重新发明做法。

定义和调用函数 ​

定义函数用 def 关键字：def 函数名(参数列表):。参数是你传给函数的信息，函数可以用这些信息来执行不同的操作。return 语句用来把计算结果送回给调用者。

python
def greet(name):
    return "你好，" + name + "！"

def add(a, b):
    return a + b

print("调用 greet('小明'):", greet("小明"))
print("调用 greet('小红'):", greet("小红"))
print("调用 add(3, 5):", add(3, 5))
print("调用 add(100, 200):", add(100, 200))
text
调用 greet('小明'): 你好，小明！
调用 greet('小红'): 你好，小红！
调用 add(3, 5): 8
调用 add(100, 200): 300

默认参数 ​

函数参数可以有默认值。如果在调用时没有给出该参数的实际值，Python 就会自动使用默认值。默认参数让函数用起来更灵活——大多数情况下你不需要填所有参数。

python
def describe_person(name, age, hobby="编程"):
    print("  姓名:", name)
    print("  年龄:", age)
    print("  爱好:", hobby)

print("带默认参数的函数:")
describe_person("小华", 15)
print("---")
describe_person("小李", 16, "打球")
text
带默认参数的函数:
  姓名: 小华
  年龄: 15
  爱好: 编程
---
  姓名: 小李
  年龄: 16
  爱好: 打球

当你不传第三个参数时，hobby 自动使用默认值 "编程"；当你传了第三个参数时，"打球" 就会覆盖掉默认值。

导入模块 ​

模块是什么？ ​

Python 自带了一个庞大的"标准工具箱"（被称为"标准库"），里面有处理数学运算、文件读写、日期时间、随机数等各类任务的现成工具。除此之外，社区开发者还贡献了成千上万个第三方模块（比如 NumPy、Matplotlib、PySpice）。

想用这些工具，你需要先用 import 语句把它们"请"进你的程序里来。导入一次之后，这个模块里的所有工具你都可以随意使用了。

常见导入方式 ​

import 模块名 是最基础的导入方式，使用模块中的函数时需要加 模块名. 前缀。如果你觉得前缀太长，可以用 as 给它起个简短的别名。如果你只想要模块里的某一个特定函数，可以用 from 模块名 import 函数名。

python
import math

print("math.pi =", math.pi)
print("math.sqrt(16) =", math.sqrt(16))
print("math.sin(math.pi / 2) =", math.sin(math.pi / 2))
print("math.log(100, 10) =", math.log(100, 10))

import random

NumPy 基础 ​

NumPy 是什么？ ​

NumPy（发音"纳姆派"，Numerical Python 的缩写）是整个 Python 科学计算生态系统的基石。它提供了一个核心数据结构——ndarray（N 维数组），以及一整套在数组上做高效数学运算的函数。无论是 PySpice 的仿真结果，还是 Matplotlib 的图表数据，背后都在用 NumPy 数组来存储和传递数据。

你可以把 NumPy 数组想象成一个"超级升级版列表"：和 Python 原生的列表相比，NumPy 数组不仅运算速度更快，还支持直接在数组级别做加减乘除等数学运算——不需要写循环，一行代码就能完成。

创建数组 ​

python
import numpy as np

arr = np.array([1, 2, 3, 4, 5])
print("np.array([1, 2, 3, 4, 5]) =", arr)
print("  类型:", type(arr))
print("  形状:", arr.shape)
print("  元素类型:", arr.dtype)

arr2d = np.array([[1, 2, 3], [4, 5, 6]])
print()
print("二维数组:")
print(arr2d)
print("  形状:", arr2d.shape)
text

  形状: (5,)
  元素类型: int64

二维数组:
[[1 2 3]
 [4 5 6]]
  形状: (2, 3)

np.array() 是最基本的创建方式，你把一个 Python 列表传给它，它就返回一个 NumPy 数组。数组的 shape 属性告诉你它的"维度尺寸"——(5,) 表示这是一维数组、有 5 个元素；(2, 3) 表示这是一个 2 行 3 列的二维数组，总共 6 个元素。

arange() 和 linspace()：生成数字序列 ​

NumPy 提供了两种生成等差数列的方法：

  • np.arange(起始, 结束, 步长)：和 Python 的 range() 几乎一样，从起始值开始，以固定步长递增，到结束值之前停止。
  • np.linspace(起始, 结束, 元素个数)：在起始值和结束值之间等间距地生成指定个数的元素。和 arange 不一样的是，linspace 会包含结束值，让你能精确控制数组的长度。

在电路仿真中，linspace 经常用来生成分析时间点。

python
print("np.arange:")
print("  np.arange(10) =", np.arange(10))
print("  np.arange(2, 10, 2) =", np.arange(2, 10, 2))

print()
print("np.linspace:")
print("  np.linspace(0, 1, 5) =", np.linspace(0, 1, 5))
print("  np.linspace(0, 10, 6) =", np.linspace(0, 10, 6))

数组运算 ​

NumPy 最强大的特性之一就是向量化运算——你不需要写循环，直接在数组层面做运算，NumPy 会自动对每个元素分别执行。这就是所谓的"逐元素运算"（element-wise operation）。

python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
print("a =", a)
print("b =", b)
print("a + b =", a + b)
print("a * b =", a * b)
print("a * 2 =", a * 2)
print("a ** 2 =", a ** 2)
print("np.sum(a) =", np.sum(a))
print("np.mean(a) =", np.mean(a))
text
a = [1 2 3]
b = [4 5 6]
a + b = [5 7 9]
a * b = [ 4 10 18]
a * 2 = [2 4 6]
a ** 2 = [1 4 9]
np.sum(a) = 6
np.mean(a) = 2.0

a + b 把两个数组的对应位置的元素相加：1+4=5、2+5=7、3+6=9。a * 2 把数组每个元素都乘以 2。这就是"向量化"的威力——不需要写 for i in range(3): print(a[i] + b[i])。NumPy 还提供了 np.sum()、np.mean() 这类统计函数，它们对整个数组做汇总计算。

Matplotlib 基础 ​

Matplotlib 是什么？ ​

Matplotlib 是 Python 最流行的绘图库。不管你是要画折线图、柱状图、散点图，还是更复杂的热力图、3D 图，Matplotlib 都能帮你实现。在电路仿真中，你用 PySpice 算出电压、电流数据后，正是用 Matplotlib 把它们画成直观的波形图来分析和展示。

Matplotlib 最核心的模块是 pyplot，通常用 import matplotlib.pyplot as plt 导入。plt 这个别名已经成了全 Python 社区的通识。

画一条简单的曲线 ​

创建一个完整的图表大致需要以下几步：

  1. 准备 x 轴和 y 轴的数据
  2. 用 plt.plot() 把数据画出来
  3. 用 plt.xlabel()、plt.ylabel() 和 plt.title() 添加坐标轴标签和标题
  4. 用 plt.legend() 显示图例（如果你画了多条曲线）
  5. 最后用 plt.show()（在交互环境中显示图片）或者 plt.savefig()（保存为文件）
python
import matplotlib
matplotlib.use('Agg')  # 在无图形界面的环境中保存图片，非必须
import matplotlib.pyplot as plt
import numpy as np

t = np.linspace(0, 2 * np.pi, 100)
y_sin = np.sin(t)
y_cos = np.cos(t)

plt.figure(figsize=(8, 4))

plt.plot(t, y_sin, label='sin(t)', color='blue', linewidth=2)
plt.plot(t, y_cos, label='cos(t)', color='red', linestyle='--', linewidth=2)

plt.xlabel('t (radians)')
plt.ylabel('Function Value')
plt.title('Sine and Cosine Functions')
plt.legend()
plt.grid(True)

plt.savefig('/workspace/quickstart_python_plot.png', dpi=100)
print("图表已保存为: /workspace/quickstart_python_plot.png")

plt.close()
text
图表已保存为: /workspace/quickstart_python_plot.png

在这个例子中，我们先用 np.linspace(0, 2*np.pi, 100) 生了 100 个从 0 到 2π 的等间距点作为 x 轴数据。然后我们分别计算这些点对应的正弦值和余弦值作为 y 轴数据。最后调用 plt.plot() 两次画出两条曲线，label 参数为每条曲线指定名字以便图例显示。linewidth 控制线条粗细，linestyle='--' 把余弦曲线画成虚线。

注意：matplotlib.use('Agg') 是在没有显示器的服务器或容器环境中才需要的一行设置——它告诉 Matplotlib 使用"无界面模式"，只把图片存成文件而不是弹出一个窗口。如果你在自己的笔记本上用 VS Code 写代码，通常不需要这一行，直接用 plt.show() 就能在弹出的窗口中看到图表。
