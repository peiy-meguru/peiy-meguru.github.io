第6章 电磁感应 ​

1. 本节你将学到 ​

  • 理解法拉第电磁感应定律：ε=−dΦdt\varepsilon = -\frac{d\Phi}{dt}ε=−dtdΦ​，变化的磁通量产生感应电动势
  • 掌握楞次定律：感应电流的方向总是阻碍引起感应电流的磁通量变化（增反减同）
  • 认识自感现象：线圈中的电流变化会在自身产生感应电动势 ε=−LdIdt\varepsilon = -L\frac{dI}{dt}ε=−LdtdI​
  • 学会用 PySpice 的 .transient() 瞬态仿真，观察 RL 电路中电流上升和电感电压衰减的过程

2. 知识回顾/情景引入 ​

上一章我们学了两件事：(1) 电流在磁场中受安培力（电动效应），(2) 电流周围产生磁场（磁效应）。现在我们要研究电磁学中第三个——也是最不可思议的——现象：变化的磁场能在闭合回路中"凭空"产生电流。

这听起来像是魔术：没有电池、没有发电机，仅仅靠磁铁在线圈中动一动，线圈两端就出现了电压，甚至能点亮小灯泡！

2.1 法拉第的十年探索 ​

1820 年奥斯特发现电流产生磁场后，英国科学家迈克尔·法拉第（Michael Faraday）开始思考一个反向的问题：既然电流能产生磁场，那么磁场能不能反过来产生电流？

这是一个极其艰难的课题。法拉第花了将近十年的时间，尝试了无数种实验方案，终于在 1831 年取得了突破。他发现：当穿过闭合线圈的磁通量发生变化时——比如把磁铁插入线圈或从线圈中拔出——线圈两端就产生了电压，回路中出现了感生电流。

2.2 法拉第电磁感应定律 ​

法拉第将他的发现总结为一条精确的数学定律：

ε=−dΦdt\varepsilon = -\frac{d\Phi}{dt} ε=−dtdΦ​

其中 ε\varepsilonε 是感应电动势（单位 V），Φ\PhiΦ 是穿过回路的磁通量（单位 Wb），dΦdt\frac{d\Phi}{dt}dtdΦ​ 是磁通量的变化率，负号来自楞次定律。

三大感应方式：

  1. 动生电动势：导体在磁场中运动切割磁感线 —— ε=BLv\varepsilon = BLvε=BLv（BBB 为磁感应强度，LLL 为导体长度，vvv 为运动速度）
  2. 感生电动势：磁场本身随时间变化（如交变磁场），在静止导体中产生感应电场
  3. 自感电动势：线圈自身电流变化引起磁场变化，进而在自身产生感应电动势 —— ε=−LdIdt\varepsilon = -L\frac{dI}{dt}ε=−LdtdI​

2.3 楞次定律——电磁世界的"惯性定律" ​

楞次定律给出了判断感应电流方向的方法：

感应电流的方向，总是使它产生的磁场阻碍引起感应电流的原磁通量的变化。

用四个字概括就是增反减同：

  • 原磁通增加时，感应电流产生的磁场与原磁场相反（反抗增加）
  • 原磁通减少时，感应电流产生的磁场与原磁场相同（补偿减少）

💡 楞次定律可以类比为物理学的"惯性定律"——自然界总是倾向于抵抗变化。推一个重物有惯性阻力，改变线圈中磁通量也有"电磁惯性"来抵抗。这种电磁惯性正是电感（inductance）的本质来源。

3. 动手设计电路 ​

3.1 本节电路：RL 串联电路的瞬态过程 ​

我们要研究的是自感现象的一个经典案例。电路构成：

  • 电压源 V=5VV = 5\text{V}V=5V（直流阶跃——在 t=0t = 0t=0 时刻从 0V 跳变到 5V）
  • 电阻 R=100ΩR = 100\OmegaR=100Ω（限制稳态电流）
  • 电感 L=10mHL = 10\text{mH}L=10mH（感应元件，产生自感电动势）

三个元件串联：电压源正端（节点 1）→ 电阻（节点 1 → 节点 2）→ 电感（节点 2 → 地）。

3.2 电路方程与公式推导 ​

当开关合上的瞬间（t=0t = 0t=0），电压源从 0V 突然加上 5V。电感中的电流不能突变（否则 dI/dtdI/dtdI/dt 为无穷大，根据 ε=−LdIdt\varepsilon = -L\frac{dI}{dt}ε=−LdtdI​，感应电动势也会为无穷大——这不可能）。因此：

t=0+t = 0^+t=0+ 时：电流 I=0I = 0I=0，电感上电压等于全电压 VL=5VV_L = 5\text{V}VL​=5V（电阻两端电压为零，因为电流为零）。

t→∞t \to \inftyt→∞（稳态）时：电流不变，dIdt=0\frac{dI}{dt} = 0dtdI​=0，感应电动势为零，电感相当于一根导线（电阻为零）。此时电流受电阻限制：I∞=VR=5100=0.05A=50mAI_{\infty} = \frac{V}{R} = \frac{5}{100} = 0.05\text{A} = 50\text{mA}I∞​=RV​=1005​=0.05A=50mA。电感上电压 VL=0V_L = 0VL​=0。

瞬态过程（0<t<∞0 < t < \infty0<t<∞）中，电流按指数规律上升：

I(t)=VR(1−e−t/τ)I(t) = \frac{V}{R}\left(1 - e^{-t/\tau}\right) I(t)=RV​(1−e−t/τ)

其中 τ=LR\tau = \frac{L}{R}τ=RL​ 是 RL 电路的时间常数。

VL(t)=LdIdt=V⋅e−t/τV_L(t) = L\frac{dI}{dt} = V \cdot e^{-t/\tau} VL​(t)=LdtdI​=V⋅e−t/τ

代入 L=10mHL = 10\text{mH}L=10mH，R=100ΩR = 100\OmegaR=100Ω：

τ=10×10−3100=1×10−4s=100μs\tau = \frac{10 \times 10^{-3}}{100} = 1 \times 10^{-4}\text{s} = 100\mu\text{s} τ=10010×10−3​=1×10−4s=100μs

时间常数 100μs100\mu\text{s}100μs 意味着：

  • 经过 1τ1\tau1τ（100μs100\mu\text{s}100μs）后，电流上升至终值的 63.2%63.2\%63.2%（约 31.6mA31.6\text{mA}31.6mA）
  • 经过 3τ3\tau3τ（300μs300\mu\text{s}300μs）后，电流上升至终值的 95.0%95.0\%95.0%
  • 经过 5τ5\tau5τ（500μs500\mu\text{s}500μs）后，电流上升至终值的 99.3%99.3\%99.3%，可以认为基本达到稳态

4. 用 Python 实现电路仿真 ​

4.1 构建 RL 电路并执行瞬态分析 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

circuit = Circuit('RL Circuit')
circuit.V('pulse', 1, circuit.gnd, 5@u_V)
circuit.R(1, 1, 2, 100@u_Ω)
circuit.L(1, 2, circuit.gnd, 10@u_mH)

simulator = circuit.simulator(temperature=25, nominal_temperature=25,
                              simulator='ngspice-subprocess')
analysis = simulator.transient(step_time=1@u_us, end_time=500@u_us)

代码解释：

  • circuit.L(1, 2, circuit.gnd, 10@u_mH)：添加一个 10mH10\text{mH}10mH 的电感元件，连接在节点 2 和地之间。L 是电感元件的关键词。
  • .transient(step_time=1@u_us, end_time=500@u_us)：这是全新的分析类型！瞬态分析（Transient Analysis）模拟电路从 t=0t=0t=0 开始随时间变化的过程。step_time 是仿真时间步长（1μs1\mu\text{s}1μs），end_time 是仿真总时间（500μs500\mu\text{s}500μs，即 5 个时间常数）。
  • 电压源 V('pulse', ...) 在 t=0t=0t=0 时刻从 0V 阶跃到 5V——模拟开关突然合上的效果。

5. 深入理解 ​

5.1 自感的微观机理 ​

当电感线圈中的电流变化时，它产生的磁场也跟着变化。变化的磁场在线圈自身中产生感应电动势（法拉第定律）——这就是自感。

自感系数 LLL（简称电感）的定义：

L=ΦIL = \frac{\Phi}{I} L=IΦ​

即：单位电流产生的磁通链。电感的单位是亨利（H）。1H=1Wb/A1\text{H} = 1\text{Wb/A}1H=1Wb/A。

对于长直螺线管，电感近似为：

L=μ0n2VL = \mu_0 n^2 V L=μ0​n2V

其中 nnn 是单位长度匝数，VVV 是螺线管的体积。匝数越多、体积越大，电感越大。

5.2 电感与电阻的时间常数对比 ​

在电阻电路中（纯电阻），加电压后电流瞬间就达到稳态值（因为没有任何阻碍电流变化的东西）。在 RL 电路中，电感产生的反向感应电动势就像"电磁惯性"，让电流不能突变，必须经过一个时间常数 τ=L/R\tau = L/Rτ=L/R 的指数过程。

特性纯电阻电路RL 电路
电流建立速度瞬时指数上升，τ=L/R\tau = L/Rτ=L/R
初始电流V/RV/RV/R（立即）0（从零开始）
元件作用限制电流限制电流的变化率
频率响应频率无关高频时阻抗大

5.3 电感在各领域的应用 ​

电感与电容、电阻一起构成了三大基本无源元件：

  • EMI 滤波：电感对高频信号呈高阻抗，常用于电源输入端滤除高频噪声。
  • DC-DC 变换器（如 Buck/Boost 电路）：电感是储能元件，通过周期性地储存和释放磁能来实现电压变换——几乎所有手机充电器、电脑电源中都有电感。
  • 继电器与电磁阀：线圈通电产生磁场吸合衔铁，断电后靠感应电动势快速释放。
  • 无线充电：发射线圈中的交变电流产生交变磁场，接收线圈通过电磁感应产生电压为设备充电——整个过程基于法拉第定律。

5.4 瞬态仿真 vs 工作点分析 ​

本章引入了 PySpice 中第三种重要的分析类型，与前面学过的两种对比：

分析类型方法输出适用场景
工作点分析.operating_point()一组稳定的电压/电流值纯电阻电路、直流稳态
DC 扫描.dc()一系列工作点（一个参数扫描）研究 I-V 特性、参数依赖
瞬态分析.transient()电压/电流随时间变化的波形含有电容或电感的动态电路

瞬态分析是研究动态电路（RC、RL、RLC）的基本工具。在后续章节中，你还将遇到电容的充放电（第 7 章 RC 电路）和 LC 振荡（第 10 章），它们都必须通过瞬态分析来观察。

6. 本章小结 ​

  • 法拉第电磁感应定律 ε=−dΦdt\varepsilon = -\frac{d\Phi}{dt}ε=−dtdΦ​：穿过回路的磁通量变化率等于产生的感应电动势。负号表示楞次定律。
  • 楞次定律（增反减同）：感应电流的方向总是阻碍原磁通量的变化——这是能量守恒定律在电磁学中的体现。
  • 自感现象 εL=−LdIdt\varepsilon_L = -L\frac{dI}{dt}εL​=−LdtdI​：线圈自身的电流变化产生自感电动势，抵抗电流的变化。
  • RL 电路的时间常数 τ=L/R\tau = L/Rτ=L/R 决定了电流建立的快慢：经过 5τ5\tau5τ 后基本达到稳态。
  • PySpice 的 .transient() 瞬态分析可以模拟电路的动态过程，观察电压和电流随时间的变化波形。

7. 练习 ​

  1. 直接计算：一个 50mH50\text{mH}50mH 的电感，其中流过的电流以 2A/s2\text{A/s}2A/s 的速率均匀变化。求电感情人产生的自感电动势的大小和方向（注意：电流是增大还是减小决定了感应电动势的方向）。

  2. 时间常数：将仿真代码中的电阻改为 50Ω50\Omega50Ω（电感保持 10mH10\text{mH}10mH），重新运行瞬态分析。新的时间常数 τ\tauτ 是多少？电流到达稳态的 63.2% 需要多长时间？观察仿真输出，和你的计算结果对比。

  3. 楞次定律分析：有一磁铁正在快速离开线圈（线圈固定不动，磁铁拔出）。请判断：(1) 原磁场通过线圈的方向（假设 N 极朝线圈）；(2) 原磁通是增加还是减少；(3) 感应电流产生的磁场方向是什么（与原磁场同向还是反向）？(4) 由此推断线圈中的感应电流方向（画图表示）。

  4. 能量转换：在电感储能的过程中（电流从 0 逐渐增大到稳态值 50mA），电感储存了多少磁能？能量储存在哪里？当电源切断后，这些能量去哪儿了？（提示：电感储能 W=12LI2W = \frac{1}{2}LI^2W=21​LI2，电流减小时能量通过感应电动势释放回电路。）
