第5章 磁场与电磁力 ​

1. 本节你将学到 ​

  • 理解磁场的基本概念：磁感线、磁场方向、磁感应强度 BBB
  • 掌握安培力公式 F=BILF = BILF=BIL：通电导线在磁场中受到的力
  • 认识磁通量 Φ=BS\Phi = BSΦ=BS：穿过某一面积的磁感线条数
  • 理解电流的磁效应（奥斯特实验）：电流周围产生磁场，用右手螺旋定则判断方向
  • 了解常见磁场的分布：直线电流、环形电流、通电螺线管

2. 知识回顾/情景引入 ​

在初中物理中，我们学过磁铁有两个极——N 极和 S 极，同极相斥、异极相吸。地球本身就是一个巨大的磁体，指南针之所以指南北，就是因为地球磁场的作用。

但高中物理要问一个更深层的问题：磁场和电流之间有什么关系？电流能产生磁场吗？磁场能反过来对电流施加力吗？

这两个问题的答案将电流和磁场紧紧地联系在了一起，构成了电磁学最核心的基石。

2.1 奥斯特的惊人发现 ​

1820 年 4 月的一个晚上，丹麦物理学家汉斯·克里斯蒂安·奥斯特（Hans Christian Ørsted）在哥本哈根大学做电学演示实验时，意外地发现了一件奇妙的事情：当他接通导线中的电流时，放在导线旁边的小磁针竟然发生了偏转！

这个发现的意义极其重大——它第一次揭示了电与磁不是互相独立的现象，而是彼此关联的。通电导线周围产生了磁场，这个磁场对磁针施加了力，让磁针转动。奥斯特的发现开启了电磁学的大门，被后人尊称为"电磁学之父"。

2.2 磁场的基本概念 ​

磁场是存在于磁体或电流周围空间的一种特殊物质，它对放入其中的磁体或运动电荷有力的作用。为形象地描述磁场，法拉第引入了磁感线（也叫磁力线）的概念：

  • 磁感线上每一点的切线方向表示该点磁场方向（小磁针 N 极的受力方向）
  • 磁感线的疏密表示磁场的强弱——越密的地方磁场越强
  • 磁感线从 N 极出发，回到 S 极（在磁体外部）；在磁体内部，磁感线从 S 极到 N 极，形成闭合曲线
  • 磁感线不相交、不中断

磁感应强度 BBB 是定量描述磁场强弱的物理量，单位是特斯拉（T）。地球磁场在地表大约为 5×10−5 T5 \times 10^{-5}\ \text{T}5×10−5 T，医用 MRI 磁体的磁场强度可达 1.5T1.5\text{T}1.5T 到 3T3\text{T}3T。

3. 安培力——磁场对电流的作用力 ​

3.1 安培力公式 ​

如果有一段长度为 LLL 的直导线，通有电流 III，垂直放置在磁感应强度为 BBB 的匀强磁场中，那么导线将受到一个力的作用。这个力叫安培力，大小为：

F=BILF = BIL F=BIL

力的方向垂直于磁场方向和电流方向所决定的平面，用左手定则来判断：

  • 左手定则：伸开左手，让磁感线从掌心穿入，四指指向电流方向，则大拇指所指的方向就是安培力的方向。

💡 这是高中物理最重要的两个手指定则之一（另一个是下一章的右手定则用来判断感应电动势方向）。记法口诀：左力右电——左手判断力（安培力），右手判断电（感应电流/电动势方向）。

如果导线与磁场方向有夹角 θ\thetaθ（而不是垂直），安培力的大小为：

F=BILsin⁡θF = BIL\sin\theta F=BILsinθ

当 θ=90∘\theta = 90^\circθ=90∘（垂直）时，F=BILF = BILF=BIL（最大）；当 θ=0∘\theta = 0^\circθ=0∘（平行）时，F=0F = 0F=0（不受力）。

3.2 安培力的应用 ​

安培力在生活中有广泛应用：

  • 电动机：通电线圈在磁场中受到安培力而旋转——这是所有电动机（从玩具小马达到电动汽车驱动电机）的基本原理。换向器不断切换线圈中的电流方向，保证线圈持续朝同一方向转动。
  • 磁电式电流表：线圈通电后在磁场中偏转，偏转角与电流大小成正比。第 4 章中改装的表头就是靠安培力工作的——线圈受到的安培力矩和游丝的弹性力矩平衡，指针偏转到对应的刻度。
  • 电磁炮：巨大的脉冲电流通过导轨上的炮弹，安培力将炮弹以极高速度弹射出去（速度可达数千米每秒）。

4. 电流产生磁场 ​

4.1 右手螺旋定则（安培定则） ​

电流不仅能受到磁场的力，电流自身也会产生磁场。判断电流产生磁场的方向用右手螺旋定则：

直线电流：右手握住导线，大拇指指向电流方向，弯曲的四指所指的方向就是磁感线的环绕方向（磁场是环形的，围绕导线）。

环形电流（如线圈）：右手弯曲的四指指向电流方向，大拇指所指的方向就是环形电流轴线上（圈内中心区域）的磁场方向——即 N 极和 S 极的指向。

4.2 几种典型电流的磁场 ​

电流类型磁场分布特点磁感应强度公式
无限长直线电流以导线为轴的同心圆环B=μ0I2πrB = \frac{\mu_0 I}{2\pi r}B=2πrμ0​I​
环形电流（圆环）轴线上类似条形磁铁圆心处 B=μ0I2RB = \frac{\mu_0 I}{2R}B=2Rμ0​I​
通电螺线管（长直）管内部近似匀强磁场B=μ0nIB = \mu_0 n IB=μ0​nI（nnn 为单位长度匝数）

其中 μ0=4π×10−7 T⋅m/A\mu_0 = 4\pi \times 10^{-7}\ \text{T·m/A}μ0​=4π×10−7 T⋅m/A 是真空磁导率。

通电螺线管内部产生的是近似匀强磁场——这正是电磁铁的原理。在螺线管中插入铁芯（软铁），铁芯被磁化后磁场强度可以增强数百至数千倍，这就是工业上广泛使用的电磁铁。电磁起重机可以利用这个原理吸起数吨重的钢铁废料。

5. 磁通量 ​

磁通量 Φ\PhiΦ 的定义是：穿过某一面积 SSS 的磁感线条数（严格来说，是磁感应强度 BBB 与该面积 SSS 的标量积）：

Φ=BS\Phi = BS Φ=BS

当磁场方向与面积法线方向一致时，Φ=BS\Phi = BSΦ=BS；当有夹角 θ\thetaθ 时，Φ=BScos⁡θ\Phi = BS\cos\thetaΦ=BScosθ。

磁通量的单位是韦伯（Wb）：1 Wb=1 T⋅m21\ \text{Wb} = 1\ \text{T} \cdot \text{m}^21 Wb=1 T⋅m2。

磁通量在下一章（电磁感应）中至关重要——只要穿过闭合回路的磁通量发生变化，回路中就会产生感应电动势。这就是法拉第电磁感应定律的核心内容。可以说，安培力和磁通量构成了描述电与磁相互作用的两个基本"接口"。

6. 本章小结 ​

  • 磁场是电流和磁体周围空间中的特殊物质，用磁感线形象描述，用磁感应强度 BBB（单位 T）定量表达。
  • 安培力 F=BILF = BILF=BIL：通电导线在磁场中受到的力，方向用左手定则判断（左力）。
  • 电流的磁效应：通电导线周围产生磁场，方向用右手螺旋定则判断（直线电流和环形电流）。
  • 磁通量 Φ=BS\Phi = BSΦ=BS：穿过某一面积的磁感应强度积分，单位 Wb。磁通量的变化是产生感应电动势的根源。
  • 本章内容以物理概念为主，不涉及电路仿真——磁场和安培力的定量计算在后续章节（电磁感应、变压器）中通过电感元件间接体现。

  2. 磁场方向判断：一根竖直的导线中电流方向向上（从脚底指向头顶），求导线周围磁感线的环绕方向。如果有一枚小磁针放在导线的正东方向 2cm 处，磁针的 N 极会指向哪个方向？

  3. 螺线管分析：一个螺线管长 0.2m0.2\text{m}0.2m，绕了 500500500 匝，通以 0.5A0.5\text{A}0.5A 的电流。求：(1) 单位长度匝数 nnn；(2) 管内磁感应强度 BBB；(3) 如果在管内插入一根 S=2cm2S = 2\text{cm}^2S=2cm2 的铁芯，穿过铁芯截面的磁通量大约是多少？
