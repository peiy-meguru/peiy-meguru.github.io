  • 理解有效值（RMS）的定义与物理意义：U=Um2U = \frac{U_m}{\sqrt{2}}U=2​Um​​，I=Im2I = \frac{I_m}{\sqrt{2}}I=2​Im​​

2. 知识回顾/情景引入 ​

2.1 从电池到电厂——交流电的"逆袭" ​

在前面所有章节中，我们使用的电源都是恒定的直流电压——就像一节干电池或一个稳定的直流稳压电源。但在现实生活中，从墙上的插座取出来的电是交流电：电压的大小和方向都随时间作周期性变化。

1880 年代，历史上爆发了著名的"电流之战"（War of Currents）：托马斯·爱迪生（Thomas Edison）大力推广直流电系统，而尼古拉·特斯拉（Nikola Tesla）和乔治·威斯汀豪斯（George Westinghouse）则力推交流电。最终交流电凭借一个压倒性的优势胜出——它可以方便地用变压器改变电压，从而实现高压输电（减少线路损耗）和低压用电（保证安全）。今天全球的电网几乎全是交流电系统。

2.2 正弦交流电的数学描述 ​

交变电流的最基本形式是正弦交流电。以电压 u(t)u(t)u(t) 为例（可以用小写字母表示随时间变化的瞬时值）：

u(t)=Umsin⁡(ωt+φ0)u(t) = U_m \sin(\omega t + \varphi_0) u(t)=Um​sin(ωt+φ0​)

其中：

  • UmU_mUm​ 是峰值（振幅），即电压的最大瞬时值，单位 V
  • ω=2πf=2πT\omega = 2\pi f = \frac{2\pi}{T}ω=2πf=T2π​ 是角频率，单位 rad/s
  • fff 是频率，单位赫兹（Hz），表示每秒完成完整正弦周期的次数
  • T=1fT = \frac{1}{f}T=f1​ 是周期，单位秒（s），表示完成一个完整正弦波所需的时间
  • φ0\varphi_0φ0​ 是初相位，表示 t=0t = 0t=0 时刻正弦波所在的角度

对于电流同理：i(t)=Imsin⁡(ωt+φ0′)i(t) = I_m \sin(\omega t + \varphi_0')i(t)=Im​sin(ωt+φ0′​)。

我国的市电标准频率为 50 Hz（周期 T=20msT = 20\text{ms}T=20ms），峰值为 Um=2202≈311VU_m = 220\sqrt{2} \approx 311\text{V}Um​=2202​≈311V。美国等部分国家使用 60 Hz 标准。

2.3 为什么需要有效值（RMS） ​

交流电的电压和电流随时都在变化，瞬时值不方便也不能直接用于计算功率。我们需要的是一种等效于直流电的恒定数值——有效值（Root Mean Square，简称 RMS）。

定义思路：让交流电通过一个电阻，在一个周期内产生的热量，刚好等于某一直流电通过同一电阻、在相同时间内产生的热量。这个直流电的数值就是该交流电的有效值。

数学推导：交流电流 i(t)=Imsin⁡(ωt)i(t) = I_m \sin(\omega t)i(t)=Im​sin(ωt) 通过电阻 RRR，瞬时功率为 p(t)=i2(t)Rp(t) = i^2(t)Rp(t)=i2(t)R。一个周期内的平均功率为：

Pavg=1T∫0Ti2(t)R dt=1T∫0TIm2sin⁡2(ωt)R dtP_{\text{avg}} = \frac{1}{T} \int_0^T i^2(t)R\, dt = \frac{1}{T} \int_0^T I_m^2 \sin^2(\omega t) R\, dt Pavg​=T1​∫0T​i2(t)Rdt=T1​∫0T​Im2​sin2(ωt)Rdt

利用 sin⁡2(ωt)=1−cos⁡(2ωt)2\sin^2(\omega t) = \frac{1 - \cos(2\omega t)}{2}sin2(ωt)=21−cos(2ωt)​，积分后余弦项在一个周期内平均为零。得到：

Pavg=12Im2RP_{\text{avg}} = \frac{1}{2}I_m^2 R Pavg​=21​Im2​R

令这个平均热功率与直流 III 产生的热功率 I2RI^2 RI2R 相等，得：

I=Im2I = \frac{I_m}{\sqrt{2}} I=2​Im​​

同理，电压的有效值为：

U=Um2U = \frac{U_m}{\sqrt{2}} U=2​Um​​

我们平时说的"市电 220V"，指的就是有效值 220V，而峰值 311V311\text{V}311V 是 2\sqrt{2}2​ 倍。"电器的额定电压"也都是有效值。不过，对电器绝缘需要考虑峰值电压而非有效值。

2.4 正弦交流电的相量表示法（初步） ​

虽然本节不做深入相量法讲解，但需要知道一个基本概念：在同频率的正弦电路中，可以用相量（一个复数或旋转矢量）来表示正弦量的大小和相位关系。这大大简化了交流电路的分析，也是后续大学课程中交流稳态分析的基础。

电源频率 f=50Hzf = 50\text{Hz}f=50Hz 意味着周期 T=1/f=0.02s=20msT = 1/f = 0.02\text{s} = 20\text{ms}T=1/f=0.02s=20ms。

  • 仿真步长：Δt=100μs\Delta t = 100\mu\text{s}Δt=100μs（远小于周期 20ms20\text{ms}20ms，保证波形细节清晰）

4. 用 Python 实现电路仿真 ​

4.1 构建正弦交流电路并执行瞬态分析 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

circuit = Circuit('AC Demo')
circuit.SinusoidalVoltageSource('ac', 1, circuit.gnd, amplitude=10@u_V,
                                frequency=50@u_Hz)
circuit.R(1, 1, circuit.gnd, 100@u_Ω)

simulator = circuit.simulator(temperature=25, nominal_temperature=25,
                              simulator='ngspice-subprocess')
analysis = simulator.transient(step_time=100@u_us, end_time=40@u_ms)

代码解释：

  • circuit.SinusoidalVoltageSource('ac', 1, circuit.gnd, amplitude=10@u_V, frequency=50@u_Hz)：这是本章引入的全新元件！创建一个正弦交流电压源：
    • 'ac'：元件名称
    • 1, circuit.gnd：正端接节点 1，负端接地
    • amplitude=10@u_V：振幅（峰值）为 10V
    • frequency=50@u_Hz：频率为 50Hz
  • .transient(step_time=100@u_us, end_time=40@u_ms)：瞬态分析，步长 100μs100\mu\text{s}100μs，总时长 40ms40\text{ms}40ms（2 个完整周期）。采样点多达 400400400 个，能精细呈现正弦波形。

5. 深入理解 ​

5.1 RMS 的物理检验——发热等效 ​

有效值的定义——"在相等时间内通过同一电阻产生相同热量"——可以通过数值积分来验证。仿真中我们获得了 400400400 个采样点的电压值，可以计算数值 RMS：

Urms≈1N∑k=1NVk2U_{\text{rms}} \approx \sqrt{\frac{1}{N}\sum_{k=1}^{N} V_k^2} Urms​≈N1​k=1∑N​Vk2​​

仿真得到的结果应当非常接近 7.07V7.07\text{V}7.07V，从而验证理论推导的 Um/2U_m/\sqrt{2}Um​/2​ 公式。

5.2 频率与周期的关系 ​

频率 fff 和周期 TTT 互为倒数：T=1/fT = 1/fT=1/f。对 50Hz50\text{Hz}50Hz 而言：

  • T=1/50=0.02s=20msT = 1/50 = 0.02\text{s} = 20\text{ms}T=1/50=0.02s=20ms
  • 1 秒内完成 50 个完整正弦周期
  • 角频率 ω=2πf≈314.16 rad/s\omega = 2\pi f \approx 314.16\,\text{rad/s}ω=2πf≈314.16rad/s

在交流电路中，频率是极其重要的参数。同一个电路（例如包含电容或电感的电路）在不同频率下的响应可能天差地别——这正是频率响应的概念，也是推动交流分析发展的核心原因之一。

5.4 为什么电力系统使用 50Hz（或 60Hz） ​

这是一个值得思考的工程问题。交流频率的选取得当是多方折中的结果：

  • 太低（如 10Hz）：变压器需要更大的铁芯（因为磁通变化慢），灯光会明显闪烁（人眼对低于 50Hz 的闪烁比较敏感）。
  • 太高（如 400Hz）：输电线路的感抗增大（XL=ωLX_L = \omega LXL​=ωL），损耗增加；同时电机的铁耗也随频率增加。
  • 50/60Hz 是历史上综合考虑变压器体积、电机转速和线路损耗后的最优选择。航空系统因其特殊性使用 400Hz 以减小设备重量。

6. 本章小结 ​

  • 交流电（AC）的电压和电流大小、方向随时间周期性变化。最基础的交流电是正弦交流电。
  • 正弦交流电由三个参数唯一确定：振幅（UmU_mUm​、ImI_mIm​）、频率（fff，或周期 T=1/fT = 1/fT=1/f）和初相位（φ0\varphi_0φ0​）。
  • 有效值（RMS）是交流电等效于直流电的数值：Urms=Um/2U_{\text{rms}} = U_m/\sqrt{2}Urms​=Um​/2​，Irms=Im/2I_{\text{rms}} = I_m/\sqrt{2}Irms​=Im​/2​。日常所说的"220V"正是有效值。
  • 有效值的物理含义：在相同时间、相同电阻上产生相同热量的恒定电流值——即发热等效。
  • PySpice 中 SinusoidalVoltageSource 可以产生正弦波，配合 .transient() 分析可以观察到电压随时间变化的波形；.ac() 分析则用于研究频率响应。
  • 频率 fff 是交流电路的核心参数之一。同一电路中不同频率下电容和电感的阻抗不同，这一特性是交流电路分析和设计的基础。
