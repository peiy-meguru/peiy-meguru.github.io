  • 认识谐振（Resonance）现象：当外加信号频率等于电路固有频率时，响应达到最大

2. 知识回顾/情景引入 ​

2.1 从秋千到电路——无处不在的谐振 ​

想象你正在荡秋千。如果每次秋千荡回来时，你恰好在其运动方向上推一把（即外加力与秋千运动同步），秋千就会越荡越高。但如果推的节奏不对——快了或慢了——反而会阻碍秋千的运动，甚至让它停下来。

这个现象的本质是谐振（Resonance）：当一个系统受到与自身固有频率匹配的外部激励时，振幅达到最大值。荡秋千只是谐振现象的一个例子。同样的原理支配着：

  • 乐器弦线（吉他、钢琴）的振动频率
  • 酒杯被歌手唱碎（声波频率 = 玻璃的固有频率）
  • 桥梁在风力下的摇晃（塔科马海峡大桥倒塌的教训）
  • 无线电接收：调节收音机旋钮就是在调节接收电路的固有 LC 频率，使之与目标电台频率"谐振"，从中挑选出想要的信号

在电学中，LC 振荡电路是最基本的谐振系统。它由电容 CCC 和电感 LLL 组成——两个储能元件在一个闭合回路中交替充放能量，形成持续的电磁振荡。

2.2 从 LC 振荡到电磁波——麦克斯韦的伟大预言 ​

1864 年，苏格兰物理学家詹姆斯·克拉克·麦克斯韦（James Clerk Maxwell）发表了他的电磁学方程组。从这套方程出发，他做出了一个石破天惊的预言：

变化的电场产生变化的磁场，变化的磁场又产生变化的电场——两者交替激发，形成一种以光速 c=3×108 m/sc = 3 \times 10^8\,\text{m/s}c=3×108m/s 传播的波——电磁波。

更惊人的是，麦克斯韦计算出电磁波的传播速度：

v=1ε0μ0≈3×108 m/sv = \frac{1}{\sqrt{\varepsilon_0 \mu_0}} \approx 3 \times 10^8\,\text{m/s} v=ε0​μ0​​1​≈3×108m/s

这个数值竟然与当时已知的光速完全一致！麦克斯韦据此大胆推测：光本身就是一种电磁波。这是物理学史上最震撼人心的理论统一之一——把光学并入了电磁学。

1887 年，德国科学家海因里希·赫兹（Heinrich Hertz）用火花放电实验产生了并检测到电磁波，证实了麦克斯韦的预言。今天，从无线电广播到手机通信，从 WiFi 到微波炉，再到 X 光成像——整个现代无线通信大厦都建立在 LC 振荡→电磁波的这一基本物理链条之上。

2.3 LC 振荡的物理图像 ​

考虑一个理想的 LC 回路（无电阻，无能量损耗）：

  1. t=0t = 0t=0：电容充满电（电压最大 U0U_0U0​），电场能最大。电感中电流为零，磁场能为零。
  2. 电容开始放电：电流开始在线圈中建立，电感产生自感电动势抵抗电流的变化（回忆第 6 章 RL 电路中的"电磁惯性"）。电流逐渐增大，电场能（电容）逐渐转化为磁场能（电感）。
  3. T4\frac{T}{4}4T​ 时刻：电容放完（电压为零），电场能为零。此时电流达最大值 Imax⁡I_{\max}Imax​，磁场能全部集中在电感中。
  4. T4→T2\frac{T}{4} \to \frac{T}{2}4T​→2T​：电感的自感电动势维持电流继续流动（惯性！），给电容反向充电。电流逐渐减小，磁场能又转化回电场能——但这次电容极板的极性反了。
  5. T2\frac{T}{2}2T​ 时刻：电容反向充满，电流为零。电场能回到最大。然后重复整个过程，但方向相反。

这个过程就像没有摩擦的弹簧-质量块系统：质量块（电感——惯性）在弹簧（电容——回复力）两端来回振荡，动能与势能交替转化，永不停息。而在实际 LC 电路中，导线和元件的电阻会慢慢消耗能量，振荡最终衰减（阻尼振荡）。

2.4 固有频率公式的推导 ​

从能量守恒出发，任意时刻 ttt 电路中的总能量为：

Wtotal=12Li2(t)+12Cu2(t)=常量W_{\text{total}} = \frac{1}{2}Li^2(t) + \frac{1}{2}Cu^2(t) = \text{常量} Wtotal​=21​Li2(t)+21​Cu2(t)=常量

对时间求导并用 i=Cdudti = C\frac{du}{dt}i=Cdtdu​ 代入，得：

Ld2udt2+1Cu=0L\frac{d^2 u}{dt^2} + \frac{1}{C}u = 0 Ldt2d2u​+C1​u=0

这是一个简单的简谐振动微分方程，其解为 u(t)=U0cos⁡(ω0t+φ)u(t) = U_0 \cos(\omega_0 t + \varphi)u(t)=U0​cos(ω0​t+φ)，其中角谐振频率为：

ω0=1LC\omega_0 = \frac{1}{\sqrt{LC}} ω0​=LC​1​

对应的谐振频率（Hz）和周期为：

f0=ω02π=12πLCT0=1f0=2πLCf_0 = \frac{\omega_0}{2\pi} = \frac{1}{2\pi\sqrt{LC}} \qquad T_0 = \frac{1}{f_0} = 2\pi\sqrt{LC} f0​=2πω0​​=2πLC​1​T0​=f0​1​=2πLC​

这就是经典的汤姆逊公式（Thomson Formula），以英国物理学家威廉·汤姆逊（开尔文勋爵）命名。它简洁地指出：LC 回路的振荡频率只取决于 LLL 和 CCC 的乘积——电感越大（惯性大）、电容越大（回复力小），振荡越慢（频率越低）。

3. 动手设计电路 ​

3.1 本节电路：RLC 串联谐振电路 ​

电路构成：

  • 正弦交流激励源：振幅 1V1\text{V}1V（小信号，避免非线性），频率可扫描
  • 串联电阻 R=10ΩR = 10\OmegaR=10Ω（限制谐振峰的高度；无电阻时峰值为无穷大，不便于仿真）
  • 电感 L=10mHL = 10\text{mH}L=10mH（储能/惯性元件）
  • 电容 C=10μFC = 10\mu\text{F}C=10μF（储能/回复元件）

三元件串联：电压源正端（节点 1）→ 电阻（节点 1 → 节点 2）→ 电感（节点 2 → 地）→ 电容（节点 2 → 地）。输出节点为节点 2——LC 并联的公共端。

实际上这是一个 R + LC 并联的电路结构：电阻与电压源串联，然后驱动 LLL 和 CCC 的并联支路。在谐振时，并联 LC 阻抗最大，节点 2 上输出电压最大。

3.2 理论谐振频率计算 ​

代入 L=10mH=10×10−3HL = 10\text{mH} = 10 \times 10^{-3}\text{H}L=10mH=10×10−3H，C=10μF=10×10−6FC = 10\mu\text{F} = 10 \times 10^{-6}\text{F}C=10μF=10×10−6F：

f0=12πLC=12π10×10−3×10×10−6=12π10−7f_0 = \frac{1}{2\pi\sqrt{LC}} = \frac{1}{2\pi\sqrt{10 \times 10^{-3} \times 10 \times 10^{-6}}} = \frac{1}{2\pi\sqrt{10^{-7}}} f0​=2πLC​1​=2π10×10−3×10×10−6​1​=2π10−7​1​

=12π×3.162×10−4≈11.987×10−3≈503.3 Hz= \frac{1}{2\pi \times 3.162 \times 10^{-4}} \approx \frac{1}{1.987 \times 10^{-3}} \approx 503.3\,\text{Hz} =2π×3.162×10−41​≈1.987×10−31​≈503.3Hz

即电路的固有谐振频率约在 503Hz503\text{Hz}503Hz 附近。频率扫描范围设为 100Hz∼10kHz100\text{Hz} \sim 10\text{kHz}100Hz∼10kHz（约 10kHz10\text{kHz}10kHz 的上限足够覆盖并观测到谐振峰两侧的衰减行为）。

3.3 频率扫描设置 ​

.ac() 交流分析参数：

  • 起始频率：100Hz100\text{Hz}100Hz（低于谐振点，便于观察上升段）
  • 终止频率：10kHz10\text{kHz}10kHz（高于谐振点，便于观察下降段）
  • 扫描点数：200200200（200 个对数等间距频率点，保证谐振峰附近有足够的采样密度）
  • 变尺度：'dec'（对数扫描，在每个数量级内均匀取点——对于宽频率范围的谐振分析非常合适）

4. 用 Python 实现电路仿真 ​

4.1 构建 LC 谐振电路并执行频率扫描 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

circuit = Circuit('LC Oscillator')
circuit.SinusoidalVoltageSource('ac', 1, circuit.gnd, amplitude=1@u_V)
circuit.R(1, 1, 2, 10@u_Ω)
circuit.L(1, 2, circuit.gnd, 10@u_mH)
circuit.C(1, 2, circuit.gnd, 10@u_uF)

simulator = circuit.simulator(temperature=25, nominal_temperature=25,
                              simulator='ngspice-subprocess')
analysis = simulator.ac(start_frequency=100@u_Hz, stop_frequency=10@u_kHz,
                         number_of_points=200, variation='dec')

代码解释：

  • circuit.SinusoidalVoltageSource('ac', 1, circuit.gnd, amplitude=1@u_V)：振幅 1V1\text{V}1V 的小信号正弦源——对于线性 AC 分析，振幅大小不影响频率响应的形状（只影响幅度缩放），所以 1V1\text{V}1V 是方便的标准选择。
  • circuit.L(1, 2, circuit.gnd, 10@u_mH) 和 circuit.C(1, 2, circuit.gnd, 10@u_uF)：电感和电容并联在节点 2 和地之间，形成并联 LC 谐振网络。
  • .ac(start_frequency=100@u_Hz, stop_frequency=10@u_kHz, number_of_points=200, variation='dec')：从 100Hz100\text{Hz}100Hz 到 10kHz10\text{kHz}10kHz 的对数频率扫描，200200200 个频率点。扫频的结果是一个复数数组，其中频率轴表示仿真的激励频率，输出为对应频率下的复数稳态响应（包括幅值和相位）。

5. 深入理解 ​

5.1 品质因数 Q——谐振的"尖锐度" ​

在 RLC 谐振电路中，品质因数（Quality Factor，简称 Q 值）是衡量谐振"好坏"的关键参数：

Q=1RLC=ω0LR=1ω0CRQ = \frac{1}{R}\sqrt{\frac{L}{C}} = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 C R} Q=R1​CL​​=Rω0​L​=ω0​CR1​

Q 值越高，谐振峰越尖锐（频率选择性越好），能量损耗越小（振荡衰减越慢）。对于本节电路：

Q=11010×10−310×10−6=1101000≈3.16Q = \frac{1}{10}\sqrt{\frac{10 \times 10^{-3}}{10 \times 10^{-6}}} = \frac{1}{10}\sqrt{1000} \approx 3.16 Q=101​10×10−610×10−3​​=101​1000​≈3.16

Q 值不太高——谐振峰会比较宽（因为 R=10ΩR = 10\OmegaR=10Ω 是故意取的较大值以确保仿真稳定性）。在无线通信中，常需要极高 Q 值（100∼1000100 \sim 1000100∼1000）的谐振电路来实现精确频率选择，从而不至于被相邻频道干扰。

5.2 带宽与滤波应用 ​

谐振曲线的带宽（BWBWBW）定义为信号幅度下降到最大值 1/2≈0.7071/\sqrt{2} \approx 0.7071/2​≈0.707 倍（即 −3dB-3\text{dB}−3dB 点）时，上下两个频率之差：

BW=fH−fL=f0QBW = f_H - f_L = \frac{f_0}{Q} BW=fH​−fL​=Qf0​​

这直接关系到电路作为带通滤波器（Band-Pass Filter）的选频能力。例如收音机旋钮调节的就是一个 LC 谐振电路的频率，通过改变可变电容的 CCC 值来移动 f0f_0f0​，从而挑选出想要的电台。

5.3 串联 RLC vs 并联 RLC ​

本节使用的 R+L∥CR + L\|CR+L∥C（电阻串联，LC 并联）拓扑在谐振时的行为与纯串联 RLC 有所不同：

  • 串联 RLC：谐振时阻抗最小（为零，仅剩 RRR），电流最大——常用于选频放大（如天线谐振回路）。
  • 并联 RLC：谐振时阻抗最大（理想为无穷大），电压最大——常用于带阻滤波和振荡器选频网络。

两者具有相同的谐振频率公式 f0=12πLCf_0 = \frac{1}{2\pi\sqrt{LC}}f0​=2πLC​1​，但电流/电压行为正好相反——设计电路时需根据应用场合选择合适的拓扑。

5.4 从振荡到电磁波 ​

当 LC 回路的频率提高到射频范围（kHz ∼\sim∼ MHz 及更高）且电路尺寸接近波长 λ=c/f\lambda = c/fλ=c/f 时，振荡的电场和磁场不再被约束在电容极板间和电感线圈内，而是辐射到周围空间中——这就是电磁波的产生。

赫兹在 1887 年的经典实验中使用的发射器正是一个火花隙 LC 振荡器：两个金属球之间流过一个高压火花，产生一个强烈衰减的高频振荡，向空间辐射电磁波；距离数米之外的接收器（一个带有可调间隙的金属环）中出现了感应火花——人类第一次在实验室中产生了并探测到了电磁波。

从高考物理的视角，同学们应该掌握的要点是：LC 振荡产生的周期性变化的电场和磁场，按照麦克斯韦电磁场理论，以电磁波的形式在空间传播——电场与磁场互相垂直、与传播方向也互相垂直（横波），速度 c=1/εμc = 1/\sqrt{\varepsilon\mu}c=1/εμ​。

6. 本章小结 ​

  • LC 振荡是电容中的电场能与电感中的磁能周期性相互转化的过程，类似弹簧-质量块的机械振动。无损耗的 LC 回路以固有频率做简谐振动。
  • 汤姆逊公式给出了 LC 振荡的固有频率：f0=12πLCf_0 = \frac{1}{2\pi\sqrt{LC}}f0​=2πLC​1​，周期 T=2πLCT = 2\pi\sqrt{LC}T=2πLC​。振荡快慢仅取决于 LLL 和 CCC 的乘积。
  • 谐振现象：当外加激励频率等于电路固有频率时，系统响应达到最大——谐振峰的位置由汤姆逊公式精确确定。
  • 品质因数 Q=1RL/CQ = \frac{1}{R}\sqrt{L/C}Q=R1​L/C​ 衡量谐振的尖锐程度和能量损耗：高 Q 值 = 高峰、窄带、低损耗。
  • 电磁波由周期性变化的电场和磁场交替激发而成，以光速 c=3×108 m/sc = 3\times 10^8\,\text{m/s}c=3×108m/s 传播。LC 振荡电路中足够高频的振荡可以辐射电磁波。
  • PySpice 的 .ac() 频率扫描配合对数频率轴，可以绘制出完整的频率响应曲线（Bode 图的幅度部分），直观地观察和验证谐振行为。
