  • 掌握电容的符号、单位和充放电行为
  • 推导RC电路暂态过程的电压变化规律：Vc(t)=V0(1−e−t/RC)V_c(t) = V_0(1 - e^{-t/RC})Vc​(t)=V0​(1−e−t/RC)（充电）和 Vc(t)=V0e−t/RCV_c(t) = V_0 e^{-t/RC}Vc​(t)=V0​e−t/RC（放电）
  • 理解时间常数 τ=RC\tau = RCτ=RC 的物理意义：充放电快慢的量度

2. 知识回顾/情景引入 ​

我们在第6章学习了电感元件——它抵抗电流的变化，像电磁世界中的"惯性"。现在我们要学习另一个同样重要的储能元件：电容。

2.1 电容的诞生——莱顿瓶的故事 ​

1745年，荷兰莱顿大学的教授穆森布罗克（Pieter van Musschenbroek）在一次实验中偶然发现：一个装有水的玻璃瓶，内外分别贴有金属箔，用导线连接外部金属箔后，竟然能储存大量的电。这就是历史上第一个电容器——莱顿瓶。

据说穆森布罗克本人第一次尝试用手触碰莱顿瓶的电极时，被猛烈的电击几乎击倒，他在给友人的信中写道："就算把整个法兰西王国送给我，我也不愿再被电击一次。"这个故事生动地说明：电容能够储存相当可观的电荷和能量。

2.2 电容的定义与物理图像 ​

电容器的基本结构非常简单：两块导体极板，中间夹一层绝缘介质（如空气、陶瓷、电解液等）。当两极板分别带上正、负电荷时，极板间建立起电场，能量便以电场能的形式储存起来。

电容的定义式：

C=QUC = \frac{Q}{U} C=UQ​

其中 CCC 是电容量（单位法拉，符号 F），QQQ 是极板上储存的电荷量（单位库仑 C），UUU 是两极板间的电压（单位伏特 V）。

1 法拉是非常大的单位。实际中常见的电容为微法（μ\muμF）、纳法（nF）或皮法（pF）。1 F=106 μF=109 nF=1012 pF1\,\text{F} = 10^6\,\mu\text{F} = 10^9\,\text{nF} = 10^{12}\,\text{pF}1F=106μF=109nF=1012pF。

2.3 平行板电容器的电容公式 ​

对于最简单的平行板电容器，其电容量由几何参数决定：

C=εrε0SdC = \frac{\varepsilon_r \varepsilon_0 S}{d} C=dεr​ε0​S​

其中 SSS 是极板正对面积，ddd 是板间距离，ε0\varepsilon_0ε0​ 是真空介电常数（8.85×10−12 F/m8.85 \times 10^{-12}\,\text{F/m}8.85×10−12F/m），εr\varepsilon_rεr​ 是介质的相对介电常数。极板面积越大、距离越近、介质介电常数越大，电容量就越大。

2.4 电容的充放电——类比水桶 ​

电容的充放电过程可以直观地用水桶注水来类比：

  • 充电过程：给一只空水桶注水，开始水流很快（因为压差大），随着水位升高，注水越来越慢，最终水满，再也注不进去。电容充电也是如此：电压差大时充电电流大，随着电容电压接近电源电压，充电电流逐渐减小到零。
  • 放电过程：拔掉水桶底部的塞子，水流出——开始水流快，随着水位下降逐渐变慢，最终水放干。电容放电也是如此。

💡 类比：电阻是"摩擦力"（阻碍电荷运动），电感是"惯性"（阻碍电流变化），电容则是"水桶"（储存电荷和能量）。

3. 动手设计电路 ​

3.1 本节电路：RC 串联充电电路 ​

电路构成：

  • 直流电压源 V=5VV = 5\text{V}V=5V（模拟阶跃输入——t=0t = 0t=0 时刻从 0V 跳变到 5V）
  • 电阻 R=1kΩR = 1\text{k}\OmegaR=1kΩ（限制充放电电流，决定时间常数）
  • 电容 C=100μFC = 100\mu\text{F}C=100μF（储能元件）
  • 串联：电压源正端（节点 1）→ 电阻（节点 1 → 节点 2）→ 电容（节点 2 → 地）

3.2 电路方程与公式推导 ​

根据基尔霍夫电压定律，RC 串联回路中：

V=VR(t)+VC(t)V = V_R(t) + V_C(t) V=VR​(t)+VC​(t)

在充电过程中，VR(t)=i(t)RV_R(t) = i(t)RVR​(t)=i(t)R，而 i(t)=CdVCdti(t) = C\frac{dV_C}{dt}i(t)=CdtdVC​​。代入可得：

V=RCdVCdt+VC(t)V = RC\frac{dV_C}{dt} + V_C(t) V=RCdtdVC​​+VC​(t)

这是一阶线性微分方程。初始条件 VC(0)=0V_C(0) = 0VC​(0)=0（电容初始无电荷），解得充电方程：

VC(t)=V(1−e−t/RC)=V(1−e−t/τ)V_C(t) = V\left(1 - e^{-t/RC}\right) = V\left(1 - e^{-t/\tau}\right) VC​(t)=V(1−e−t/RC)=V(1−e−t/τ)

VR(t)=Ve−t/RC=Ve−t/τV_R(t) = V e^{-t/RC} = V e^{-t/\tau} VR​(t)=Ve−t/RC=Ve−t/τ

其中 τ=RC\tau = RCτ=RC 称为 RC 电路的时间常数，单位是秒（s）。

电阻上的电压和电流由 i(t)=VR(t)R=VRe−t/τi(t) = \frac{V_R(t)}{R} = \frac{V}{R} e^{-t/\tau}i(t)=RVR​(t)​=RV​e−t/τ 给出——呈指数衰减。

代入本实验参数 R=1kΩ=1000ΩR = 1\text{k}\Omega = 1000\OmegaR=1kΩ=1000Ω，C=100μF=100×10−6FC = 100\mu\text{F} = 100 \times 10^{-6}\text{F}C=100μF=100×10−6F：

τ=RC=1000×100×10−6=0.1s=100ms\tau = RC = 1000 \times 100 \times 10^{-6} = 0.1\text{s} = 100\text{ms} τ=RC=1000×100×10−6=0.1s=100ms

3.3 关键时间节点 ​

  • t=0t = 0t=0（初始瞬间）：VC=0V_C = 0VC​=0，VR=V=5VV_R = V = 5\text{V}VR​=V=5V。电容相当于短路（对阶跃信号而言，极板尚未充电，无反向电压）。
  • t=τt = \taut=τ（t=100mst = 100\text{ms}t=100ms）：VC=V(1−e−1)≈0.632V=3.16VV_C = V(1 - e^{-1}) \approx 0.632V = 3.16\text{V}VC​=V(1−e−1)≈0.632V=3.16V。约充到终值的 63.2%。
  • t=3τt = 3\taut=3τ（t=300mst = 300\text{ms}t=300ms）：VC≈0.950VV_C \approx 0.950VVC​≈0.950V。充到终值的 95%。
  • t=5τt = 5\taut=5τ（t=500mst = 500\text{ms}t=500ms）：VC≈0.993V≈5VV_C \approx 0.993V \approx 5\text{V}VC​≈0.993V≈5V。工程上认为基本充满。
  • t→∞t \to \inftyt→∞（稳态）：VC=V=5VV_C = V = 5\text{V}VC​=V=5V，VR=0V_R = 0VR​=0，电流为零。电容相当于开路。

💡 时间常数 τ\tauτ 的物理意义：τ\tauτ 越小，充放电越快（小电阻小电容 = 快响应）；τ\tauτ 越大，充放电越慢（大电阻大电容 = 慢响应）。在电路设计中，τ\tauτ 直接决定了瞬态行为的时间尺度。

4. 用 Python 实现电路仿真 ​

4.1 构建 RC 电路并执行瞬态分析 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

circuit = Circuit('RC Circuit')
circuit.PulseVoltageSource('pulse', 1, circuit.gnd,
                           initial_value=0@u_V, pulsed_value=5@u_V,
                           delay_time=0@u_ms, rise_time=1@u_ns,
                           fall_time=1@u_ns,
                           pulse_width=10@u_s, period=20@u_s)
circuit.R(1, 1, 2, 1@u_kΩ)
circuit.C(1, 2, circuit.gnd, 100@u_uF)

simulator = circuit.simulator(temperature=25, nominal_temperature=25,
                              simulator='ngspice-subprocess')
analysis = simulator.transient(step_time=1@u_ms, end_time=500@u_ms)

代码解释：

  • circuit.C(1, 2, circuit.gnd, 100@u_uF)：添加一个 100μF100\mu\text{F}100μF 的电容元件，C 是电容关键词，连接在节点 2 和地之间。在 PySpice 中 @u_uF 表示微法。
  • .transient(step_time=1@u_ms, end_time=500@u_ms)：瞬态分析，从 t=0t = 0t=0 开始模拟 500ms500\text{ms}500ms（即 5τ5\tau5τ），时间步长 1ms1\text{ms}1ms。
  • PulseVoltageSource(...)：脉冲电压源！initial_value=0@u_V 初始值为 0V，pulsed_value=5@u_V 脉冲值为 5V，在 t=0t = 0t=0 时从 0V 阶跃至 5V——完美模拟开关突然合上的效果。pulse_width=10@u_s 的高脉冲宽度远大于仿真时间，确保整个瞬态过程内电源保持在 5V。

5. 深入理解 ​

5.1 RC时间常数的本质 ​

时间常数 τ=RC\tau = RCτ=RC 的量纲检查：

[RC]=Ω⋅F=VA⋅CV=CA=CC/s=s[RC] = \Omega \cdot \text{F} = \frac{\text{V}}{\text{A}} \cdot \frac{\text{C}}{\text{V}} = \frac{\text{C}}{\text{A}} = \frac{\text{C}}{\text{C/s}} = \text{s} [RC]=Ω⋅F=AV​⋅VC​=AC​=C/sC​=s

确实具有时间的量纲！这个推导本身就揭示了 τ\tauτ 的物理含义：它是电路中电荷重新分布所需的特征时间。

5.2 指数衰减的普适性 ​

RC 电路的指数衰减行为并非巧合，而是大自然中普遍存在的规律——一阶系统的暂态响应总是指数型的。类似的现象包括：

  • 热水冷却到室温（牛顿冷却定律）
  • 放射性元素的衰变
  • 药物在人体内的代谢（一级动力学）
  • 人口的指数增长（马尔萨斯模型）

所有这些现象都来源于同一个数学结构：变化率正比于当前值与终值之差——这正是 RC 电路的微分方程 RCdVCdt=V−VCRC\frac{dV_C}{dt} = V - V_CRCdtdVC​​=V−VC​ 所描述的关系。

5.3 电容在电路中的角色总结 ​

稳态条件电容行为
直流稳态（电压不变）相当于开路——没有电流通过（i=CdVdt=0i = C\frac{dV}{dt} = 0i=CdtdV​=0）
瞬态（刚上电/切换）相当于短路——极板未充/未放完电，容易被推动
交流（正弦波）呈现频率相关的容抗 XC=1ωC=12πfCX_C = \frac{1}{\omega C} = \frac{1}{2\pi fC}XC​=ωC1​=2πfC1​
高频交流容抗小——电容近乎短路（"隔直通交"）
低频交流容抗大——电容近乎开路

5.4 电容的典型应用 ​

  • 电源滤波：滤除电源中的纹波电压，让输出变得平滑稳定
  • 耦合与去耦：传递交流信号同时隔离直流成分
  • 定时电路：与电阻组合利用 RCRCRC 时间常数实现延时（如 555 定时器）
  • 闪光灯/储能焊机：缓慢充电、瞬间放电，释放大功率脉冲
  • 触摸屏/触控按键：利用手指接触改变电容量来检测触摸

6. 本章小结 ​

  • 电容是一种储能元件，通过极板间的电场储存能量。电容的定义为 C=Q/UC = Q/UC=Q/U，单位是法拉（F）。
