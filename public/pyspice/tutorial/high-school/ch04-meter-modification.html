第4章 电表改装 ​

1. 本节你将学到 ​

  • 理解电流表和电压表的测量原理：它们由同一个灵敏表头（检流计）改装而来
  • 掌握电流表改装公式：Rs=IgRgI−IgR_s = \frac{I_g R_g}{I - I_g}Rs​=I−Ig​Ig​Rg​​（并联分流电阻）
  • 掌握电压表改装公式：Rs=UIg−RgR_s = \frac{U}{I_g} - R_gRs​=Ig​U​−Rg​（串联分压电阻）
  • 学会用 Python 计算分流/分压电阻的精确值，并验证改装后的量程

2. 知识回顾/情景引入 ​

在初中物理实验中，你一定用过电流表和电压表。把电流表串联在电路中，就能读出流过的电流值；把电压表并联在元件两端，就能读出元件两端的电压值。

但你有没有想过：电流表和电压表的内部构造是什么样的？为什么同一个"表头"既能测电流又能测电压？

2.1 灵敏表头（检流计） ​

电流表和电压表的核心都是一个灵敏表头——通常是一个磁电式检流计。表头本质上是一个小量程的电流表，它有两个关键参数：

  • 表头内阻 RgR_gRg​：表头线圈自身的内电阻（通常几十到几百欧姆）
  • 满偏电流 IgI_gIg​：表头指针偏转到最大刻度所需的电流（通常微安到毫安级别）

一个典型的表头参数：Rg=100ΩR_g = 100\OmegaRg​=100Ω，Ig=1mAI_g = 1\text{mA}Ig​=1mA。这意味着：

  • 当 1mA1\text{mA}1mA 的电流流过表头时，指针恰好偏转到满刻度
  • 表头两端电压为 IgRg=0.001×100=0.1VI_g R_g = 0.001 \times 100 = 0.1\text{V}Ig​Rg​=0.001×100=0.1V
  • 表头本身就是一个量程 1mA1\text{mA}1mA 的电流表和量程 0.1V0.1\text{V}0.1V 的电压表！

2.2 为什么需要改装 ​

表头的量程太小了——1mA1\text{mA}1mA 的电流和 0.1V0.1\text{V}0.1V 的电压在实际电路中几乎用不上。日常生活中我们需要测量安培级别的电流、伏特级别的电压。

解决方案：给表头"配上"合适的电阻——并联一个分流电阻来扩大量程（改装成电流表），串联一个分压电阻来扩大量程（改装成电压表）。

3. 动手设计电路 ​

3.1 改装电流表：并联分流 ​

目标：用表头（Rg=100ΩR_g = 100\OmegaRg​=100Ω，Ig=1mAI_g = 1\text{mA}Ig​=1mA）改装成一个量程 I=1AI = 1\text{A}I=1A 的电流表。

原理：并联一个分流电阻 RsR_sRs​，使得当总电流为 1A1\text{A}1A 时，表头恰好流过 1mA1\text{mA}1mA，剩余的 0.999A0.999\text{A}0.999A 全部流过 RsR_sRs​。

推导：

并联电路中，电压相等。表头两端电压 Ug=IgRg=0.001×100=0.1VU_g = I_g R_g = 0.001 \times 100 = 0.1\text{V}Ug​=Ig​Rg​=0.001×100=0.1V。分流电阻两端也是 0.1V0.1\text{V}0.1V，流过它的电流 Is=I−Ig=0.999AI_s = I - I_g = 0.999\text{A}Is​=I−Ig​=0.999A。

因此：

Rs=UgIs=IgRgI−IgR_s = \frac{U_g}{I_s} = \frac{I_g R_g}{I - I_g} Rs​=Is​Ug​​=I−Ig​Ig​Rg​​

代入：

Rs=0.001×1001−0.001=0.10.999≈0.1001ΩR_s = \frac{0.001 \times 100}{1 - 0.001} = \frac{0.1}{0.999} \approx 0.1001\Omega Rs​=1−0.0010.001×100​=0.9990.1​≈0.1001Ω

改装后的等效内阻（表头内阻和分流电阻并联）：

RA=Rg⋅RsRg+Rs≈100×0.1001100.1001≈0.100ΩR_{\text{A}} = \frac{R_g \cdot R_s}{R_g + R_s} \approx \frac{100 \times 0.1001}{100.1001} \approx 0.100\Omega RA​=Rg​+Rs​Rg​⋅Rs​​≈100.1001100×0.1001​≈0.100Ω

注意：改装后的电流表内阻非常小（≈0.1Ω\approx 0.1\Omega≈0.1Ω），这样才能在串联测量时尽量不影响原电路。

3.2 改装电压表：串联分压 ​

目标：用同一个表头（Rg=100ΩR_g = 100\OmegaRg​=100Ω，Ig=1mAI_g = 1\text{mA}Ig​=1mA）改装成一个量程 U=10VU = 10\text{V}U=10V 的电压表。

原理：串联一个分压电阻 RsR_sRs​，使得当总电压为 10V10\text{V}10V 时，表头恰好流过 1mA1\text{mA}1mA。

推导：

串联电路中，电流相等。总电压 U=10VU = 10\text{V}U=10V 分配在 RgR_gRg​ 和 RsR_sRs​ 上：U=Ig(Rg+Rs)U = I_g(R_g + R_s)U=Ig​(Rg​+Rs​)。

因此：

Rs=UIg−RgR_s = \frac{U}{I_g} - R_g Rs​=Ig​U​−Rg​

代入：

Rs=100.001−100=10000−100=9900ΩR_s = \frac{10}{0.001} - 100 = 10000 - 100 = 9900\Omega Rs​=0.00110​−100=10000−100=9900Ω

改装后的等效内阻（表头内阻和分压电阻串联）：

RV=Rg+Rs=100+9900=10000Ω=10kΩR_{\text{V}} = R_g + R_s = 100 + 9900 = 10000\Omega = 10\text{k}\Omega RV​=Rg​+Rs​=100+9900=10000Ω=10kΩ

注意：改装后的电压表内阻非常大（10kΩ10\text{k}\Omega10kΩ），这样才能在并联测量时尽量不分走被测电路的电流。

4. 用 Python 计算与验证 ​

4.1 分流/分压电阻计算 ​

以下代码直接计算改装所需的电阻值，并用欧姆定律反向验证改装后的量程是否正确：

python
Rg = 100
Ig = 0.001

# --- 电流表改装 ---
I_total = 1.0
R_shunt = (Ig * Rg) / (I_total - Ig)
print("电流表改装")
print("表头内阻 Rg = {} Ω, 满偏 Ig = {} mA".format(Rg, Ig*1000))
print("目标量程 I = {} A".format(I_total))
print("分流电阻 Rs = {:.4f} Ω".format(R_shunt))

# 验证：总电流 1A 时，表头分到的电流
U_g = I_total * (Rg * R_shunt) / (Rg + R_shunt)
I_g_verify = U_g / Rg
print("验证：表头电流 = {:.4f} A = {:.2f} mA (应为 1.000 mA)".format(I_g_verify, I_g_verify*1000))

# --- 电压表改装 ---
V_total = 10
R_series = V_total / Ig - Rg
print("\n电压表改装")
print("目标量程 V = {} V".format(V_total))
print("分压电阻 Rs = {:.0f} Ω".format(R_series))

# 验证：总电压 10V 时，表头分到的电压
R_total = Rg + R_series
I_v = V_total / R_total
V_g_verify = I_v * Rg
print("验证：表头电压 = {:.3f} V (应为 0.100 V)".format(V_g_verify))

目标量程 I = 1.0 A
分流电阻 Rs = 0.1001 Ω

计算结果精确。电流表改装后的分流电阻仅 0.1Ω0.1\Omega0.1Ω——这么小的值需要使用精密电阻；电压表改装后的分压电阻达到 9.9kΩ9.9\text{k}\Omega9.9kΩ。验证步骤确认：总电流 1A1\text{A}1A 时表头恰好流过 1mA1\text{mA}1mA，总电压 10V10\text{V}10V 时表头两端恰好 0.1V0.1\text{V}0.1V，改装完全成功。

5. 深入理解 ​

5.1 为什么电流表要串联、电压表要并联 ​

这不只是因为"量程匹配"的需要，更是因为 "理想测量"的原则：

  • 电流表串联：如果电流表并联在电路中，它的内阻极小（0.1Ω0.1\Omega0.1Ω），相当于把电路短路——会烧毁表头。串联时，虽然电流表也有内阻，但因为 RAR_{\text{A}}RA​ 远小于通常的负载电阻，它几乎不分走电压，对原电路的影响很小。理想电流表内阻为零（电流流过它时零电压损耗）。
  • 电压表并联：如果电压表串联在电路中，它的内阻极大（10kΩ10\text{k}\Omega10kΩ），会把电路几乎断开——电流极小，电器无法工作。并联时，RV≫R负载R_{\text{V}} \gg R_{\text{负载}}RV​≫R负载​，电压表分走的电流可以忽略不计。理想电压表内阻为无穷大（没有电流流入电压表）。

5.2 多量程电表 ​

实际使用的万用表通常有多个量程档位（如电流有 200μA,2mA,20mA,200mA,10A200\mu\text{A}, 2\text{mA}, 20\text{mA}, 200\text{mA}, 10\text{A}200μA,2mA,20mA,200mA,10A 等）。每个量程对应一个不同的分流电阻，通过旋转选择开关来切换。原理和本章一模一样——只是用了一组分立电阻而不是单个电阻。

5.3 测量误差的来源 ​

任何使用表头的测量都存在两个误差来源：

  1. 表头精度：表头线圈在制造时的误差（标称 Ig=1.000mAI_g = 1.000\text{mA}Ig​=1.000mA，实际可能是 0.998mA0.998\text{mA}0.998mA），导致指针位置偏差。
  2. 改装电阻误差：分流/分压电阻的实际值若偏离理论值，会使量程偏移。精密电阻（误差 ±1%,±0.1%\pm 1\%, \pm 0.1\%±1%,±0.1%）可以大幅减小这个误差。

6. 本章小结 ​

  • **表头（检流计）**是电流表和电压表的共同核心，本质是一个小量程电流计，参数为 RgR_gRg​ 和 IgI_gIg​。
  • 改装电流表：并联小电阻 Rs=IgRgI−IgR_s = \frac{I_g R_g}{I - I_g}Rs​=I−Ig​Ig​Rg​​ 来扩大电流量程。改装后等效内阻很小。
  • 改装电压表：串联大电阻 Rs=UIg−RgR_s = \frac{U}{I_g} - R_gRs​=Ig​U​−Rg​ 来扩大电压量程。改装后等效内阻很大。
  • 电流表必须串联接入电路（内阻极小），电压表必须并联接入电路（内阻极大）。
  • Python 可以精确计算所需的分流/分压电阻，并自动验证量程计算的正确性。
