第2章 恒定电流与电阻定律 ​

1. 本节你将学到 ​

  • 理解恒定电流的条件：导体两端维持恒定电势差，电流的大小和方向不随时间变化
  • 掌握电阻定律 R=ρLSR = \rho\frac{L}{S}R=ρSL​：电阻由材料、长度和横截面积共同决定
  • 认识电阻率 ρ\rhoρ 的物理意义：不同材料对电流阻碍能力的本质差异
  • 学会用 PySpice 参数化构建电路，通过改变电阻值观察对工作点的影响

2. 知识回顾/情景引入 ​

在第 1 章中，我们认识了电场和电势差——电压是驱动电荷流动的根本原因。但不同的导体对电流的"阻碍程度"是不一样的：同样加 10V 的电压，粗铜线的电流非常大，细钨丝的电流却很小。

那么，导体的电阻到底由什么决定？ 为什么有些材料"导电好"、有些材料"导电差"？

2.1 恒定电流 ​

在闭合电路中，如果电源维持的电压不变，电路中就会形成恒定电流（也叫稳恒电流）。恒定电流的特点是：任意时刻通过导体同一截面的电流大小和方向都不变。我们日常使用的干电池供电电路、USB 充电电路，都属于恒定电流的范畴。

恒定电流的存在有一个前提条件：导体内部电场不随时间变化。如果导体两端的电势差稳定不变，导体内部的电场就是稳定的，电荷受到的驱动力就是恒定的——于是电流也就不变。

2.2 电阻定律的发现 ​

1826 年，欧姆在实验中发现：对于同一根金属导线，电阻与导线的长度成正比，与导线的横截面积成反比。这个规律后来被总结为电阻定律：

R=ρLSR = \rho \frac{L}{S} R=ρSL​

其中：

  • RRR：导体的电阻，单位欧姆（Ω\OmegaΩ）
  • ρ\rhoρ：导体材料的电阻率，单位 Ω⋅m\Omega \cdot \text{m}Ω⋅m
  • LLL：导体沿电流方向的长度，单位米（m）
  • SSS：导体垂直于电流方向的横截面积，单位平方米（m2^22）

💡 直觉理解：把电流想象成水流。导线就像一根水管——水管越长（LLL 大），水流遇到的摩擦越多，阻力越大；水管越粗（SSS 大），水流有更多的空间通过，单位时间能流过更多的水，阻力越小。电阻率 ρ\rhoρ 则代表"管壁的粗糙程度"——铜管的壁很光滑（ρ\rhoρ 小），铁管的壁很粗糙（ρ\rhoρ 大）。

2.3 常见材料的电阻率 ​

材料电阻率 ρ\rhoρ (Ω⋅m\Omega\cdot\text{m}Ω⋅m)导电性能
银1.6×10−81.6 \times 10^{-8}1.6×10−8极佳（最良导体）
铜1.7×10−81.7 \times 10^{-8}1.7×10−8良好（导线首选）

铜的电阻率极低（1.7×10−8 Ω⋅m1.7 \times 10^{-8}\ \Omega\cdot\text{m}1.7×10−8 Ω⋅m），所以它被广泛用于电线、电缆和电路板走线。银的电阻率更低，但成本太高，只在特殊场合使用。碳（石墨）的电阻率比铜大了约 2000 倍——这就解释了为什么铅笔芯（主要成分是石墨）导电很差。

3. 动手设计电路 ​

3.1 本节电路与物理模型 ​

我们要用仿真来验证电阻定律：固定电压 10V，构建几个不同参数的电阻，观察电流如何随长度和横截面积变化。

物理模型：假设我们有一根圆柱形铜导线，电阻率 ρ=1.7×10−8 Ω⋅m\rho = 1.7 \times 10^{-8}\ \Omega\cdot\text{m}ρ=1.7×10−8 Ω⋅m。我们构建三根不同的导线：

导线编号长度 LLL (m)半径 rrr (mm)截面积 SSS (m2^22)R=ρL/SR = \rho L / SR=ρL/S (Ω\OmegaΩ)
①1.01.03.14×10−63.14 \times 10^{-6}3.14×10−60.0054
②2.01.03.14×10−63.14 \times 10^{-6}3.14×10−60.0108
③1.00.57.85×10−77.85 \times 10^{-7}7.85×10−70.0216
  • 导线 ① 与 ② 对比：截面积相同，② 的长度是 ① 的 2 倍 → 电阻增大为 2 倍（R∝LR \propto LR∝L）
  • 导线 ① 与 ③ 对比：长度相同，③ 的半径是 ① 的一半 → 截面积是 ① 的 1/4 → 电阻增大为 4 倍（R∝1/SR \propto 1/SR∝1/S）

电路连接方式：10V 电源正端 → 不同阻值的电阻 → 地（节点 0）。

3.2 公式推导 ​

根据欧姆定律，对于每一根导线：

I=VR=VρL/S=VSρLI = \frac{V}{R} = \frac{V}{\rho L/S} = \frac{VS}{\rho L} I=RV​=ρL/SV​=ρLVS​

所以电流 I∝SLI \propto \frac{S}{L}I∝LS​——截面积越大、长度越短，电流越大；截面积越小、长度越长，电流越小。

代入数值计算：

  • ① 号导线：I=10/0.0054≈1850AI = 10 / 0.0054 \approx 1850\text{A}I=10/0.0054≈1850A
  • ② 号导线：I=10/0.0108≈926AI = 10 / 0.0108 \approx 926\text{A}I=10/0.0108≈926A
  • ③ 号导线：I=10/0.0216≈463AI = 10 / 0.0216 \approx 463\text{A}I=10/0.0216≈463A

注意：这些电流值非常大，因为 0.005Ω0.005\Omega0.005Ω 级别的电阻几乎是短路的。在实际仿真中，我们将使用欧姆级别的电阻值（通过调整长度或选用电阻率更高的材料），但这不影响验证原理——比例关系保持不变。

4. 用 Python 实现电路仿真 ​

4.1 参数化电路构建 ​

我们定义三种不同的电阻值（对应上述三种导线的相对比例），在 10V 电源下分别计算工作点，对比电流变化：

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

# 定义三组电阻值（模拟不同长度和截面积的比例关系）
rho = 1.7e-8
lengths = [10, 20, 10]       # 长度扩大，方便获得 Ω 级电阻
areas   = [3.14e-6, 3.14e-6, 7.85e-7]
resistances = [rho * L / S for L, S in zip(lengths, areas)]

在实际仿真中，我们直接使用比例关系验证，不必拘泥于真实铜线的微小电阻值。我们用几个有代表性的电阻值（如 5Ω5\Omega5Ω、10Ω10\Omega10Ω、20Ω20\Omega20Ω）来展示比例关系，因为这和电阻定律的比例逻辑完全一致。

4.2 对每个电阻值进行工作点仿真 ​

python
for R_val in [5, 10, 20]:
    circuit = Circuit('Resistance Law R={}'.format(R_val))
    circuit.V('source', 1, circuit.gnd, 10@u_V)
    circuit.R('load', 1, circuit.gnd, R_val@u_Ω)

    simulator = circuit.simulator(temperature=25, nominal_temperature=25,
                                  simulator='ngspice-subprocess')
    analysis = simulator.operating_point()

    voltage = float(analysis.nodes['1'][0])
    current = voltage / R_val
    print("R = {} Ω | V = {:.2f} V | I = {:.3f} A".format(R_val, voltage, current))

5. 深入理解 ​

5.1 电阻定律的微观解释 ​

为什么 R∝LR \propto LR∝L 而 R∝1/SR \propto 1/SR∝1/S？这可以从电子在导体中的漂移运动来理解。

导体中的自由电子在电场驱动下沿导线方向运动，沿途不断与金属晶格中的原子发生碰撞。导线越长，电子需要经历更多的碰撞 → 损失更多的能量 → 等效于更大的电阻。导线截面积越大，同一截面上可以容纳更多电子同时通过 → 单位时间通过的电子总数更多 → 同样的电压下电流更大 → 等效于电阻更小。

5.2 电阻率与温度的关系 ​

电阻率 ρ\rhoρ 并不是一个绝对常数，它会随温度变化。对于大多数金属导体：

ρt=ρ0[1+α(t−t0)]\rho_t = \rho_0 [1 + \alpha (t - t_0)] ρt​=ρ0​[1+α(t−t0​)]

其中 α\alphaα 是电阻温度系数（铜的 α≈0.0039/∘C\alpha \approx 0.0039/^\circ\text{C}α≈0.0039/∘C）。温度每升高 1∘C1^\circ\text{C}1∘C，铜的电阻率大约增加 0.39%0.39\%0.39%。

这也解释了为什么灯泡（白炽灯）在刚开启的瞬间最容易烧坏——冷态时灯丝电阻小，通电瞬间电流很大，热冲击容易使灯丝断裂。

5.3 超导现象 ​

1911 年，荷兰物理学家昂内斯发现：当水银的温度降到 4.2K4.2\text{K}4.2K（约 −269∘C-269^\circ\text{C}−269∘C）时，其电阻突然消失——这就是超导现象。超导体的电阻率为零，电流一旦建立就不需要电压来维持，理论上可以永远循环下去。

超导现象的根本原因是：在极低温度下，电子两两配对形成"库珀对"，可以在晶格中无阻碍地运动，不再发生碰撞——因此没有能量损耗，电阻为零。超导技术目前被用于 MRI 磁共振成像、粒子加速器、磁悬浮列车等领域。

6. 本章小结 ​

  • 电阻定律 R=ρLSR = \rho \frac{L}{S}R=ρSL​：电阻由材料的电阻率 ρ\rhoρ、导体长度 LLL 和横截面积 SSS 共同决定。
  • 长度越长、截面积越小，电阻越大——R∝LR \propto LR∝L（正比），R∝1/SR \propto 1/SR∝1/S（反比）。
  • 电阻率 ρ\rhoρ 是材料的本征属性：铜的电阻率极低（1.7×10−8 Ω⋅m1.7 \times 10^{-8}\ \Omega\cdot\text{m}1.7×10−8 Ω⋅m），是优良导体；碳的电阻率高出千倍以上。
  • 电阻率随温度变化（大多数金属升温电阻增大），极端低温下可能发生超导（电阻消失）。
  • PySpice 可以通过参数化循环构建多个电路，批量对比不同电阻值下的 DC 工作点，高效验证电阻定律。
