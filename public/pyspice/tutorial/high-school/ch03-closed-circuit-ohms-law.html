第3章 闭合电路欧姆定律 ​

1. 本节你将学到 ​

  • 理解电源电动势 EEE 与路端电压 UUU 的区别：EEE 是电源的"总推力"，UUU 是实际输出的电压
  • 掌握内阻 rrr 的概念：任何实际电源内部都有电阻，它不是理想的
  • 学会闭合电路欧姆定律 I=ER+rI = \frac{E}{R+r}I=R+rE​ 及其变形 U=E−IrU = E - IrU=E−Ir
  • 用 PySpice 仿真电源内阻对负载电压的影响，理解负载匹配的概念

2. 知识回顾/情景引入 ​

在前面几章中，我们一直把电池当作"完美电源"——它能输出铭牌上标的电压、能提供任意大小的电流而自身电压永远不变。

但现实中没有任何电源是完美的。你有没有注意过这样的现象：当手机只剩 5% 的电量时，屏幕亮度会明显变暗？当你同时给手机充电、开着热点、打着游戏时，充电速度会特别慢？

这些现象的背后，都指向同一个概念：电源自身也有内阻。

2.1 电动势 vs 路端电压 ​

电动势 EEE（Electromotive force, EMF）是电源内部的非静电力（如电池中的化学反应、发电机中的电磁感应）将单位正电荷从负极搬运到正极所做的功：

E=W非qE = \frac{W_{\text{非}}}{q} E=qW非​​

注意：电动势虽然叫"势"，单位也是伏特（V），但它和上一章的"电势"是不同的物理量。电势是静电场的性质，电动势是非静电力的做功本领。

路端电压 UUU 是电源正负极两端的实际电压值——也就是你用电压表在电池正负极之间测到的值。在电路没有接通时（开路），路端电压等于电动势 U=EU = EU=E。一旦电路接通，电流开始流动，内阻分走了一部分电压，路端电压就会小于电动势：U<EU < EU<E。

2.2 内阻的来源 ​

任何实际电源都有内阻 rrr。以干电池为例：

  • 电池内部的电解液有电阻
  • 电极与电解液的接触面有接触电阻
  • 电极材料本身也有体电阻

内阻的大小因电源类型而异：普通干电池内阻大约 0.1Ω∼2Ω0.1\Omega \sim 2\Omega0.1Ω∼2Ω，纽扣电池内阻可达几十欧，汽车蓄电池（铅酸电池）内阻仅有几毫欧（所以能输出巨大的启动电流）。

2.3 闭合电路欧姆定律 ​

把电源的电动势 EEE、内阻 rrr 和外电路的负载电阻 RRR 一起考虑，就得到了闭合电路欧姆定律：

I=ER+rI = \frac{E}{R + r} I=R+rE​

这个公式可以改写为：

E=IR+IrE = IR + Ir E=IR+Ir

其中 IRIRIR 是负载电阻两端的电压（即路端电压 UUU），IrIrIr 是内阻两端的电压（即"内部分压"）。于是：

U=E−IrU = E - Ir U=E−Ir

这个公式揭示了一个重要的规律：路端电压随电流的增大而减小。当电流为零（开路）时，U=EU = EU=E；当电流最大（短路，R=0R=0R=0）时，I=E/rI = E/rI=E/r，路端电压 U=0U = 0U=0——整个电动势全部降在内阻上。

3. 动手设计电路 ​

3.1 本节电路 ​

我们的电路模型如下：电动势 E=12VE = 12\text{V}E=12V 的电源，内阻 r=1Ωr = 1\Omegar=1Ω 串联在正极后面，外部负载电阻 R=10ΩR = 10\OmegaR=10Ω。两个电阻实际上是串联关系，总电阻 R总=r+R=11ΩR_{\text{总}} = r + R = 11\OmegaR总​=r+R=11Ω。

电路拓扑：电源正端（节点 1）→ 内阻 rrr（节点 1 到节点 2）→ 负载电阻 RRR（节点 2 到地）。

3.2 公式推导与手算 ​

规律非常清楚：负载 RRR 越小，电流越大，内阻分走的电压就越多，路端电压就越低。当 R=rR = rR=r（负载电阻等于内阻）时，路端电压恰好等于电动势的一半（6V）——此时负载获得的功率是最大的（最大功率传输定理）。

4. 用 Python 实现电路仿真 ​

4.1 构建电路并运行工作点分析 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

circuit = Circuit('Closed Circuit Ohm Law')
circuit.V('source', 1, circuit.gnd, 12@u_V)
circuit.R('internal', 1, 2, 1@u_Ω)  # 内阻 1Ω
circuit.R('load', 2, circuit.gnd, 10@u_Ω)  # 负载 10Ω

simulator = circuit.simulator(temperature=25, nominal_temperature=25,
                              simulator='ngspice-subprocess')
analysis = simulator.operating_point()

代码解释：

  • 电压源 V('source', 1, circuit.gnd, 12@u_V)：这是理想电压源（电动势 EEE），不包含内阻。内阻是单独放在电路中的——这忠实地反映了"实际电源 = 理想电源 + 串联内阻"的物理模型。
  • circuit.R('internal', 1, 2, 1@u_Ω)：内阻连接在节点 1（电源正端）和节点 2（内阻输出端）之间。
  • circuit.R('load', 2, circuit.gnd, 10@u_Ω)：负载电阻连接在节点 2 和地之间。
  • .operating_point() 计算各节点电压，节点 2 的电压即为路端电压。

4.2 负载扫描：观察路端电压变化 ​

为了观察 RRR 变化对 UUU 的影响，我们对多个负载值做工作点分析：

python
E = 12.0
r = 1.0
R_values = [0.5, 1, 2, 5, 10, 20, 50, 100]
print("负载扫描：E = {} V, r = {} Ω".format(E, r))
print()
print("R(Ω)    I(A)      U(V)     U_theory(V)")
print("-" * 45)

for R_val in R_values:
    circuit = Circuit('Sweep R={}'.format(R_val))
    circuit.V('source', 1, circuit.gnd, E@u_V)
    circuit.R('internal', 1, 2, r@u_Ω)
    circuit.R('load', 2, circuit.gnd, R_val@u_Ω)

    sim = circuit.simulator(temperature=25, nominal_temperature=25,
                            simulator='ngspice-subprocess')
    an = sim.operating_point()

    U_sim = float(an.nodes['2'][0])
    I_calc = U_sim / R_val
    U_theory = E * R_val / (R_val + r)
    print("{:6.1f}   {:6.3f}   {:6.3f}   {:6.3f}".format(R_val, I_calc, U_sim, U_theory))

这段代码展示了 PySpice 的一个常见用法：在同一分析中反复构建电路、运行仿真、对比理论值。每一次循环构建一个带有不同负载电阻的新电路，然后用 .operating_point() 计算节点 2 的电压。

5. 深入理解 ​

5.1 为什么电池用久了电压会降低 ​

新的干电池内阻大约是 0.1Ω∼0.5Ω0.1\Omega \sim 0.5\Omega0.1Ω∼0.5Ω，用久之后，电池内部的化学物质被消耗，电极表面沉积了反应产物，电解液浓度降低——这些都会导致内阻增大。内阻 rrr 增大 → 同样的负载 RRR 下，路端电压 U=E⋅R/(R+r)U = E \cdot R/(R + r)U=E⋅R/(R+r) 减小 → 电器得不到足够的电压 → 表现异常或无法工作。

当你把"没电"的电池取出来用万用表（电压表）量一下，可能会发现它还有 1.4V 左右（开路时 U=EU = EU=E），但一接上负载，电压就暴跌到 1.0V 以下——这就是内阻过大的典型症状。老电池不是"没电了"，而是"内阻太大了"，无法输出足够的功率。

5.2 负载匹配与最大功率传输 ​

在负载扫描中可以发现：当 R=r=1ΩR = r = 1\OmegaR=r=1Ω 时，负载获得的功率为 P=IU=6×6=36WP = IU = 6 \times 6 = 36\text{W}P=IU=6×6=36W；而当 R=0.5ΩR = 0.5\OmegaR=0.5Ω 时，P=8×4=32WP = 8 \times 4 = 32\text{W}P=8×4=32W；当 R=2ΩR = 2\OmegaR=2Ω 时，P=4×8=32WP = 4 \times 8 = 32\text{W}P=4×8=32W。负载功率在 R=rR = rR=r 时达到最大值——这就是最大功率传输定理。

在电子电路设计中（如功放匹配音箱），往往追求 R=rR = rR=r 以获得最大功率输出。但在电力系统中，内阻（线路电阻）远小于负载，效率接近 100%——因为电力的目标是高效传输能量，而不是最大化某一级的功率。

5.3 短路电流 ​

当负载 R=0R = 0R=0（用导线直接将电源正负极连通）时：

I短路=ErI_{\text{短路}} = \frac{E}{r} I短路​=rE​

如果电源内阻很小（如铅酸电池 r≈0.005Ωr \approx 0.005\Omegar≈0.005Ω，E=12VE = 12\text{V}E=12V），短路电流可达 2400A2400\text{A}2400A！这么巨大的电流会在极短时间内使导线和电池剧烈发热——这就是短路极其危险的原因（详见初中篇第 6 章焦耳定律与安全用电）。

6. 本章小结 ​

  • 电动势 EEE 是电源内部非静电力驱动电荷的能力，路端电压 UUU 是电源外部实际可用的电压。开路时 U=EU = EU=E，有负载时 U<EU < EU<E。
  • 闭合电路欧姆定律：I=ER+rI = \frac{E}{R + r}I=R+rE​，其中 rrr 是电源内阻。
  • 路端电压公式：U=E−IrU = E - IrU=E−Ir——电流越大，内阻分压越大，路端电压越小。
  • 当负载电阻等于内阻（R=rR = rR=r）时，负载获得最大功率；当 R≫rR \gg rR≫r 时，效率接近 100%。
  • PySpice 中通过串联电阻来建模电源内阻，通过 operating_point() 计算各节点电压即可获得路端电压。
