2. 知识回顾/情景引入 ​

2.1 让电路"感知"世界 ​

前面十章的电路有一个共同特点：它们都被动地执行我们预先设计好的功能。电阻值是固定的，电压是已知的，电容和电感的值是我们直接给定的。但在现实世界中，电路通常需要对外界的变化做出主动反应。

想象一个简单的场景：夜晚来临，路灯自动亮起；天亮后，路灯自动熄灭。这个自动化的背后，是什么元件让电路"知道"了白天与黑夜的区别？答案是光敏电阻（Light Dependent Resistor, LDR）——一种电阻值随光照强度而变化的传感器。

再比如：空调设定为当室温升到 26∘C26^\circ\text{C}26∘C 时就启动压缩机制冷。让空调"知道"室温的元件是热敏电阻（Thermistor）——电阻值随温度变化。又比如：智能手机屏幕能感应手指的触摸（电容式触摸传感器），汽车安全气囊能在碰撞瞬间感应到巨大的减速度（加速度传感器/MEMS 传感器），楼道声控灯能感应到脚步声（麦克风/声音传感器）。

所有这些应用的共同基础是——传感器（Sensor）：一种将非电物理量（光、热、力、声、位置等）转换为电信号的装置。传感器是电子系统与物理世界之间的接口，没有传感器，所有智能设备都将是"盲人"和"聋子"。

2.2 传感器的电学本质 ​

从电路分析的角度来看，最基础的传感器可以看作一个可变电阻。当外部物理量（光照、温度、压力等）发生变化时，传感器的电阻值随之改变。传感器阻值的变化通过分压电路转换为电压的变化——而电压是任何电子系统都能轻松处理的标准信号。

传感器类型感应物理量阻值变化趋势典型应用
光敏电阻（LDR、CdS）光照光越强 → 电阻越小自动路灯、照度计、火焰报警器
热敏电阻（NTC）温度温度越高 → 电阻越小体温计、空调温控、CPU 过热保护
热敏电阻（PTC）温度温度越高 → 电阻越大过流保护、消磁电路、恒温加热器
应变片（Strain Gauge）形变/力拉伸 → 电阻增大电子秤、桥梁应力监测
湿敏电阻湿度湿度越高 → 电阻越小气象站、加湿器控制、粮仓监控

2.3 为什么使用分压电路 ​

传感器改变的是自己的电阻值，但我们真正需要的是电压信号（因为单片机/ADC 的输入是电压）。这需要一个转换电路——最经典最简单的就是电阻分压电路（Voltage Divider）。

将传感器的可变电阻 RsensorR_{\text{sensor}}Rsensor​ 与一个固定的参考电阻 RrefR_{\text{ref}}Rref​ 串联，接上供电电压 VccV_{cc}Vcc​。输出电压从两者的串联节点引出：

Vout=Vcc×RsensorRref+RsensorV_{\text{out}} = V_{cc} \times \frac{R_{\text{sensor}}}{R_{\text{ref}} + R_{\text{sensor}}} Vout​=Vcc​×Rref​+Rsensor​Rsensor​​

这个公式告诉我们：当传感器阻值 RsensorR_{\text{sensor}}Rsensor​ 变化时，VoutV_{\text{out}}Vout​ 也会跟着变化。例如对于光敏电阻：

  • 光照强（白天）：RsensorR_{\text{sensor}}Rsensor​ 很小 → VoutV_{\text{out}}Vout​ 很小（接近 0V）→ 灯的开关检测到低电压，关灯
  • 光照弱（黑夜）：RsensorR_{\text{sensor}}Rsensor​ 很大 → VoutV_{\text{out}}Vout​ 很大（接近 VccV_{cc}Vcc​）→ 灯的开关检测到高电压，开灯

参考电阻 RrefR_{\text{ref}}Rref​ 的选取很关键——它决定了分压曲线的灵敏度和工作范围。一般选择 RrefR_{\text{ref}}Rref​ 的大小接近传感器工作范围内的中间阻值，以获得最大的灵敏度。

3. 动手设计电路 ​

3.1 本节电路：传感器分压电路 ​

电路构成：

  • 直流电源 Vcc=5VV_{cc} = 5\text{V}Vcc​=5V（常见单片机系统供电电压——如 Arduino 开发板）
  • 参考电阻 Rref=10kΩR_{\text{ref}} = 10\text{k}\OmegaRref​=10kΩ（固定）
  • 传感器等效电阻 RsensorR_{\text{sensor}}Rsensor​（可变，模拟不同物理条件下的传感器阻值）

两个电阻串联：电源正端（节点 1）→ RrefR_{\text{ref}}Rref​（节点 1 → 节点 2）→ RsensorR_{\text{sensor}}Rsensor​（节点 2 → 地）。输出电压 VoutV_{\text{out}}Vout​ 从节点 2 引出——即 RsensorR_{\text{sensor}}Rsensor​ 两端的电压。

3.2 电路分析 ​

分压公式：

Vout=Vcc×Rsensor10kΩ+RsensorV_{\text{out}} = V_{cc} \times \frac{R_{\text{sensor}}}{10\text{k}\Omega + R_{\text{sensor}}} Vout​=Vcc​×10kΩ+Rsensor​Rsensor​​

当 RsensorR_{\text{sensor}}Rsensor​ 从极小变化到极大时：

  • Rsensor→0R_{\text{sensor}} \to 0Rsensor​→0（传感器近似短路）：Vout→0VV_{\text{out}} \to 0\text{V}Vout​→0V
  • Rsensor=Rref=10kΩR_{\text{sensor}} = R_{\text{ref}} = 10\text{k}\OmegaRsensor​=Rref​=10kΩ（传感器阻值等于参考电阻）：Vout=Vcc/2=2.5VV_{\text{out}} = V_{cc}/2 = 2.5\text{V}Vout​=Vcc​/2=2.5V——这是平衡点，也是线性度最好的工作区间
  • Rsensor≫RrefR_{\text{sensor}} \gg R_{\text{ref}}Rsensor​≫Rref​（传感器近似开路）：Vout→Vcc=5VV_{\text{out}} \to V_{cc} = 5\text{V}Vout​→Vcc​=5V

3.3 典型的传感器阻值范围 ​

以常见的光敏电阻（CdS LDR）为例：

  • 强光照射下（白天太阳直射）：R≈1∼5 kΩR \approx 1 \sim 5\,\text{k}\OmegaR≈1∼5kΩ
  • 室内灯光下（一般环境光）：R≈10∼20 kΩR \approx 10 \sim 20\,\text{k}\OmegaR≈10∼20kΩ
  • 昏暗环境下（傍晚）：R≈50∼100 kΩR \approx 50 \sim 100\,\text{k}\OmegaR≈50∼100kΩ
  • 完全黑暗下：R≈1 MΩR \approx 1\,\text{M}\OmegaR≈1MΩ 以上

配合 Rref=10kΩR_{\text{ref}} = 10\text{k}\OmegaRref​=10kΩ 的分压电路，白天输出电压约 5×5/(10+5)≈1.67V5 \times 5 / (10 + 5) \approx 1.67\text{V}5×5/(10+5)≈1.67V，黑夜输出电压接近 5V5\text{V}5V——电压变化范围约 3.3V3.3\text{V}3.3V，足够单片机 ADC 可靠分辨。

4. 用 Python 实现电路仿真 ​

4.1 构建分压电路 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

circuit = Circuit('Sensor Voltage Divider')
circuit.V('input', 1, circuit.gnd, 5@u_V)
circuit.R('ref', 1, 2, 10@u_kΩ)
circuit.R('sensor', 2, circuit.gnd, 10@u_kΩ)

simulator = circuit.simulator(temperature=25, nominal_temperature=25,
                              simulator='ngspice-subprocess')
analysis = simulator.operating_point()

v_out = float(np.array(analysis['2']).flat[0])

代码解释：

  • 电路是经典的分压电路：R('ref', 1, 2, 10@u_kΩ)（参考电阻连接节点 1 → 节点 2），R('sensor', 2, circuit.gnd, 10@u_kΩ)（传感器电阻连接节点 2 → 地）。
  • 这里给 RsensorR_{\text{sensor}}Rsensor​ 设了一个初始值 10kΩ10\text{k}\Omega10kΩ（等于 RrefR_{\text{ref}}Rref​，平衡状态），然后通过 Python 循环手动计算不同 RsensorR_{\text{sensor}}Rsensor​ 值对应的输出电压——这相当于一个参数扫描（Parameter Sweep），比 SPICE 内部的 .dc() 扫描在此场景下更灵活。

4.2 手动参数扫描与分析 ​

由于 PySpice / ngspice 的 .dc() 扫描主要设计用于扫描电压源或电流源（不直接支持电阻扫描），我们改为在 Python 层面进行数值计算——直接使用分压公式对各阻值计算 VoutV_{\text{out}}Vout​。这等于用 Python 做"Mathematical Simulation"：

python
print("传感器分压电路分析")
print("参考电阻 R_ref = 10 kΩ, Vcc = 5V")
print("平衡时输出电压 V_out = {:.3f} V".format(v_out))
print()
print("输出电压 Vout = Vcc * R_sensor/(R_ref + R_sensor)")
print()
print("R_sensor(kΩ)    V_out(V)    说明")
print("-" * 50)
sensor_values = [1, 5, 10, 20, 50, 100]
for rs in sensor_values:
    vout = 5 * rs / (10 + rs)
    desc = ""
    if rs < 10:
        desc = "(光敏电阻—光照强)"
    elif rs > 10:
        desc = "(光敏电阻—光照弱)"
    else:
        desc = "(平衡)"
    print("{:8.1f}         {:6.3f}      {}".format(rs, vout, desc))

5. 深入理解 ​

5.1 分压电路灵敏度优化 ​

分压电路在传感器阻值等于参考电阻（Rsensor=RrefR_{\text{sensor}} = R_{\text{ref}}Rsensor​=Rref​）附近具有最好的灵敏度（即 dVout/dRsensordV_{\text{out}}/dR_{\text{sensor}}dVout​/dRsensor​ 最大）。

灵敏度公式为：

dVoutdRsensor=Vcc×Rref(Rref+Rsensor)2\frac{dV_{\text{out}}}{dR_{\text{sensor}}} = V_{cc} \times \frac{R_{\text{ref}}}{(R_{\text{ref}} + R_{\text{sensor}})^2} dRsensor​dVout​​=Vcc​×(Rref​+Rsensor​)2Rref​​

当 Rsensor=RrefR_{\text{sensor}} = R_{\text{ref}}Rsensor​=Rref​ 时，灵敏度达到最大值：

(dVoutdRsensor)max⁡=Vcc4Rref\left(\frac{dV_{\text{out}}}{dR_{\text{sensor}}}\right)_{\max} = \frac{V_{cc}}{4R_{\text{ref}}} (dRsensor​dVout​​)max​=4Rref​Vcc​​

这告诉我们一条重要的设计原则：参考电阻 RrefR_{\text{ref}}Rref​ 应选择在传感器目标工作阻值范围的中间附近，以最大化电路的检测灵敏度。

5.2 惠斯通电桥——更精密的测量方案 ​

简单的二电阻分压电路虽然简洁，但有一个缺点：输出电压中的直流偏置（即 Vcc/2V_{cc}/2Vcc​/2 附近的背景电压）会随电源电压波动而漂移，降低测量精度。

更精密的传感器测量电路使用惠斯通电桥（Wheatstone Bridge）——由四个电阻组成的桥式电路。当 R1/R2=R3/R4R_1/R_2 = R_3/R_4R1​/R2​=R3​/R4​ 时，电桥平衡，输出电压为零。一旦某个桥臂的电阻（传感器）发生变化，平衡被打破，电桥输出一个仅反映电阻变化的差分电压——对电源噪声和温度漂移具有天然的抗干扰能力。大部分精密仪器（如电子秤、应变测量仪）都使用惠斯通电桥方案。

5.3 从传感器到智能系统 ​

一个完整的传感器系统通常包含以下几个环节：

传感器 → 信号调理（分压/电桥/放大/滤波） → ADC 模数转换 → 微控制器/处理器（分析/判断） → 执行器（电机/蜂鸣器/继电器等）。

例如智能路灯的完整信号链路：

  1. 光敏电阻感应光照 → 电阻值变化
  2. 分压电路转换为电压变化
  3. 微控制器的 ADC 读取电压值（每次采集约 10μs10\mu\text{s}10μs）
  4. 微控制器比较电压与预设的"天黑阈值"（如 3V3\text{V}3V）
  5. 若电压 > 阈值 → GPIO 引脚输出高电平 → 驱动继电器吸合 → 路灯通电亮起
  6. 若电压 < 阈值 → GPIO 输出低电平 → 继电器断开 → 路灯熄灭

整个过程每秒可能重复成百上千次，但原理核心仍是本节所学的分压电路电压公式。

5.4 物联网时代中的传感器 ​

在 2024 年的今天，传感器已经渗透到日常生活的方方面面：

  • 智能手机中集成了数十个传感器：加速度计、陀螺仪、磁力计、气压计、接近传感器、环境光传感器、指纹传感器、面部识别传感器……
  • 智能家居：温湿度传感器、人体红外传感器（PIR）、烟雾传感器、门窗磁传感器、水浸传感器 —— 通过 Zigbee/WiFi 联网上报到家庭中枢
  • 汽车：一辆现代汽车搭载超过 100 个传感器——从胎压监测到倒车雷达，从车道保持摄像头到激光雷达（LiDAR，用于自动驾驶）
  • 工业物联网：振动传感器监测电机轴承状态（预测维护），压力传感器监测管道泄漏，流量计跟踪原料消耗——所有这些构成了"工业 4.0"的数据基础

无论传感器系统的复杂度如何增长，其核心始终是：将物理量转化为电阻/电容/电感的变化，再由电路转化为电压/电流的变化——这与本节所学的分压电路原理一脉相承。

6. 本章小结 ​

  • 传感器是连接物理世界与电子系统的桥梁，将光、热、力、声等非电物理量转换为可处理的电信号。
  • 最基础的传感器可视为一种可变电阻——其电阻值随被测量（光照、温度等）而变化。
  • 分压电路是传感器信号调理的最基本方案：Vout=Vcc×RsensorRref+RsensorV_{\text{out}} = V_{cc} \times \frac{R_{\text{sensor}}}{R_{\text{ref}} + R_{\text{sensor}}}Vout​=Vcc​×Rref​+Rsensor​Rsensor​​。
  • 参考电阻 RrefR_{\text{ref}}Rref​ 的选取影响分压电路在目标阻值范围内的灵敏度和动态范围。
  • 分压电路在 Rsensor=RrefR_{\text{sensor}} = R_{\text{ref}}Rsensor​=Rref​ 时灵敏度最大，输出电压为 Vcc/2V_{cc}/2Vcc​/2——此即最优设计点。
  • 通过 PySpice 直流工作点分析结合 Python 数值扫描，可以研究传感器电阻变化对输出电压的影响，为实际电路设计提供依据。
