第9章 变压器 ​

1. 本节你将学到 ​

  • 理解变压器的工作原理——基于法拉第电磁感应定律
  • 掌握变压器的匝数比关系：U1U2=N1N2\frac{U_1}{U_2} = \frac{N_1}{N_2}U2​U1​​=N2​N1​​ 和 I1I2=N2N1\frac{I_1}{I_2} = \frac{N_2}{N_1}I2​I1​​=N1​N2​​
  • 了解耦合电感的概念及耦合系数 kkk 的物理含义
  • 认识感抗：L∝N2L \propto N^2L∝N2——电感值与匝数的平方成正比
  • 学会用 PySpice 的耦合电感元件 K 和 .ac() 分析验证变压器电压比

2. 知识回顾/情景引入 ​

2.1 电能的远距离运输难题 ​

假设你要把一座水电站发出的电力输送到 500 公里外的城市。你面临一个两难选择：

  • 用低压输电（如 220V）：电流大（I=P/UI = P/UI=P/U），线路损耗大（Ploss=I2RP_{\text{loss}} = I^2RPloss​=I2R），大量电能浪费在导线发热上。
  • 用高压输电（如 500kV）：电流小，损耗小——但发电机发不出这么高的电压，而且 500kV 直接入户极其危险。

解决这一矛盾的神奇装置就是变压器（Transformer）。它能在发电端把电压"升"上去（升压变压器），在用电端把电压"降"下来（降压变压器）。从发电到用电，电力每经过一次变压器就改变一次电压等级，全程保持高电压低电流传输以最小化损耗。

2.2 变压器的基本结构 ​

变压器由三个核心部分组成：

  1. 铁芯（Iron Core）：由硅钢片叠压而成，提供低磁阻的磁路，引导磁通线。
  2. 初级线圈（Primary Winding）：匝数 N1N_1N1​，接输入电压（一次侧）。
  3. 次级线圈（Secondary Winding）：匝数 N2N_2N2​，接负载（二次侧）。

本质上，变压器是两个没有电气连接（在理想变压器中，初次级是绝缘的）但通过磁场紧密耦合的电感线圈。交流电在初级产生变化的磁通，这个变化的磁通穿过次级，在次级中感应出电压——整个过程纯粹基于法拉第电磁感应定律。

2.3 理想变压器的电压比推导 ​

设初级交流电压为 u1(t)u_1(t)u1​(t)，产生的磁通为 Φ(t)\Phi(t)Φ(t)。由于铁芯的导磁性能良好，几乎所有的磁通都穿过次级线圈（即无漏磁的理想情况）。

由法拉第定律，初级自感电动势为：

E1=−N1dΦdt\mathcal{E}_1 = -N_1 \frac{d\Phi}{dt} E1​=−N1​dtdΦ​

忽略初级线圈的电阻（理想情况），外加电压 u1u_1u1​ 与自感电动势平衡：u1≈−E1≈N1dΦdtu_1 \approx -\mathcal{E}_1 \approx N_1\frac{d\Phi}{dt}u1​≈−E1​≈N1​dtdΦ​。

同一变化磁通 Φ(t)\Phi(t)Φ(t) 在次级中感应的电动势为：

E2=−N2dΦdt\mathcal{E}_2 = -N_2 \frac{d\Phi}{dt} E2​=−N2​dtdΦ​

因此次级开路电压 u2u_2u2​（空载电压）为：

u2≈−E2≈N2dΦdtu_2 \approx -\mathcal{E}_2 \approx N_2\frac{d\Phi}{dt} u2​≈−E2​≈N2​dtdΦ​

两式相除，得理想变压器的电压比公式：

U1U2=N1N2\frac{U_1}{U_2} = \frac{N_1}{N_2} U2​U1​​=N2​N1​​

其中 U1U_1U1​、U2U_2U2​ 通常取有效值（或峰值之比）。

2.4 功率守恒与电流比 ​

理想变压器没有内部损耗，因此输入功率等于输出功率：

U1I1=U2I2U_1 I_1 = U_2 I_2 U1​I1​=U2​I2​

结合电压比公式 U1U2=N1N2\frac{U_1}{U_2} = \frac{N_1}{N_2}U2​U1​​=N2​N1​​，立即得出电流比：

I1I2=N2N1\frac{I_1}{I_2} = \frac{N_2}{N_1} I2​I1​​=N1​N2​​

关键结论：电压与匝数成正比，电流与匝数成反比。升压变压器（N2>N1N_2 > N_1N2​>N1​）升压的同时降流；降压变压器（N1>N2N_1 > N_2N1​>N2​）降压的同时升流——两者乘积（功率）在理想情况下不变。

2.5 电感与匝数的关系 ​

对于相同铁芯、相同几何结构的绕组，电感值 LLL 与匝数 NNN 的平方成正比：

L∝N2L \propto N^2 L∝N2

这是因为磁通Φ∝NI\Phi \propto N IΦ∝NI（匝数越多，同样的电流产生越多的磁通），而电感 L=NΦI∝N2L = \frac{N\Phi}{I} \propto N^2L=INΦ​∝N2。

因此，如果我们用两个耦合的电感来模拟变压器，且它们的电感比满足 L1:L2=N12:N22L_1 : L_2 = N_1^2 : N_2^2L1​:L2​=N12​:N22​，对应的匝数比即为 N1N2=L1L2\frac{N_1}{N_2} = \sqrt{\frac{L_1}{L_2}}N2​N1​​=L2​L1​​​。

3. 动手设计电路 ​

3.1 本节电路：耦合电感模拟变压器 ​

电路构成：

  • 正弦交流电压源：振幅 10V10\text{V}10V，频率 50Hz50\text{Hz}50Hz（接初级）
  • 串联电阻 Rsrc=1ΩR_{\text{src}} = 1\OmegaRsrc​=1Ω（避免直接驱动感性负载导致仿真问题）
  • 初级电感 L1=100mHL_1 = 100\text{mH}L1​=100mH（代表 N1=100N_1 = 100N1​=100 匝）
  • 次级电感 L2=25mHL_2 = 25\text{mH}L2​=25mH（代表 N2=50N_2 = 50N2​=50 匝）
  • 耦合系数 K=0.99K = 0.99K=0.99（接近理想耦合，等于 1 时可能导致数值问题）

节点连接：电压源接节点 1（正）和地（负）→ 串联电阻（1 → 2）→ 初级电感 L1L_1L1​（2 → 地）→ 次级电感 L2L_2L2​（节点 3 → 地），通过耦合系数 KKK 与 L1L_1L1​ 磁耦合。

3.2 匝数比与电感比的对应关系 ​

已知 L1=100mHL_1 = 100\text{mH}L1​=100mH，L2=25mHL_2 = 25\text{mH}L2​=25mH。

L1L2=10025=4\frac{L_1}{L_2} = \frac{100}{25} = 4 L2​L1​​=25100​=4

由 L∝N2L \propto N^2L∝N2，得：

N1N2=L1L2=4=2\frac{N_1}{N_2} = \sqrt{\frac{L_1}{L_2}} = \sqrt{4} = 2 N2​N1​​=L2​L1​​​=4​=2

因此这个"变压器"是一个降压变压器，匝数比 2:12:12:1，理论次级电压应为初级电压的一半。

U2U1=N2N1=12=0.5\frac{U_2}{U_1} = \frac{N_2}{N_1} = \frac{1}{2} = 0.5 U1​U2​​=N1​N2​​=21​=0.5

若初级电压峰值 U1≈10VU_1 \approx 10\text{V}U1​≈10V，则次级开路电压峰值理论值为 U2≈5VU_2 \approx 5\text{V}U2​≈5V。

3.3 瞬态分析设置 ​

由于 AC 分析对耦合电感电路的支持有限，我们使用 .transient() 瞬态分析来观察变压器的时域波形，并从中提取次级与初级电压的峰值比：

  • 仿真步长：Δt=100μs\Delta t = 100\mu\text{s}Δt=100μs（每个正弦周期 T=20msT = 20\text{ms}T=20ms 内采样 200 点，波形精细）
  • 仿真时长：tend=40mst_{\text{end}} = 40\text{ms}tend​=40ms（覆盖两个完整正弦周期，确保稳态建立）
  • 电压比通过对比后半段（稳态）的峰值来得出

4. 用 Python 实现电路仿真 ​

4.1 构建变压器电路并执行瞬态分析 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import numpy as np

circuit = Circuit('Transformer Demo')
circuit.SinusoidalVoltageSource('ac', 1, circuit.gnd, amplitude=10@u_V,
                                frequency=50@u_Hz)
circuit.R('src', 1, 2, 1@u_Ω)
circuit.L(1, 2, circuit.gnd, 100@u_mH)
circuit.L(2, 3, circuit.gnd, 25@u_mH)
circuit.K('coupling', 'L1', 'L2', 0.99)

simulator = circuit.simulator(temperature=25, nominal_temperature=25,
                              simulator='ngspice-subprocess')
analysis = simulator.transient(step_time=100@u_us, end_time=40@u_ms)

代码解释：

  • circuit.L(1, 2, circuit.gnd, 100@u_mH)：创建初级电感 L1=100mHL_1 = 100\text{mH}L1​=100mH，自动命名为 L1，连接在节点 2 和地之间。
  • circuit.L(2, 3, circuit.gnd, 25@u_mH)：创建次级电感 L2=25mHL_2 = 25\text{mH}L2​=25mH，自动命名为 L2。
  • circuit.K('coupling', 'L1', 'L2', 0.99)：耦合系数元件 K！
    • 第一个参数 0.99 是耦合系数 kkk（0≤k≤10 \leq k \leq 10≤k≤1），k=0.99k=0.99k=0.99 表示耦合非常紧密，几乎无漏磁。
    • 后两个参数是电感元件的名称字符串 'L1' 和 'L2'——注意是用字符串引用而不是 Python 对象属性。
  • .transient(step_time=100@u_us, end_time=40@u_ms)：瞬态分析，步长 100μs100\mu\text{s}100μs，总共仿真 40ms40\text{ms}40ms（两个 50Hz 的正弦周期）。

5. 深入理解 ​

5.1 耦合系数 k 的含义 ​

耦合系数 kkk 的范围为 0≤k≤10 \leq k \leq 10≤k≤1：

  • k=0k = 0k=0：两个线圈完全无耦合（磁通互不关联）——没有变压器效应
  • k=1k = 1k=1：全耦合（理想变压器），初级产生的所有磁通全部穿过次级——无漏磁
  • 0<k<10 < k < 10<k<1：部分耦合——现实中的变压器 kkk 通常在 0.95∼0.990.95 \sim 0.990.95∼0.99 之间

在 SPICE 中，耦合系数通过互感 M=kL1L2M = k\sqrt{L_1 L_2}M=kL1​L2​​ 来实现。如果 k=1k = 1k=1（完全耦合），互感 M=L1L2M = \sqrt{L_1 L_2}M=L1​L2​​，此时仿真可能会遇到数值稳定性问题——这就是为什么我们在仿真中使用了 k=0.99k = 0.99k=0.99。

5.2 实际变压器的非理想因素 ​

与理想变压器不同，实际变压器存在：

  1. 绕组电阻（铜损）：线圈导线的电阻会消耗功率（I2RI^2RI2R 发热）。
  2. 铁芯损耗（铁损）：磁滞损耗和涡流损耗（铁芯中的感应电流——这就是为什么铁芯要用绝缘的硅钢片叠成）。
  3. 漏磁：部分磁通未穿过次级，导致耦合系数 k<1k < 1k<1。
  4. 励磁电流：即使次级开路，初级仍需一小电流 I0I_0I0​ 来产生维持磁通的励磁安匝——空载电流。

在设计高功率变压器时，这些损耗产生的热量必须妥善处理（大型变压器往往浸泡在油中进行散热）。

5.3 电感的 PySpice 妙用 ​

本章引入了两个重要的 PySpice 新特性：

  • circuit.L() 电感元件：第 6 章首次遇到，本章进一步用于构建变压器。
  • circuit.K() 耦合系数元件：将两个（或多个）电感绑定在一起，指定耦合程度。K 是非理想元件，不消耗功率，仅描述磁耦合关系。
  • .ac() 交流分析：在指定频率范围内扫描电路频率响应——非常适合研究变压器的频响特性、滤波器和 LC 谐振等。

5.4 变压器在各领域的应用 ​

  • 电力传输：升压变压器将发电机端电压升至数百 kV 以减少线路损耗；降压变压器将高压降至低压供家庭和工业使用。
  • 电子设备：几乎所有电子设备内部都有一个小型变压器（或开关电源中的高频变压器），将 220V/110V 市电降至几V 到几十V 供电子电路使用。
  • 阻抗匹配：音频变压器将高阻抗的音源匹配到低阻抗的扬声器（Z1Z2=(N1N2)2\frac{Z_1}{Z_2} = \left(\frac{N_1}{N_2}\right)^2Z2​Z1​​=(N2​N1​​)2）。
  • 隔离：隔离变压器在初次级间提供电气隔离，用于安全保护（如医疗设备、维修工作台）。
  • 测量：电压互感器（PT）和电流互感器（CT）将高电压/大电流按比例降至仪表可测量的范围。

6. 本章小结 ​

  • 变压器基于法拉第电磁感应定律工作：初级交流电产生的变化磁场耦合到次级，在次级感应出电压。
  • 理想变压器的电压比公式：U1U2=N1N2\frac{U_1}{U_2} = \frac{N_1}{N_2}U2​U1​​=N2​N1​​，电压与匝数成正比。
  • 功率守恒给出电流比：I1I2=N2N1\frac{I_1}{I_2} = \frac{N_2}{N_1}I2​I1​​=N1​N2​​，电流与匝数成反比。
  • 电感与匝数关系：L∝N2L \propto N^2L∝N2，匝数比可通过电感比开方得到。
  • PySpice 中的耦合电感（K 元件 + 两个 L 元件）可以准确模拟变压器行为。
  • .ac() 交流分析给出了稳态正弦响应，是验证变压器电压比和频率响应的有力工具。
  • 耦合系数 kkk（0≤k≤10 \le k \le 10≤k≤1）描述了初次级间的磁耦合程度。k=1k=1k=1 对应理想全耦合，实际值约在 0.95∼0.990.95 \sim 0.990.95∼0.99。

7. 练习 ​

  1. 匝数比计算：一台理想降压变压器，初级接 220V220\text{V}220V 交流电，匝数 N1=2200N_1 = 2200N1​=2200，要求次级输出 11V11\text{V}11V。求：(1) 次级匝数 N2N_2N2​；(2) 如果次级接一个 11Ω11\Omega11Ω 的电阻负载，求次级电流 I2I_2I2​ 和初级电流 I1I_1I1​。

  2. 电感比验证：将仿真代码中 L2L_2L2​ 改为 100mH100\text{mH}100mH（即初次级电感相等）。重新运行：(1) 匝数比变为多少？(2) 理论电压比应为多少？(3) 仿真结果中的 V2/V1V_2/V_1V2​/V1​ 是多少？是否符合预期？

  3. 耦合系数影响：将仿真中的耦合系数 kkk 从 0.990.990.99 逐步降至 0.90.90.9、0.80.80.8、0.50.50.5，观察次级输出电压 V2V_2V2​ 如何变化。解释为什么耦合越松（kkk 越小），次级电压越低。（提示：互感 M=kL1L2M = k\sqrt{L_1 L_2}M=kL1​L2​​ 随 kkk 减小，次级感应到的磁通变少。）

  4. 升压变压器：修改代码参数，设计一个 1:31:31:3 的升压变压器（初级 N1=50N_1 = 50N1​=50 匝对应 L1=25mHL_1 = 25\text{mH}L1​=25mH，次级 N2=150N_2 = 150N2​=150 匝——请问 L2L_2L2​ 应取多少？）。用仿真验证电压比是否为 1:31:31:3。如果初级电压峰值为 10V10\text{V}10V，次级开路时电压峰值理论上应该是多少？观察仿真结果是否符合理论预测。
