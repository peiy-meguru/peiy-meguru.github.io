第1章 电场与电势 ​

1. 本节你将学到 ​

  • 理解电场的物理概念：E=F/qE = F/qE=F/q，电场强度是单位正电荷在电场中所受的力
  • 掌握电势与电势差的定义：U=W/qU = W/qU=W/q，Vab=Va−VbV_{ab} = V_a - V_bVab​=Va​−Vb​
  • 认识电压的本质——电压是电势差，是驱动电荷在电路中移动的根本原因
  • 学会用 PySpice 的 DC 扫描 从 -10V 到 10V，观察电压极性反转对电流方向的影响

2. 知识回顾/情景引入 ​

在初中篇中，我们学会了搭建最基础的电路：电池、导线、开关、用电器，也学会了用欧姆定律 I=V/RI = V/RI=V/R 来计算电路中的电流。那时我们把电压简单理解为"电池铭牌上标的数字"——10 伏特的干电池、220 伏特的市电。

但如果你再深入追问一句：电压到底是什么？它是从哪儿冒出来的？为什么两个点之间有电压，电荷就会流动？

这些问题在初中阶段我们暂时搁置了，现在高中篇的第一章，让我们回到电学的起点，重新认识电场的本质。

2.1 电场的发现 ​

1785 年，法国物理学家库仑通过扭秤实验发现了库仑定律：两个静止点电荷之间的作用力，与它们电荷量的乘积成正比，与它们之间距离的平方成反比：

F=kq1q2r2F = k\frac{q_1 q_2}{r^2} F=kr2q1​q2​​

其中 k≈8.99×109 N⋅m2/C2k \approx 8.99 \times 10^9\ \text{N·m}^2/\text{C}^2k≈8.99×109 N⋅m2/C2，是静电力常量。

库仑定律告诉我们：两个电荷之间不需要直接接触就能产生力。这个力是怎么"传递"的？法拉第给出了一个伟大的答案：电场。

2.2 电场强度的定义 ​

电场看不见摸不着，但它实实在在地存在于每一个电荷周围。我们用电场强度 E⃗\vec{E}E 来描述电场的强弱和方向：

E=FqE = \frac{F}{q} E=qF​

其中 FFF 是电荷在电场中受到的力（单位：牛顿 N），qqq 是该电荷的电量（单位：库仑 C），EEE 的单位是 N/C（牛顿/库仑），也等价于 V/m（伏特/米）。

这个公式的含义是：电场强度等于单位正电荷在电场中某点受到的力。如果某点的电场强度是 10 N/C10\ \text{N/C}10 N/C，那么一个 +1C+1\text{C}+1C 的电荷放在那儿，就会受到 10N10\text{N}10N 的力。

💡 直觉理解：如果把电场看作"电荷感受到的引力场"，电场强度 EEE 就类似于重力场中的重力加速度 ggg——物体受到的重力 G=mgG = mgG=mg，电荷受到的电场力 F=qEF = qEF=qE。两者在数学结构上完全一致。

2.3 电势与电势差 ​

把一个正电荷放进电场中，它会受到电场力的作用而被推动。电场力推动电荷移动，就会做功。电势的定义与这个功有关：

U=WqU = \frac{W}{q} U=qW​

其中 WWW 是电场力将电荷从无穷远处移动到该点所做的功，qqq 是电荷量。电势的单位是伏特（V），1V=1J/C1\text{V} = 1\text{J/C}1V=1J/C。

电势差（也叫电压）就是两个点之间的电势之差：

Vab=Va−VbV_{ab} = V_a - V_b Vab​=Va​−Vb​

当 Vab>0V_{ab} > 0Vab​>0（a 点电势比 b 点高），正电荷会从 a 流向 b——这就像水从高处流向低处，电荷从高电势流向低电势。因此，电压就是驱动电流的"电势高度差"。

💡 将电势差类比为"水位差"是非常形象的：电池就像一个水泵，不断把电荷从低电势"抽"到高电势；导线中的电阻就像水管中的狭缝，让电荷在跌落过程中释放能量。整个电路就是电荷从高电势出发、流经用电器、回到低电势的循环旅程。

3. 动手设计电路 ​

3.1 本节电路 ​

我们要研究的是一个最简单的电路：一个电压可调的电源，正端连接节点 1，负端接地（节点 0），用一个 100Ω100\Omega100Ω 的电阻连接在节点 1 和地之间。

电场比喻图：如果把电池看作一个"电场泵"，正极是高电势的"山顶"，负极是低电势的"山谷"。正电荷从正极出发，在电场力的作用下顺着电阻"滑落"到负极——就像石块从山顶滚到山谷。电压（电势差）越高，"山"就越高，电荷受到的"推力"就越大，电流自然也就越大。

3.2 公式推导 ​

根据欧姆定律 I=VRI = \frac{V}{R}I=RV​，其中 VVV 是电阻两端的电势差。当电阻 R=100ΩR = 100\OmegaR=100Ω 固定时：

I=V100I = \frac{V}{100} I=100V​

当 V=10VV = 10\text{V}V=10V 时，I=0.10AI = 0.10\text{A}I=0.10A（电流从节点 1 流向地——高电势流向低电势）。 当 V=−10VV = -10\text{V}V=−10V 时，I=−0.10AI = -0.10\text{A}I=−0.10A（电流反向——因为此时节点 1 的电势低于地，负电荷从节点 1 流向地，等效于正电荷从地流向节点 1）。

4. 用 Python 实现电路仿真 ​

4.1 构建电路并执行 DC 扫描 ​

python
import PySpice.Logging.Logging as Logging
logger = Logging.setup_logging()

from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

circuit = Circuit('Electric Field Demo')
circuit.V('source', 1, circuit.gnd, 1@u_V)
circuit.R('load', 1, circuit.gnd, 100@u_Ω)

simulator = circuit.simulator(temperature=25, nominal_temperature=25,
                              simulator='ngspice-subprocess')

analysis = simulator.dc(Vsource=slice(-10, 10, 0.1))

voltage = np.array(analysis['1'])
current = np.array(-analysis['vsource'])

代码解释：

  • slice(-10, 10, 0.1)：DC 扫描从 -10V 到 10V，步长 0.1V，共 201 个数据点。这一步让 Ngspice 自动遍历所有电压值，计算每个电压下的电流。
  • -analysis['vsource']：读取流过电压源的电流。加负号是为了让正电流对应正电压（从电源正极流出的电流方向）。
  • 扫描范围包含负电压，直观展示电压极性反转时电流方向的变化。

4.3 I-V 特性曲线 ​

仿真生成的 I-V 曲线呈现出一条完美的过原点直线，斜率为 1/R=0.011/R = 0.011/R=0.01。这条直线贯穿第二、第三象限（对应负电压和负电流）和第一象限（对应正电压和正电流），展现了电压与电流在全范围内的严格线性关系。

5. 深入理解 ​

5.1 电场、电势、电势差的关系 ​

这三个概念层层递进，构成了静电学的完整理论框架：

  • 电场强度 EEE 描述空间中每一点电场力的强弱，是"点的性质"。
  • 电势 VVV 描述空间某点电场做功的本领，也是"点的性质"。它是标量（只有大小，没有方向），方便计算。
  • 电势差 ΔV=Va−Vb\Delta V = V_a - V_bΔV=Va​−Vb​ 描述两点之间的电势"落差"，是电路分析中最重要的量——它直接决定电流的大小和方向。

电场强度与电势差之间存在积分关系：在匀强电场中，两点之间的电势差等于电场强度乘以沿电场方向的距离：

Vab=E⋅dV_{ab} = E \cdot d Vab​=E⋅d

这就是为什么电场强度的单位既可以写成 N/C，也可以写成 V/m——两者是等价的。

5.2 为什么正电荷从高电势流向低电势 ​

这可以用能量守恒来解释。正电荷在高电势处具有较高的电势能 Ep=qVE_p = qVEp​=qV。在电场力的推动下，正电荷向低电势移动，电势能转化为动能（或通过电阻转化为热能）。这就像物体在重力场中从高处落向低处——重力势能转化为动能——两者的物理逻辑完全相同。

5.3 电压极性反转的物理意义 ​

当 DC 扫描跨越 V=0V=0V=0 这个点，电流方向发生了反转。这意味着：

  • V>0V > 0V>0：节点 1 的电势高于地，电场方向从节点 1 指向地，正电荷沿此方向运动
  • V=0V = 0V=0：节点 1 与地等电势，无电场驱动，电流为零
  • V<0V < 0V<0：节点 1 的电势低于地，电场方向从地指向节点 1，正电荷反向运动

在交流电路中（第 8 章会学到），电压会周期性地正负交替，电流也就跟着来回振荡——这正是"交变电流"名称的由来。

6. 本章小结 ​

  • 电场强度 E=F/qE = F/qE=F/q：描述电场对电荷作用力的强弱，单位 N/C 或 V/m
  • 电势 U=W/qU = W/qU=W/q：描述电场做功的本领，电势高的地方电荷具有更大的电势能
  • 电势差（电压） Vab=Va−VbV_{ab} = V_a - V_bVab​=Va​−Vb​：两点之间的电势落差，是驱动电流的根本原因
  • 电压极性反转导致电流方向反转——电流总是从高电势流向低电势
  • PySpice 的 DC 扫描可以在一个命令中遍历电压范围，快速验证 I-V 关系的全貌

7. 练习 ​

  1. 电场强度计算：在匀强电场中，若 A、B 两点相距 0.2m，电势差为 10V，求电场强度 EEE。再用仿真验证：当电源电压为 10V 时，流过 100Ω100\Omega100Ω 电阻的电流是否与欧姆定律一致。

  2. 电压极性思考：修改代码中的扫描范围从 slice(-5, 5, 0.1)，缩小范围后观察电流变化。在 V=−3VV = -3\text{V}V=−3V 和 V=3VV = 3\text{V}V=3V 时的电流分别是多少？它们的绝对值相同吗？为什么？

  3. 能量转换题：一个 +2C+2\text{C}+2C 的电荷从电势为 10V 的点移动到电势为 4V 的点，电势能减少了多少焦耳？这些能量在电阻上转化为了什么？

  4. 综合思考：把电池比作"水泵"、导线比作"水管"、电阻比作"水轮机"、电压比作"水位差"、电流比作"水流"。在这个类比中，电场强度 EEE 相当于什么？电势 VVV 相当于什么？尝试用这个类比解释为什么导线越长、电阻越大。
