环境配置安装 ​

欢迎来到 PySpice 教程的环境配置章节！在开始探索电路世界之前，我们需要在你的电脑上安装一些必要的工具。别担心——本章会像搭积木一样，手把手带你完成每一步。即使你之前完全没有接触过编程，也完全没问题。

什么是 Python，为什么要用它？ ​

在正式开始之前，让我们先回答一个最基本的问题：什么是编程语言，以及我们为什么要用 Python 来学习电路？

编程语言是什么？ ​

编程语言是人类用来向计算机下达指令的一种语言。就像我们用中文、英文来和人交流一样，我们可以用 Python、C++ 等编程语言来告诉计算机该做什么。计算机虽然很强大，但它自己并不会主动思考——它需要你给出清晰、精确的指令。

Python 是目前世界上最流行、最友好的编程语言之一。它的语法非常接近自然语言，读起来就像在读英文句子。举个例子，如果你想让计算机在屏幕上显示"你好，电路世界！"，你只需要写一行代码：print("你好，电路世界！")。是不是很直观？

为什么要用 Python 来仿真电路？ ​

你可能会好奇：学习电路为什么要用电脑？直接用电池、导线、灯泡做实验不是更有趣吗？

是的，动手搭建真实的电路确实很有趣。但是，用计算机仿真电路有以下几个无可替代的优势：

首先，安全是第一位的。在物理实验中，短路、过流、元器件损坏等问题都有可能发生。尤其是当你尝试设计复杂的电路时，稍有不慎就可能烧毁元件，甚至引起触电。而在计算机仿真中，你怎么"玩"都不会有危险——出错了大不了重新来一遍。

其次，不需要购买昂贵的器材。一个物理实验室里面的示波器、信号发生器、电源等设备动辄几千甚至上万元。而有了 PySpice，你的电脑就是一个完整的电路实验室——里面啥都有，一分钱都不用多花。

第三，效率高得不可思议。你可以在几秒钟之内搭建好一个电路、运行仿真、看到结果，然后修改参数再看新结果。这在现实世界中可能需要几个小时甚至一整天。

第四，可以看到物理世界看不到的东西。在仿真中，你可以精确测量每个节点的电压、每条支路的电流，甚至可以看到电荷的流动方向和能量分布。这些东西在真实的电路中是很难直接观察到的。

最后，学习编程和电路一举两得。通过 PySpice，你不仅可以深入理解电路原理，还能顺带学会 Python 编程。Python 是人工智能、数据分析、网页开发等许多前沿领域的入门语言，学好它会为你打开许多扇门。

PySpice 是一个连接 Python 和开源电路仿真引擎 Ngspice 的"翻译官"——你用 Python 写出电路的描述，PySpice 帮你翻译给 Ngspice 去仿真，然后把结果再翻译回 Python 让你查看和分析。整个过程流畅自然，你甚至感觉不到中间有个"中介"的存在。

好了，既然了解了为什么要用 Python 仿真电路，接下来就让我们正式开始安装吧！

安装 Python ​

Python 是我们这个课程的核心工具。不管你是 Windows、macOS 还是 Linux 用户，安装 Python 都非常简单。

Windows 用户 ​

Windows 系统通常不自带 Python，需要手动安装。操作步骤如下：

  1. 打开浏览器，访问 python.org。
  2. 点击网站正中央那个大大的黄色按钮 "Download Python"，会自动下载适合你系统的最新版本安装包。（本教程推荐 Python 3.8 及以上版本。）
  3. 下载完成后，双击 .exe 文件运行安装程序。
  4. 重要！ 在安装界面的底部，有一个复选框写着 "Add Python to PATH"（将 Python 添加到 PATH），请务必勾选它。这一步就像把你的 Python 工具箱登记到了系统的"快速检索目录"中，以后在命令行里直接打 python 就能找到它。
  5. 点击 "Install Now"（立即安装），等待安装完成。
  6. 安装完成后，打开"命令提示符"（按键盘 Win + R，输入 cmd，回车），输入以下命令验证安装：
bash
python --version

如果屏幕上显示了类似于 Python 3.12.x 这样的版本号，恭喜你，Python 已经安装成功了！如果提示"找不到命令"，大概率是第 4 步没有勾选 "Add Python to PATH"。回到安装程序重新运行一次，或者参考本章最后一节"如果遇到问题"中的解决方案。

macOS 用户 ​

macOS 系统中通常会预装一个很老的 Python 2.x 版本，但现在大家用的都是 Python 3，所以我们需要单独安装 Python 3。

推荐使用 Homebrew 来安装（Homebrew 是 macOS 上最流行的软件包管理器）。如果你还没有装过 Homebrew，先打开"终端"应用，运行以下命令安装它：

bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Homebrew 安装完成后，在终端中运行：

bash
brew install python3

安装完成后，验证一下：

bash
python3 --version

如果你不想用 Homebrew，也可以直接在 python.org 下载 macOS 版本的安装包，双击 .pkg 文件按向导安装即可。安装完成后同样用 python3 --version 验证。

Linux 用户 ​

大多数 Linux 发行版都已经预装了 Python 3。你可以打开终端，输入以下命令确认：

bash
python3 --version

如果提示未找到命令，说明你的系统还没有安装 Python 3。不同发行版的安装命令稍有不同：

  • Ubuntu/Debian:

    bash
    sudo apt update
sudo apt install python3

  • Fedora:

    bash
    sudo dnf install python3

  • Arch Linux:

    bash
    sudo pacman -S python

安装完成后，用 python3 --version 确认版本号不低于 3.8。

推荐方式：使用 Podman 容器 ​

如果你是第一次接触编程环境配置，上面这一大堆步骤可能让你感到有些头疼。Windows 上 PATH 怎么配？macOS 上 pip 有问题怎么办？Linux 上权限不对怎么处理？

别慌！ 我们为你准备了一键式的解决方案——Podman 容器。

什么是 Podman？ ​

简单来说，Podman 像一个"应用胶囊"。你把一个完整的工作环境（包括 Python、Ngspice、PySpice 以及所有配置）打包进这个胶囊里，然后不管在哪台电脑上，只要运行这个胶囊，里面的一切都会原封不动地跑起来。

你可以这样理解：如果你要搬家，Podman 不是帮你把每件家具一件一件搬过去，而是直接把整个房间用一个巨大的泡泡包起来，整个端走。不管目标地点是沙漠还是雪山，泡泡里面的温度、湿度、物品都完全不变。

对我们来说，这意味着：只要你的电脑能运行 Podman，你就不需要单独安装 Python、Ngspice、PySpice 中的任何一个。我们会给你一个预配置好的"胶囊"（叫做容器镜像），你拿来直接用就行，完全省心。

安装 Podman ​

Podman 是免费的、开源的，在各个平台上都可以安装：

  • Windows：确保你已经安装了 winget（Windows 包管理器，Windows 10 1809+ 自带），然后在"命令提示符"或 PowerShell 中运行：

    bash
    winget install Podman.Podman

    你也可以去 podman.io 下载 Windows 安装程序，双击运行。

    安装完成后，建议重启电脑，然后打开终端运行 podman info 确认 Podman 正常工作。

  • macOS：在终端中运行：

    bash
    brew install podman

    安装完成后，初始化 Podman 虚拟机：

    bash
    podman machine init
podman machine start

  • Linux：大多数发行版的官方仓库都包含 Podman：

    bash
    sudo apt install podman    # Ubuntu/Debian
sudo dnf install podman    # Fedora
sudo pacman -S podman      # Arch Linux

    安装了 Flatpak 的用户也可以用 flatpak install podman。

拉取并运行教程容器 ​

Podman 安装完毕后，我们就来"领取"预配置好的 PySpice 教程容器。这个容器镜像里包含了 Ubuntu 24.04、Python 3.12、Ngspice 42 和 PySpice 1.5，开箱即用。

首先，在你的终端中运行以下命令，从 GitHub 容器仓库拉取镜像（大约 500MB，初次下载需要几分钟，之后就不用再下载了）：

bash
podman pull ghcr.io/peiy-meguru/pyspice-tutorial

拉取完成后，你就可以用下面的命令来运行你的 Python 电路脚本了。假设你有一个脚本叫 my_circuit.py：

bash
podman run --rm --userns=keep-id -v $(pwd):/workspace:Z --entrypoint "python3" pyspice-tutorial my_circuit.py

这个命令看起来有点长，我们来逐一解释每个参数的含义，这样你就能懂得它到底做了什么：

  • podman run：告诉 Podman 运行一个容器。
  • --rm：容器运行结束后自动删除。每次运行都会从一个干净的环境开始，不会积累垃圾。
  • --userns=keep-id：保持你的用户 ID 不变，这样容器生成的文件不会出现权限问题。
  • -v $(pwd):/workspace:Z：把你当前所在的文件夹"映射"到容器内的 /workspace 目录。这样容器就能读写你电脑上的文件了。（$(pwd) 表示当前目录，在 Windows PowerShell 上请用 ${PWD} 代替。）
  • --entrypoint "python3"：指定容器启动后要运行的程序，这里设置为 python3 解释器。
  • pyspice-tutorial：使用的镜像名称，也就是我们刚刚拉取的那个。
  • my_circuit.py：替换成你的 Python 脚本文件名，容器会运行它。

建议你把这段长命令记在一个文本文件里，或者以后创建一个简短的 shell 脚本 / bat 文件，省得每次都要重新打一遍。

从源代码构建容器 ​

容器镜像的源代码和构建配置托管在单独的 Git 仓库中。如果你想从源代码自行构建，可以克隆镜像仓库：

bash
git clone https://github.com/peiy-meguru/pyspice-tutorial-image.git
cd pyspice-tutorial-image
podman build -f Containerfile -t pyspice-tutorial .

镜像仓库中的 Containerfile 定义了完整的 PySpice 环境（Ubuntu 24.04、Python 3、Ngspice 42、PySpice 1.5）。构建过程大约需要几分钟（第一次会慢一些，因为要下载基础镜像和软件包）。

镜像仓库通过 GitHub Actions 自动构建并发布到 ghcr.io/peiy-meguru/pyspice-tutorial。

构建完成后，你就可以像使用拉取下来的镜像一样使用它了。

选哪种方式？ 如果网络条件允许，直接拉取预构建的镜像最方便。如果你想学习容器技术的原理，或者需要自定义镜像（比如添加额外的 Python 库），就选择从 Containerfile 构建。

备选方式：本地安装 ​

如果你的网络不方便下载大文件，或者你想更深入地了解每一步环境配置的细节，也可以选择本地安装。下面详细说明每一步。

创建虚拟环境 ​

Python 的虚拟环境是一种"隔间"机制——你可以在不影响系统全局 Python 配置的前提下，给每个项目都创建一个独立的 Python 环境。这样即使两个项目需要不同版本的同一个库，它们也不会相互干扰。

首先，打开终端（Windows 用户请用命令提示符或 PowerShell），进入你想存放项目代码的文件夹。比如：

bash
mkdir ~/pyspice-tutorials
cd ~/pyspice-tutorials

然后，创建虚拟环境：

bash
python3 -m venv pyspice-env

这个命令会在当前目录下创建一个名为 pyspice-env 的文件夹，里面装着一套独立的 Python 解释器和包管理器。

激活虚拟环境 ​

创建好虚拟环境后，你需要"激活"它。激活之后，你运行的所有 Python 和 pip 命令都会作用于这个虚拟环境，而不是系统全局环境。

  • Linux / macOS：

    bash
    source pyspice-env/bin/activate

  • Windows（命令提示符）：

    bash
    pyspice-env\Scripts\activate

  • Windows（PowerShell）：

    bash
    pyspice-env\Scripts\Activate.ps1

激活成功后，你的终端提示符前面会出现 (pyspice-env) 的字样，表示虚拟环境已经生效了。比如：

text
(pyspice-env) user@computer:~/pyspice-tutorials$

如果以后你想退出虚拟环境，只需要输入 deactivate 并按回车即可。

安装 PySpice 及相关库 ​

虚拟环境激活后，我们来安装 PySpice 以及它依赖的核心 Python 库：

bash
pip install PySpice numpy matplotlib schemdraw

这条命令使用 Python 的包管理器 pip 来安装以下四个库：

  • PySpice：本教程的核心，连接 Python 与 Ngspice 电路仿真引擎。
  • NumPy：Python 科学计算的基础库，用于处理仿真产生的数值数据（数组、矩阵运算等）。
  • Matplotlib：Python 最流行的绘图库，用于可视化仿真结果（波形图、曲线图等）。
  • Schemdraw：一个用于绘制电路原理图的 Python 库，可以让你用代码直接画出漂亮的电路图。

如果你在中国的网络环境下，pip 直接下载可能会比较慢。你可以使用清华大学的镜像源来加速：

bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple PySpice numpy matplotlib schemdraw

安装完成后，你可以用以下命令检查已安装的包及其版本：

bash
pip list | grep -E "PySpice|numpy|matplotlib|schemdraw"

安装 Ngspice ​

PySpice 本身只是"翻译官"，它需要 Ngspice 这个"计算引擎"才能真正运行电路仿真。因此，你还需要安装 Ngspice。

  • Ubuntu / Debian：

    bash
    sudo apt install ngspice

  • Fedora：

    bash
    sudo dnf install ngspice

  • Arch Linux：

    bash
    sudo pacman -S ngspice

  • Windows：Ngspice 为 Windows 提供了安装程序。请访问 Ngspice 下载页面 下载最新的 .exe 安装包。安装时，请务必勾选"Add Ngspice to PATH"（如果安装程序提供了这个选项），或者记住安装路径，以便后续配置。

  • macOS：

    bash
    brew install ngspice

安装完成后，在终端中输入以下命令验证 Ngspice 是否可用：

bash
ngspice --version

应该能看到 Ngspice 的版本信息。如果提示"找不到命令"，请检查 Ngspice 是否被正确添加到系统的 PATH 环境变量中。

注意：如果你使用的是 Podman 容器方式，容器中已经预装了 Ngspice，你不需要再单独安装。

选择代码编辑器 ​

写代码需要一个趁手的编辑器。就像写作文需要纸和笔一样，好的编辑器能让编程体验愉快很多。以下是几种推荐的编辑器：

VS Code（强烈推荐） ​

Visual Studio Code（简称 VS Code）是目前全球最流行的免费代码编辑器，由微软开发。它跨平台（Windows、macOS、Linux 通用），速度快，功能强大，拥有海量插件扩展。

从 code.visualstudio.com 下载并安装 VS Code。

安装完成后，建议安装以下插件来提升 Python 开发体验：

  1. 打开 VS Code，点击左侧活动栏中的"扩展"图标（或按 Ctrl+Shift+X）。
  2. 搜索并安装 Python 插件（发布者是 Microsoft）。这个插件提供代码补全、错误检查、调试等功能。
  3. （可选）搜索并安装 Chinese (Simplified) Language Pack 以将界面切换为中文。
  4. （可选）搜索并安装 Jupyter 插件，如果你想在 VS Code 中使用逐段交互式的 Jupyter Notebook 来学习电路。

安装完 Python 插件后，用 VS Code 打开你的项目文件夹（File → Open Folder），VS Code 会自动检测你的虚拟环境并提示你选择它作为 Python 解释器。选择 pyspice-env 后，你就可以享受智能代码补全了。

PyCharm Community Edition ​

PyCharm 是 JetBrains 公司出品的专业 Python IDE（集成开发环境），功能比 VS Code 更深更全，但相对更重。"Community"（社区版）是免费的，足够满足本教程的所有需求。

从 jetbrains.com/pycharm/download 下载安装。安装后的配置方式和 VS Code 类似——打开项目文件夹，PyCharm 会自动检测虚拟环境。

IDLE（Python 自带） ​

如果你不想安装任何额外工具，Python 本身自带了一个简单的编辑器叫做 IDLE。它功能非常基础，但对于初学者来说也够用。在终端中输入 idle（或 idle3）即可启动。

IDLE 适合用来快速试一小段代码，但对于编写较长的脚本，还是建议使用 VS Code 或 PyCharm。

验证安装 ​

一切就绪后，让我们来写一个非常简单的测试脚本，验证你的 PySpice 环境是否配置正确。

测试脚本 ​

用你选择的编辑器创建一个新文件，命名为 test_circuit.py，输入以下内容：

python
"""
简单的 PySpice 测试脚本
创建一个电阻分压电路，打印网表（netlist）
"""

import PySpice.Logging.Logging as Logging
# 设置日志级别，INFO 会显示仿真过程的一些信息
logger = Logging.setup_logging(logging_level='INFO')


from PySpice.Spice.Netlist import Circuit
from PySpice.Unit import *

# 创建一个电路对象，取名为 "Voltage Divider"（分压器）
circuit = Circuit('Voltage Divider (分压器)')

# 添加元器件：一个 5V 的直流电压源 V1
# 正极接节点 1，负极接节点 0（GND / 参考地）
circuit.V('input', 1, 0, 5@u_V)

# 添加元器件：两个电阻 R1 和 R2，串联在电源两端
circuit.R(1, 1, 2, 2@u_kΩ)     # 2kΩ 电阻，连接节点 1 和 2
circuit.R(2, 2, 0, 1@u_kΩ)     # 1kΩ 电阻，连接节点 2 和 0

# 打印电路的网表
# 网表是 Ngspice 能理解的电路描述文本
print("===== 电路网表 (Netlist) =====")
print(str(circuit))

print("\n===== 验证成功！ =====")
print("如果你能看到上面的网表内容，说明 PySpice 环境配置正确。")
print(f"电路名称: {circuit.title}")

运行测试 ​

  • 使用 Podman 容器：

    bash
    podman run --rm --userns=keep-id -v $(pwd):/workspace:Z --entrypoint "python3" pyspice-tutorial test_circuit.py

  • 使用本地环境（确保虚拟环境已激活）：

    bash
    python test_circuit.py

预期输出 ​

如果一切配置正确，你应该能看到类似下面的输出（网表的具体格式可能略有差异）：

text

.title Voltage Divider (分压器)
Vinput 1 0 5V
R1 1 2 2kOhm
R2 2 0 1kOhm
.end

===== 验证成功！ =====
如果你能看到上面的网表内容，说明 PySpice 环境配置正确。
电路名称: Voltage Divider (分压器)

如果遇到问题 ​

在配置环境的过程中，你可能会遇到一些小问题。这非常正常——即使是经验丰富的程序员也经常被环境配置折磨。下面列出了一些常见问题及其解决方法。

Python 不在 PATH 中 ​

现象：在终端输入 python 或 python3 时提示"找不到命令"。

解决方法：

  • Windows：重新运行 Python 安装程序，这次务必勾选 "Add Python to PATH"。或者参考 这篇官方文档 手动将 Python 添加到系统环境变量。
  • macOS：确认使用 python3 而不是 python。如果 Homebrew 安装后仍有问题，运行 brew link python3。
  • Linux：确保用 sudo 安装了 python3 包。有些发行版需要额外安装 python-is-python3 来让 python 命令指向 python3。

pip 找不到 ​

现象：输入 pip 时提示"找不到命令"。

解决方法：

  • 如果你创建了虚拟环境，请先确认虚拟环境已经激活（终端提示符前应有 (pyspice-env)）。
  • 如果虚拟环境已激活仍不行，尝试用 python -m pip 替代 pip，例如：python -m pip install PySpice。
  • 在某些 Linux 发行版中，pip 需要单独安装：sudo apt install python3-pip。

Ngspice 找不到 ​

现象：运行测试脚本时出现与 Ngspice 相关的错误（如 "OSError: ngspice not found"）。

解决方法：

  • 确认 Ngspice 已经正确安装：在终端中运行 ngspice --version。
  • 在 Windows 上，需要将 Ngspice 的安装目录添加到 PATH 环境变量中。Ngspice 通常安装在 C:\Program Files\Ngspice\bin\ 或 C:\Spice64\bin\。
  • 如果你使用的是 Podman 容器方式，容器里已经预装了 Ngspice，不需要在宿主机上单独安装。请确保你是用 Podman 命令来运行脚本的。

虚拟环境激活不成功 ​

现象：在 Windows PowerShell 中无法激活虚拟环境，提示"无法加载文件"。

解决方法：PowerShell 默认的安全策略可能阻止脚本运行。以管理员身份打开 PowerShell，运行以下命令放宽策略：

powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

然后重新尝试激活虚拟环境。

如何获取帮助 ​

如果你遇到上面没有列出的问题，可以通过以下途径寻找帮助：

  • 本教程的 GitHub 仓库：访问项目仓库的 Issues 页面，搜索相关问题，或者新建一个 Issue 提问。
  • 搜索引擎：把错误信息复制粘贴到搜索引擎里，大概率有人已经遇到并解决过相同的问题。
  • AI 助手：如果你有使用 ChatGPT 或类似工具的权限，向它描述你遇到的问题，它会给出有用的解决建议。
  • 同学和老师：如果你在学校，身边的同学和老师可能已经配置好了环境，直接向他们请教是最快的方式。

不要被环境配置中遇到的小挫折打倒。搞定这一步之后，后面的电路仿真世界将为你敞开大门。接下来，让我们一起进入下一章，正式开始写代码探索电路吧！
