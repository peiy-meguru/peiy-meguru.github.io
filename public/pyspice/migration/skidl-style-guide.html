SkiDL 编码风格指南（PySpice 迁移用） ​

导入 ​

python
from skidl.pyspice import *
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

from skidl.pyspice import * 会同时导入 SkiDL 的线路描述功能和 InSpice 的仿真功能。

零件创建 ​

python
# 电压源（必须用 ref 指定分支名）
vs = V(ref='VS', dc_value=5@u_V)

# 脉冲电压源
vs = PULSEV(initial_value=0, pulsed_value=5@u_V,
            pulse_width=1@u_ms, period=2@u_ms)

# 正弦电压源
vs = SINEV(amplitude=1@u_V, frequency=100@u_Hz)

# 电流源
isrc = I(dc_value=1@u_A)

# 电阻
r1 = R(value=100@u_Ohm)

# 电容
c1 = C(value=1@u_uF)

# 电感
l1 = L(value=10@u_mH)

# 二极管（需要 .model）
d1 = D(model='MyDiode')

# BJT / MOSFET（需要 .model）
q1 = BJT(model='2N2222')
m1 = MOSFET(model='IRF540')

# 受控源
vc = VCVS(gain=2.5)        # 电压控电压源
cc = CCCS(gain=100)        # 电流控电流源

单位（@ 运算符） ​

python
1@u_V       # 1 伏
5@u_kOhm    # 5 千欧
10@u_uF     # 10 微法
1@u_mH      # 1 毫亨
0.01@u_ms   # 0.01 毫秒
100@u_Hz    # 100 赫兹
1@u_A       # 1 安培

接线 ​

串联（& daisy-chain） ​

python
# 分压器：VS → R1 → R2 → GND
vs['p'] & r1 & r2 & gnd
vs['n'] += gnd

& 会自动创建中间节点。链的从左到右即电流路径。

并联（多 & 链） ​

python
# 电阻并联到同一电源
vs['p'] & r1 & gnd
vs['p'] & r2 & gnd
vs['n'] += gnd

接地 ​

python
gnd += vs['n'], r[2], c[2]        # 多个引脚接同一地
vs['n'] += gnd                    # 单引脚

使用 gnd（SKiDL pyspice 预定义的地线，其 SPICE net 名为 "0"），不使用 Net('GND')。

多引脚受控源 ​

受控源的多端口用 += 语法：

python
vc['ip', 'in'] += vs['p'], gnd    # 输入端口
vc['op', 'on'] += Net(), gnd      # 输出端口

TEMPLATE 复用 ​

python
r = R(dest=TEMPLATE)
inp & r(value=1@u_kOhm, tag='rupper') & outp & r(value=1@u_kOhm, tag='rlower') & gnd

tag= 用于在结果中区分复用零件。

仿真 ​

生成网表 ​

python
reset()              # 每次脚本开头，清空之前的状态
circ = generate_netlist()  # 生成 InSpice Circuit 对象

创建仿真器 ​

python
sim = Simulator.factory(simulator='ngspice-subprocess')
analysis = sim.simulation(circ, temperature=25, nominal_temperature=25)

工作点分析 ​

python
analysis.operating_point(run=False)
result = sim.run(analysis)
v_node = float(result[node(vs['p'])])     # 节点电压
i_branch = float(result['VS'])            # 分支电流（电压源）

DC 扫描 ​

python
dc = sim.dc(VS=slice(0, 10, 0.1))
voltage = dc[node(vs['p'])].as_ndarray()
current = dc['VS'].as_ndarray()

瞬态分析 ​

python
wf = sim.transient(step_time=0.01@u_ms, end_time=10@u_ms)
time = wf.time.as_ndarray()
vout = wf[node(c['+'])].as_ndarray()

AC 分析 ​

python
ac = sim.ac(start_frequency=10@u_Hz, stop_frequency=100@u_kHz,
            number_of_points=100, variation='dec')
freq = ac.frequency.as_ndarray()
vout = ac[node(c['+'])].as_ndarray()

数据访问模式 ​

需求语法
节点电压result[node(pin)] 或 result[node(net)]
电压源电流result['VS']（负值 = 从正极流出）
瞬态时间wf.time.as_ndarray()
AC 频率ac.frequency.as_ndarray()
转 numpy.as_ndarray()
取标量float(result[node(pin)])

零件注释 ​

所有注释保持中文，与原始 PySpice 脚本的注释内容一致。

python
# 第3章：欧姆定律
# 通过扫描电压来绘制电阻的 I-V 特性曲线

反模式（禁止） ​

  • ❌ from skidl import * — 无法仿真
  • ❌ Net('GND') 自建地线 — 用 gnd
  • ❌ circuit.V('name', n1, n2, value) — 用 V(ref='name', dc_value=...) + 接线
  • ❌ circuit.simulator(...) — 用 Simulator.factory().simulation(circ)
  • ❌ analysis['1'] 或 analysis.branches['Vinput'] — 用 node() / result['VS']
