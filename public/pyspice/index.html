PySpice使用 Python 进行电路仿真

以 Python 驱动 Ngspice / Xyce 模拟器

快速开始
初升大教程
查看示例

支持 Ngspice 和 Xyce

兼容两种主流开源电路模拟器，支持 Linux、Windows 和 macOS 平台，基于 GPLv3 开源协议。

面向对象 API

通过 Python 类定义电路网表，仿真结果转为 NumPy 数组，使用 Matplotlib 绘图分析。

单位系统与 SPICE 解析

完整支持国际单位制（SI），可解析 SPICE 网表，并可与 KiCad 原理图编辑器协作。
