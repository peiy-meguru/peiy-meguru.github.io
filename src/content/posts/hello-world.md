## 关于这个博客

Sakura 主题最初由 [Mashiro](https://github.com/mashirozx) 为 WordPress 设计开发，有Hexo分支。而本项目使用Astro重构，最初目标用于Agent编码测试。

- **极速加载** — 纯静态页面，零 JS 运行时
- **Markdown 写作** — 专注内容，无需分心

## 本地预览

```bash
git clone https://github.com/peiy-meguru/sakura-astro.git
cd sakura-astro
npm install
npm run dev
```

访问 `http://localhost:4321` 查看效果。
